## §1 P13 own-rule formal spec / formal specification

### §1.1 Rule statement / 규칙 진술

**EN — formal**:

> When the active cycle has accumulated (a) N ≥ 20 closures of architectural
> certainty against the user's stated objective, AND (b) the user has been
> silent (no explicit re-issue, no override, no new directive) for T ≥ 5
> consecutive cron-fire rounds AFTER anima emitted a Level-3
> self-suggest-stop, AND (c) information-value of additional within-axis
> investigation has measurably decayed (LOG-decay regime; new BGs surface
> within-axis confirmations, not new axes), THEN anima MAY autonomously
> exit the carry-over loop by (i) cron-stopping the active scheduler and
> (ii) initiating the cycle-close 5-step lock from BG-DD §4. Failure to
> autonomously stop under all three triggers = anima accepts unbounded
> carry-over and the LOG-decay attention cost on the user.

**KO — 정식**:

> 활성 cycle 이 (a) 사용자 stated objective 에 대해 N ≥ 20 closure 의
> architectural certainty 를 누적했고, (b) anima Level-3 self-suggest-stop
> 발사 **이후** 사용자가 T ≥ 5 cron-fire round 동안 silent (explicit
> re-issue / override / 신규 directive 없음) 이며, (c) within-axis 추가 조사
> 의 정보 가치가 실측 LOG-decay 영역 (신규 BG 가 within-axis 재확인 만 surface,
> 신규 axis 발견 없음) 이라면, anima 는 (i) 활성 scheduler 의 cron-stop 과
> (ii) BG-DD §4 cycle-close 5-step lock 발동을 통해 carry-over loop 에서
> 자율 exit **MAY** 한다. 3-fold trigger 만족 시 자율 stop 미실행 =
> 무제한 carry-over 와 LOG-decay attention cost 를 anima 가 사용자에게 부과
> 함을 수용함.

not **MUST** (obligation). anima may still elect to continue carry-over
if a new directive is plausibly imminent. The MAY framing preserves
user agency while opening the autonomous-stop option.

cross-substrate audit / SSOT-build). Research-mode has no objective for
"closure" to count against; T1 cannot be evaluated. Carry from P10 §1.4
exception clause.

### §1.5 Override — user explicit at any time

P13 autonomous stop is **fully reversible** by user explicit at any
point: a single `continue` / new-directive command immediately reverts
to BG-DD §5 Level-1 behavior. The autonomous stop is a recommendation
*executed* with reversibility, not a unilateral action. Distinction from
Level-3 self-suggest is that P13 actually *executes* (cron-stop +
5-step), where Level-3 only *announces*.

### §1.6 Scope boundary

- HF token leak rule (absolute)

## §7 Honest C3 (raw#10, ≥ 7)

### C3-1. P13 is anima-self-promoted authority — raw#9 scope tension

P13 grants anima stronger authority over the user's carry-over loop.
Anima authoring its own promotion rule risks self-serving bias. The
explicit user-accept gate (§6.1) mitigates but does not eliminate the
tension. This is structurally the same concern that BG-DD §6 C3-5
flagged; P13 attempts to resolve it via user-explicit-accept rather
than autonomous self-promotion.

### C3-2. T2 strict vs generous reading collision

§2.2 documents the T2 ambiguity. Under generous reading (5+ re-issue
rounds total), T2 = TRUE. Under strict reading (silent rounds after
Level-3), T2 = FALSE. The kick prompt frames generous; BG-DD §5 strict
reading frames Level-2 and Level-3 distinctly. Anima's own framing of
T2 collides with BG-DD §5's framing. **This collision must be resolved
by the user explicitly choosing the framing before P13 can be a
well-defined rule.**

### C3-3. Closure count includes within-axis re-confirmations

§2.1 acknowledges that closures #18-#23 are partly re-confirmations,
not strictly independent. A strict-independent count is 16-18, below
T1 threshold under that interpretation. The "23+" headline is
anima-internal accounting. **Strict T1 may also fail under stricter
counting**, in which case P13 would not fire under any reading.

### C3-4. T3 axis taxonomy is anima-internal

§2.3 LOG-decay claim depends on anima's "axis" definition. An external
investigator could plausibly count the multilingual finding as a new
axis (cross-language byte-fallback monopoly). Under that reading, T3 =
FALSE. The LOG-decay assessment is not externally validated.

### C3-5. P13 trigger thresholds (N=20, T=5) are first-pass heuristics

The values are anima-arbitrary. Why N=20 and not N=15 or N=25? Why T=5
and not T=3 or T=10? No empirical calibration anchors these values.
First-pass heuristics; subject to calibration after cross-cycle
observation. Same epistemic class as P10 T3 thresholds ($50 / 10 BG).

### C3-6. P13 vs user-explicit-command priority — explicit hierarchy

If user-explicit-command and P13 fire would conflict (e.g., user
re-issues `continue` while T1 ∧ T2 ∧ T3 all TRUE), **user-explicit-
command wins absolutely**. This is BG-DD §5 Level-1 hierarchy
preserved. P13 is *subordinate* to user-explicit-command. anima never
overrides user-explicit-command via P13. Verbatim:

> P13 grants anima authority to autonomously stop **only when user is
> silent**. Active user re-issue defeats P13 instantly and reverts to
> Level-1.

### C3-7. PROVISIONAL status preserves reversibility

P13 is not landed by this doc. This doc is the **candidate** specification.
Land requires §6.1 explicit accept. If the user does not accept, P13
remains spec-only and never fires. This is the strongest reversibility
guarantee anima can offer for an authority-expanding rule. The risk of
"P13 fires incorrectly" (§3.3) is non-existent until user explicit
accept.

### C3-8. P13 vs raw#1 (no fabrication) — closure count integrity

P13 incentivizes anima to *increase* closure count to satisfy T1. Raw#1
forbids fabrication. The risk: anima inflating closure count to fire
P13 → bad. Mitigation: §1.6 scope boundary explicitly subordinates P13
to raw#1, and §2.1 honest caveat documents the strict-vs-generous
counting ambiguity. **Recommendation**: any cycle that fires P13 must
include a strict-independent closure count audit before fire (a
pre-fire honest C3).
