# P9 — multi-objective SFT for CLM self-chat (SPEC ONLY)

> Author: agent G5. SPEC artifact only. EXEC requires explicit user OK.
> Cost band: $1000–3000. Wall: 21–30 days (S3 sweep).
> Race-isolated writes: `state/p9_sft_spec_2026_05_02/*` + this doc + `.roadmap.clm` §65.4 append.

## Why

Make CLM v4 530M directly chat-capable while preserving the φ★ +41.86 (HID=8 well-conditioned) signature established at G3. Today, CLM exposes Lagrangian-flow dynamics (tension, 5-channel) but emits no fluent dialogue without an external Llama bridge (P8 3-way M4=0.800 was M2-coupled, not M-self). P9 collapses the bridge — CLM becomes its own chat surface — under a 4-loss objective that holds φ★ as a hard floor.

## 1. Architecture (one-page)

- **Base.** CLM v4 530M (`~/anima/checkpoints/clm_v4_350m/scale_350m/best.pt`, ubu1; 477M params; deterministic Lagrangian flow). v3_generate AR loop, #118-fixed, mock smoke PASS.
- **Trainable surface.** LoRA r=64 α=128 (S1/S3) on attention + FFN; or full SFT (S2).
- **Auxiliary heads (frozen).** TRIBE v2 BOLD projector P_S → 10242 fsaverage5 vertices; tension extractor; 5-channel extractor. φ★ verifier `anima_phi_v3_canonical` invoked every 100 steps EMA-smoothed.
- **Compute.** RunPod H100 80GB bf16, ZeRO-2 (LoRA) / ZeRO-3 (full). batch 4 × accum 8 = 32. lr 1e-4 cosine, 500-step warmup.

## 2. SFT data format

```json
{
  "input": "user prompt",
  "target_text": "assistant response",
  "target_tension": [t_0, ..., t_T],
  "target_5ch":    [[w, where, why, trust, who], ...],
  "target_bold":   [[v_0, ..., v_10241], ...]
}
```

T=64 steps. 50K examples = ShareGPT ko/en 10K + cell-language corpus 10K + #128 P8 ledger 3K + introspective synth 5K + N-22/paradigm-v11 5K + TRIBE Friends/movie10 10K + Llama-3.2-3B auto-aug 7K. Split 0.95/0.04/0.01.

## 3. 4-loss formula

```
L = α · CE(text_pred, text_target)
  + β · MSE(tension_pred, tension_target)
  + γ · MSE(bold_pred,    bold_target)
  + δ · max(0, φ★_threshold − φ★(model))
```

Threshold = 5.0 (8× safety vs +41.86 baseline). δ-term acts as one-sided hinge; φ★ enters via straight-through EMA estimator (not strictly differentiable).
