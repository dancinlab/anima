[Q3] 프롬프트 왼쪽에 무엇이 있나 — 학습 vs 평가
     학습:  ...이전인스턴스.b'\n'이 영화 X => 긍정.
     평가:  [공백 33개]이 영화 X => 긍정.   (pad=32 · core/decode.py:955)
     => 지금까지의 평가 문맥(win=64)이 이미 **분포 밖**이다 — 학습에서 프롬프트 왼쪽은
        언제나 '앞선 인스턴스 + 개행'이었지 공백 런이 아니었다.
     => DEMO-PORT 의 1-shot 시연은 문맥을 **분포 안으로 되돌린다**. D8(자기-PC 급소)은
        해소를 넘어 역전 — 시연 포맷이 현행 포맷보다 학습분포에 가깝다.

[byte budget] 시연 ≤38B + 대상 seed ≤41B + gold 7B = **≤86B**
