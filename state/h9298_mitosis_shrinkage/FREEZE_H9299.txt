1. 물음 (H_9298 이 정당화한 p8-native 일반화)

H_9298 이 증명한 원리: 자식 분포를 부모에게 shrink 시키면 분할비용이 0 이 되고
                      정보가 회수된다 (2.61186 → 2.45205, 스윙 0.160 nats).

그런데 MITOSIS 는 이미 부모-자식 구조를 가지고 있다 — 세포 분열 족보(lineage) 그 자체다.
지금까지 모든 실험에서 이 족보는 partition 을 만들고 나서 버려졌다 (leaf 들만 flat 하게 사용).

H_9299 = 족보를 버리지 말고 backoff 체인으로 쓴다:
   딸 셀의 head 가 모 셀의 head 로 WB-shrink 되고, 모 셀은 다시 조모 셀로, … 루트까지 재귀.
   각 내부 노드의 통계 = 그 서브트리(자손 전체)의 TRAIN 카운트 합.
   루트 = 전체 TRAIN (전역 unigram) → 균등분포로 shrink.

   P_node = λ_node · MLE_node + (1 − λ_node) · P_parent(node)
   λ_node = Witten-Bell = n_node / (n_node + T_node)      ← 자유 하이퍼 0

이것이 참이면 p8 이 문자 그대로 강해진다: **분열은 파티션을 만드는 행위이자 동시에
통계적 상속 위계를 만드는 행위다** (분열 = 표현 + 추정기, 하나의 사건).

2. arm

  FLAT   leaf → ROOT 로 직접 WB-shrink              — 중간 조상 SKIP (= 순수 shrinkage 총량)

  SHUF   LIN 과 동일하되 족보를 무작위 재배선        — 트리 깊이·shrinkage 총량 보존, 부모의 정체만 파괴

   LIN 이 SHUF 도 이겨야 "이긴 이유가 족보(= 통계적으로 가장 가까운 조상)"임이 벌린다.
