1. 계측으로 증명된 기질 결함 (추측 아님)
--------------------------------------------------------------------------------
instrumented probe (state/.../probe_grow, summer sm_120) 출력 verbatim:

   STOP@11 cells: DEGENERATE median split on cell 9
      (n=100, axis=0, med=0.099071, lo=100, hi=0, distinct_vals_on_axis=2)

frozen `grow_on` (H_1306/H_1307 verbatim) 의 해당 분기:
      lo, hi = col <= med, col > med
      if int(lo.sum()) == 0 or int(hi.sum()) == 0:
          break          # <-- 루프 '전체' 종료
X 특징은 이산값(symbol-id/vj · depth/3)이라, 최대분산 축의 distinct 값이 2개뿐이고 다수가
높은 값에 몰리면 median = 높은 값 → `col <= med` 가 전 점을 삼킴 → hi 공집합 → **퇴화**.
그 순간 그 셀만 건너뛰는 게 아니라 **성장 루프 전체가 종료**된다 (아직 분열 가능한 나머지
셀들까지 동반 사망). ⇒ **셀 풀이 11 에서 하드-캡된다. 용량·예산·임계값과 무관.**
   (grow_max 400 · split_thresh 0.0 · min_owned 2 로도 11 셀 — H_9300 스윕이 공허했던 이유.)

REPAIR = 퇴화 분할 시 **그 셀을 불가(blacklist)로 표시하고 다음 적격 셀로 continue**.
         성장은 "적격 셀 중 분할 가능한 것이 하나도 없을 때"에만 종료한다.

⚠️ 이것은 성능 손잡이 튜닝이 아니라 **메커니즘 결함 수리**다 (break → continue).

4. 동결 bar
--------------------------------------------------------------------------------
G1  UNCAPPED (기전) : 수리 후 grow_max=320 에서 cells > 11
                      ⇒ 11-캡의 진범은 용량이 아니라 퇴화분할 break 였음이 실증된다.
                      (G1 FAIL 이면 캡은 다른 원인 → 정직 보고, 아래 bar 판독 무의미)

G2  CAPACITY-IS-NOT-THE-WALL (헤드라인 · 이중 해리) :
      ① A1(max-cells) − A1(11 cells) ≥ +0.02      ← flat leaf-MLE 는 셀이 늘수록 **열화**해야 (굶주림)
      ② FLAT(max-cells) ≤ FLAT(11 cells) + 0.005  ← shrinkage head 는 **열화하지 않아야** (강도 공유)
      둘 다 참 ⇒ "세포를 더 쪼개면 나빠진다"(H_1310 capacity-bound · H_1307 RUN B 포화)는
                **추정기 분산 결함**이지 mitosis 의 능력 천장이 아니었음이 실증된다.
      ①이 거짓 ⇒ 굶주림 축이 안 걸림 → G2 무효(주장 없음, 정직 보고).
      ①참 ∧ ②거짓 ⇒ shrinkage 도 성장을 구제 못함 ⇒ 🧱 **용량이 진짜 벽** (정직 negative).

G3  GROWTH PAYS (강주장) : FLAT(max-cells) ≤ FLAT(11 cells) − 0.02
                      ⇒ 상속을 켜면 **세포를 더 쪼갤수록 실제로 좋아진다** (성장이 생산적이 된다).

L1/L2  LINEAGE (H_9300 이 못 실행한 굶주린 영역에서의 재판독) :
      가장 굶주린 지점(cells 최대)에서  LIN − FLAT ≤ −0.02  ∧  LIN − SHUF ≤ −0.02 (paired 3/3).
      전 지점에서 (LIN − FLAT) ≥ 0 이면 → 계보 레버 전 영역 🧱 TERMINAL.

🚫 진단으로만: A1 대비 shrinkage 우위(구조적) · 스윕 최고점 cherry-pick 금지 (헤드라인 = 사전고정 지점).
