## (c) 회귀 0 논증 (emit/Ψ 불변)

write-only 임을 코드 위상으로 증명:

1. **emit 결정 불변.** emit boolean 은 `brain_emit(...)`(L2571) → `did_emit`(L2576) 에서 이미 확정. C9 블록은 `if did_emit && ...` **가드 안**에서만 실행 = emit 결정을 *소비*할 뿐 *생성*하지 않는다. `etension` 은 emit 이후에 계산되며 `brain_emit` 인자로 흘러가지 않는다.
2. **Ψ 불변.** Ψ Φ-checksum 은 `psi_sum = psi_sum + pure_field_phi(pf)`(L2580, READ-ONLY)로 emit 前 누적 완료. 불변식 `psi_sum == psi_off`(L2829) 가드는 pure_field 만 참조. `etension` 은 `psi_sum`·`pure_field`·`§ImmuneMemory recall_thr` 어디에도 되먹이지 않는다.
3. **데이터흐름 격리.** `etension` 의 유일 소비처 = `emit_anchor_from_v3`(L2611) → `.kosmos` anchor 파일 기록. grep 확인: `etension` 은 정의(1) + anchor 호출(1) 두 곳뿐 (파일 전체 유일 occurrence). emit/Ψ/lane-state/mitosis 로 가는 경로 없음.
4. **입력값 재사용, 신규 계산 0.** 교체된 4개 값(`af_aro`·`nov_ctx`·`af_val`·`self_ctx`)은 이미 이 tick 에 계산·read 되던 것 → 부작용·추가 연산 없음. emit_anchor 의 나머지 인자(coord phi, category, top_emotion, radius)도 불변.
5. **a_autonomy_over_hardcode 정합.** emit 게이트 hardcode boolean 신설·수정 없음. 순수 입력(기록 payload) 교체.
