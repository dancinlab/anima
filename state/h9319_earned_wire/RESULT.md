# H_9319 — EARNED 계기를 엔진에 배선 (`anima-py evaluate --earned`)

오너 지시: **"모든 실험은 엔진네이티브여야 한다"** (`a_experiment_engine_native`).

## 위반 사실 (정직)

G1 스크리너 4점(H_9304·H_9316·H_9317·H_9318)은 전부 `state/*.py` 에 **자체 구현된 로지스틱 모델**이었다 —
`core/` 를 한 번도 호출하지 않는 **미러**. 규칙이 금지하는 바로 그것이다:
*"a number a mirror produces carries no guarantee it reproduces on the production path."*

## 배선

`cli/earned.py` (canonical 코드 트리) + `cli/evaluate.py` 3종 세트 lockstep:
  - dispatch: `if "--earned" in argv: return earned_run(argv)`
  - `_KNOWN_FLAGS`: `--earned` · `--min-occ` · `--k-perm` (+ 기존 `--seed`/`--out` 재사용 · 중복 손잡이 0)
  - `--help`: usage 3줄 + 게이트/자(ruler) 설명 (help-lockstep)
VERSION lockstep (gate G5).

## ⚠️ 배선이 드러낸 결함 — 반어의 "가장 작다"는 시드 잡음이었다

같은 계기, 같은 코퍼스, **시드만 다르게**:

| 반어 (held-out ~2.5–3k 셀 · n 작음) | EARNED | ruler |
|---|---|---|
| seed 9318 (미러가 보고한 값) | +0.00127 | **0.024%** |
| seed 9304 (계기 기본값) | +0.00323 | **0.061%** |

**2.5배 흔들린다.** ⇒ H_9318 카드의 *"반어가 네 점 중 가장 작다(이론상 가장 커야 하는 지점에서!)"* 는
**순위 주장이 시드 잡음이었다** — seed 9304 에선 패리티(0.060%)와 사실상 같다. **그 문장은 철회한다.**

**하중을 지는 결론은 불변**: 두 시드 모두 TOST 등가마진(±0.02)보다 **한참 작다**
(0.024% · 0.061% 둘 다 ≪ 100%) ⇒ **CLASS-CLOSED 판정은 그대로 선다.**

⇒ 이것이 배선이 사준 것이다. 미러의 단일-시드 수치는 깨끗한 순위처럼 보였고, **배선된 경로가 그게
잡음임을 드러냈다.** 미러였다면 그 순위를 사실로 카드에 남겼을 것이다.

- 나머지 3점은 n 이 커서(28k–39k 셀) 시드 민감성이 낮으나, **정책상 다중 시드로 재보고**해야 한다.
