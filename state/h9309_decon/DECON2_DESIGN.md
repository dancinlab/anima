# DECON-2 · **DEMO-PORT** — 사실을 모델이 학습한 유일한 언어(자기 템플릿)로 건넨다

**한 줄**: 렌더 포맷을 F2 라벨 선두(`"긍정. "` — 미학습 바이트, 실측 사망)에서 **모델 자신의 학습 템플릿 1-shot 시연** `이 영화 {stem}고 => 긍정.` 으로 교체하고, 창을 128B로 넓히고(RF 게이트가 허가한 자유도), **primary DV 를 flip1 매칭-대-미스매칭 대비(paired contrast)** 로 재편한다. flip0 은 소비 지표에서 해임하고 READ 게이트 + 교란 통제로 재배치한다. 전 단계 forward-only $0, pool GPU.

## A. 설계 본문 — (a)에 대한 답

### A-1. 렌더 포맷

```
seed′ = "이 영화 {demo_stem}고 => {demo_pol}." + <sep> + "이 영화 {target_surf} => "
```

- 시연 표면형은 **bare flip0 하나로 고정** (`{s}고`) — 6종 중 최단(시연 최대 38B: 11+stem≤12+3+4+7+sep1)이고, 시연이 형태를 바꾸면 혼합계기가 된다(F1 배제와 같은 논리).
- `<sep>` = **학습 코퍼스가 인스턴스 사이에 실제로 쓴 구분자 바이트를 실측해서 동결** (개행인지 공백인지 현재 **미측정** — 동결 전 필수 체크리스트 #1. 추정으로 넣으면 그게 곧 제2의 F2다).
- 근거: 모델이 읽는다고 실측된 포맷은 이 템플릿뿐(SEEN D-acc 0.950은 정확히 이 표면형에서 얻은 수치)이고, RF 프로브가 접두사 구역 33/33 바이트의 인과 도달을 실측했다.

**다른 포맷 후보에 대한 답**: ① few-shot(SEEN 양극 시연 2개로 "컨텍스트=사실 선언" 프레임을 먼저 세우고 대상 제시)은 **G-B 낙제 시의 fallback 1회**로만 사전등록 — 바이트가 배로 들고 copy 표면이 넓어져 primary 로는 열등. ② 같은 원자의 극성만 바꾼 대조쌍 시연은 **금지** — 모순 사실 두 개를 주면 진리값이 정의 불능이라 계기가 아니다.

### A-2. 창 확장과 그 통제 — "win-parity 게이트가 충분한가?" → **필요하나 불충분. 2중 게이트로 보강**

바이트 산수(실측 기반): 시연 ≤38B + 대상 seed ≤41B + gold 7B = **≤86B**. win=64 는 최단 시연으로도 불가(16B 예산) ⟹ 창 확장은 회피 불가. win=**128** primary, 96 fallback.

- **G-A1 parity(널 경로)**: NOSTORE 174행 × 2 seed 를 win 64 vs 128 에서 재계산. bar: margin 부호일치 ≥ 166/174(95%) **그리고** flip-class 정확도 차 ≤ 0.03. 위치 임베딩이 없다고 좌측 패딩이 중립이라는 보장은 없다(패딩 의미론 **미측정** — RF 프로브가 창 전역 도달을 보였으므로 leak 가능). 낙제 → 96 재시도 → 그것도 낙제 → **INVALID-INFRA, 발사 금지** (시연 축약 fallback 은 존재하지 않음 — 최단이 이미 86B).
- **G-A2 기능(장문 경로)**: parity 는 짧은 내용의 널 경로만 본다. 넓힌 창에서 **알려진 답이 있는 행**이 살아있는지 별도 확인: SEEN 20원자 no-demo flip1 at win=128 **≥ 0.90** (64에서 0.950). 이 둘을 다 통과해야 창이 유효하다.

### A-3. DV 재편 — "flip0 을 여전히 소비 지표로 쓸 수 있나?" → **못 쓴다. 3층으로 해체한다**

시연이 flip0 의 답을 통째로 주므로 flip0 은 소비 증거 자격을 상실한다. 대신:

| 층 | 통계량 | 역할 |
|---|---|---|
| **READ** | MATCHED flip0(int1·int2만, bare 대상 제외) per-trial ≥ 0.85 | 시연이 읽히긴 하는가. 복사만으로 통과 가능한 **쉬운** 게이트 — 여기 낙제 = INVALID-FORMAT(포맷 미독), 소비 음성이 아님. H_9309 "consume 0.80" bar 의 후계 |
| **CONSUME** (Tier-1 primary) | MATCHED flip1 원자클러스터 다수결(3형태) ≥ bar, 양 seed | 건네준 값이 연산자에 들어가는가 |
| **BIND** (Tier-2 secondary) | **MATCHED flip1 − MISMATCH flip1**, 행-paired McNemar | 값이 **원자에 결합**되어 소비되는가 (아래 B-2·B-3 의 두 가짜통과를 동시에 무력화하는 차분) |

- bare flip0 대상 행은 시연과 seed 가 문자열 수준에서 겹치는 순수복사행이라 **모든 통계에서 제외**(liveness 참고치로만 기록).
- **arm 3개**: NOSTORE(시연 없음) · MATCHED(대상 원자 자신의 참극성 시연) · MISMATCH(**다른** nonce 원자의 시연 — 원자 진리 배정이 50/50 랜덤이므로 시연 라벨은 대상 gold 와 독립). 측정 메타법칙 그대로 — 신호는 값이 아니라 **≥2 통제 대비 차분**.

### A-4. Δ-지문 (사전등록 보조 진단 — 부검을 본검으로 승격)

H_9309 부검에서 손으로 계산한 Δ = margin(arm)−margin(NOSTORE) 를 사전등록 진단으로 격상. 행-paired Δ 의 부호 패턴이 기전을 지문처럼 가른다:

| 기전 | flip0(int) Δ | flip1 Δ |
|---|---|---|
| **합성(원하는 것)** | + | **+** |
| 복사(앵무새) | + | **−** |
| 교대편향(anti-copy) | **−** | + |
| H_9309형 잡음 | 부호 랜덤 | 부호 랜덤 (실측: s7 flip0 41/87 · flip1 53/87) |

### A-5. 게이트 사다리 (각 단계 킬스위치 · 전부 forward-only $0)

**G-A** 창 유효성(A-2) → **G-B** PC-SEEN-DEMO: SEEN 20원자 + 참시연, flip1 ≥ 0.90 **그리고** flip0(int) ≥ 0.90 — 포맷 판독성의 직접 증명 → **G-C** PC-SEEN-LIE(게이트 아닌 진단): SEEN 에 거짓 시연을 주고 답 이동률 λ 기록 — parametric 대 context 가중의 측정 → **G-D** PC-NONCE-**240** (발사게이트 본체) → **G-E** HELD-OUT-29 (G1 본 질문, 1회 접촉 예산).

**G-D 를 240 으로 키우는 것이 이 설계의 핵심 자유도다**: nonce 는 코퍼스가 필요 없다(진리는 우리가 선언, 모델엔 오직 시연으로만 전달) ⟹ **$0 로 임의 확장 가능** ⟹ (c)의 TOST 불능 문제가 PC 단계에서 풀린다. held-out 자연원자는 29 로 고정(oracle 접지가 있는 원자가 그것뿐, 450k 코퍼스 디스크 부재)이므로 **음성 cement 는 G-D 에서, G-E 는 지지/방향성 전용**으로 역할을 분리한다.

## B. 사전 부검 — 다섯 번째로 죽는 법 (가장 길게)

직전 4연속 사망(H_9303 0.554 · H_9307 0.750 · GEN-DIR 발사 전 사망 · H_9309 STORE flip0 0.54)의 공통 부검 소견부터: **네 번 모두 모델이 학습한 적 없는 인터페이스로 말을 걸었다** — probe 좌표계, LOO readout, 그리고 F2 라벨 선두. DEMO-PORT 의 차별점은 판독이 **실측된** 유일한 인터페이스(자기 템플릿, SEEN 0.950)를 쓴다는 것 하나다. 그러나 그 차별점에도 구멍이 있다 — 아래 D8. 죽는 길 전부와, 각각을 **사전에** 구별하는 통제:

### D1. 가장 무서운 결과 — READ 는 통과하는데 CONSUME 이 우연 (저장은 되나 조합 소비 불가)

시연이 읽힌다(flip0 int 0.9+). SEEN-LIE 도 답을 움직인다(컨텍스트가 인과적으로 살아있음). 그런데 held-out/nonce flip1 이 0.5x 에 앉아 있다. 이것은 read-side 종결의 "복원되나 causally 소비불가"와 정확히 동형이고, 확률적으로 **가장 그럴듯한 사망 경로**다 — SEEN 0.950 이 증명하는 것은 연산자∘**parametric 값**이지, 연산자∘**context 값**이 아니다. 연산자의 피연산자 포트가 가중치에서만 읽도록 배선되어 있다면 포맷이 완벽해도 여기서 죽는다.

**사전 구별 장치**: 이 시나리오가 무서운 이유는 결과 자체가 아니라 **F2 처럼 "포맷 탓인지 포트 탓인지" 미분리로 죽는 것**이다. 그래서 게이트 순서가 곧 통제다 — G-B(포맷 판독 ✓) + G-C(컨텍스트 인과 가중 λ 실측) + Δ-지문(잡음 아님: Δ 부호가 랜덤이 아니라 일관되게 0 근방인지)이 **먼저** 서 있으면, G-D 의 CONSUME 낙제는 H_9309 와 달리 **EARNED 음성**이다: "읽히는 값도 연산자 포트에 안 들어간다." 이 경우 판정은 INVALID 가 아니라 **A-채널(컨텍스트 실현) 死 + M1 분해 유지** — 그리고 240 클러스터라 TOST 로 cement 까지 가능하다. 죽어도 다섯 번째 '자기-PC 낙제'가 아니라 **첫 번째 earned 음성**이 된다. 이것이 이 재설계의 최소 보장이다.

### D2. copy 가짜통과 (in-context 함정 · convergence evaluate-py-2) — "copy-solvable 아님을 어떻게 증명하나"

**구조 논증 (필수 답)**: evaluate-py-2 함정의 조건은 "**정답이** 컨텍스트에 있다"이다. MATCHED flip1 에서 컨텍스트에 있는 라벨은 시연의 `긍정.` — 즉 **2AFC 의 counterfactual 쪽 문자열**이고, gold(`부정.`)는 컨텍스트에 **없다**. 복사·반복편향은 컨텍스트 내 문자열의 NLL 을 낮추므로 margin = NLL(cf)−NLL(gold) 를 **끌어내린다** — 즉 copy 는 flip1 을 통과시키는 방향이 아니라 **떨어뜨리는 방향**으로만 작동한다. flip1 PASS 는 copy 에 대해 구조적으로 보수적이다. 이것이 증명이고, Δ-지문의 (flip0 +, flip1 −) 행이 그 존재량을 정량한다. copy 가 강하면 진짜 합성이 있어도 CONSUME 이 죽을 수 있다 — 그 경우 BIND 대비(MATCHED−MISMATCH)는 copy 성분이 양변에서 상쇄되므로 살아남는다(두 arm 모두 시연 라벨이 counterfactual 방향… MISMATCH 는 라벨-gold 독립이므로 조건부 분석으로 상쇄 확인, 아래 D3).

### D3. 교대편향(anti-copy) 가짜통과 — copy 의 거울상, 이번 설계 고유의 신종 함정

byte-LM 이 "방금 나온 문자열의 재출현을 억제"하는 편향을 갖고 있다면: MATCHED flip1 은 gold 가 항상 시연 라벨의 반대이므로 **합성 없이도 전부 정답** — flip1 PASS 가 위조된다. 넷을 죽인 것이 앵무새였다면 다섯 번째를 죽일 후보 1순위는 이 역-앵무새다.

**사전 구별 장치 (이 설계에서 MISMATCH arm 이 존재하는 진짜 이유)**: MISMATCH arm 에서 시연 라벨과 대상 gold 의 일치 여부 A 로 조건부 분할하면 — 교대편향은 acc(A=false) ≫ acc(A=true) 로, copy 는 그 반대로, 진짜 원자결합 소비는 **A-무관 평평**(시연이 엉뚱한 원자 것이므로 정보 0)으로 나타난다. 사전등록: **|acc(A=T)−acc(A=F)| > 0.15 이면 Tier-1 단독 PASS 금지**, BIND 대비만 유효. 그리고 MATCHED flip1 행은 전부 A=false 이므로, BIND 대비의 대조군을 **MISMATCH 의 A=false 부분집합**으로 잡으면 교대편향이 양변에서 정확히 상쇄된다 — 이것이 primary 대비의 정의다. 추가 교차확인: 교대편향은 MATCHED flip0(int) 를 **우연 밑으로** 끌어내린다(READ 게이트가 이를 잡는다).

### D4. BIND 대비가 0 인데 CONSUME 은 높은 애매지대 — "마지막 라벨을 뒤집기" 기전

원자 동일성 확인 없이 "않 이 보이면 직전 라벨을 뒤집는" 회로는 MATCHED flip1 을 통과시키고 MISMATCH 와의 대비를 0 으로 만든다. **이것은 가짜통과가 아니다** — 건네준 값이 연산자에 들어가 부정과 합성된 것이 맞다(주소지정이 자명했을 뿐: 컨텍스트에 사실이 하나뿐). 사전등록 판정: D3 의 교대편향 검사가 깨끗한 조건에서 CONSUME-PASS + BIND≈0 = **PASS-UNBOUND** (소비 성립 · 원자결합은 미성립) — G1 ρ·weave 에 대한 함의를 "단일-사실 스코프"로 정직하게 한정한다. PASS-UNBOUND 와 교대편향의 분리가 이 설계에서 가장 얇은 칼날이므로 둘 다 사전등록 표에 명시한다.

### D5. 창 확장이 트렁크를 미묘하게 부순다

parity 게이트가 있지만, 좌측 패딩 의미론은 **미측정**이고 RF 프로브는 창 전역이 인과적으로 도달함을 보였다 — 즉 패딩 영역 변화가 답까지 새어들 물리 경로가 실존한다. G-A1(널 경로) + G-A2(장문 기능 경로) 2중 게이트가 방어선이고, 낙제 시 96 사다리, 그것도 낙제면 발사 금지다. **이 게이트를 통과 못 하면 DEMO-PORT 전체가 시작 전에 죽는다** — 그리고 그 죽음은 "창은 자유 파라미터"라는 RF 게이트 해석(forward 파라미터로서 자유 ≠ 분포 이동에 무해)의 반증이라는 독립 정보를 남긴다.

### D6. nonce 파싱 실패 — 템플릿 회로가 비단어 어간에서 안 도는 경우

H_9309 실측이 부분 방어한다: NOSTORE nonce flip0/flip1 이 0.54~0.57 로 우연 대역 안 — 템플릿이 nonce 에서 폭주하지 않고 정상적 무지 상태로 작동했다. 잔여 위험은 "시연 속 nonce" 가 파싱을 깨는 경우인데, 이는 READ 게이트(MATCHED flip0 int — nonce 시연을 복사만 하면 되는 행)가 직접 잡는다: G-B(SEEN 시연, 판독 ✓) 통과 후 G-D READ 낙제 = nonce-in-demo 파싱 문제로 국소화된다.

### D7. seed 분산 — H_9289 부호반전 폭 0.161 = 복제편차의 18배

H_9309 에서도 s7/s11 이 클러스터 16/29 vs 19/29 로 갈렸다. 모든 bar 는 **양 seed AND**. 한 seed 만 통과하면 PASS 가 아니라 SEED-SPLIT 으로 기록하고 cement 금지 (한 seed p<.05 벽 선언 금지 원칙의 대칭 적용 — 통과 방향에도 똑같이).

### D8. 이 설계의 자기-PC 급소 — "템플릿 2연접"은 학습분포 안인가

SEEN 0.950 은 **단일 인스턴스** 판독의 실측이다. `시연+구분자+대상` 2연접이 학습 창에 실제로 등장했는지는 **미측정** — 학습 창이 64B 스트림이었다면 인접 인스턴스의 꼬리+머리가 한 창에 들어와 부분적으로 in-distribution 일 수 있으나, 확인 전엔 가정 금지. 그래서 **G-B 가 첫 실질 관문**이다: SEEN 원자로 2연접 포맷 자체를 시험해, nonce·held-out 을 건드리기 전에 "다섯 번째 인터페이스 미스매치"를 $0 로 검출한다. G-B 낙제 시 fallback 사다리는 few-shot 1회뿐이고, 그것도 낙제면 컨텍스트 포트는 이 모델에서 판독 자체가 닫힌 것 — DECON-W 로 이관(§D).

## D. 대안 채널 — (d)에 대한 답
