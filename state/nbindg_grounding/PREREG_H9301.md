# H_9301 — 사전등록 (FROZEN · K_CTX 캡 해제 · 측정 前 커밋)

## §0 발견 — 세 번째 코드 캡

이 레인의 음성 판정 3연속은 **전부 계기가 스스로 버린 것** 위에 서 있었다:

```
k_cap = 15   →  held-out 원자 29개만          (H_9297 이 풀어 91개 · bar 1.62σ → 2.86σ)
WIN   = 24   →  모델에게 한글 8자만           (H_9300 · 오라클은 64자를 읽었다)
K_CTX = 24   →  원자당 문맥 24개만            (지금)
```

**K_CTX 실측** (코퍼스 450k · 원자 111개):

| | 값 |
|---|---|
| 원자당 **가용** 문맥 | 중앙값 **717** · 최소 **182** · 최대 24,899 |
| 프로브가 **쓴** 문맥 | 전 원자 예외없이 **24** |
| 캡이 물리는 원자 | **111/111 = 100%** |
| 버려진 문맥 | **197,169** |

캡이 100% 항목에 물리면 그건 데이터 한계가 아니라 **코드 캡**이다(convergence `gt-step0-gprobe-py-1`).

## §1 물음 — 그 캡이 음성을 만들었는가

프로브의 특징 = 한 원자의 **문맥들을 평균낸 hidden**. 극성은 문맥에 실려 있고(H_9291 오라클이
증명), 잡음은 √K 에 반비례해 줄어든다.

```
K=24  → per-atom 특징 잡음 1.00
K=182 → per-atom 특징 잡음 0.36        √(182/24) = 2.75배 선명
```

> **H_9297 의 EARNED 음성("표현에 극성이 없다")이 잡음-제한 음성인가?**

⚠️ **bar 는 움직이지 않는다.** 우연 sd 는 원자 수 n=91 이 정하는 것이지 문맥 수가 아니다
(sd = √(0.25/91) = 0.0524 불변 · bar 0.65 = 2.86σ 불변). K_CTX 는 **특징의 잡음만** 줄인다.
따라서 이것은 bar 를 낮추는 게 아니라 **계기의 눈을 뜨게 하는** 변경이다 — tune-to-green 아님.

## §2 방법 — **K_CTX 하나만** 바꾼다

H_9297/H_9300 에서 그대로 동결(1바이트도 안 움직임): 같은 4 frozen ckpt · 같은 원자 split
(train 20 / held-out 91) · 같은 인증 bar(purity ≥ 0.85 · occ ≥ 100 · OCC_FLOOR 30) · 같은 좌문맥
절단(`frag[-64:]`) · **bar 0.65** · P-LIN primary · 200회 라벨-순열 귀무분포 · 같은 seed.

**바꾸는 것:** `K_CTX = 24` → **`K_CTX = 182`** (모든 원자가 공급 가능한 **최소치** — 어떤 원자도
남보다 적은 문맥으로 평균되지 않는다).
**창:** H_9300 이 확정한 창을 쓴다(그 H 가 착지한 뒤에 고정 · 이 H 는 창을 건드리지 않는다).

**비용:** 프롬프트 2,664 → **20,202** (7.6배) · dump 는 pool(aiden) · mini 금지.

## §3 상시 V-게이트 (H_9300 개정 II 를 **상속**)

- **V-CAP (신규 · 이 H 의 전제)** — 모든 원자가 정확히 182 문맥을 받아야 한다(부족한 원자 0). 실측 보고.
- **V-CONTRAST (결정적)** — **같은 프로브를 K_CTX=24 로도 돌려** H_9300 의 착지 수치를 재현해야 한다.
  재현 실패 = 파이프라인 불일치 ⇒ 어떤 수치도 읽지 않는다. ⇒ **두 K 의 차이만이** 이 H 의 신호다.
- **V-LENGTH-A / B (상속)** — length-only 바닥(0.648)을 넘어야 하고, 길이-잔차 프로브도 bar 를
  넘어야 한다. 못 넘으면 ⏳ LENGTH-CONFOUND (tier 미보고).
- **V-CV (상속)** — train 20 원자 LOO ≥ 0.60 (V-FIT 은 n=20·d=768 이라 자명 ⇒ 폐기).
- **V-PERM** — 200회 라벨-순열 귀무분포 백분위 (밴드 아님).
- **V-BASE** — `base_only` arm 은 bar 미달이어야 한다.

## §5 동결 예측 + 틀릴 최빈 경로

> **Pre-registered:** *K=182 에서 held-out probe-acc 가 **상승하되 bar 는 못 넘는다*** — 즉 **🟡
> PARTIAL** 또는 **🧱**. 근거: 잡음 2.75배 감소는 **있는 신호를 선명하게** 할 뿐 **없는 신호를 만들지
> 못한다**. 그리고 A7(감성 축 자체가 얕다 · win=128 에서 0.590)이 "신호가 애초에 작다"를 지지한다.

**틀릴 최빈 경로:** ① 문맥을 많이 평균낼수록 **원자-특이적 성분이 아니라 코퍼스 평균**으로 수렴해
극성이 오히려 **씻겨나갈** 수 있다(평균풀링의 양날 — 그 경우 K=182 가 K=24 보다 **낮게** 나오고,
그것도 결과다: 판정 2행). ② 182 문맥 중 상당수가 **극성 중립 문맥**이면 잡음이 아니라 **희석**이
늘어난다(§3 V-CAP 이 개수만 보고 질은 안 본다 — 인정하고 간다).
