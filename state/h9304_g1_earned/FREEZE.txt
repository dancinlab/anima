4. 두 모델 (held-out 전이가 유일한 차이)
--------------------------------------------------------------------------------
  M_add (가법 · 주효과만) :  logit P(T=1 | A,B) = α_A + γ_B
        → held-out (A,1) 예측 = α_A + γ_1   (어간 효과 **그대로**, 전역 부정 오프셋만)
  M_op  (연산자 · flip)   :  logit P(T=1 | A,B) = (1 − 2B)·α_A + γ_B
        → held-out (A,1) 예측 = −α_A + γ_1  (어간 효과 **뒤집힘**)

α_A 는 A 의 **비부정(B=0)** 출현에서 추정 (held-out 셀 자체는 절대 안 봄).
γ_B 는 **다른** 어간들의 (·,1) 셀에서 추정 = 전역 연산자.
⇒ M_op 가 M_add 를 held-out 에서 이기면 **부정 = 전이 가능한 재조합 연산자**가 실재한다.
   두 모델의 자유도 차이 0 (같은 파라미터 수) — 복잡도 이득이 아니다.

G-POWER  : held-out 셀 인구조사를 **먼저**. occ 임계별 N_heldout 집계.

7. 동결 판정표 (세 게이트 PASS 후에만 판독 · 음성은 사전등록 TOST)
--------------------------------------------------------------------------------
Δ_eq = 0.02 nats (데이터 前 고정) · CI = 90% (K=1000 순열 널)

  🟢 INFO-PRESENT   : held-out EARNED 의 CI 하한 > +Δ_eq
                      ⇒ 정보 실재 + **전이됨** ⇒ shrinkage 시도 근거 성립 · 프런티어 crack 후보
                        (MITOSIS 법칙과 G1 이 **통합**)

  🧱 OPERATOR-ABSENT: held-out TOST PASS (CI ⊂ ±Δ_eq)  ∧  **seen 시너지 ≫ +Δ_eq**
                      ⇒ 자연의 비가법성은 **전량 collocation** · 전이 연산자 **0**
                      ⇒ G1벽 = "자연 코퍼스에 전이 가능한 재조합 연산자 자체가 없다 ·
                         XBIND crack = 자연에 없는 연산자를 우리가 주입한 것"으로 **격상 종결**
                      (법칙 **직교** 확정 · Fable 의 사전 예측 = 이것)

  🧱 DATA-ADDITIVE  : held-out TOST PASS  ∧  **seen 시너지도 ≈ 0**
                      ⇒ 자연 코퍼스에 비가법 정보 자체가 없음 ⇒ 어떤 추정기도 무력 · G1 = DATA 벽

  ⏳ NOT-POWERED    : CI 가 0 과 +Δ_eq 를 **모두** 관통 ⇒ N 부족. 더 큰 라벨 코퍼스 (spend-go).
                      (power-before-negative-verdict: 음성 선언 전 검정력 먼저)

  ⛔ INVALID        : G-PEDESTAL / G-ALIVE 실패, 또는 N_heldout < N_REQ ⇒ 벽 판정 불가.

🔑 **이중해리(seen vs held-out)가 OPERATOR-ABSENT 와 DATA-ADDITIVE 를 가른다** —
   둘 다 held-out TOST PASS 지만 배우는 것이 정반대다.
