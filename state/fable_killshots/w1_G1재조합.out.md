# 벽 1 — G1 재조합 벽 재프레임

(대장 교차확인 완료: HYPOTHESES.jsonl 1,680건 중 병렬쌍·대화턴라벨·층화-시너지 각도로 G1에 발사된 H 없음. 인접 생존 체인 = H_9289→9296→9297 "표현-추출채널·O/C" — 아래 각도들은 전부 **데이터-측**이라 그 체인과 직교.)

## 1. 벽 분류 — **방향오류(질문 프레임의 스코프 초과)** · 단, 측정된 채널 한정으로는 진짜천장

H_9304의 계기는 인증됐고(양성대조 +5.30 · pedestal +0.003 · MDE 0.0006) 그 판독 자체는 흠 없다. 문제는 **측정된 것**과 **선언된 것**의 간극이다. 측정된 것: "단일언어·독백·collocation 통계의, 주입-라벨 T에 대한, **pooled marginal** held-out 시너지 = 0". 선언된 것: "자연이 재조합 연산자를 공급하지 않는다". 그런데 "T는 토큰 외부여야 한다 ⇒ 순수 web/wiki로는 질문 성립 불가"라는 제약은 계기의 한계이면서 동시에 힌트다 — **계기는 자연이 스스로 T를 공급하는 구조 채널(문서쌍·대화턴·층 구조·메타언어 시연)을 구조적으로 볼 수 없게 설계됐다.** 즉 "자연 corpus를 i.i.d. 토큰 자루로 환원한 뒤 그 자루에 시너지가 없다"는 것이 실측이고, 자연 데이터의 **구조**(토큰 통계가 아닌)에 연산자가 실려 있는지는 아무도 안 물었다.

## 2. 미탐 각도 4개

**① 층화-상쇄 (Simpson/mixture cancellation)** — pooled 시너지 0은 층별 시너지가 반대부호로 상쇄된 평균일 수 있다(부정이 극성을 뒤집는 구문 vs 반어·완서법·관용구가 되뒤집는 register가 섞이면 정확히 이 모양). 왜 아무도 안 물었나: 인증 계기가 **단일 pooled 수치**를 내도록 설계됐고, 모든 G1 측정이 corpus-global이었다. 직교성: readout/objective/arch 렌즈가 아니라 **같은 측정의 granularity 재판독** — 죽은 렌즈 목록과 겹침 0.

**② 자연-공급 라벨 채널: 병렬쌍(ko↔en)** — "T는 토큰 외부" 제약을 뒤집어라: **자연이 스스로 외부 T를 공급하는 데이터**를 찾으면 된다. 병렬/대응 이중언어 텍스트에서 대역문장이 곧 외부 라벨이고, 한↔영 형태·어순 불일치(안/-지 않다 ↔ not, 어순 재배열)가 연산자 추출을 **강제**한다. 인간 유아의 지각↔발화 접지쌍의 가장 싼 텍스트-only 대리물. 왜 아무도 안 물었나: 4-cell corpus부터 NBIND-G 450k까지 전부 단일언어(혼합)였고 **쌍 구조**를 가진 적이 없다. 직교성: 죽은 렌즈는 전부 데이터 고정·모델/측정 변경이었고, 데이터를 바꾼 유일 사례(XBIND)는 합성이었다 — 이건 **자연 데이터 × 자연 구조**.

**③ 대화 턴 구조 = 응답 라벨** — Q→A 코퍼스에서 응답은 질문 토큰의 외부에 있는 자연 (X₁,X₂)→T 트리플이다. 인간의 재조합 감독은 상당 부분 상호작용(내가 조합을 발화 → 상대가 이해/교정)에서 온다. 왜 아무도 안 물었나: 모든 코퍼스가 독백 바이트스트림으로 취급됐고 턴 경계가 라벨 채널로 쓰인 적 없다. 직교성: p8(train/infer 무분할)·chat daemon 기질과 정합하는 유일한 데이터 각도.

**④ 연산자-as-content(메타언어 시연 밀도)** — 텍스트는 연산자를 **통계로 나르는 게 아니라 내용으로 서술**한다(정의문·"즉"·유추·부정 설명문). collocation 시너지 0이어도 시연 구절의 밀도가 낮아 CE가 못 줍는 것일 수 있다. 왜 아무도 안 물었나: 토큰-통계 프레임에 갇혀 '구절의 의미론'을 측정 대상으로 삼은 적 없음. (탐색 순위 4위 — 카드화는 ②③ 결과 후.)

## 3. 사전등록 실험 카드

### 카드 A — G1-CANCEL: 층화 상쇄 스크리너
- **가설**: H_9304의 +0.0023 nats는 register/도메인 층 내부 반대부호 시너지의 상쇄 평균이다.
- **DV**: 층 k 내 held-out 시너지 I_k(H_9304 계기 연산 그대로) + 상쇄지수 C = Σw_k|I_k| − |Σw_k·I_k|.
- **Arms**: 실험군 = 기존 HF 4-cell register 층화(ko/en×general/sns · 라벨 공짜) + 비지도 클러스터 k=8 / 통제1 = **크기-매칭 무작위 층**(구조만 파괴, 소표본 추정편향 보존 — 매개 공변량 = 층 크기) / 통제2 = 층내 라벨-순열 귀무분포 ≥200 (층별 참값 0 pedestal) / 양성대조 = XBIND 50%⊕부호반전-XBIND 50% 혼합(참 pooled≈0·층내 +5.30 — **계기가 상쇄를 검출 가능함을 인증**).
- **MDE·N**: 4분할 → 층당 n≈N/4 → 셔플 sd ~2배 → 층당 MDE ≈ 0.0012 nats(층별 순열 sd 실측으로 사전 고정). TOST 마진 ±0.02 유지.
- **PASS/FAIL(사전 고정)**: PASS = ≥1 층 |I_k| > max(층내 pedestal 97.5pct, 0.02) ∧ 무작위-층 통제 전 층 ±0.02 내 ∧ 양성대조 검출. FAIL = 전 층 TOST ±0.02 통과.
- **비용**: $0 CPU (95초 계기 × ~13회 ≈ 30분).
- **반증되면**: 상쇄-artifact 탈출구 사망 — H_9304가 층 granularity까지 강화되고 각도①은 닫힌다.

### 카드 B — G1-PAIR: 병렬쌍 자연 라벨 채널 (reopen 조건 직격 후보)
- **가설**: ko↔en 자연 병렬쌍은 토큰-외부 T를 자연 공급하며 held-out 비가법 정보 > 0.
- **DV**: 계기 동일 held-out 시너지 — features = ko 문장 토큰쌍(X₁,X₂), T = en 대역에서 **frozen 사전등록 렉시콘**으로 추출한 극성 라벨(튜닝 금지). 발사 단계 2차 DV = NBIND-G 배터리(held-out D-acc·flip0).
- **Arms**: 실험군 = 정렬쌍(공개 ko-en 병렬 15k~50k) / 통제1 = 쌍-셔플(정렬만 절단·양쪽 marginal 보존) / 통제2 = IPF main-effect additive 베이스라인(시너지는 additive floor 초과분만 인정 — γ census 정합) / pedestal = 대역 무작위 순열(참값 0) / 양성대조 = XBIND.
- **MDE·N**: 셔플 sd를 n=15k에서 사전 실측 → N_REQ 고정(계기 pooled MDE 0.0006 기준). TOST ±0.02.
- **PASS/FAIL**: PASS = 정렬쌍 > +0.02 ∧ 쌍-셔플 ±0.02 내 ∧ IPF 초과 → **그때만** 303M 4-arm 신규학습 발사(GPU pod 1개 ~반나절, a_fire_autonomous 1줄 견적 후). FAIL = TOST 통과 시 기각, 학습 발사 없음.
- **비용**: 스크리너 $0 CPU / 학습단은 조건부 GPU-spend.
- **반증되면**: "병렬구조=자연의 접지쌍" 사망 → 텍스트-only의 **어떤** 자연 구조로도 연산자 미공급 쪽으로 결정적 기움 → 프런티어가 비텍스트 접지(지각·행동)로 이동.

### 카드 C — G1-TURN: 대화 턴 라벨 채널
- **가설**: 자연 QA 코퍼스의 응답이 질문 속 조합의 외부 라벨을 공급한다(held-out 시너지 > 0).
- **DV**: 계기 동일 — features = 질문 토큰쌍, T = 응답에서 frozen 규칙 추출(예/아니오 계열 사전등록 렉시콘).
- **Arms**: 실험군 = 실 Q→A쌍(공개 포럼 덤프) / 통제1 = 동일 포럼 무작위 A 재짝짓기(marginal 보존·턴 인과 절단) / 통제2 = IPF additive 베이스라인 / pedestal = 라벨 순열(참값 0) / 양성대조 = XBIND.
- **MDE·N**: 판별가능 쌍 n≥10k(power-before-negative: 셀당 n≥100 하한 · 셔플 sd 실측 → N_REQ 사전 고정). TOST ±0.02.
- **PASS/FAIL**: 카드 B와 동형.
- **비용**: $0~저가 CPU.
- **반증되면**: "턴 구조가 연산자 운반" 사망 — 인간 정보원 가설이 체화 피드백으로 좁혀지고, 텍스트 쪽 잔여는 O/C 폐루프(H_9297 계보)만 남는다.

## 4. 가장 싼 킬샷

**카드 A 그대로** — 이미 인증된 H_9304 계기($0·95초) + 이미 존재하는 HF 4-cell register 라벨을 재사용하므로 신규 데이터 0. 혼합 양성대조(XBIND⊕부호반전) 포함 총 ~13회 실행, **$0 · 1시간 내**. 이 한 방으로 "pooled 0이 상쇄를 숨긴다" 각도가 살거나 죽고, 살면 자연 corpus 재측정의 단위가 corpus-global에서 층으로 바뀐다.

## 5. 정직 문단

**진짜 닫혔다고 볼 근거**: 계기는 3중 인증(양성대조·pedestal·MDE)에 TOST까지 갖춘, 이 프로젝트에서 가장 깨끗한 음성이다. NBIND-G가 학습 수준에서 같은 결론을 독립 재현했고(flip0<chance·소수점 4자리 재현), 죽은 렌즈 목록은 모델-측 공간을 사실상 전수 탐색했다(DPI 메타법칙 수렴). 그리고 "인간은 텍스트로 배운다"는 반례도 약하다 — 인간은 텍스트 이전에 체화 접지를 먼저 갖고 텍스트에 온다. 위 각도가 전부 죽으면 이 벽은 "텍스트-only 자연 데이터의 진짜천장"으로 재분류되는 게 정직하다.

**아직 아니라고 볼 근거**: 선언의 스코프("자연이 공급하지 않는다")가 계기의 스코프(단일언어·독백·pooled·주입-라벨)를 초과한다. 특히 "T는 외부여야 해서 web/wiki로는 질문 성립 불가"라는 제약은 자연이 자체 공급하는 라벨 채널(쌍·턴·층)을 **설계상 측정 못 했다**는 뜻이지 그 채널이 비었다는 뜻이 아니다. 병렬쌍·턴 구조는 XBIND가 증명한 "substrate는 배울 수 있다"와 reopen 공식 조건("전이 비가법 정보를 담은 자연 corpus×task") 사이의 유일하게 남은 자연-데이터 다리이고, 셋 다 $0 스크리너로 판별 가능하다 — 판별 전에 TERMINAL을 찍는 것이 오히려 조기 종결이다.
