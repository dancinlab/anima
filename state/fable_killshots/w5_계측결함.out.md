# 벽 5 — 계측 결함 census 재프레임

## 1. 벽 분류

**측정-artifact (주) + 투자부족/검정력 (부).** 이 벽의 실체는 "자원 희소성이 G1 레버가 아니다"가 아니라 **"이 lane에 관한 어떤 판정도 아직 내려진 적이 없다"**이다. F13 부호반전(−0.209 → +0.129)·V2 게이트 역전·seed 이질성 z=2.22는 기질에 대한 정보가 아니라 계기에 대한 정보이고, sd 0.545 · signed mean ≈ 0 · n=20 vs N_REQ=53은 교과서적 잡음지배+검정력 미달이다. 즉 organelle lane은 KILL도 GREEN도 아닌 **판정불가(NOT-POWERED · INSTRUMENT-UNCERTIFIED)** 상태이며, 5대 결함이 전부 사후 발견됐다는 사실 자체가 6번째 결함의 사전확률을 높인다. 기질한계·진짜천장 분류는 현 증거로 라이선스 불가.

## 2. 미탐 각도 4개

### 각도 1 — 이득(gain) 미교정: 참값 k≠0 SPIKE-IN 부재 (제6결함 최유력)

5대 결함의 계보를 보면 전부 **거짓양성 쪽에서 사후 발견**됐다(Φ 90배 인플레 → pedestal, tune-to-green → V-gate). 그래서 체크리스트가 전부 "부풀림 검출"만 본다. 아무도 반대 방향을 안 물었다: **detector의 이득이 1 미만이면**(참 효과를 0.1배로 압축) pedestal(절편=0 검사)은 통과하면서 실재 효과를 "ns"로 만들어 **거짓 KILL을 양산**한다. 이 벽의 판정이 전부 음성이라는 점에서 정확히 이 사각지대에 앉아 있다. `tool-definition-read-code` 메모리의 SPIKE-IN 교훈(측정/참값 상수비 검산)이 이미 존재하는데 절편에서만 쓰였고 **기울기(선형성)에서는 한 번도 안 쓰였다** — pedestal은 bias-at-0 검사, spike-in ladder는 gain 검사로, 서로 직교한다.

**선제 결함 체크리스트 (사전등록형 · D6~D13)** — 파이프라인 단계별:

| # | 결함 클래스 | 유형 | 검사 방법 (사전등록 항목) |
|---|---|---|---|
| D6 | detector 이득/선형성 미교정 | 거짓 KILL | k∈{0, ½σ, 1σ, 2σ} spike-in ladder → 기울기 ∈ [0.8, 1.25] 요구 |
| D7 | 음성판정 비대칭(원장 래칫) | 원장 오염 | GREEN엔 V-gate·wiring·verify가 있는데 **KILL엔 라이선스 관문이 0** → KILL이 check-ledger로 미래 발사를 차단하며 축적. KILL 전용 V-gate(검정력 증명 + TOST + detector 인증) 의무화 |
| D8 | census 내 비독립성 / family-wise 오류 | 거짓 확신 | 11 패밀리가 같은 ckpt·seed·코퍼스 공유 = 11개의 독립 증거 아님. 공유 자원 그래프 명시 + family-wise α 보정 |
| D9 | 유계 DV 절단(censoring) | 검정력 상실 | chance floor/ceiling 근처 DV를 원척도로 TOST하면 무효 — logit/rank 변환 사전 고정 |
| D10 | 정지규칙 미등록(optional stopping) | 거짓양성·음성 | "언제 실험이 끝나는가"가 사전 고정된 적 없음 → group-sequential α-spending 등록 |
| D11 | arm-환경 결합 | 편향+검정력 | arm별로 host/시각/numeric path/RNG stream이 다르면 교란, 같게 안 맞추면(CRN 부재) 검정력 낭비 — arm 간 CRN + 동일 host 실행 명시 |
| D12 | seed = 고정효과 취급 | 거짓 KILL/GREEN | F13이 반쯤 발견(z=2.22). seed는 랜덤효과: seed 2개 × item 다수의 유효 n은 seed 수준에서 **2**. seed ≥5 + 혼합모형 의무 |
| D13 | item/cue 세트 재활용 | 원장 과적합 | 개발 중 쓰던 cue를 판정에 재사용 → 원장 전체가 item에 과적합. 판정용 cue는 판정 시점 신규 생성 + sha256 동결 |

### 각도 2 — F2 sham: "점통제 불가능"의 정체와 탈출구 (질문 ②의 답)

sham 4연속 붕괴는 sham **설계**의 실패도, 정보이론적 **불가능**도 아니다 — 정확히는 **"연산공간 내 점귀무(point-null) 통제가 공허한 지지집합을 가진다"**는 구조적 사실이다. 논증: F2의 주장은 I(L; 융합출력의 국소관측) > I(L; 비융합 국소관측)이다. "융합을 하되 정보를 안 더하는" sham은 *잘 정의된 융합쌍*이기를 요구하는데, F2 도메인에서는 **쌍의 잘-정의됨(load-공급 상보성) 자체가 L의 함수**다 — 즉 domain = signal. 상보성을 깨면 연산이 구조붕괴하는 건 통제 실패가 아니라 "H0을 연산 내부에서 실현할 수 없다"는 증명이다. 그러나 이것이 반증불가를 뜻하지 않는다. 귀무를 **연산 안이 아니라 생성 단계로** 올리면 된다:

- **(a) 생성시점 잠재 무작위화**: L을 입력 구성 *이전에* 셔플 → 각 입력은 개별적으로 well-formed, 쌍은 L에 대해 0 bit. 연산은 정상 실행되고 참값은 구성상 0 — 이것이 구성 가능한 참값-0 pedestal이다.
- **(b) 용량-반응(dose-response)이 점통제를 대체**: 쌍 충실도 p∈{1, .75, .5, .25}를 연속 조작(교체쌍은 S_tot 층화 매칭 — 매개 공변량 통제 준수). 판정은 sham 대비 차분이 아니라 **기울기**. p=0 끝점이 퇴화해도 내부점은 멀쩡하다.
- **(c) 분석시점 순열 귀무**: 연산은 건드리지 않고 L 라벨만 순열해 통계량의 귀무분포 생성.

세 경로가 **모두** 붕괴할 때에만 "F2는 정의상 참 = 경험적 질문이 아님"으로 재분류하고, 질문을 "융합이 정보를 더하는가"(정의상 예)에서 **"얼마나, 오라클 대비 몇 %, 더 싼 연산자 대비 몇 배"**라는 정량 질문으로 바꿔야 한다. 아무도 안 물은 이유: 4번 모두 "더 나은 sham"을 같은 연산공간 안에서 찾았다 — 귀무의 **위치**를 옮긴다는 선택지가 탐색 밖이었다.

### 각도 3 — 동일 예산 검정력 3~5배: decode 파이프라인 좌석 배치 (질문 ③의 답)

검정력을 n으로만 사려 했고(n=20→53은 GPU 2.6배), **분산을 줄여서 사는** 경로는 파이프라인에 한 번도 앉힌 적이 없다. 구체 배치:

1. **Within-item CRN 쌍대화** — 같은 (item, seed, RNG stream)으로 EXP/control 둘 다 decode(det-eval 경로는 이미 존재, 확률 decode는 (item, position)별 stream 고정). Var(diff)=2σ²(1−ρ), ρ≈0.7이면 **3.3배**.
2. **CUPED/ANCOVA** — 처치 전 공변량(base ckpt의 per-item CE·item 길이·S_tot)으로 회귀조정, 잔차분산 (1−R²)배. 사내 실증 이미 있음: H_9294 ANCOVA R²=0.986. 필요 배선은 `anima-py evaluate`에 per-item JSONL dump 플래그 하나 + $0 분석 스크립트.
3. **seed를 블록으로** — seed 2×item 200 대신 **seed 6×item 67**(동일 decode 예산). F13이 보인 seed간 이질성 하에서 유효 n = n/(1+(m−1)·ICC)라 seed 증설이 item 증설을 압도.
4. **$0 item 스크리닝** — py numpy 채널(CPU pool, $0)로 대량 item의 판별력을 선측정 → Fisher 정보 상위 item에만 GPU arm 지출.
5. **group-sequential 정지규칙** — O'Brien-Fleming α-spending으로 큰 효과는 n=20에서 조기 종료, 아니면 계속 — 평균 비용 절감분으로 위 3을 산다.

합산 수치: F13 sd 0.545 → 쌍대화(ρ=.5)+CUPED(R²=.6)로 잔차 sd ≈ 0.244 → **N_REQ 53 → ~11 블록**, 동일 GPU 예산에서 ~4.8배.

### 각도 4 — 분산 법의학(variance forensics)

0.545라는 sd가 **어디서 오는지**(seed × item × RNG × host 분해)를 아무도 측정 안 했다. 검정력 계산은 늘 사후에, 총분산 한 덩어리로만 했다. 기존 trace JSONL(state/에 이미 존재)로 $0 분산성분 분해가 가능하고, 그 결과가 각도 3의 어느 레버를 사야 하는지를 직접 결정한다. 기존 렌즈(효과 추정)와 직교 — 이건 효과가 아니라 **잡음의 구조**를 측정한다.

## 3. 사전등록 실험 카드

### 카드 A — CAL-6: detector 이득 사다리 교정
- **가설**: census detector 중 ≥1개의 이득이 0.5 미만(참 효과 2배 이상 압축)이어서 실재 효과를 ns-KILL로 변환해 왔다.
- **DV**: 측정 Δ̂ / 주입 Δ_true 비율의 회귀 기울기(= gain). 주입은 control-arm 기존 decode 출력에 분석입력 수준 라벨/토큰 교체로 구성 — 참값이 정확히 계산됨.
- **Arms**: spike-in 사다리 k∈{½σ, 1σ, 2σ} + **k=0 pedestal**(절편 검사) + **양성대조**(XBIND급 기지 대효과 — 기대 gain비 기지값 재현).
- **MDE·N**: item n=200/단(CPU $0) → 기울기 se ≈ 0.05, gain 편차 0.15 검출.
- **사전 PASS/FAIL**: detector별 log-gain TOST ±0.22 (gain ∈ [0.8, 1.25]) → 이탈 시 그 detector가 라이선스한 **모든 KILL을 INVALID로 강등**.
- **비용**: $0 (기존 state/ trace 재분석 · 재학습 없음).
- **반증되면**: 전 detector gain≈1 → "제6결함=이득" 가설 사망, 원장의 문제는 검정력 단일 원인으로 확정.

### 카드 B — F2-DOSE: sham을 용량-반응으로 대체
- **가설**: F2 정보이득은 쌍 충실도 p의 단조 증가함수이며, 연산공간 sham 없이 측정 가능하다.
- **DV**: 동결 decoder(sha256 사전등록)의 국소관측 판독점수 D(p), p∈{1, .75, .5, .25} (교체쌍은 S_tot 층화 매칭).
- **Arms**: 4점 dose ladder + **생성시점 L-무작위화 arm**(참값 0 pedestal — 입력은 개별 well-formed, 쌍은 0 bit) + **오라클 쌍 양성대조**.
- **MDE·N**: F2가 n=20에서 t=+27이었으므로 dose당 n=20이면 기울기 MDE ≈ 전체 효과의 1/10. within-item 쌍대화 + blind-arm 공변량 CUPED 적용.
- **사전 PASS/FAIL**: 기울기>0 (p<.005) **AND** pedestal TOST 등가(마진 = 전체 효과의 10%). pedestal ≠ 0이면 decoder가 정보가 아니라 형식을 읽는 것 → F2 5번째 INVALID + **"질문 불성립"으로 영구 재분류**.
- **비용**: $0 CPU (F2는 원래 cheap-probe 레인 · 학습 없음).
- **반증되면**: 평평한 기울기 + 좁은 CI → H_9287 "재조합 대수가 물리 정보를 더한다" DIRECTIONAL이 진짜로 죽는다.

### 카드 C — POW-X: 분산성분 분해 + CUPED 개장 (A/A 안전핀 포함)
- **가설**: F13 채널 sd 0.545의 ≥70%가 item×seed 귀속이며 쌍대화+ANCOVA로 제거 가능 → N_REQ 53→≤15.
- **DV**: 블록당 EXP−control 잔차 sd — (a) CRN 쌍대화 후 (b) base-ckpt per-item 점수 CUPED 후.
- **Arms**: 기존 trace 재분석 + 신규 CRN decode + **A/A placebo arm**(양쪽 다 control = 참값 Δ=0 pedestal — 조정 파이프라인 자체의 거짓양성률 검사).
- **사전 PASS/FAIL**: A/A가 ±MDE TOST 내 **AND** 잔차 sd ≤ 0.25 (= 유효 n 4.8배).
- **비용**: 재분석 $0 · 신규 CRN decode GPU pod ~1h ≈ $1–2 (a_fire_autonomous 1줄 견적 범위).
- **반증되면**: sd가 거의 안 줄면 잡음이 item 내 환원불가(RNG 지배) → 유일한 레버는 n = MoE-capacity 채널은 정직하게 "측정 비용상 미측정"으로 기록(KILL 아님).

## 4. 가장 싼 킬샷

**F13의 sha256 동결 detector 하나에 대한 단발 gain 검산** — 그 detector의 자기 control trace(state/ 기존 JSONL)에 기지 비율 라벨교체로 Δ_true를 주입하고 측정/주입 비를 1점 검산. gain ≪ 1이면 **그 detector가 라이선스한 모든 음성판정이 한 방에 INVALID**. $0 · 기존 파일 · ~1시간. (카드 A의 1-rung 축약판.)

## 5. 정직 문단

**닫혔다고 볼 근거**: 5대 결함은 전부 실재했고 재현됐다. F13의 사전등록 하 부호반전은 잡음의 교과서적 서명이고, sd 0.545에 signed mean ≈ 0인 채널에서 n=20으로 뭔가를 주장하는 것 자체가 무리였다. 찾는 효과가 작다는 것도 여러 lane에서 일관된다. **아직 아니라고 볼 근거**: 이 lane의 모든 판정이 INVALID라는 사실은 대칭적이다 — 기질에 대해 아무것도 확립되지 않았고, "없다"의 증거도 없다. 검정력은 한 번도 충분한 적이 없고(n=20 vs 53), detector 이득은 한 번도 교정된 적이 없어 실재 효과가 압축됐을 가능성이 열려 있으며, CLOSED 철회의 사유가 정확히 "가설이 아니라 계기가 실패했다"였다. 정직한 현재 상태: **벽이 아니라 계기 미인증**이며, CAL-6과 POW-X(및 A/A 안전핀)를 통과하기 전까지 이 lane의 어떤 KILL도 원장에 🧱로 기록되어선 안 되고, 어떤 GREEN도 마찬가지다.
