# 4차 적대검증 (self-refute) — 사전등록 판정을 흔들어 본다

**결론: STILL INVALID(sham 4번째 붕괴)를 유지. 담체 성공(+13 부호안정)은 적대검증을 견딤 = licensed.**

1. **"a_comp 승리 = detector 동어반복 아닌가?"** — a_comp는 순간 slack=S−L 극단만 본다(모델-free·myopic).
   헤드라인은 warm-window **정상상태** min(L,S) 시간평균(그 사이 damage/repair 동역학 개입). myopic 국소정책이
   정상상태를 올리는 건 자명하지 않다. 그럼에도 오라클(전모델 정상상태 최대화, 준-동어반복 상한)에 붙었다 =
   설정이 아니라 **결과**. detector 근접성은 코드 헤더에 사전 공시. ⇒ 동어반복으로 기각 불가.

2. **"sign_all_pos가 tune-to-green 아닌가?"** — 상수/규약/arm/detector 실행 전 고정, 한 번 발사, 사후 이동 0.
   부호는 데이터가 정했다(a_comp 최소 우위 +1.99 @LIVE repair 끝점 = 아슬한 게 아니라 전 축 여유+). o_health는
   같은 프레임에서 +1.75/+1.34로 blind 근처(3차엔 뒤집힘) = 담체가 결과를 만든 것이지 튜닝 아님.

3. **"sham FAIL을 tune-to-red로 죽이는 것 아닌가?"** — sham tag_gap=0.000은 실측 붕괴(범주 tag 동질화). 임계
   0.30을 아무리 낮춰도(0.05?) blind 0.002와 구별 불가. 붕괴는 임계 아티팩트가 아니라 구조(보존적 융합의 신호
   동질화). 사전등록이 sham distinct를 hard-gate로 못박았고 실패 = 정직한 INVALID. 사후에 gate를 풀어 PASS로
   만들면 그게 F8/F13 진범(사후 detector 교체) = 금지. ⇒ INVALID 유지가 정직, tune-to-red 아님.

4. **"guard_off atp=88이 a_comp보다 높다 = a_comp가 약한 것 아닌가?"** — guard_off는 G2 degeneracy 진단 arm
   (sibling-ban/쿨다운 OFF → fission 직후 동일쌍 재융합 = 무료 ATP). a_comp는 guards ON에서 71로 정당.
   guard_off의 self_remerge 폭증이 왜 G2 guards가 load-bearing인지 실증 = 방어 작동 증거.

5. **미채점의 정확한 위치:** 3차는 PRIMARY 부호가 뒤집혀 미채점(담체 결함). 4차는 PRIMARY 부호안정 성공,
   sham 통제 구축 불가로 미채점(통제 결함). 결함이 담체→통제로 한 칸 이동 = 담체 질문은 사실상 답(YES,
   부호불변, 오라클급)을 얻었고, 남은 건 통제 형식 하나. 이는 3차보다 엄격히 전진한 INVALID.
