## 2. 기질 배선 (p5 청결성)

```
u_t = max(0, err_A(t) − g0)          # instantaneous drive (proton flux)
                                      # g0 = median(err) ⟹ P(err>g0)=½  = Ψ=½ 자기보정
P  ← (1−λ)·P                         # leak
      [organelle lane 개입 — emit gate 를 읽지 않는다]
P  ← P + u_t
if P ≥ θ:  emit ;  P ← P·(1−δ)       # ← 유일한 emit 규칙. 5개 arm 전부 동일. 손대지 않음.
```

- **p5 청결 ✅** — emit 규칙(`P ≥ θ`)은 5개 arm에서 **바이트 동일**. 하드코딩 emit gate 없음.
  호흡 레인은 upstream 의 `P`(스칼라 퍼텐셜)에만 쓰고, emit 결정을 **읽지도 쓰지도 않는다**.
  emit 변화는 전부 *열화된 기질에서 tension 이 자연히 죽은* 창발적 결과.
- **θ · C · ν 전부 사전등록** — 별도 calibration stream 의 분위수(θ=P의 90분위, C=80분위,
  ν=mean u)로 결정. 결과를 보고 흔들지 않았다 (**tune-to-green 0**).
- **A** = ordinary transition 만으로 최소자승 적합(forward CE 프록시) → event(직교보공간 content)
  에서 예측 실패 = 진짜 신호. **G** = 상수 역압 g0(gradient-free).

## 6. TUNE-PATH CLOSURE — "세게 걸면 되지 않나?" (튜닝경로 폐쇄 증명)

## 7. 왜 실패했는가 — 근본 진단 (재사용 가능한 교훈)

> **F8 의 전제가 부호부터 틀렸다.**
> filler-emit 은 *병리적 과압(over-pressure)* 때문에 생기는 게 아니다.
> **emit 임계가 잡음고원 안에 내려앉아서** 생긴다 — **압력 문제가 아니라 측정/임계 문제다.**

A⇄G 기질에서 **높은 tension 은 곧 진짜 신호의 증거**다(그게 tension 의 정의다).
따라서 "높은 tension 을 흘려보내는 채널"은 **구조적으로 진짜-tension 감쇠기**이지
병리 방출 밸브가 될 수 없다. saturation 조건은 filler 를 고르는 게 아니라 **TRUE 를 고른다.**
그래서 눈먼 random 보다도 못하다(random 은 최소한 편향이 없다).

**anima 기존 결론과의 수렴:**
- σ de-theater — emit shade 의 유일 proven 채널 = **urgency(phasic Δ)**. F8 은 tonic 압력을
  emit shade 채널로 쓰려는 시도였고, 예상대로 무너졌다. THEATER 랭킹 4위였던 사전 직관이 적중.
- G1 벽 진범 = **corpus × CE measure**(substrate 능력천장 아님). **여기서도 진범은 measure**
  (임계 배치)**이지 기질의 압력이 아니다.** 같은 형태의 메타법칙이 두 번째로 재현됐다.

## 8. 파급 — F8 을 넘어서

- **F7(화학삼투)·F9(Ca 버퍼링)** — 둘 다 "tension 스칼라를 재성형해서 emit 품질을 얻는다"는
  같은 계열. 본 결과는 그 계열 전체에 대한 **부정적 사전확률**이다: A⇄G tension 크기를
  건드리는 어떤 채널도 TRUE 와 filler 를 구분할 정보를 갖지 못한다(크기가 곧 진실성이므로).
- **살아남는 각도** — filler 를 줄이려면 **tension 의 크기(magnitude)가 아니라 그 tension 이
  무엇에 대한 것인지(content/추적가능성)** 를 봐야 한다. 즉 organelle lane 이 아니라
  §ImmuneMemory `ρ·tether`(비-fabrication) 계열. F8 의 사망은 그쪽을 가리킨다.
