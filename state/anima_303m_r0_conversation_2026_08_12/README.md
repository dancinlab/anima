# Anima 303M R0 meaningful-conversation rebuild — 2026-08-12

Status: **COMPLETED — FAIL-MEANINGLESS-CONVERSATION.** R1 and production deployment remain locked.

This run repairs the measurement and data failures found by the 25 local micro experiments. It uses
only the canonical Python `anima-py` corpus, train, evaluate, serialize, and chat paths. It does not
extend or execute Hexa. The in-progress Hexa removal is an intentional user change and remains part
of the working tree.

The first R0 question is now whether the native 303M byte mouth can hold a meaningful Korean and
English conversation. A response fails when it is empty, invalid UTF-8, mostly in the wrong
language, a copy of the question, dominated by repeated n-grams, duplicated across unrelated
questions, irrelevant to the registered semantic concepts, or unable to use a fact/correction from
the preceding turn. Raw generated bytes and scored text are both retained. A passing automatic
score is not by itself a production approval: every registered response must also receive a manual
meaning review, and eventual staging must pass real FIFO/reply ownership plus live Korean and
English user QA.

Pre-model scorer calibration raised the prompt-echo ceiling from the initial draft `0.75` to
`0.90`: the registered correct correction answer necessarily repeats “favorite color is purple”
from the question and scored `0.8333`, while a copied question remains `1.0` and is still rejected.
This change was made before any new checkpoint was decoded and is covered by positive and negative
scorer controls; the value is now frozen for this run.

The previous `broad_dialogue`, `en_sns`, and `ko_sns` cells are excluded from this new run. Sampling
showed that they contain synthetic generic replies, language mixing, persona fragments, and
question/answer mismatches of the same shape as the reported meaningless production output. They
remain immutable in their old HF revisions and historical results. The replacement mixture uses
clean general-language cells plus human OpenAssistant English conversations and KLUE MRC Korean
question-answer records. Source commits and licenses are pinned in `protocol.json`.

Training and validation are separate files. General-text records are normalized, exact-deduplicated,
and assigned by a deterministic document hash. OpenAssistant retains its tree-level official split;
KLUE retains its official example split. A final cross-cell normalized-hash audit must find zero
train-to-validation overlap before upload. Before any training, documents containing an exact
normalized registered panel user turn are removed and reported as evaluation decontamination; the
post-filter audit must retain zero matches. This rule was frozen before the data build and model run.
The immutable result is uploaded to a private dataset in
the HF `dancinlab` organization; the trainer receives only pinned `hf://datasets/...@commit/...`
URIs. No model or training dataset is retained as a local production source of truth.

`protocol.json` is the execution SSOT. `conversation_panel.json` is fixed before any new checkpoint
is trained. The order is:

1. certify the conversation scorer on its registered good and meaningless controls;
2. build, deduplicate, split, upload, and hash-verify the four data cells;
3. run a tiny Python corpus → trainer → checkpoint → conversation evaluator flow locally;
4. run one fixed seed-7 303M checkpoint on a full 24–48 GB Vast.ai GPU, not an H100;
5. evaluate meaningful conversation first;
6. only after that automatic gate and a complete manual meaning review pass, run the remaining
   language/reach diagnostics and consider multi-seed R0;
7. R1 recurrent workspace remains locked until the multi-seed R0 protocol is separately registered
   and passed;
8. record pass or failure without changing data, seed, endpoint, decoding, panel, or bars, upload
   model evidence to private HF `dancinlab`, commit and push, then delete the Vast.ai instance.

`ING.jsonl` and `stream_mi.json` are existing user files and must remain untouched.

## Result

The fixed seed-7 run completed all 14,000 steps on a Vast.ai L40S 48 GB. It used the private,
immutable dataset revision
`dancinlab/anima-303m-r0-conversation-data-2026-08-12@42fadd08f88cb3b74757b373629d2d7910ca35ec`.
The dataset audit retained 638,420 documents, found zero train/validation exact-hash overlap and
zero remaining panel contamination, and reported 430 near-duplicate pairs without filtering them.
All eight training/validation files were downloaded from the immutable revision and SHA-256
verified.

Training itself descended: CE moved from `5.63180` to `0.71687`, and all four held-out cells stayed
below uniform CE. That did not produce a usable conversation model. The final equal-cell validation
CE was `1.49157`: English general `1.19245`, Korean general `1.07143`, English dialogue `1.40510`,
and Korean dialogue `2.29729`. The dialogue cells worsened while training loss kept falling. The
1.30 MB Korean QA train cell received the same round-robin byte budget as the approximately 57 MB
general cells, making repeated dialogue exposure the strongest shared data/sampler root-cause
candidate. This is evidence against the fixed recipe, not proof that 303M capacity is insufficient.

The meaningful-conversation scorer controls passed, and GPU decode passed all three NumPy/CuPy
parity regressions. The final conversation result then failed decisively:

- English semantic relevance: `0/7`; structural form: `2/7`.
- Korean semantic relevance: `0/7`; structural form: `7/7`.
- All four final multi-turn memory/correction answers failed.
- Manual review found `0/14` meaningful, relevant answers.
- “Why does ice feel cold?” produced an unrelated carbon-monoxide recommendation.
- “얼음은 왜 차갑게 느껴지나요?” produced `모스크바 3상회의`.
- The remembered cat-name question produced `영지주의자`; the corrected favorite color produced
  `아이폰5s`.

This is the exact failure the new gate was designed to catch: syntactically valid Korean can still
be unrelated retrieval-like fragments rather than conversation. Per the registered order gate,
remaining reach diagnostics, R1 recurrent workspace, serving, and production deployment were not
run.

The failed engine checkpoint, exact-resume checkpoint, training summary, logs, data manifest,
protocol, panel, and all 14 lossless responses are private in
`dancinlab/anima-303m-r0-conversation-seed7-2026-08-12@ff2ccc5c945bfb6f5e1765948591cd8fb6cc3db9`.
Nine registered artifacts were downloaded from that revision and SHA-256 verified. Full structured
evidence is in `result.json`.
