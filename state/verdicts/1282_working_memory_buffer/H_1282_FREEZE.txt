TASK — DELAYED-MATCH (DMS) / n-back, p7 deterministic
────────────────────────────────────────────────────────────────────────────
Each trial: PRESENT a cue item (a DIM-vector token), then N DISTRACTOR steps
(each a fresh random non-cue token streamed through the same lane), then PROBE:
present a query that is EITHER the cue (match-trial) OR a foil (nonmatch-trial);
the system must decide MATCH iff the maintained item == the probe.
Metric = delayed-match ACCURACY as a function of distractor length N
        (accuracy = mean over match+nonmatch trials, balanced).

ARMS (pre-registered):
  (A) NO WM BUFFER — rely on the flat decoder context window of fixed size W.
      The cue is "in context" only if it lies within the last W streamed
      tokens at probe time. With N distractors, the cue is N steps back; once
      N >= W it has SCROLLED OUT → A must guess (chance) → sharp collapse.
      W frozen at 4 (a small fixed window; the decoder cannot hold > W back).
  (B) GATED WM BUFFER lane — K slots, each (activation vec, gate). On the cue:
      GATE-IN (admit, set activation high). Each distractor step: LEAK all
      activations ×λ (volatile), and the distractor weakly gates in (capacity
      pressure / displacement of the weakest slot). At probe: nearest-slot
      match; MATCH iff best slot activation × similarity >= θ. Graceful decay:
      activation falls smoothly with N, so accuracy degrades gracefully and
      stays above chance well past W.
