TASK — MEMORY RECALL UNDER SHIFTING LOAD (p7, exact ground truth):
  A population store binds facts (key→value) as immune/clonal cells (H_1227/1231
  paradigm). Keys = byte-trigram FNV-1a hashed to DIM=16 vectors (H_1227 key).
  Each "fact" = a distinct key; recall = nearest-cell fires, ABSTAIN if recon-err
  beyond an abstain margin (no fabrication). We stream a sequence of (write | recall)
  events under load and measure end-to-end recall accuracy + non-fabrication.

  CAPACITY-BOUNDED store (max_cells < #facts) so plasticity/split policy MATTERS —
  on an unbounded byte-exact store everything saturates (H_1230 lesson: clean
  associative store has no headroom). Cells evict LRU when over capacity.

THREE REGIMES (the controller must win across ≥2, not one tuned point):
  R1 STABLE      : fixed fact set, low key noise σ=0.01, no drift. Tests that
                   adaptation does not HURT the easy stationary case.
  R2 DRIFT       : fact values periodically REWRITTEN (concept drift) — old binding
                   must be overwritten; high-surprise events recur. Plasticity
                   should RISE on drift, FALL when stable (ACh expected-uncertainty).
  R3 NOISE-BURST : key noise alternates low(0.01)↔high(0.05) in bursts; bursts are
                   UNEXPECTED uncertainty — controller must NOT over-split on noise
                   (the H_1230 self-inflicted-forgetting failure mode: over-eager
                   split pins duplicate cells → crowd → LRU-evict OTHER facts).

NEUROMODULATOR (ARM B) — substrate state → knobs, NO loss term (p7, p8):
  state per tick = (surprise s = recon-err of current key, confidence margin m =
  gap between nearest and 2nd-nearest cell, reward r = +1 on a correct recall else 0,
  running expected-uncertainty û = EMA of surprise).
  ACh plasticity  : LR(t)    = clip(LR0 * (1 + kA*(s - û)), 0.05, 0.60)
                    (raise plasticity on UNEXPECTED surprise s>û; calm when s≈û)
  ACh/novelty split: THRESH(t)= clip(TH0 * (1 + kT*û),       0.15, 0.60)
                    (RAISE the split bar when expected-uncertainty is high = noise
                     regime ⇒ DON'T over-split on noise, the H_1230 guard; LOWER
                     when calm ⇒ readily allocate a cell for a genuinely new fact)
  NE exploration  : abstain margin widened by current û (cautious under noise).
  DA gain         : reward EMA scales the winner-pull on CORRECT recalls (consolidate
                    what works): LR(t) *= (1 + kD * reward_ema). gain∈[1,1.5].
  All knobs are READ-OUTS of substrate state computed under no-grad; NONE is added
  to any objective/loss. ARM A holds (LR0, TH0) FIXED at their grid-tuned best.

ARMS (identical store, seeds, fact set, event stream, capacity; ONLY policy differs):
  A FIXED   : best (LR0*, TH0*) found by a SMALL grid on a SEPARATE tuning seed
              (not a scored seed), then HELD CONSTANT across all 3 regimes. This is
              the strongest honest fixed baseline (one global operating point).
  B NEUROMOD: (LR0, TH0) = A's tuned constants as the BASE, modulated per-tick by
              the neuromodulator above. Same base → any lift is from ADAPTATION.

CONTROLS:
  (1) param/budget matched — same max_cells, same #events, same key dim, same seeds.
  (2) A is TUNED (grid over LR0∈{0.1,0.2,0.3,0.4}, TH0∈{0.2,0.3,0.4}) so the
      baseline is the BEST fixed point, not a strawman.
  (3) shuffle control C-SHUF: B's knob schedule REPLACED by a time-shuffled
      (phase-scrambled) version of the SAME knob values — destroys the
      state→knob COUPLING but keeps the marginal distribution. If C-SHUF ≈ B then
      the lift is from knob VARIETY not context-COUPLING (a non-finding).

METRIC (p7, exact — NO LLM judge, NO perplexity):
  capability(regime) = recall_accuracy - fabrication_rate
    recall_accuracy = #(correct recalls) / #(recall events)
    fabrication_rate = #(confident WRONG recalls on out-of-store / stale keys) /
                       #(recall events)  [abstain is NOT a fabrication]
  Report per-regime mean over seeds for A, B, C-SHUF.

≥3 seeds (rng = [11, 22, 33]); tuning seed = 7 (DISJOINT from scored seeds).
