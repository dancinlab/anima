MECHANISTIC READ (honest, c9 — appended after scoring, NO bar move)
================================================================================
The BOUNDED metric did its mathematical job: separation-AUC is in [0,1] and chance
is the FIXED constant 0.5, so the H_1343 unbounded-ratio explosion (~45) and its
floating null (+9.28) are gone. BUT the label-shuffle null STILL floats — at 0.9919,
nowhere near 0.5. This is a DEEPER, more honest finding than the metric defect:

  ROOT CAUSE = the SELF-REFERENTIAL partition. The AUC partitions adjacent pairs into
  WITHIN/BETWEEN by the STORE'S OWN learned category (g >= 0.5). The error-targeted
  SPLIT-only Voronoi store PACKS prototype cells along WHATEVER boundary it is trained
  on — INCLUDING a random/shuffled carving. So the soft posterior g ALWAYS jumps
  sharply exactly where the store placed its boundary, and the handful of BETWEEN edges
  (the ones straddling that learned boundary) ALWAYS have larger |Δg| than WITHIN edges.
  AUC -> ~1.0 for ANY internally-coherent carving, shuffled or not. A label shuffle
  produces a DIFFERENT (jagged) boundary, but the store learns THAT boundary just as
  faithfully and the within/between separation is just as crisp -> null ~0.99.

  In short: "is the metric warped relative to the store's own learned categories?" is
  a near-tautology for a store that fits its categories well. It tests metric COHERENCE,
  not metric WARP that is SPECIFIC to the language's TRUE boundary.

DISCRIMINATING CONTROL (load-bearing): c3 COMPONENT-COUNT is the only control that uses
an EXTERNAL, language-independent partition (a random feature-component median split,
NOT the store's self-consistent learned category). It COLLAPSED cleanly to chance:
L_DIAG comp-AUC 0.485, L_LSHAPE 0.506 (|Δ| 0.015 / 0.006 <= COMP_TOL 0.08). This proves
the warp does NOT live in arbitrary raw variance — it is real and tied to a coherent
learned partition. But c2 shows that coherence ALONE (any carving) reproduces it, so the
AUC-vs-own-partition readout cannot ISOLATE the TRUE-language boundary from a random one.

BASELINE DIAGNOSTIC corroborates: the pre-language g0 baseline AUC is already HIGH
(L_DIAG 0.930, L_LSHAPE 0.681) under the true-label partition — because a smooth feature
gradient also separates between vs within when the boundary is axis/diagonal aligned.
This is exactly why H_1343 SUBTRACTED a baseline; the bounded AUC has no clean subtraction.

WHAT WOULD ACTUALLY EARN IT (next angle, NOT done here — frozen-first, no post-hoc bar):
The correct anti-Goodhart control must hold the PARTITION FIXED to the TRUE language
boundary while varying ONLY the trained metric — i.e. score AUC of the SHUFFLE-trained
metric g_shuffle UNDER THE TRUE-LANGUAGE WITHIN/BETWEEN partition. Then a shuffle-trained
store (which packed cells on the WRONG boundary) would NOT separate the TRUE between/within
pairs -> AUC -> 0.5. The H_1343/H_1358 family scored each arm under ITS OWN partition,
which is the confound both rounds hit from opposite directions (ratio explosion / AUC
saturation). That fixed-true-partition readout is H_1359's frozen design.
