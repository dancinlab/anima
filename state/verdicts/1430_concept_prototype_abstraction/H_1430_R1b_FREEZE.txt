R1 DEGENERACY (measured diagnostic on aiden):
  - PROTO_SEP=6.0 is only a FLOOR; random uniform-[-5,5]^24 prototypes land at ~16.4
    actual pairwise L2 (the floor almost never binds) -> categories trivially apart.
  - At NOISE_TRAIN=NOISE_TEST=1.0 in DIM=24: a sample sits d~5.3 from its OWN proto
    but d~19.5 from the nearest OTHER proto (margin ~ +14.2). The noise ball is far
    inside the Voronoi cell of its own category, so 1-NN EXEMPLAR already classifies
    every novel instance perfectly (A=1.000). With A saturated, the prototype lane has
    NO headroom to beat it (c2) and ablating B to exemplar mode loses nothing (c4).
  The Posner-Keele prototype-EFFECT only exists in the HIGH-DISTORTION regime, where
  novel instances scatter widely enough that the category MEAN (centroid, which
  averages noise toward the true proto) outperforms any single noisy stored exemplar.

R1b FIX (geometry only — bars unchanged):
  (1) CONTROLLED separation: prototypes placed on an orthogonal-axis frame scaled to
      EXACTLY PROTO_SEP pairwise (proto c = e_c * PROTO_SEP/sqrt(2), + a small random
      rigid shift per seed), so separation is a KNOWN constant, not an accident of
      dimensionality.
  (2) HIGH distortion: NOISE_TRAIN/NOISE_TEST large RELATIVE to PROTO_SEP so the noise
      ball overlaps neighbouring Voronoi cells -> individual exemplars are unreliable,
      the averaged centroid is reliable. NOISE_TEST > NOISE_TRAIN so novel-test
      instances are FARTHER out than anything trained — the exact condition under which
      a stored exemplar is a worse anchor than the abstracted mean (Posner-Keele 1968).
  (3) ABSTAIN_D / FOIL_MIN re-scaled to the new distance regime so the NO-FAB far-foil
      test (c5) and the in-category accept band stay well-posed.

RATIONALE for the band (pre-registered, $0-checkable): in DIM=24 a gaussian-noise
sample sits at radius ~ std*sqrt(DIM) from its centre. The centroid's expected error
to the true proto ~ NOISE_TRAIN/sqrt(N_TRAIN) ~ 1.06, far inside PROTO_SEP, so B stays
accurate; a single noisy exemplar sits at radius ~ NOISE*sqrt(DIM) and a novel-FAR test
instance is an unreliable nearest-neighbour anchor, so A/Babl degrade. FOIL_MIN=14 vs a
typical in-cat nearest-centroid distance ~1.06 keeps the foil ABSTAINED (>ABSTAIN_D=10)
while an in-cat instance is ACCEPTED.
