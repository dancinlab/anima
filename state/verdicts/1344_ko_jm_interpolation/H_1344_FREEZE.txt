  The Korean byte-LM floor is REPRESENTATION-bound: NFD jamo decomposition dropped held-out KO
  next-symbol CE from raw-byte 2.95342 to 2.51335 nats/UTF-8-byte (H_1316 🟢, GREEN+wired H_1321).
  Below-jamo attempts (H_1322 featural) are 🧱 (data-richness limited; opaque count-MLE is
  info-optimal at dense 30MB). The 2.51335 floor was reached by a FIXED-CAPACITY gradient-free
  Voronoi MITOSIS over a 3-D context (GROW_MAX=40). The genuine *language-modeling* question it
  never asked: a non-fragmenting frozen-λ Jelinek-Mercer interpolation that MIXES jamo-level
  n-gram orders (1..N) with a PRE-REGISTERED λ schedule — does mixing higher-order jamo context
  (which a single mitosis partition cannot hold) dip BELOW 2.51335, or confirm the floor?

  WHY NOT MITOSIS: a single Voronoi partition with GROW_MAX cells can only condition on a fixed
  low-D feature vector; it CANNOT smoothly back off from a sparse high-order jamo context to a
  dense low-order one. Jelinek-Mercer interpolation is the classic NON-FRAGMENTING fix: every
  order's count-MLE is computed on the FULL stream (no count fragmentation across cells), and a
  FROZEN λ mixes them. If higher-order jamo structure carries exploitable signal beyond what
  the floor captures, JM-interp dips below 2.51335; if the floor is data-richness-bound, it does
  not (honest 🧱, valid result c9).

REPRESENTATION (identical jamo symbolization to H_1316 — byte-fair axis)
  Scan UTF-8 codepoints. Hangul syllable U+AC00..U+D7A3 → one SYMBOL per NFD jamo (id 256+rank);
  non-Hangul codepoint → one SYMBOL per raw byte (id 0..255). Each symbol carries n_bytes that
  SUM to the source UTF-8 bytes (3-jamo→[1,1,1], 2-jamo→[2,1], 1→[3]; raw byte→1). Lossless axis.
  CE axis = Σ(−log p(sym)) / Σ(n_bytes(sym)) over the HELD-OUT split — the SAME nats/UTF-8-byte
  axis as the 2.51335 floor (apples-to-apples). Vocab Vj == 323 (built over the FULL 30MB window).

HELD-OUT SPLIT
  Even/odd symbol-position split at ko_stride=300 (the SAME held-out construction the floor used:
  decimate by stride, then even index = TRAIN, odd index = TEST). All counts built on TRAIN ONLY;
  scored on disjoint TEST. NO test symbol contributes to any order's counts.

METHOD — frozen-λ Jelinek-Mercer interpolation over jamo n-gram orders (NON-FRAGMENTING)
  For max order N (pre-registered N=5), build order-k jamo count-MLE tables (k=1..N) on TRAIN with
  add-LAPLACE=1.0 smoothing of the UNIGRAM only (higher orders backed off purely by interpolation,
  the classic JM recipe — NO per-order Laplace fragmentation). The model prob of the next symbol
  given its (N−1)-jamo history h:
      p_JM(s|h) = Σ_{k=1..N} λ_k · p_k(s | last (k−1) symbols of h)
  where p_k is the order-k count-MLE on TRAIN, p_1 is Laplace-smoothed unigram (no zeros), and
  Σ λ_k = 1. Counts are computed on the FULL TRAIN stream per order (NO fragmentation across cells
  — this is the whole non-fragmenting point vs mitosis). When an order-k context is UNSEEN on
  TRAIN, p_k falls back to the order-(k−1) estimate INSIDE the same recursion (standard JM
  recursive back-off), so every order always returns a proper distribution.

  FROZEN λ SCHEDULE (pre-registered HERE, NOT tuned to TEST — the whole anti-Goodhart point):
    N=5, λ = [λ1,λ2,λ3,λ4,λ5] = geometric emphasis on higher order, normalized:
      raw weights w_k = 2^(k-1)  → w = [1,2,4,8,16], λ = w / Σw = [1/31, 2/31, 4/31, 8/31, 16/31]
      i.e. λ ≈ [0.03226, 0.06452, 0.12903, 0.25806, 0.51613].
    This schedule is FIXED before any TEST score is computed. It is NOT optimized, NOT EM-fit,
    NOT grid-searched on the test set. (A separate NON-GATING diagnostic may report an EM-fit
    λ* on TRAIN-only for context, but the GATING bar c1 uses ONLY this frozen λ.)
