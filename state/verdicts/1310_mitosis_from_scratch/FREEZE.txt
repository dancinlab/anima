THE QUESTION (deepest p8): can a next-byte model be grown FROM SCRATCH by mitosis
ALONE — seed = ONE cell, split-only under next-byte error pressure, GRADIENT-FREE —
and HOW does its held-out next-byte CE compare to a gradient baseline of MATCHED
effective capacity? Honest hypothesis to test/possibly REFUTE: pure-mitosis cells are
LOCAL experts (Voronoi/nearest-neighbor over byte-trigram features). Without a learned
deep representation underneath, pure mitosis may hit a LOWER ceiling than gradient — it
tiles the input space but builds no compositional depth. That ceiling, if real, is a
first-class result (c9), NOT a failure.

CORPUS (REAL English bytes, reproducible):
  source = /usr/share/dict/words (system fixed asset), filtered isalpha 2..12 chars,
           lowercased, Random(13100).shuffle, first 4000 words, space-joined+newline,
           truncated to 24000 bytes.
  sha256 = 86864aa32dcf1c8680ab254e1b28357bf0326c8d45a86837ae4e3b9d09350f62
  size   = 24000 bytes · alphabet = 27 symbols (a-z + space/newline collapsed)
  split  = first 80% bytes = TRAIN, last 20% = held-out TEST (deterministic, disjoint).

FEATURE (shared by ALL arms; the byte-trigram context, a_no_llm_frame_trap — local
columns over recent-byte context, NOT a deep net): for predicting byte t, the context
is the previous 2 bytes (order-2). Mitosis cells partition this 2-byte context space;
each cell holds an online next-byte frequency table over the bytes it owns.

ARMS (3 seeds = [13101, 13102, 13103]):
  B_scratch  = from n_cells=1 (one prototype = the all-context centroid), mitosis-grow
               ONLY: walk TRAIN bytes; on each byte the nearest cell predicts; when a
               cell's running owned-error (1 - p(true byte)) exceeds SPLIT_THRESH and a
               budget slot is free, the ERROR cell SPLITS (mitosis: bisect its owned
               context territory by median, two children re-seed at half-centroids).
               GRADIENT-FREE. Evaluated at a frozen cell-budget LADDER.
  A_gradient = gradient-trained softmax next-byte head over the SAME order-2 context,
               one-hot context features, full-batch SGD CE. MATCHED-capacity comparator
               (capacity matched at the 512-cell rung: ~ K_context effective params).
  A_freq     = order-2 Markov (add-1 smoothed trigram counts) — the n-gram floor.
  B_shuffle  = CONTROL: same budget ladder but split a RANDOM cell each step (not the
               error cell) — mis-targeted growth, same capacity, wrong place.

CELL-BUDGET LADDER (frozen): [1, 8, 64, 512] cells. Report held-out CE at each rung.

METRIC: held-out next-byte CROSS-ENTROPY in NATS (mean -log p(true byte)), deterministic.
  Lower = better. NEVER perplexity-as-verdict (p7); CE reported directly.

FROZEN BARS (set BEFORE scoring; mean over 3 seeds at the TOP rung = 512 cells):
  (1) PRESENCE: B_scratch CE DROPS MONOTONE as cells grow 1->8->64->512
      (CE[512] < CE[64] < CE[8] < CE[1], each strictly; learning happens from nothing).
  (2) THE KEY GAP (B_scratch[512] vs A_gradient): report GAP = CE_B - CE_A (nats).
        GAP <= +0.10 nats          => "MATCHES gradient" (within a tenth-nat).
        +0.10 < GAP <= +0.50 nats  => "near gradient (small ceiling)".
        GAP > +0.50 nats           => "HONEST LOCAL-EXPERT CEILING" (plateaus above
                                       gradient; needs a learned representation under it).
      (frozen interpretation thresholds — the result is whatever it is, c9.)
  (3) FLOOR: B_scratch[512] CE < A_freq CE - 0.02 nats (mitosis beats n-gram counting;
      else mitosis is not even learning structure → honest RED on the floor).
  (4) CONTROL COLLAPSE: B_shuffle CE-vs-cells curve does NOT improve like B_scratch —
      specifically B_shuffle[512] >= B_scratch[512] + 0.10 nats (error-targeting is what
      drives the learning, not merely adding capacity).

VERDICT TIERS (frozen):
  GREEN-MATCH   = bars 1,3,4 PASS AND GAP <= +0.10 (from-scratch mitosis MATCHES gradient).
  GREEN-NEAR    = bars 1,3,4 PASS AND +0.10 < GAP <= +0.50 (real path, small ceiling).
  HONEST-CEILING= bars 1,3,4 PASS AND GAP > +0.50 (mitosis LEARNS + beats n-gram + is
                  error-targeted, but plateaus above gradient = local-expert ceiling;
                  a FIRST-CLASS c9 result, the thesis "structure-bound not capacity-bound").
  FLOOR-FAIL    = bar 3 FAILS (mitosis does not beat n-gram) → RED.
  NO-LEARN      = bar 1 FAILS (CE does not drop with cells) → RED.
  CONTROL-LEAK  = bar 4 FAILS (shuffle improves as much → capacity not targeting) → RED.

SCOPE (a_toy_scale_recheck · a_scale_honest_scope): TOY/DIRECTIONAL. 24KB English,
order-2 context, 3 seeds. Tests the STRUCTURE of from-scratch pure-mitosis learning
(matches-gradient vs ceiling), an EXISTENCE-PROBE, NOT a production "anima trains from
scratch" claim. Engine-transfer + scale + higher-order-context UNVERIFIED. If the result
is HONEST-CEILING we report the gap, we do NOT claim mitosis trains from scratch.
