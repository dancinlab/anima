R3 ANGLE (a_break_the_wall / c16 — the R2 follow-on, verbatim: "a sharper error-
concentration target to fire c2"):
  Use a target where error CONCENTRATES at sharp, localized boundaries so error-targeted
  split MUST beat random split. LANGUAGE / BYTE-TEXT is exactly such a target: token /
  morpheme / syllable boundaries + a heavy-tailed byte distribution put nearly all of the
  predictive uncertainty at a FEW context regions (word/syllable starts) while long
  stretches (mid-multibyte UTF-8 continuation, repeated function words) are near-
  deterministic. A trainer that SPENDS its growth where error concentrates (boundary
  contexts) should beat one that splits at random (which wastes cells on the already-easy
  deterministic region). This is ALSO a direct step toward the standing goal of training
  KOREAN: the corpus is real Korean + English UTF-8 bytes (V256), so a GREEN here makes a
  real (larger) Korean mitosis-grow training rung a legitimate next, cost-gated rung.

TASK (next-byte prediction on real Korean+English UTF-8 bytes, V256):
  Corpus = a small fixed Korean+English byte string (declared IN the script, provenance-
  visible; mixed Hangul 3-byte UTF-8 + ASCII English + punctuation/space). Build supervised
  pairs (context -> next byte) over the byte stream with context length CTX=4 bytes.
  CONTEXT FEATURE (the partition key, kept low-dim so the SAME R2 Voronoi mechanism applies):
  for each position, a fixed deterministic feature vector phi(context) in R^3:
    f0 = last byte value / 255.0                 (the strongest next-byte predictor)
    f1 = (2nd-last byte value) / 255.0
    f2 = utf8_continuation_depth / 3.0           (how deep we are inside a multibyte run:
         0 at an ASCII / lead position, rises 1..3 across a Hangul 3-byte sequence — this
         is the deterministic structural signal that makes mid-sequence bytes near-certain
         and boundary bytes uncertain; computed mechanically from the byte values, NO labels)
  This feature is a fixed function of the raw bytes (NO learned embedding, NO gradient).
  TRAIN/TEST split: deterministic interleave (even idx -> train, odd idx -> test) so the
  two halves cover the same contexts disjointly. 3 seeds [770,771,772] (seed perturbs only
  tie-breaking + arm A init + shuffle-arm RNG; the corpus + features are seed-independent).

ARMS:
  A GRADIENT  — fixed-size softmax classifier over V256 on phi(context): a single linear
    layer W (V256 x 3) + bias, full-batch CROSS-ENTROPY gradient descent (standard backprop).
    INCUMBENT control. params = V256*(3+1) = 1024.
  B MITOSIS-GROW — gradient-free hard-partition mitosis (R2 mechanism, ported to
    classification): start 2 cells (centroids in feature space); each context owned by its
    NEAREST cell centroid (Voronoi). Per-cell head = empirical next-byte frequency table
    (closed-form MLE, add-1 Laplace smoothing over V256) on OWNED training points only —
    the categorical analog of R2's local least-squares head, still NO global backprop.
    SPLIT the cell with the highest LOCAL (owned) train CROSS-ENTROPY; split = bisect the
    owned points at the MEDIAN of their highest-variance feature axis, recenter on the two
    half-centroids (data-matched median split + centroid recenter, exactly R2). Finite
    GROW_MAX.
  B-SHUFFLE — split a RANDOM eligible cell (not the highest-CE one). On a sharp target this
    MUST now collapse vs B (the c2 discriminator R1/R2 could not fire). If it STILL does not
    collapse, that is an honest WALL + a real finding: error-targeting does not help even on
    sharp targets.
  B-ABLATE — growth frozen at the 2 start cells (no split ever) -> must underfit.

METRIC (p7 — legitimate for a CONVERGENCE/optimization comparison, NOT perplexity-as-meaning):
  primary = held-out next-byte CROSS-ENTROPY (nats/byte) on the test split.
  also reported: known-byte top-1 ACCURACY (argmax next-byte == true next-byte) as a simple
  coherence check (NOT perplexity-as-truth).
