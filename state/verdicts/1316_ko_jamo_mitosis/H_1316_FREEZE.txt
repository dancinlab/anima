--- REPRESENTATION (the jamo lens) --------------------------------------------------------------
  SYMBOL STREAM: scan the UTF-8 codepoints of the corpus. For each codepoint:
    - if it is a precomposed Hangul syllable (U+AC00..U+D7A3): NFD-decompose to its L/V/T jamo
      sequence (2 or 3 conjoining-jamo codepoints U+1100.. / U+1161.. / U+11A8..) and emit one
      SYMBOL per jamo.
    - else (ASCII, spaces, punctuation, other scripts): emit one SYMBOL per the codepoint's UTF-8
      bytes? NO — to keep the alphabet small and the next-SYMBOL task well-posed, NON-Hangul
      codepoints are emitted as a SYMBOL per BYTE (raw byte id 0..255), so ASCII/markup is byte-LM
      identical to the raw lane there. Hangul is the ONLY thing that changes representation.
    => SYMBOL ALPHABET = {0..255 raw-byte ids} ∪ {distinct jamo codepoints seen}. Vocab Vj.
  EACH SYMBOL carries n_bytes = the number of UTF-8 bytes it accounts for (raw byte=1; a jamo =
  its share of the syllable's 3 bytes, distributed so the per-syllable jamo n_bytes SUM to exactly
  the syllable's UTF-8 byte length (3) — L=1,V=1,T=1 for a 3-jamo syllable; L=2,V=1 (or 1,2) for a
  2-jamo syllable so the two sum to 3). This makes the byte-accounting EXACT and lossless.
