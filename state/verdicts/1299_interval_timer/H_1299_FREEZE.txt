  noisy stream, not a copy of a single literal. Init D̂_0 = 5 (uninformative; ≠ 8,13,20).
  Learning rule (running mean, gradient-free): on each observed event, gap = t − t_last;
  D̂ ← (1−lr)·D̂ + lr·gap, lr = 0.5 (B), lr = 0.0 (B-ABLATE).
