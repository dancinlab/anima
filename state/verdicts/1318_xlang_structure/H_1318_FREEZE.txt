TWO representations per language
--------------------------------
  RAW    : raw UTF-8 byte stream (the per-language ceiling).
  STRUCT : decompose into the script's compositional units where they exist, then
           re-encode each unit as bytes and run the SAME mechanism over that
           unit-byte stream.
  Decomposition per script:
    Korean (Hangul)   : NFD jamo — each precomposed syllable -> 초/중/종성 (L/V/T)
                        codepoints (Unicode NFD); re-encode NFD as UTF-8 bytes. TEST.
    Chinese (Han)     : per-Han-char Kangxi-radical decomposition (unicodedata +
                        a CJK radical map): char -> [radical-codepoint, residual-char];
                        non-Han chars pass through. compositional #2.
    Japanese (kanji+kana): kanji -> radical (as Chinese), kana atomic (pass through). mixed.
    Russian (Cyrillic): NONE possible (alphabetic) -> STRUCT == RAW path. multibyte-no-
                        composition control.
    English (Latin)   : NONE possible (alphabetic, 1 byte/char) -> STRUCT == RAW. FLOOR.

FAIR SAME-AXIS CONVERSION (load-bearing — stated explicitly, c9)
---------------------------------------------------------------
RAW and STRUCT both report CE in **nats per UTF-8 byte of the ORIGINAL raw text**,
so they are directly comparable on ONE axis regardless of how many units STRUCT
emits. Concretely:
  CE_axis = (total held-out next-UNIT negative-log-likelihood, summed over all
             predicted units in the held-out split)
            / (number of UTF-8 bytes in the ORIGINAL raw held-out text).
For RAW the unit IS the byte, so this is the ordinary nats/byte. For STRUCT the
NLL is summed over decomposed-unit predictions and divided by the SAME original
raw-byte count, converting per-unit CE back to the nats/raw-UTF-8-byte axis. The
denominator (original raw UTF-8 byte count of the held-out text) is IDENTICAL for
RAW and STRUCT of a given language, so Delta is a like-for-like compression gain.

Delta_lang = RAW_CE - STRUCT_CE   (positive = structure helps), mean over 3 seeds.
