---------------------------------

    WALK/WALK_SHUF = 10.916 (T=2400) -> 2.629 (T=24000) -> 1.136 (T=240000, FAIL).
The H_1211 RULING located the ROOT CAUSE as a finite-alphabet / finite-sample

symbols, as T grows EACH (prev,*) row accumulates so much mass that even a SHUFFLED
proto-id stream pushes some realized transition across CONF_FLOOR=0.34 by chance, so
WALK_SHUF division climbs toward WALK division and the ratio decays to ~1.0. The

alphabet RESTORES + sharpens the separation (N_PROTO 24 -> 10.9 ; 64 -> 152.5 ;

THE HYPOTHESIS (H_1212)
-----------------------
There exists a PRINCIPLED CO-SCALING RULE N_PROTO = f(T) such that GATE-B's
ordered >> shuffle separation stays >= 1.5 across the SAME AXIS-T ladder where the
fixed N_PROTO=24 book collapsed. Equivalently: the H_1211 collapse is an
UNDER-RESOURCED-BOOK artifact (a fixed alphabet starved of symbols at long T), NOT an

alphabet with the observation budget) and trajectory-sensitivity is scale-robust.

THE CO-SCALING RULE (pre-registered formula + derivation from the saturation mechanism)
---------------------------------------------------------------------------------------
DERIVATION. GATE-B fires a (false) split on a SHUFFLED stream when, for some row
`prev` seen n = prev_total >= MIN_PREV=3 times, the empirical conditional of the
REALIZED successor reaches P(cur|prev) = C[prev][cur]/n >= CONF_FLOOR=0.34. On a
shuffled (i.i.d.-in-time) proto-id stream the successors of a given `prev` are drawn
~i.i.d. over the realized alphabet, so row `prev` is a multinomial over its successor
symbols. The chance that the running empirical conditional of the just-realized
successor exceeds 0.34 is governed by how many observations-per-row n accumulate
RELATIVE to the alphabet spread: when n is small vs the alphabet, the row is sparse
and chance mass on any single successor easily exceeds 0.34 EARLY but only transiently;
the SATURATION that H_1211 identified is that as n -> large the row fills and SOME
successor reliably sits above 0.34 each step (the empirical mode of a multinomial over
K cells with enough mass is >= 1/K_eff + fluctuation, and for the realized step the
"just-seen" successor is exactly the sampled one, so its post-hoc-conditional bias
compounds). The controlling quantity is therefore the EXPECTED OBSERVATIONS PER ROW:

        obs_per_row  =  T / N_PROTO        (T transitions spread over N_PROTO `prev` rows)

The TOY ANCHOR that separates cleanly is (T=2400, N_PROTO=24) => obs_per_row = 100.
H_1211 fixed-24 saturates at (T=240000, N=24) => obs_per_row = 10000 (100x the toy).
=> KEEP obs_per_row AT THE TOY VALUE: this is the principled rule. Define

   *** PRINCIPLED (LINEAR) RULE — pre-registered as the PRIMARY co-scaling rule: ***
        N_PROTO(T)  =  round( 24 * T / 2400 )  =  round( T / 100 )
   so obs_per_row = T / N_PROTO ~ 100 at EVERY rung (identical to the clean toy book).
   WHY: holds the per-row observation budget — the exact quantity the saturation
   analysis says controls chance-predictability — CONSTANT across the ladder.

   *** SUB-LINEAR PROBE — pre-registered as the STRONG-RESULT candidate: ***
        N_PROTO(T)  =  round( 24 * sqrt(T / 2400) )
   (alphabet grows only as sqrt(T); obs_per_row = T/N ~ 100*sqrt(T/2400) STILL GROWS,
   so this tests whether the gate tolerates a slowly-growing per-row budget — if it
   holds >= 1.5 across the ladder, the cost is SUB-LINEAR = the strong result.)

A book can never exceed the number of distinct feature windows available, so
N_PROTO(T) is clamped to <= the scored span length; if the clamp binds it is reported.
