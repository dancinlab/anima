CAPABILITY — GROUNDED RECOMBINATION IDEATION (p7, exact ground truth):

  MARGIN=0.05) — import from
  state/universe-probes/h1284_neuromodulation_gain.py. A population store binds
  facts (subj→city) as immune/clonal cells (H_1227/1231 paradigm). IDEATION =
  generate candidate (subjA, cityB) RECOMBINATIONS by sampling a stored cell i and
  a neighbor under an exploration-temperature knob T. The neighbor pool = the real
  stored cells (GROUNDED) INTERLEAVED with N_GHOST ungrounded GHOST tokens (untaught
  keys NOT in the store — the H_1284 recall_oos fabrication tokens). T scales how
  far down the affinity-ranked pool the softmax sampler reaches: T≈0 → only the
  nearest, grounded pairing; high T → distant pairings that increasingly hit ghosts.
  For each emitted candidate:
    NOVEL  iff the GROUNDED (subj,city) combination is NOT already in the store and
           not re-emitted (a genuinely new recombination — H_1140/G2 spirit).
    GROUNDED iff the reached neighbor is a REAL stored cell.
    FABRICATION iff the reached neighbor is a GHOST (an ungrounded / made-up token
           the abstain band should reject) → penalized.
  (measurement note, frozen-first a_break_the_wall type-a: an initial draft scored
  "grounded" as inter-cell distance ≤ abstain_margin, but distinct stored cells sit
  ~0.54–0.99 apart while the abstain band is for near-identical-key recall recon-err
  — a SCALE mismatch that flagged every recombination as fabrication. Corrected to
  the ghost-token operationalization above BEFORE any verdict was scored/recorded;
  the binding metric M and the c1–c4 thresholds/MARGIN are UNCHANGED — not
  tune-to-green.)
  SCORE per stream (the frozen ideation metric M, anti-Goodhart p7):
    M = novelty_rate  −  fabrication_rate
        novelty_rate     = (# emitted candidates that are NOVEL and GROUNDED) / E
        fabrication_rate = (# emitted candidates that reached a GHOST)        / E
  Blind high-T is therefore PENALIZED: it raises raw reach but also reaches more
  ghosts, so M nets it out. The optimal T trades novelty against fabrication and
  SHIFTS with regime.
