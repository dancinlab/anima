WHY A CLOCK IS DISTINCT FROM EVERY LANE (load-bearing, the (ii) requirement):
A circadian/interval clock is a SELF-SUSTAINING PHASE OSCILLATOR that advances on
ELAPSED TICKS ALONE — its phase = (tick_count mod PERIOD)/PERIOD, REGARDLESS of any
regulated variable, content, context, or grounding. It FIRES at phase boundaries on a
fixed schedule, and crucially it is NOT reset by a consummatory/grounding event.

THE LANE = CircadianClock: a phase oscillator with a fixed PERIOD. It holds ONLY its own
integer tick counter `t` (the sole mutable state). phase(t) = (t mod PERIOD)/PERIOD in
[0,1). It FIRES (a scheduled "wake"/salience pulse) when t mod PERIOD == 0 (the phase-0
boundary). step() advances t by 1 REGARDLESS of any argument — no context, no key, no
immune store read. It NEVER reads grounding, NEVER mutates any other lane, NEVER touches
pure_field Phi/phase/Psi (Psi-disjoint by construction). It is NOT an emit gate —
clock_fire() is an OPTIONAL scheduling pulse a caller MAY consult
(a_autonomy_over_hardcode), exactly as homeo_motivation_bias / spatial_map_nearest are
optional reads.

THE FALSIFIER (signal lives ONLY in periodic elapsed-tick phase, never in content):
A grounded, constant context is streamed for N_TICKS. Each tick the harness asks each arm
"FIRE NOW? (a scheduled wake pulse)". GROUND-TRUTH fire schedule = phase-0 boundaries
(ticks 0,8,16). The metric sched_acc = BALANCED accuracy over the two classes {fire-tick,
no-fire-tick} so a constant predictor (always-fire or never-fire) scores 0.5 by
construction (chance). The clock matches the schedule exactly → 1.0. The homeostat under
constant grounding cannot match a fixed period → ~chance.
