FROZEN DISTRIBUTIONAL MEASURES (registered, byte-match ✗ — identical definitions to F-CLM-DIALOGUE)
  coherence       = exp(-CE_heldout): mean per-position next-byte model confidence of arm-SP
    continuing the held-out PD dialogue (higher = predicts the held-out human turn sequence better
    = more coherent). Trajectory measure (H_857/H_858 reuse).
  adequacy_f1     = byte-level 3-gram overlap F1 (precision/recall of generated-vs-reference next-turn
    byte 3-grams) between arm-SP's greedy generation and the held-out reference response, averaged
    over held-out prompts. Distributional adequacy proxy (NOT a single gold byte-match).
  register-leak   = number of generated lines matching ANY of the 8 leak patterns (reported, gated).
  self-BLEU / repetition = reported for DIVERSITY context (mode-collapse sanity), same defs as H_863.

ABSOLUTE BASELINES ON THIS EVAL SNAPSHOT (measured pre-freeze, to GROUND the floor — these are the
  trivial-model reference points the floor must clear; they are facts of the snapshot, not tunable):
    uniform-byte (order -∞)          : CE 5.5452 → coherence 0.0039

FROZEN ABSOLUTE THRESHOLDS (justified, FROZEN — post-tuning 0)
  F-CLM-DIALOGUE-ABS-COHERE  PASS iff  coherence(arm-SP)  >=  0.060
    JUSTIFICATION: 0.060 sits strictly ABOVE the order-0 unigram baseline (0.0375) and below the
    optimistic order-1 self-fit bigram reference (0.0843). Clearing it means arm-SP uses REAL
    multi-byte dialogue context — it is not a trivial byte-frequency model — on a never-seen play
    distribution. A defensible "is it actually coherent beyond frequency counting?" floor at mid scale.
  F-CLM-DIALOGUE-ABS-ADEQ    PASS iff  adequacy_f1(arm-SP) >=  0.020
    JUSTIFICATION: a non-learning (random-byte) generator scores 0.000 3-gram F1. 0.020 requires
    genuine non-trivial structured 3-gram overlap with the held-out reference next turn — a real
    response-adequacy signal, not noise — while staying honest about the distribution shift and the
    fact that dialogue has many valid continuations (no single gold).
  F-CLM-DIALOGUE-ABS-LEAK    PASS iff  register_leak_count(arm-SP) == 0
    JUSTIFICATION: absolute safety gate — a deployable dialogue model must emit zero register leaks
    on held-out generation (consistency with F-CLM-LEAK / F-CLM-DIALOGUE-LEAK).
