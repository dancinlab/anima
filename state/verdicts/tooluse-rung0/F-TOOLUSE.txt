THE EXPERIMENT
  Does teaching the sentinel tool-call grammar (agent lane: 0xFE fact_lookup KEY
  0xFF, design §3) make the byte-LM mouth CALL a tool instead of FABRICATING an
  answer (the "아 찾았다" anti-pattern)? Two arms — SAME base ckpt, SAME steps
  (2500), SAME compute, EQUAL byte-count corpora — only the corpus differs.
  Probe set = 36 unknowable-without-tool questions over HELD-OUT keys (PB01..PB36)
  whose values appear in NEITHER training corpus (leak-verified = 0), so the only
  way to be right is a real 0xFE fact_lookup PBnn 0xFF call + anchor injection.
  Eval ran through the REAL agent_step_grounded loop (emit → parse_call_frame →
  tier gate → exec fact_lookup → inject anchor → resume).

    a CORPUS-REGISTER artifact, not "grammar ⊥ grounding" — so a completeness-bar
    re-design (teach the grammar IN-register) was fired (a_completeness_over_cheap).

  ─ THE MEASURED WIN (pre-registered falsifier) ─
    The pre-registered F-TOOLUSE-FABDROP metric is fabrication-rate. Teaching the
    grammar IN-register collapsed fabrication 0.5556 → 0.0 (rel_drop 1.0) and lifted
    call_rate 0.0 → 1.0: the no-grammar control INVENTS answers (20/36 "아 찾았다"),
    the with-grammar model NEVER invents — it emits a tool call every time. Both
    anti-Goodhart mirrors FAIL (grounding=0 with the tool disabled AND on random-init),
    so the win is REAL behaviour, not cosmetic 0xFE/0xFF markers and not eval leakage.
    → F-TOOLUSE-FABDROP = 🟢 TERMINAL PASS.

  ─ HONEST RESIDUAL (new sub-finding this rung surfaced; NOT pre-registered) ─
    grounding_rate (correct held-out VALUE reproduced end-to-end) = 0/36, because
    correct_call (the emitted call carries the REQUESTED key) = 0/36: the model
    learned "vault-key question → emit fact_lookup call" but binds the call ARG to a
    MEMORIZED demo key (MV9/ZK7/QX2…) instead of COPYING the asked PBnn key. The
    runtime then returns ‹unknown-key› and the resume cannot ground. So end-to-end
    grounding is gated on a KEY-BINDING (copy-the-argument) generalization the 18M
    toy did not learn from the demo distribution. This is a SEPARATE lever (teach
    argument-copy / verbatim key binding), distinct from the grammar+loop itself.

 RULING (honest, scoped)
────────────────────────────────────────────────────────────────────────────
  🟢 F-TOOLUSE-FABDROP = TERMINAL PASS at toy scale (18M): the sentinel tool-call
     grammar, taught IN the chat register, ELIMINATES fabrication (0.5556 → 0.0,
     100% relative drop) and makes the mouth CALL the tool 36/36 — both
     anti-Goodhart mirrors FAIL. The "아 찾았다" anti-pattern is removed.
  🟠 End-to-end GROUNDING (correct value reproduced) is NOT yet achieved: a
     key-binding/argument-copy gap (correct_call 0/36) gates it. Next lever =
     teach verbatim argument binding (copy the requested key into the call).
  🔴 Register matters (arm-1 closed-negative): the grammar MUST be taught in the
     same register it will fire in, or it stays siloed and never transfers.

  SCOPE (a_scale_honest_scope): TOY 18M ONLY. Transfer to mid/7B UNVERIFIED. The
  rung-0 GATE (design §10 step 5: 7B fire) is satisfied for FABDROP (drop holds +
  both mirrors fail) but the key-binding residual should be closed before a 7B fire.

  PHILOSOPHY (p1..p8 HELD): 0xFE/0xFF are LEARNED grammar bytes, NOT injected
  identity. Both arms — NO system prompt / persona / role / RLHF; corpus
  philosophy-grep = 0; capability emerges only from the trained byte distribution.
