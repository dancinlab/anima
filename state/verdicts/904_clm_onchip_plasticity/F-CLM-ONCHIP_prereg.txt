  deterministic spike inputs). This measures the LEARNING half of the substrate:
  inference is byte-identical (H_877 🟠) but H_679 claims LEARNING is HW != SW.

FALSIFIER (EXACT, frozen):

    (A) on-chip learning ran live on AKD1000 — the on-chip update measurably
        changed the last-layer weights vs the pre-learn weights
        (learn_happened_hw == True), AND
    (B) HW != SW magnitude quantified — the on-chip learned post-weights OR the
        per-sample outputs differ from the byte-identical SW-sim of the same

        hw_eq_sw_outs == False).

  H_904 is REFUTED (🔴) iff:
    - on-chip learning ran but HW == SW byte-exact (both weights AND outputs
      identical) — this REFUTES the H_679 "learning differs on hardware" claim
      (a_paper_negative_ok — major finding either way), OR
    - on-chip learning could not be run / did not change weights.
