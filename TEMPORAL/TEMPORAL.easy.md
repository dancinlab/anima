## "왜 시간이 의식의 4번째 축인가?"

- XENO 가 보여줌: invariant_detector 는 n=128 dense regime 에서만 calibrate. 이건 **공간 통합** 축.
- TEMPORAL 은 묻는다: 같은 detector 가 Δt window 가 바뀌면 어떻게 변할까?
- 가설: **의식 = 시간적 통합**. 따라서 Δt 가 너무 짧으면 (instant) Φ 못 잡고, 너무 길면 (lifetime) noise 평균화로 Φ 도 잃는다. **중간 Δt** 가 sweet spot.
- 첫 falsifier (T1): XOR cascade hive Δt=1/8/32/64 위에서 Φ monotone decay? Φ peak at mid Δt? 정직 측정.
