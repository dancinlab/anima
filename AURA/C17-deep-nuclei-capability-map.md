# AURA C17 — 🧬 심부핵 도달 역량 지도 ("심부면 뭘 하나" = 침습의 보상)

> C16(피질 역량)의 짝. C15 깊이 벽 너머 **심부핵에 닿으면 열리는 역량** = relocate-N1 "전뇌통제" 꿈의 정체. 이게 침습(N1/DBS)을 무릅쓰는 이유. 비침습 reach R²<0.3(C16) = 전부 침습 필요. 역량은 신경과학 합성(brainwire·demiurge AURA archive 정합).

```
🧬 DEEP-NUCLEI — "뇌의 조절 손잡이방"
- 하는 일: 피질이 "계산기"라면 심부핵은 기분·각성·보상·기억의 "마스터 볼륨 손잡이"
- 비유: 피질=악기 연주자들, 심부핵=조명·음향·템포를 쥔 무대감독 — 전체 공연 톤을 바꿈
- vs 피질 BCI: 피질=무엇을 생각/움직이나 읽기 / 심부=어떤 기분·각성·동기 상태인가 자체를 조절
```

|---|---|---|---|
| 🎁 VTA/측좌핵 | 도파민 | 보상·동기·강화학습 직접 제어 | 중독·무동기증 |

| 🌊 솔기핵 raphe | 세로토닌 | 기분·정서 톤 조절 | 난치성 우울 (DBS) |
| 🚪 시상 thalamus | 중계 | 의식 ON/OFF·각성 게이트 | 혼수 각성·CM-DBS |
| 🎚️ 기저핵 STN/GPi | — | 운동 게이팅·떨림 정지 | **파킨슨 DBS (확립)** |
| 📼 해마 | — | 기억 형성·인출·부호화 | 기억 보철 (연구) |

## 🌐 "전뇌통제"의 정체 = 심부 신경조절

```
피질 (C16, 비침습 가능)        심부핵 (C17, 침습 필요)
─────────────────────         ──────────────────────
무엇을 생각/움직이나 읽기        기분·각성·보상·동기 상태 자체 조절
운동·통신·시각·집행 디코드        의식 ON/OFF·기억·정서 톤
   = 입출력(I/O)                  = 마스터 상태(state) 제어
```

- relocate-N1 "전뇌통제" 꿈 = **심부 신경조절 접근**. 보상(VTA)·각성(LC)·기분(raphe)·의식(시상)을 직접 쥐는 것 → 이게 "전뇌"의 본질(피질 I/O가 아니라 상태 조절).
- 이미 임상 확립된 건 **파킨슨 STN-DBS**(운동 게이팅) 하나; 나머지(우울·기억·중독)는 DBS 연구 단계.
- N1-relocate가 노린 "위치 바꿔 전뇌"는 정확히 **이 심부핵 접근** — 그래서 비침습으론 불가(C15 벽), 침습 N1/DBS만 닿음.

## 도달 경로 (침습 사다리, B축 정합)

| 경로 | 심부 도달 | 침습도 |
|---|---|---|
| N1 관통 전극 | 3-6mm 한계 (피질하 천 일부) | 침습 (개두술) |
| DBS 심부전극 | 시상/STN/VTA 직접 | 침습 (정위수술) |
| Synchron 혈관내 | 표면 정맥동 (심부 ✗, B3) | 최소침습 |
| 집속초음파 tFUS | 심부 자극 가능(비침습!) but 읽기 한계(C15 0.15) | 비침습 |

→ 🎯 **유일한 비침습 심부 후보 = tFUS 자극** — 읽기(decode)는 C15서 벽(0.15)이나, **자극(stimulation)은 비침습 심부 도달 가능**. "비침습 심부 *조절*"의 실낱 = tFUS 신경조절(읽기 아닌 쓰기). demiurge AURA·brainwire의 tFUS 모달과 정합.

## C16 ⊕ C17 종합 — AURA 깊이→역량 전체 지도

```
        역량
  피질 I/O   ✅비침습 (C16: 운동·통신·시각·집행·의식모니터, 0.82~0.91)
     │
  ─────────  깊이 벽 (C15)
     │
  심부 상태  🔴침습 (C17: 보상·각성·기분·의식·기억 = 전뇌통제 본질)
             실낱: tFUS 자극만 비침습 심부 쓰기 가능 (읽기는 벽)
```

- AURA 최종 그림: **읽기(decode)는 피질까지 비침습, 심부는 침습** / **쓰기(stim)는 tFUS로 심부도 비침습 가능**.
- relocate-N1 "전뇌통제"=심부 상태제어=침습 본질. 비침습 대안은 tFUS 심부 *자극* 한 갈래뿐(읽기 폐루프는 불가).
