# H_188 — Clinical Φ Correlation Cluster

## Hypothesis

anima Φ-proxy 가 임상-/biological 의식 측정과 cross-validate 되는 두 paradigm 의 cluster.

1. **Hc_921 (PCI/TMS-EEG clinical)**: Massimini 2013 PCI (Perturbational Complexity Index) 의 TMS-free 16ch OpenBCI surrogate + Stage-2 fluidity-dFC + functional-repertoire 가 method-validated (6/6 PASS at 0.25 cutoff, w6=0.10 UNCHANGED, sample-size 1). 임상 골드스탠다드 (Massimini 2013) 도달 후보.
2. **Hc_924 (Octopus per-arm Φ exclusion)**: Octopus 8-arm 분산 nervous system (2/3 뉴런 arm) 의 per-arm Φ가 독립적이면 IIT exclusion postulate (consciousness 는 unique maximal Φ complex) falsification 후보. '8 minds in one body' community-of-minds 가설의 first empirical test 후보.

종합: anima 는 simulation 이지만, biological-/clinical-measurement 과 의 cross-validation 이 anima Φ-proxy 의 외부 anchoring 을 결정한다. 두 Hc 가 같은 'clinical anchoring' lane 을 형성한다.

## Honest Limits (≥6)

- **L-H188-1 (CLINICAL)**: **anima is a simulation, not a biological measurement** — cross-validation against actual clinical data is the only real falsifier; literature-comparison alone is weak. Inherited from Hc_921/Hc_924 L-CLINICAL.
- **L-H188-2 (SAMPLE)**: **sample-size 1 → not statistically meaningful** — Stage-2 6/6 PASS is method-validated only; N=1 cannot distinguish 'true correlation' from 'lucky single subject'.
- **L-H188-3 (TMS-FREE GAP)**: **TMS-free OpenBCI surrogate vs real TMS-EEG has unvalidated validation gap** — Hc_921 cannot claim PCI-equivalence until cross-validated against a real-TMS dataset.
- **L-H188-4 (IIT 4.0)**: **IIT exclusion postulate formal statement 미정확** — Hc_924's 'maximal Φ complex uniqueness' depends on which IIT version (3.0 vs 4.0); claim's falsifiability requires fixing the IIT spec first.
- **L-H188-5 (ETHICS)**: **octopus per-arm Φ measurement requires invasive neural recording or terminal EM tracing** — ethical (IRB / animal-welfare) constraints likely defer the direct experiment for years; literature meta-analysis is the actual achievable path.
- **L-H188-6 (ENGINE)**: **anima Φ-engine substrate-specific (H_174 D-mod-192 aliasing)** — anima-Φ values are not formal-IIT Φ; engine internal state may dominate measurement. PCI / octopus correlation may reflect engine artifact rather than substrate property.
- **L-H188-7 (CUTOFF POST-HOC)**: **anima 0.25 cutoff selected from larger parameter family** — w6=0.10 UNCHANGED label is method-validated but 0.25-cutoff anchor is post-hoc; pre-registration of cutoff value relative to Massimini PCI threshold absent.
