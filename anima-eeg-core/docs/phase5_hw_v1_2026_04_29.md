## Mock vs Real Mode (raw#10 honest)

Legacy `anima-eeg/board_health_check.hexa` and `eeg_recorder.hexa` have a
strict argv parser that does not handle `hexa.real` binary path prefix.
Per raw#18 we do **not** modify legacy. Instead:

- **selftest mode** in `board_health.hexa` and `recorder.hexa`: the
  wrapper synthesizes a minimal honest mock kv-block (16-ch all alive
  / 2-segment synthetic) — the legacy CLI selftest is bypassed for
  parser compatibility but the mock satisfies the kv-block contract.
- **selftest mode** in `impedance.hexa`, `adjustment.hexa`,
  `headplot.hexa`: forwarded to legacy via `hexa.real <path> --selftest`
  (without `run` prefix — legacy parsers tolerate this form).
- **real mode** (`--check` / `--record` / `--watch` / `--live`):
  forwarded to legacy backend on Mac local USB (raw#42 host always
  Mac local for hardware verbs).

This is honest about the legacy parser limitation and avoids touching
frozen code (raw#18).

## raw#159 RFC Candidates

- **BrainFlow stdin streaming**: recorder currently invokes `.venv-eeg`
  subprocess + captures stdout; a native hexa-lang BrainFlow binding or
  in-process stdin streaming primitive would remove the venv dependency
  and enable in-process segment emission.
- **chflags uchg lock idempotence**: 5 module files locked via
  `chflags uchg`; the dispatcher edit required temporary unlock + re-lock,
  candidate for a `_core/chflags_lock.hexa` helper invocation in the
  Phase 5 commit script.
