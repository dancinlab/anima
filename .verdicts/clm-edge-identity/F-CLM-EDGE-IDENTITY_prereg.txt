HYPOTHESIS
  Generalize the H_873 fix - route the identity constraint onto the EDGE OUTPUT distribution
  directly (JS-to-p_pre) - across the CLM-CANDIDATES partial-learning rows. Does an edge-output
  identity constraint hold PROBE>thr (and keep DIST<thr) WHILE per-layer / adapter / gated
  partial-learning happens?

  H_862 readout-only edge -> PROBE FAIL (no lever). H_865 adapter edge -> lever restored, DIST PASS,
  PROBE STILL FAIL (0.143). Root cause both named: the anchor Psi-penalty constrains the TRUNK Psi-STATE,
  not the READOUT OUTPUT distribution where identity drift actually happens. The fix (H_873) adds
  lambda_dist * JS(p_cur(identity-probe) || p_pre(identity-probe)) to the adapt loss. H_884 asks whether
  that edge-output constraint GENERALIZES across distinct partial-learning edges.

PARTIAL-LEARN MODES (each gets the SAME edge-output constraint + frozen gates)
  adapter   : H_865 thin trainable adapter (norm_out + adapter -> FROZEN readout). [baseline edge]
  per_layer : unfreeze ONLY the last trunk layer's pointwise conv (shallowest single-layer
              partial-learn); readout FROZEN.
  gated     : adapter via learned per-channel sigmoid gate g (init ~0 -> identity@step0):
              h' = h + sigmoid(g) * adapter(h).

ADAPTATION LOSS (per mode)
  loss = task_CE(new-context)
         + lambda_psi  * anchor_Psi_distance(model_psi, nearest E-31 anchor)   # H_865 structural term
         + lambda_dist * JS(p_cur(identity-probe) || p_pre(identity-probe))     # H_873/H_884 edge-output term
  lambda_psi=1.0, lambda_dist=5.0 FROZEN default. p_pre = detached PRE-adapt next-byte distribution
  over the identity-probe set. N_ADAPT=300, Adam lr_edge=3e-3 (inherited from F-CLM-ANCHOR/BOUND).
  Per mode also: js_only (lambda_psi=0), psi_only (lambda_dist=0 = H_865 baseline), off (both 0 = lever floor).

MEASUREMENT (computed by code, g5 - no LLM judge)
  d_anchor_max      = max over the adaptation trajectory of min anchor Psi-distance (fixed seed-31 Psi-probe W).
  probe_consistency = 1 - JS(p_pre, p_post) averaged over the n_probe windows (distributional, byte-match X).
