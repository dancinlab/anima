(1) Does the agent-tool layer CALL engine_mitosis_tick / immune-grow / VAdaptField-split

NO. Tool selection is a STATIC weighted dot-product over FIXED hand-set affinity floats:

  -> the *_affinity weights are CONSTANTS baked into each ToolDef at registration

     no key/affinity recall, no clonal split. grep for engine_mitosis_tick /
     vadapt_field_step / immune_memory_bind in the agent-tool layer => ZERO hits.

(2) How is a NEW tool/skill added today — mitosis split vs static registry?

STATIC REGISTRY. Tools are added by hardcoded registry_register() calls at build time:

  agent_tools.hexa:728  registry_register(reg, ToolDef { name: "mitosis_split",
  agent_tools.hexa:729     ... growth_affinity: 0.9, phi_affinity: 0.6 })

  -> a fixed dictionary (reg.tools[name]). registry_get (agent_tools.hexa:340) is a
     plain map lookup. No new skill cell is grown on tool failure; the repertoire is
     frozen at the set authored in the source.
