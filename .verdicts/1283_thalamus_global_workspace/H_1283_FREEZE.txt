FALSIFIABLE TEST
────────────────────────────────────────────────────────────────────────
4 substrate modules (M = {A, G, mitosis, memory}), each holding a dim-D real
state vector, run for T ticks driven by the SAME external input stream + SAME
seed in both arms. Each tick a module updates from the sources it can see.

  ARM A (DIRECT COUPLING — current architecture):
    module i reads only its direct neighbor(s) in the fixed A⇄G ring
    (A↔G, G↔mitosis, mitosis↔memory, memory↔A). No global view.

  ARM B (THALAMIC HUB — GWT broadcast):
    each tick the hub SELECTS the winning module (max salience = state energy)
    and BROADCASTS that winner's content to ALL modules; every module then
    updates from (its own state + the single broadcast content). One global
    workspace, one winner-take-all relay per tick.

Both arms: identical input, identical seed, identical per-module update gain,
identical tick count. The ONLY difference is the coupling topology (direct ring
vs winner-broadcast hub). Equal compute budget (each module does one update/tick
in both arms).
