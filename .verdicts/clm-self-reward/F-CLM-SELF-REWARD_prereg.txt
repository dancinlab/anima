    B = SFT + self-play          → H_863 (🟢 SUPPORTED-NUMERICAL, mid rung, RELATIVE A/B)
    C = self-reward (RLHF-like)  → THIS H (H_874)
  Method C = a self-scored reward loop. NO external LLM, NO human judge, NO ShareGPT/Alpaca.
  The in-training model generates K candidate continuations per held-out-style dialogue prompt,
  SCORES each candidate with the REGISTERED DISTRIBUTIONAL MEASURES (Q-TRUST A · the same
  coherence + adequacy + DIVERSITY measures H_857/H_858/H_863 use), then TRAINS on the
  HIGHER-REWARD branch (best-of-K, reward-weighted reflux). The reward signal is computed BY
  CODE (g5) from the registered measures — there is NO judge model (g5 · @L4 external-LLM 0).

  H_874 tests whether SELF-REWARD (arm-SR) beats SFT+self-play (arm-SP, the H_863 winner) at
  mid scale.

ARMS (mid A/B, AKIDA-envelope QAT, arm=AB trunk, equal compute budget, seed=42)
  arm-SP  : SFT + DIVERSITY-gated self-play reflux            (the H_863 method-B WINNER baseline)
  arm-SR  : SFT + self-REWARD loop. Per reflux prompt the in-training model samples K candidate
            continuations (temp set), each candidate is SCORED by the registered reward
            (see REWARD below), candidates failing the 8-pattern leak filter or the DIVERSITY
            gate are REJECTED, and the BEST-OF-K (highest reward) surviving candidate is folded

  Both: mid rung d512/L8/E8, int4-sym[-7,+7] STE + act_bits=4, seed=42, EQUAL compute budget

REWARD SIGNAL (registered distributional measures · computed BY CODE · NO external judge)
  reward(candidate) = w_coh · coherence(candidate)
                    + w_adq · adequacy(candidate)
                    + w_div · diversity_bonus(candidate)
  where, per candidate continuation generated for a held-out-style prompt:
    coherence(c)        = exp(-CE) of the model on c given the prompt context (H_857/H_858
                          trajectory measure; higher = better-formed continuation).
    adequacy(c)         = byte-level 3-gram overlap F1 between c and the reference next turn
                          (distributional adequacy proxy; H_863 reuse).
    diversity_bonus(c)  = 1 - self_BLEU(c vs the other candidates for the same prompt)
                          (rewards a candidate that is NOT a near-duplicate of its siblings;
                          discourages mode collapse at SELECTION time).
  A candidate is INELIGIBLE (reward = -inf, never selected) if it matches ANY of the 8 leak
  patterns OR if it violates the per-candidate DIVERSITY gate (self-BLEU >= 0.80 vs siblings).
  Reward weights FROZEN: w_coh = 1.0, w_adq = 1.0, w_div = 0.25. These are the SAME registered
  measures used by the eval — the reward is the eval signal applied at training-selection time,
  which is exactly the RLHF-like self-reward construction (no external LLM/human · g5 · @L4).

HELD-OUT DIALOGUE EVAL (computed by code, g5 — no LLM judge · IDENTICAL to H_863)
  held-out = a disjoint slice of the corpus (seed=863, never trained on, never used as a reflux
  prompt). Generate continuations from each arm on the held-out prompts (greedy + temp=0.8
  sample set), then compute the four distributional measures below over the generated text.
  coherence  = exp(-CE_heldout) — mean per-position model confidence continuing held-out context.
  adequacy   = byte-level 3-gram overlap F1 (gen vs reference next-turn), averaged over prompts.
  register-leak count = number of generated lines matching ANY of the 8 leak patterns.
  self-BLEU  = mean pairwise 4-gram BLEU among an arm's OWN generated responses (mode-collapse).
  repetition = fraction of repeated 4-grams within generated responses.

FROZEN NUMERICAL THRESHOLDS (mid rung · RELATIVE arm-SR vs arm-SP)
  F-CLM-SR-COHERE  PASS iff  coherence(SR)   >  coherence(SP)      (strict · RELATIVE)
  F-CLM-SR-ADEQ    PASS iff  adequacy_F1(SR)  >  adequacy_F1(SP)    (strict · RELATIVE)
  F-CLM-SR-LEAK    PASS iff  register_leak_count(SR) == 0           (ABSOLUTE gate on SR)
  F-CLM-SR-DIV     PASS iff  self_BLEU(SR) < 0.80  AND  repetition(SR) < 0.20  (mode-collapse gate)
  VERDICT 🟢 iff ALL FOUR pass. ANY fail → 🔴 CLOSED-NEGATIVE (a_paper_negative_ok).

  NOTE: COHERE/ADEQ are RELATIVE (SR must strictly beat the H_863 winner SP — multi-turn
  coherence ∧ adequacy). LEAK/DIV are ABSOLUTE gates on SR (register-leak == 0 ∧ no DIVERSITY
  collapse: self-BLEU < 0.8 ∧ repetition < 0.2). This is exactly the W2 contract pre-registered
  for this fire: reward-trained arm > SFT+self-play arm on coherence ∧ adequacy (distributional,
  byte-match ✗) ∧ register-leak == 0 ∧ no DIVERSITY collapse.
