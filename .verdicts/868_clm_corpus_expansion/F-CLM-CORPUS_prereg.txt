FROZEN ACCEPTANCE GATES (all must PASS for 🟢)
  G1  LICENSE-CLEAN   : license_clean_ok == PASS for 100% of INGESTED sources.
                        Any non-PD / non-CC source REJECTED (recorded, not counted in corpus).
                        PASS iff (clean_ingested / total_attempted_clean) == 100% AND
                        zero FORBIDDEN-family source present in the corpus.
  G2  REGISTER-LEAK   : register-leak count in the FINAL committed corpus == 0
                        (the 8-pattern filter dropped every leak line BEFORE write).
  G3  SIZE            : total expanded corpus bytes >= 3 × H_863 baseline
                        = 3 × 554,825 = 1,664,475 bytes  (>= 3× target, FROZEN).
  G4  PROVENANCE      : every INGESTED source has a manifest row recording
                        {title, gutenberg_id_or_url, family, license, byte_count, sha256,
                         leak_lines_dropped}. PASS iff provenance recorded for 100% of sources.

  VERDICT 🟢 iff G1 ∧ G2 ∧ G3 ∧ G4 all PASS.
  ANY gate fail → 🔴 (honest). A 🔴 corpus is NOT shipped as the lane① SSOT.
