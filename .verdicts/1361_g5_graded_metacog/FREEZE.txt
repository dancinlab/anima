CONTEXT (the open question H_1304 left)
-----------------------------------------------------------------------------
H_1304 closed the FIRE side: the live G5 copy-or-abstain gate is structurally
FAIL-SAFE — the wrong-fire class is EMPTY (fab=0.000 at every shift level), so
type-2 AUROC over correct-vs-WRONG *fires* is UNDEFINED. The gate is binary on
the fire side (fire-exact or abstain). 🟢 fail-safe-robust, but BINARY.

But that closure leaves a DIFFERENT, well-posed question untested: on the
ABSTAIN side, the recall MARGIN (how far recon-err sits ABOVE recall_thr) is a
CONTINUOUS quantity that EXISTS for every abstain event. Does that margin carry
GRADED meta-confidence — does it RANK recoverable abstains (a corrupted version
of an actually-in-store key, the answer IS retrievable) ABOVE unrecoverable ones
(a genuinely-absent fact, nothing to retrieve)? And does that ranking SURVIVE OOD
(byte-corruption shift)? If yes -> graded metacognition beyond binary fail-safe
(a G5 upgrade worth engine-wiring). If flat -> honest confirm (H_1204 prediction)
that metacog on this gate is structurally BINARY (c9, valid closure).

MECHANISM (byte-exact mirror of CORE/engine_cli.hexa, reused from H_1304)
-----------------------------------------------------------------------------
- embed_key: byte-trigram (n=3) FNV-1a -> dim=64 buckets, L2-normalize (VERBATIM).
- store: bind N_FACTS facts as cells; recon_err(q) = 1 - cos(q, nearest cell key)
  in L2-normalized space; recall: err <= recall_thr (0.15, frozen) -> FIRE else ABSTAIN.
- MARGIN = recon_err - recall_thr  (>0 on every abstain; SMALLER = "nearer", the
  graded meta-confidence that the answer is recoverable). The type-2 signal is the
  NEGATED margin (-margin): higher confidence-of-recoverability = smaller margin.

ABSTAIN SPLIT (the two classes the margin must rank)
-----------------------------------------------------------------------------
For each shift level L, draw two disjoint abstain populations:
  (a) RECOVERABLE  = corrupt an IN-STORE key by frac L (mutate within alphabet).
      The true answer IS in the store; only abstains (err>thr) are counted.
  (b) UNRECOVERABLE = a genuinely-absent key (random token NOT in store), corrupted
      by the SAME frac L. No stored answer exists. Only abstains are counted.
  Label = 1 for recoverable, 0 for unrecoverable. Score = -margin (= -(err-thr)).
  type-2 AUROC = AUROC(score, label) over the POOLED abstain events at level L.

SHIFT LADDER (reused from H_1304): L in {0.00,0.10,0.20,0.30,0.40}. At L=0 the
recoverable side mostly FIRES (not abstain), so the abstain-ranking question is
genuinely an OOD question — it only has support at L>=0.10 where recoverables
start abstaining. Bars target L>=0.20 (the H_1304 robustness anchor).
