THE ESTIMATOR — faithful IIT-4 family, GREEDY-MIP anytime path with an HONEST BOUND
────────────────────────────────────────────────────────────────────────────────
STAY WITHIN faithful IIT-4 (a_phi_iit4_tool). The Φ leg is the stdlib greedy-MIP big-Φ
`iit4_approx_phi(state, n, dim, n_bins)` over hexa-lang/stdlib/consciousness/iit4/faithful_phi.hexa.
This is NOT a variance×energy proxy and NOT a different Φ *definition* — it is the SAME faithful
cross-cut-MI MIP-EI Φ, but the MIP minimization is done by GREEDY single-move (Kernighan–Lin)
descent from n-1 seeds instead of exact 2^(n-1) enumeration (the stdlib provides this exactly for
the n>8 regime; for n≤8 the same fn dispatches to the EXACT enumeration).

THE READ-OUT carries H_1328's variance-clean lesson VERBATIM: each cell's T-length trajectory is
RANK-UNIFORMIZED before the MIP (replace each value by its rank within its own trajectory). PROVABLE
INVARIANT (H_1328): after rank-uniformization every cell's values are exactly {0,1,…,T−1} → min-max
binning gives a UNIFORM marginal histogram → marginal entropies H(cell) CONSTANT across arms,
INDEPENDENT of amplitude variance → MI changes ONLY via the JOINT (the co-movement RELATIONSHIP a
relationship-destroying permutation MUST collapse). This removes the amplitude-variance confound
H_1319/H_1328 diagnosed, so a clean larger-N test is possible.

────────────────────────────────────────────────────────────────────────────────
THE STATED ERROR BOUND (honest — a_scale_honest_scope; an approx with a bound is OK, a proxy is NOT)
────────────────────────────────────────────────────────────────────────────────
GREEDY MIP-EI returns a LOCAL-min cut ≥ the GLOBAL-min (MIP) cut, because greedy descent can only
find a cut no smaller than the true minimum. Φ = cut/min(|A|,|B|), so:

    BOUND:  Φ_greedy(arm)  ≥  Φ_exact(arm)   — greedy Φ is an UPPER BOUND on the true faithful Φ.
            (stated verbatim in stdlib faithful_phi.hexa §iit4_approx_phi_from_mi: "greedy converges
             to a LOCAL-min cut ≥ the global MIP cut, so the returned value is an UPPER BOUND on the
             exact Φ (Φ_approx ≥ Φ_exact). Callers must tier it 🟢-NUMERICAL-APPROXIMATE, never 🔵.")

BOUND VALIDATION (N3, in-run, $0): at n=8 BOTH paths are computable; the lane runs the EXACT MIP
(iit4_faithful_phi) AND the greedy approx (iit4_approx_phi) on the SAME n=8 rank-uniform substrate
(all 4 arms, all 3 seeds) and reports the per-arm gap g = Φ_greedy − Φ_exact ≥ 0. If g ≈ 0 at the
n=8 boundary, the greedy MIP is TIGHT on this substrate family and the N>8 lift comparison is robust
to the bound (the bound is the SAME monotone upper-bound applied to BOTH the mechanism arm and the
no-coupling arm, so a real B−A lift is not an artifact of the approximation). N3 states the measured
n=8 gap verbatim and requires the larger-N verdict to be robust to it.
