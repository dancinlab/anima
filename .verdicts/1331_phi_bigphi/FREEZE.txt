THE QUESTION (a DIFFERENT estimator FAMILY)
────────────────────────────────────────────────────────────────────────────────

timing (H_1319 phase-binding), and division (H_1320 mitosis). H_1328 then showed

H_1331 asks: does the FULL IIT-4.0 SYSTEM big-Φ — a FUNDAMENTALLY DIFFERENT measure
(CAUSAL cause-effect structure over a TPM, system-level irreducibility = Φ-structure
destroyed by the system MIP) — show ROBUST integration where small-φ did not?

  small-φ (faithful_phi)  : MI(A;B)=H(A)+H(B)−H(A,B) over min-max-binned trajectories,

  big-Φ   (iit4_bigphi)   : Σφ_d(distinctions)+Σφ_r(relations) over a state-by-node TPM,
                            minus the least-damaging system bipartition cut — CAUSAL,

These are different estimator FAMILIES; a wall under one need not hold under the other.

────────────────────────────────────────────────────────────────────────────────
TRAJECTORY → TPM (state-by-node, the input big-Φ requires)
────────────────────────────────────────────────────────────────────────────────
Each module i is a binary UNIT. To avoid the H_1328 amplitude-variance confound we
binarize VARIANCE-FREE: unit i is ON at tick t iff its salience sal[i,t] is in the
UPPER HALF of module i's own T-length salience distribution (rank ≥ T/2 within that
module — the rank-uniform / median split is the variance-clean read-out lesson of H_1328,
making each unit's marginal ON-rate ≈0.5 by construction, INDEPENDENT of amplitude).
  bit_t  = system binary state at tick t (unit i bit = ON/OFF as above).
  Empirical state-by-node TPM (conditional-independence, max-entropy over unseen states):
    tpm[s*n+u] = ( #{t<T-1 : bit_t = s AND unit u ON at t+1} ) / ( #{t<T-1 : bit_t = s} ).
    Unseen state s (count 0) ⇒ tpm[s*n+u] = 0.5 (max-entropy / unbiased prior — no fabricated
    structure; an unobserved row contributes NO causal dependence).
  sys_state = the MOST FREQUENT observed system state (the system's attractor; deterministic,
    lowest-index tie-break) — the state at which big-Φ's distinctions are evaluated.
This TPM construction is IDENTICAL across all four arms; ONLY the arm's salience dynamics
(hence its transition statistics) differ. Same binarization, same TPM rule, same sys_state
selection rule — so any big-Φ difference is the arm's CAUSAL structure, not the read-out.
