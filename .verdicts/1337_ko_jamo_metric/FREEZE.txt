THE NEW MECHANISM (A5 — learned-jamo-metric kernel-smoothed head; the crux)
--------------------------------------------------------------------------------
A5 = the per-cell OPAQUE-jamo count head (identical alphabet/axis to A1) but the per-cell
next-jamo distribution is KERNEL-SMOOTHED over a LEARNED jamo metric, so a count observed for
jamo j ALSO lends partial strength to metric-near jamo j'. The opaque head (A1) cannot do this
— it has no notion that ㄱ~ㅋ — so any lift A5 buys over A1 is the LEARNED-METRIC INFORMATION
the opaque head LACKS (the H_1329 depletion criterion, met by construction).

  Learned metric (TRAIN-ONLY, no test peeking, learned BY GRADIENT — labeled, NOT p8 gradient-free):
   1. Build a jamo×jamo co-occurrence matrix C over the TRAIN stream only: for each adjacent
      jamo pair (j_t, j_{t+1}) in train, C[j_t, j_{t+1}] += 1 (directed bigram counts over the
      jamo-id alphabet, Hangul jamo only; byte symbols excluded from the metric).
   2. PPMI(C) = max(0, log( P(i,j) / (P(i)P(j)) )) — positive pointwise mutual information,
      the standard jamo2vec association weighting.
   3. low-dim embedding E (dim D_EMB=16) = truncated SVD of PPMI (E = U_D · sqrt(S_D)); the
      jamo metric = Euclidean distance in E. THIS IS A LEARNED GEOMETRY (SVD over corpus PPMI),
      NOT the design feature map (which H_1322/1326/1329 already exhausted). To make the
      "learned BY GRADIENT" label LITERAL and unambiguous, E is additionally refined by a few
      gradient steps of a skip-gram-style log-bilinear objective on the train bigrams (Adam,
      FIXED n_steps, TRAIN-ONLY) seeded from the SVD embedding — so the metric is genuinely a
      gradient-learned embedding (jamo2vec), not merely a closed-form SVD. Labeled clearly.
   4. kernel weights: w(j, j') = exp( -dist_E(j,j')^2 / (2 h^2) ), bandwidth h = MEDIAN pairwise
      train-jamo distance (Silverman-style FIXED rule, NO per-run tuning — frozen by the median
      heuristic). Self-weight w(j,j)=1.

  Kernel-smoothed per-cell head (rides the SAME gradient-free Voronoi partition as A1, FIX-A bank):
    raw per-cell count n_k[j] (Laplace=1.0, IDENTICAL to A1's all_heads). Smoothed pseudo-count
    ñ_k[j] = Σ_{j'} w(j, j') · n_k[j']  (kernel-pool neighbor counts over the LEARNED metric),
    then P_k(j) = ñ_k[j] / Σ_j ñ_k[j]. Byte symbols (non-Hangul) scored EXACTLY as A1 (own
    count head, NO smoothing) so the ONLY difference A5-vs-A1 is the jamo-space kernel smoothing
    over the learned metric — isolating the learned-metric information.
    Held-out CE = Σ NLL(P_k(true jamo)) / Σ n_bytes, SAME nats/UTF-8-byte axis as A1/A2/A3/A4.

  WHY this is NOT an H_1329 re-factorization: A4 re-expressed the SAME target P(jamo|cell) via
