FREEZE-DEPTH PARAMETRIZATION (E5 variable-ablation)
  depth = number of TOP trunk layers (highest indices, nearest the readout) made
          TRAINABLE, from 0 .. n_trunk (=8 at mid rung).
    depth = 0       → entire trunk + moe FROZEN, only the H_865 adapter trains
                      (reproduces the H_865 BOUND 🟢 anchor).
    depth = k       → the last k trunk layers (+ adapter) become trainable; everything
                      below (embed, embed_conv, lower trunk, moe, norm_out) FROZEN.
    depth = n_trunk → the WHOLE trunk is trainable (no-freeze / deep end).
  The H_865 adapter (zero-init additive path) is ALWAYS the edge (depth=0 is a real lever,
  not the dead readout-only edge H_861 RED'd).

MEASUREMENT PROCEDURE (computed by code, g5 — no LLM judge)
  For each depth d:
    1. Re-instantiate frozen base; unfreeze the top d trunk layers; insert H_865 adapter.
    2. ce_base_pre, sd_base_pre, ce_new_pre (pre-adapt).
    3. N_ADAPT=300 steps of Adam over the TRAINABLE params (adapter + unfrozen trunk).
    4. ce_base_post, ce_new_post (post-adapt).
    5. z_drop = (ce_base_post - ce_base_pre) / max(sd_base_pre, 1e-6); gain = ce_new_pre - ce_new_post.
