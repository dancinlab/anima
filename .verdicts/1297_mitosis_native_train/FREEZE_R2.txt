ROOT-CAUSE DIAGNOSIS (why R1 walled — the SPLIT GEOMETRY, not p8):
  R1 split = perturb center +/- s/2 AND halve widths; predict = softmax responsibility
  over -dist^2/s^2. Two pathologies compound:
   (i) WIDTH-NARROWING: every split halves widths -> after ~5 splits widths ~ 2^-5,
       so cells become spike-like; a test point between cells falls in NO cell's
       support -> the softmax picks the LEAST-bad far cell -> huge extrapolation error.
   (ii) MIXTURE DEGENERACY: the global softmax mixture lets a far narrow cell with a
        steep local-linear head dominate at points it should not own.
  EVIDENCE this is the geometry not p8: B-SHUFFLE (random split) ACCIDENTALLY keeps a
  few WIDE cells, so it scores BETTER than targeted (0.047 < 0.126) — the targeted rule
  is actively hurting via narrowing. The lift mechanism is sound (ablate underfits,
  c3 PASS); the realization is wrong.

BREAKTHROUGH ANGLE (a_no_llm_frame_trap, biology lens — NOT a tuned knob):
  Real neurogenesis tiles the RESIDUAL territory a parent fails to cover, with a
  receptive field MATCHED to the local data spacing — and cortical columns own
  territory by HARD nearest-assignment (a partition), not a degenerate global mixture.
  R2 changes the MECHANISM accordingly (a principled re-design, frozen anew):
   (1) HARD PARTITION (cortical-column ownership): each train/test point is owned by
       its NEAREST cell center (Voronoi/k-d partition). Local head fit on OWNED points
       only (ordinary least-squares on the owned region). No softmax mixture, no width
       degeneracy. (This is the substrate-native "membrane / self-vs-nonsELF" tiling.)
   (2) DATA-MATCHED SPLIT: a cell splits at the MEDIAN of its owned points' x (the
       point that bisects its territory), spawning two children whose centers are the
       owned-region centroids of each half — capacity grows to MATCH local data
       density, never narrowing below the data spacing.
   (3) split signal UNCHANGED: split the cell with the highest LOCAL (owned) train MSE
       (the error-targeted tick, p8); ablate = no split; shuffle = split a RANDOM cell.
  This is a genuinely DIFFERENT mechanism (hard k-d partition + median-split +
  centroid-recenter), not a re-tuned R1. The split TRIGGER (local-error-targeted) is
  identical, so the controls remain meaningful.
