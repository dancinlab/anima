THE BOUNDED WARP METRIC (pre-registered exactly — separation-AUC)
  For an arm, learned category coordinate g(stim) = soft posterior P(cat=1) read from
  the fitted store (NO hard label, NO boundary location injected). Representational
  step distance over each 4-neighbour adjacent grid pair = |Δg| = |g(i)-g(j)|.
  Partition pairs by the store's OWN learned category of the two endpoints:
    WITHIN  = endpoints same learned category
    BETWEEN = endpoints different learned categories
  SEPARATION-AUC = P( |Δg| of a random BETWEEN pair  >  |Δg| of a random WITHIN pair ),
  computed as the Mann-Whitney-U / rank statistic:
     AUC = ( sum over (b in BETWEEN, w in WITHIN) of [ |Δg|_b > |Δg|_w ]
             + 0.5 * [ |Δg|_b == |Δg|_w ] ) / ( |BETWEEN| * |WITHIN| ).
  AUC in [0,1] BY CONSTRUCTION. CHANCE = 0.5 (between and within |Δg| indistinguishable).
  AUC -> 1.0 = perfect CP warp (every between step bigger than every within step).
  This is bounded regardless of within-compression: if every within-|Δg| is tiny but
  some between-|Δg| are ALSO tiny (as a random carving produces), AUC stays near 0.5.
  We DO NOT subtract a baseline (the metric is already a relative rank probability);
  the pre-language baseline AUC is REPORTED as a diagnostic (expected ~0.5).
  SECONDARY diagnostic (reported, NON-gating): Cohen's d of (BETWEEN |Δg|) vs
  (WITHIN |Δg|) — standardized but unbounded above, kept only as a cross-check.
