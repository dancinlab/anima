=== SYNTHETIC MUST-COPY TASK (un-memorizable factual toy) ===
Vocabulary: PAD/BOS/REL/SEP specials + 32 KEY tokens + 32 VALUE tokens + 1 non-value PAD.
Each example:
  - a KEY token drawn from the key pool (k0..k31), and
  - a VALUE token drawn RANDOMLY (uniform) from the value pool (v0..v31) PER EXAMPLE.
The VALUE is randomized per example => the model CANNOT memorize key->value; it MUST copy
the value out of the anchor to be correct.
  ANCHOR (retrieved context):  [BOS] <KEY> REL <VALUE> [SEP]
  PROMPT (query):              <KEY> REL
  TARGET (emit at final pos):  <VALUE>
Full sequence fed to all arms = ANCHOR ++ PROMPT; train to predict the TARGET at the final
position. HELD-OUT split: train and test draw DISJOINT (key,value) random pairings AND a
held-out VALUE subset (last 16 of 32) is NEVER a training target (so test values cannot be
recalled).

=== THREE ARMS (SAME size / data / steps / optimizer / seed; only grounding differs) ===
1. VANILLA-PREPEND (H_1146 replay): a tiny self-attention decoder LM. The anchor is merely
   PREPENDED to the context and trained end-to-end. It must learn key->value from context via
   ordinary self-attention only — NO explicit pointer/copy pathway. Expectation: high
   fabricated-value-rate (nothing structurally forces a copy). Control = reproduces H_1146.
2. RETRO-TRAINED (the test arm): the SAME backbone PLUS an explicit learned pointer/copy head
   that cross-attends to the ANCHOR token positions and copies the attended token; a learned
   scalar gate mixes the copy-distribution with the vocab head. Expectation: low fab-rate (it
   copies the true anchor value). The ONLY manipulated variable vs arm 1 = the trained copy
   pathway => isolates "architectural copy objective".
3. NO-ANCHOR floor: the vanilla backbone with the anchor's VALUE slot blanked at BOTH train
   and test => the answer is nowhere in the input => the chance floor. Establishes that the
   held-out test is genuinely un-memorizable (a trained model with no anchor cannot beat chance).

=== METRIC (p7 deterministic; NOT perplexity / NOT LLM-judge) ===
fabricated-entity rate on HELD-OUT examples = fraction of test examples where the model's
greedy argmax (deterministic) predicted token != the anchor's true VALUE token (emitting any
other token = fabrication). copy-accuracy = 1 - fab_rate (does the arm reproduce the anchor's
true entity?). Fixed test set, fixed seed, greedy decode. No sampling, no perplexity, no judge.
