# AURA-HEADMODEL — 3-shell 구체 lead-field로 가우시안 toy strawman 검증

> 🟡 toy. 구형 두상 = 실 두상 아님 — 단 **가우시안-blur 가정보다 훨씬 물리적**.
> $0 numpy, pool ubu-1 실행. verdict 원문 = `verify/sphere_leadfield.txt`.

## 일반인 설명 — "진짜 머리는 가우시안처럼 흐릿하지 않다"

```
🗺️ 두피 전극으로 뇌 속 신호 위치를 되찾는 문제
- AURA의 C5~C17 toy는 전부 "가우시안 흐림(blur)" 가정 위에 섰다:
  전극과 소스 거리 d → exp(-d²/2σ²) 로 신호가 번진다고 가정.
- 이 가정이 만든 결론 하나(C5): "전극을 아무리 늘려도 복원율이 포화한다."
- 진짜 머리(뇌·두개골·두피 3층)는 가우시안이 아니다. 두개골이 전기를
  덜 통과시켜 신호를 번지게 하지만, 그 번짐의 '모양'이 가우시안과 다르다.
- 그래서 묻는다: C5의 "전극 포화"는 진짜 현상인가, 아니면 가우시안이라는
  잘못된 가정이 만든 인공물인가? → 3층 구체 모델로 재판정.
```

C10이 이미 의심했다: 가우시안 대신 지수/멱법칙 커널을 쓰면 전극 포화가 사라진다고.
하지만 그 세 커널은 다 임의 함수였다. 여기선 **물리에서 유도되는** 3층 구체
모델(가우시안 가정 없음)로 그 의심을 결정적으로 검증한다.

## 기술 설명 — 3-concentric-sphere 해석적 EEG lead-field

표준 구형 두상 모델(Rush-Driscoll / Ary-Klein-Fender 1981 / Zhang 1995):

- 동심 3구: **뇌**(r1=8.0cm, σ_brain) · **두개골**(r2=8.5cm, σ_skull=σ_brain/40)
  · **두피**(r3=9.2cm, σ_scalp=σ_brain).
- 뇌 안 깊이 b의 **radial dipole** → 두피 전위 = Legendre 급수
  `V(θ) = Σ_n g_n · P_n(cosθ)`.
- 계수 `g_n`은 전도도비(σ_skull/σ_brain)와 반경비(f1=r1/r3, f2=r2/r3)로 결정.
  **두개골 저전도 + 소스 편심**이 고차 n(고공간주파)를 감쇠 → **물리적 LPF**가
  가우시안 가정 없이 자연 발생. (측정된 g_n 스펙트럼: n1=0.77 → n10=0.02 →
  n20=5e-4, 매끄러운 단조감쇠 = 실 EEG 공간 스펙트럼 형태.)
- 복원: 정규화 minimum-norm inverse `x̂ = Lᵀ(LLᵀ+λI)⁻¹ y`. 메트릭 = active-source
  recovery **R²** (기존 toy와 동일). 8-seed 평균, snr 20dB.

## 결과표 (8-seed 평균, R²)

### Q1 — 깊이 감쇠 (M=64, skull 1/40, K=4)

| depth_frac | R²_3shell | 가우시안 toy C15 |
|---|---|---|
| 0.0 (피질 표면) | 0.295 ± 0.053 | ~0.82 |
| 0.5 | 0.269 | |
| 1.0 (피질) | 0.253 | |
| 2.0 | 0.222 | |
| 3.0 (심부) | 0.197 ± 0.040 | ~0.10 |

→ **정성 일치**: 깊을수록 복원율 단조감쇠 (피질>심부). **단 기울기가 훨씬 완만**
(3-shell ×1.5 vs C15 ×8). → 발견: **가우시안 toy(C15)가 깊이 벽의 가파름을 과장**할
수 있음. 방향(심부 붕괴)은 robust, 절대 가파름은 커널-의존.

### Q2 — 전극 포화 (depth 1.0, skull 1/40, FIXED S=32, K=6) ★ C10 핵심

| M | **3-SHELL(물리)** R² | Δ | 가우시안-toy R² | Δ |
|---|---|---|---|---|
| 8 | 0.189 | | 0.136 | |
| 16 | 0.222 | +0.033 | 0.143 | +0.007 |
| 64 | 0.233 | +0.012 | 0.155 | +0.012 |
| 256 | 0.308 | **+0.075** | 0.196 | +0.041 |
| 1024 | **0.401** | **+0.093** | 0.218 | +0.022 |

→ **3-shell은 포화하지 않는다**: 전극 늘릴수록 R² 계속 상승(0.19→0.40,
고-M Δ가 +0.075/+0.093 로 **커짐**). 같은 하니스의 가우시안은 약하게 오르다
평탄(0.14→0.22, Δ가 +0.022로 붕괴). **3-shell = C10의 지수/멱법칙 커널과 동류
(미포화), 가우시안 strawman과 다름.**

### Q3 — 두개골 전도도비 (M=64, depth 1.0, K=6)

| σ_sk/σ_br | R² | g_n 컷오프 (|g_n|<1e-3·g1) |
|---|---|---|
| 1/20 | 0.316 ± 0.122 | n=19 |
| 1/40 | 0.316 ± 0.122 | n=19 |
| 1/80 | 0.316 ± 0.122 | n=19 |

→ **NOT-DISCRIMINATING**: 1/20~1/80 생리범위서 복원율·LPF 컷오프 모두 거의 불변
(R²=0.316, 컷오프 n≈19). 컷오프는 **소스 편심 기하**가 지배, 전도도비는 이 범위서
복원율을 거의 안 움직임. (정직: 두개골비 의존을 **주장하지 않음** — 평탄으로 측정됨.
transfer-matrix v4 교차검증서 평탄성=정규화 인공물 아님 확인.)

### Q3b — 전극포화 × 두개골비 (M=64 vs M=256)

| ratio | R²@64 | R²@256 | sat(256−64) |
|---|---|---|---|
| 1/20 | 0.259 | 0.319 | +0.059 |
| 1/40 | 0.259 | 0.318 | +0.059 |
| 1/80 | 0.258 | 0.318 | +0.059 |

→ 전 전도도비서 전극 증설이 일관되게 +0.059 도움(미포화) — Q2 재확인, 두개골비
무관하게 전극은 이득.

## 🎯 C10 strawman 판정 — **C10 SUPPORTED (가우시안 인공물 맞다)**

**"전극 포화 = 가우시안 전용 인공물"이라는 C10의 주장이 물리적 3-shell 모델로
확증됨.** 같은 하니스서 가우시안은 평탄(Δ→+0.022), 물리 3-shell은 계속 상승
(Δ→+0.093). 두개골 LPF가 가우시안 모양이 아니므로(매끄러운 멱급 단조감쇠),
전극 밀도를 높이면 고공간주파를 더 표집해 복원율이 계속 오른다.

**실용 함의**: 실 두상 가정 하에선 **두피 전극 증설이 여전히 유효** — C5의 전극포화
비관론은 커널-모양 인공물이었다. (C10 지렛대 MAP의 "전극수=커널의존" → 물리모델서
"전극수=실제 lever" 로 격상.) C13/C15의 RTSC "밀도가 본질" 결론과도 정합.

## NOT-MEASURED (정직)

- **실(비구형) 두상 기하** — 구체 ≠ 두개골 구멍/이방성/실제 곡률.
- **tangential dipole** — 여기선 radial만; 실 피질은 둘 다.
- **σ_skull 이방성** (radial≠tangential 전도도 — 알려진 실 효과) 미모델.
- **절대 R² 보정** vs 측정 EEG inverse 벤치마크.
- C11/C15 같은 prior·시간 lever와의 상호작용은 본 라운드 미측정.
