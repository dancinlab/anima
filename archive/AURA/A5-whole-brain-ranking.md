# A5 — 전뇌-통제 후보 위치 확정 랭킹

> 명제: **"최대 전뇌 통제"를 달성하는 임플란트/모달리티 위치는 어디인가?**
> 입력: SURVEY.md §4 매트릭스 + §5 예비 랭킹(본 문서에서 **확정**) + brainwire 4개 1차사료.
> ⚠️ **honest 전제(필독)**: 아래 모든 점수·도달%·계수는 brainwire 문서의 **추정치(estimated)** 다. 임상 측정 0건 · NIST/3rd-party 검증 0건 · 동물모델·인체 실증 미수행. "전뇌 통제"는 가설적 도달범위이지 입증된 능력이 아니다.

---

## §0. 채점 프레임 (5축)

각 후보를 5축으로 점수화한다. 신경조절 4축 도달은 SURVEY §1 깊이표 + n1-deep-access 5경로 계수 기준.

| 축 | 값 범위 | 정의 |
|---|---|---|
| **도달범위** | 피질국소 / 피질광역 / 심부일부 / 전뇌 | 단일 위치가 영향 미치는 공간 |
| **침습도** | 비침습 / 혈관내 / 경막외 / 관통피질 / 심부 | 두개·조직 침습 단계 (낮을수록 좋음) |
| **N1-as-is 가능** | ✅ 칩그대로 / ⚠ 깊이부족 / ❌ 다른모달리티 필요 | N1(3-6mm 관통) 하드웨어 무변경 사용 가능성 |
| **신경조절 4축 커버** | 0~4개 | DA(VTA) · 5HT(raphe) · NE(LC) · ACh(기저전뇌) 중 도달 핵 수 |
| **honest 제약** | 텍스트 | 가장 큰 한계 |

> 주: brainwire 12변수 모델은 ACh(기저전뇌)를 명시 변수로 두지 않았다(DA·5HT·NE·eCB·θ 중심). 본 문서는 사용자 지정 4축(DA·5HT·NE·ACh)을 채택하되, ACh/기저전뇌는 brainwire에서 **명시 경로 부재 = 추정 도달 0**으로 처리한다(honest). eCB·θ는 4축 외 보조 신경화학으로 별도 표기.

## §3. 확정 랭킹 (A) — "N1 칩 그대로 + 위치만 변경" top-3

제약: N1 하드웨어(3-6mm 관통, 단일/다중 임플란트) 무변경. 모달리티 교체 불가. **다른 modality(tFUS/DBS) 동원 후보(C4·C5·C6·C9) 전원 실격.**

| 순위 | 위치 | 도달범위 | 4축 | 핵심 근거 | honest 제약 |
|---|---|---|---|---|---|
| 🥇 **1** | **DLPFC + 섬엽 하이브리드 (C7)** | 피질광역+심부일부 | 3 (DA·5HT·NE) | 투사끝단(C1)+자율gateway(C2) 이중경로로 동일 신경조절핵 중복공략 → DA·5HT·NE 계수 상향. SURVEY §5 예비 1위 = 확정 유지 | N1 단일사이트 설계상 **임플란트 2개** 필요(neuralink §8). ACh 0. 심부 여전 간접(직접도달 ~37% 천장) |
| 🥈 **2** | **DLPFC 단독 (C1, 좌 F3)** | 피질광역 | 3 (DA·5HT·NE) | golden-zone Option A: **단일 임플란트**로 G=D×P/I 3성분 + 6/12변수 직접 + DLPFC→VTA/raphe/LC 3축 투사. 가장 검증된 단일위치 | 다중시냅스 간접(DA 0.40 등). 후방α·체성감각(V10/V11) 미커버. ACh 0 |
| 🥉 **3** | **전측 섬엽 단독 (C2)** | 심부일부 | 3 (DA·5HT·NE via 자율) | 피질발 taVNS — 섬엽→NTS/시상하부/편도로 자율신경·신경화학 3축에 효율 접근. C1과 다른 경로축이라 보완재 | taVNS의 30-40%만. 섬엽 외측열 심부 = 외과접근 난이도 최상위. ACh 0 |

> **랭킹 A 1위 = DLPFC + 섬엽 하이브리드 (C7).** "칩 그대로"의 경계 안에서 전뇌 신경조절 4축 중 3개를 최대 계수로 끌어올리는 유일한 구성. 단, 임플란트 2개 + 심부 직접도달 천장(~37%)이 honest 한계. 단일 임플란트 단순성을 우선하면 C1(DLPFC 단독)이 실무 1순위.

## §4. 확정 랭킹 (B) — "위치=모달리티까지 변경 허용" top-3

제약 해제: tFUS/DBS/하이브리드 전부 후보. 기준 = **최대 전뇌 도달(4축 커버 × 침습 효율 × 도달범위)**.

| 순위 | 위치/모달리티 | 도달범위 | 침습도 | 4축 | 핵심 근거 | honest 제약 |
|---|---|---|---|---|---|---|
| 🥇 **1** | **N1(DLPFC) + taVNS 하이브리드 (C8)** | 피질광역+심부 | 관통+비침습 | **4** | neuralink §9 확정 결론: 피질=N1(8변수 ~300%) + 심부=외부 taVNS(raphe/LC/NTS 직격, 5HT 1.20·NE 1.50). 12변수 전부 정상화, 침습 추가 최소(웨어러블). **실현가능성×도달 최적** | "단일 위치"가 아님(분산 시스템). ACh는 미주→기저전뇌 간접. 외부장비 41ms 지연(심부측) |
| 🥈 **2** | **tFUS — 비침습 심부 (C9)** | 전뇌 | **비침습** | **4** | `beyond-electrical §1a`: 12cm 깊이로 VTA·raphe·LC·기저전뇌 **전부 직격**, 2-5mm 초점, 비침습 유일 심부도달. 산점도 좌하단(이상향) 코너 단독 점유 | N1 무관(칩 아님). 신경화학 시변/지속 조절은 전극보다 거침. 12변수 영향 V1·V2·V3·V6 한정 추정. 임상 신경조절 초기단계 |
| 🥉 **3** | **뇌간 신경조절핵 DBS (C6: VTA/LC/raphe)** | 심부일부 | 심부 | **3** (DA·5HT·NE source 직접) | 전뇌 화학상태를 source에서 **직접** 통제 = 도달 계수 최강(간접 아님). 4축 중 3축 정밀 | 70-100mm 침습 천장(개두+심부전극 다발). 각 핵 정조준 = 외과 위험 극대. ACh 별도. "전뇌"가 화학축 한정(공간 broadcast는 시상이 우월) |

> **랭킹 B 1위 = N1(DLPFC) + taVNS 하이브리드 (C8).** 4축 전부 도달 + 피질 압도 + 침습 추가 최소(비침습 웨어러블) + brainwire 문서가 직접 "현실적 BCI Bridge 아키텍처"로 지목한 구성. 순수 비침습 우아함을 최우선하면 C9(tFUS)가, source-직접 도달 강도를 최우선하면 C6(DBS)가 1위 후보로 교체될 수 있으나, **도달×실현가능성 종합은 C8.**

## §5. 두 랭킹의 경계 = "칩만 그대로"의 한계선

```
                "위치만"(A)              "모달리티까지"(B)
   ┌──────────────────────────┬──────────────────────────────┐
   │ 1. DLPFC+섬엽 하이브리드  │ 1. N1(DLPFC)+taVNS 하이브리드 │
   │ 2. DLPFC 단독 (F3)        │ 2. tFUS (비침습 심부)         │
   │ 3. 전측 섬엽 단독         │ 3. 뇌간핵 DBS (VTA/LC/raphe)  │
   └──────────────────────────┴──────────────────────────────┘
      4축 중 3개 · 심부 ~37%       4축 전부 · 심부 source직접
      ACh = 0                       ACh 도달 가능
      [N1 깊이 3-6mm 천장]          [천장 돌파 = 모달리티 교체]
```

핵심: **A→B 도약은 "심부 직접도달"과 "ACh축"을 사느냐의 문제다.** N1을 어디에 두든 3-6mm 천장 때문에 심부는 16-37% 간접·ACh 0. 이 천장을 깨려면 (1) 외부 taVNS를 더하거나(C8, 최소침습) (2) tFUS로 비침습 심부직격(C9) (3) DBS로 심부전극(C6, 최대침습) — 셋 중 하나로 **위치가 아닌 모달리티를 바꿔야** 한다.

## §6. honest 종합 + 폐루프 검증 제안

- **모든 수치 estimated**: brainwire 4문서의 계수(DA 0.40, 5HT 1.20 등)·깊이(70-100mm)·도달%(16-37%)는 추정·문헌인용 기반이며 임상 측정·NIST/3rd-party 검증 0건. tFUS 12cm·2-5mm조차 essential tremor(Insightec) 외 신경조절 실증 초기.
- **"전뇌 통제" = 가설**: 어떤 후보도 입증된 전뇌통제 능력 없음. 도달범위는 잠재적 상한.
