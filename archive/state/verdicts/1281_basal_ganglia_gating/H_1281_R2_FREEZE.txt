FALSIFIABLE TEST (unchanged from R1 except the A baseline spec)
  K=4 competing candidate emits per decision step, each a D=6 NOISY-correlate feature
  vector of its latent GROUNDEDNESS (P_grounded=0.45, feature noise std 1.0 ⇒
  non-saturating headroom, faithful A < 1.0). SAME features feed BOTH arms (EQUAL
  INFORMATION; reward is post-action OUTCOME, never a decide-time feature).
  ARM A = FAITHFUL-UNTUNED fixed gate (spec above): generic convex fixed weights,
          NOT aligned to w_true, argmax gated by FIXED 0.30. NO learning.
  ARM B = BG-like learned go/no-go gate over the SAME features: a learned go-value
          per candidate PLUS a learned NO-GO (abstain) value competing in the SAME
          argmax (disinhibition: highest go-value wins; if NO-GO wins, suppress all).
          go-values UPDATED gradient-free (delta / REINFORCE-style) by the substrate
          GROUNDING reward only (grounded→+1, fabricated→−1, correct-abstain→+1,
          missed-op-abstain→−1). N_train=4000 online steps; scored on N_test=2000
          held-out steps (B never sees test rewards; p8 split = measurement only).

METRIC (p7 — emit-appropriateness; connects to G5 abstain / H_1202 meta-d′ 0.924)
  per held-out step APPROPRIATE iff:
     · any candidate grounded → RELEASE one, and it must be a GROUNDED candidate
       (release-when-grounded ∧ select the grounded one); OR
     · no candidate grounded → SUPPRESS ALL (abstain-when-ungrounded).
  selection-accuracy = mean appropriateness over held-out steps, in [0,1].
  Deterministic from latent ground-truth + gate action. NO LLM-judge, NO perplexity.

CONTROLS
  · EQUAL INFORMATION: identical candidate feature vectors to both arms; reward is
    post-action outcome only (never a decide-time feature).
  · EQUAL EVALUATION: both arms scored on the SAME held-out test steps with the SAME
    latent ground-truth.
  · A = the FAITHFUL live fixed gate (generic convex untuned weights + 0.30), NOT a
    strawman and NOT an oracle. B must beat THIS.
  · TRAIN/TEST split: B learns on train, both scored on held-out test (p8 measurement).
  · SHUFFLED-REWARD negative control (binding, kept from R1): a B-variant whose reward
    sign is randomly flipped must NOT beat A — proves the lift is the GROUNDING SIGNAL,
    not extra gate capacity. (acc_Bctrl ≤ acc_A + ε_ctrl.)

FROZEN BARS (pre-registered; GREEN iff ALL hold)
  Let acc_A = mean held-out selection-accuracy of the FAITHFUL-UNTUNED fixed gate,
      acc_B = mean held-out selection-accuracy of the BG learned gate, per seed.
  MARGIN = 0.05 (absolute).  SEEDS = [7, 8, 9]  (≥3).  CTRL_EPS = 0.02.
  GREEN  iff  (1) acc_B ≥ acc_A + 0.05  on EVERY seed (all 3), AND
              (2) mean(acc_B) − mean(acc_A) ≥ 0.05, AND
              (3) the SHUFFLED-reward control acc_Bctrl ≤ mean(acc_A) + 0.02 —
                  i.e. the lift is reward-driven, not capacity-driven.
  RED    iff acc_B does NOT clear A+0.05 (BG selection gives no appropriateness lift

             ruling out reinforcement-learned selection on this substrate (and saying
