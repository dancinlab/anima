ENGINE EXTENSION (c1 · a_engine_native_learning) — emit/brain side, namespaced apart
  CORE/brain.hexa now carries the VBasalGate lane:
    struct VBasalGate { go_w:[float], go_b:float, nogo:float, dim:int, lr:float }
    vbasal_new(dim, lr)                  — untrained gate (all-zero go-weights + zero NO-GO)
    vbasal_go_value(bg, feats)          — learned go-value of one candidate (go_w·f + go_b)
    vbasal_select(bg, cands, k)         — striatal go/no-go SELECTION over K candidates:
                                          argmax go-value vs the single NO-GO value;
                                          release the winner, or -1 ABSTAIN if NO-GO wins
    vbasal_update(bg, action, feats, r) — ONE gradient-free delta-rule tick from the
                                          grounding OUTCOME reward (abstain → nudge nogo;
                                          release → delta rule on go_w, go_b)
    vbasal_align(bg, w_ref)             — cosine alignment of learned weights to the signal
    brain_decide_bg(...)                — brain_decide WITH the BG residual: runs the
                                          UNCHANGED fixed gate (engine_g convex map + 0.30
                                          threshold) AND the learned selection; reports both
  The existing engine surfaces could NOT express a REWARD-gated go/no-go SELECTION
  (VAdaptField = recon-error growth; VForwardField = NLMS forward-prediction; neither has
  a go-value/NO-GO competition nor an outcome-reward delta rule). So the engine was
  EXTENDED rather than the mechanism trimmed — exactly as H_1199 extended AdaptField
  scalar→DIM-vector and H_1280 added VForwardField. The lane lives on the emit/brain side
  (brain.hexa), namespaced apart from the engine_cli.hexa mitosis/cerebellum/WM lanes.

ADDITIVE RESIDUAL (no replacement, no regression)
  brain_decide_bg calls brain_decide VERBATIM (the fixed convex 8-weight gate + fixed
  threshold UNCHANGED) and ADDS the BG selection (bg_select index / -1 abstain) on top.
  With k==0 (no competing candidates) the BG selection is a pure abstain and the record
  reduces to brain_decide — the residual is additive, never a replacement of the existing
  emit decision. brain_smoke stays byte-identical (low→silent / high→emit unchanged).
