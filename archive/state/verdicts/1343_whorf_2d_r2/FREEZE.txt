THE CP-WARP METRIC (boundary-curve-AGNOSTIC; the core re-specification)
  For an arm, define a learned 1-D "category coordinate" g(stim) = soft posterior P(cat=1)
  read from the fitted store (NO hard label, NO boundary location injected). The induced
  representational distance between two stimuli i,j is D(i,j) = |g(i) - g(j)|.
  Over ALL 4-neighbour adjacent grid pairs (the local stimulus steps), partition pairs by
  the arm's OWN learned category of the two endpoints:
    WITHIN  = pairs whose two endpoints are the SAME learned category (g rounds to same side)
    BETWEEN = pairs whose two endpoints are DIFFERENT learned categories
  Pre-language baseline uses the SAME partition under the language's GROUND-TRUTH labels
  but the PRE-LANG store's metric (boundary-agnostic representation, no carving).
  CP-WARP(arm) = ( mean D over BETWEEN pairs / mean D over WITHIN pairs )_arm
              minus ( same ratio )_PRE-LANG-baseline.
  A positive warp = the language EXPANDS cross-category steps and COMPRESSES within-category
  steps relative to the boundary-agnostic baseline = categorical perception. The ratio form
  is scale-free; subtracting the baseline removes any ratio the raw RBF geometry already has.

  COMPONENT-COUNT diagnostic (for c3): re-derive the warp where the BETWEEN/WITHIN partition
  uses a category defined by a SINGLE feature component chosen at random (one axis) instead of
  the trained 2-D posterior — i.e. shuffle WHICH component carries the boundary. If the warp
  is a real 2-D trained-metric effect it must COLLAPSE when the partition is tied to an
  arbitrary single component rather than the learned 2-D category.
