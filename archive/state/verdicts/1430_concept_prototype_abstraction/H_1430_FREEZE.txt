SUBSYSTEM (why MISSING from the live engine)
--------------------------------------------------------------------------------
CONCEPT / CATEGORY abstraction: from noisy training INSTANCES the brain abstracts
a category PROTOTYPE (a centroid in feature space) and classifies NOVEL never-seen
instances — including the prototype itself, which is often classified BETTER than
the trained instances even though it was NEVER shown (the Posner-Keele prototype-
enhancement effect). This is generalization-by-ABSTRACTION: a running category
centroid that summarizes a feature DISTRIBUTION, not a memory of specific items.

The live engine has NO such structure:
  - ImmuneMemory / ImmuneMemoryGrow (H_1227/1231/1288) binds each fact -> value
    INDEPENDENTLY by FNV-trigram key affinity. It MEMORIZES the trained instances;
    on a NOVEL never-bound instance its nearest-key affinity falls off and it
    abstains / guesses at chance, and it can NEVER classify the unseen prototype at
    least as well as trained exemplars — it has no binding for the prototype, only
    for the specific items it stored. It is exemplar/item memory, not abstraction.
  - SpatialMap (H_1296) holds metric POSITIONS of specific landmarks and answers a
    relational distance query; it is not a learned class boundary over a feature
    distribution and abstracts no category centroid.
  - OtherMindModel (H_1293), HierGoalStack (H_1294), WorkMemBuffer (H_1282),
    VForwardField (H_1280), HomeostaticDrive (H_1292): a separate belief store /
    an ordered plan / leaky maintenance / a next-emit forward model / a 1-D scalar
    integrator — none abstracts a category centroid from instances.

FALSIFIABLE CLAIM: a PROTOTYPE-ABSTRACTION faculty (a running per-category centroid)
classifies NOVEL instances and shows the prototype-enhancement effect; a faithful
exemplar/item-store stand-in (memorize trained instances, classify by nearest
TRAINED instance) provably (a) does WORSE on novel-far instances and (b) CANNOT
show the prototype-enhancement effect. If the centroid lane matches the exemplar
store (or its lift survives shuffling instance->category labels / ablating the
abstraction to nearest-exemplar mode), abstraction adds NOTHING -> honest 🧱.

--------------------------------------------------------------------------------
TASK (substrate-derived, NO injected label/persona/ethics — p1/p2/p3/p6)
--------------------------------------------------------------------------------
Posner-Keele-style design in feature space:
  K_CAT = 4 categories. Each category c has a HIDDEN prototype vector p_c in R^DIM
  (DIM = 24), drawn once per episode; prototypes are forced apart by a minimum
  pairwise L2 separation PROTO_SEP so categories are coherent and distinguishable.
  TRAINING: per category, N_TRAIN = 8 NOISY distortions of p_c (gaussian noise
  std = NOISE_TRAIN) are presented as (instance, category) pairs. The prototype
  itself is NEVER in the training set.
  TEST (NEW, disjoint from training):
    - NOVEL instances: N_TEST = 8 per category, NEW distortions (std = NOISE_TEST),
      never seen in training. Accuracy = argmin over a faculty's category score.
    - PROTOTYPE: the never-shown centroid p_c of each category (the signature item).
    - FAR FOIL: a vector far (>= FOIL_MIN) from EVERY prototype -> must abstain.

Score = classification accuracy over the NOVEL test instances (headline), plus the
PROTOTYPE accuracy (the signature enhancement test), plus far-foil abstain rate.
p7 script-checkable (NOT perplexity, NOT an LLM judge).

--------------------------------------------------------------------------------
ARMS (the SAME training instances feed every arm)
--------------------------------------------------------------------------------
  A  EXEMPLAR / ITEM-STORE stand-in (faithful H_1227 distinctness control):
        memorizes each TRAINED instance->category; classifies a test vector by its
        NEAREST TRAINED instance (1-NN exemplar). NO category centroid abstracted.
  B  PROTOTYPE lane: maintains a RUNNING per-category centroid (mean of observed
        instances); classifies by nearest centroid. The abstraction.
  Bshuf  EARNED-CATEGORY shuffle: instance->category labels permuted before the
        centroids are formed -> centroids become mixtures of categories (structure
        destroyed; feature frequency intact) -> must collapse.
  Babl   EARNED-ABSTRACTION ablate: the centroid abstraction is removed -> classify
        by nearest TRAINED instance only (== exemplar mode) -> the prototype-
        enhancement effect must DISAPPEAR and novel-far accuracy drop.

A confident-classification threshold gates abstain: if the best category score
(nearest distance) exceeds ABSTAIN_D (too far from every centroid/exemplar), the
faculty ABSTAINS (no confident category) — the NO-FAB discipline on far foils.
