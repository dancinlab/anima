WHAT WAS WIRED
--------------

forward logits) now draws its RNG from qentropy.rng("decoder_sample"). The FORWARD

entropy enters ONLY at the sampling/seed layer, never the forward matmul. Flipping
ANIMA_ENTROPY_MODE benchmarks quantum-vs-deterministic sampling with zero code change.

FINDING
-------
DECODER sampling is now quantum-default · deterministic-auxiliary via the single
qentropy SSOT. Quantum mode reads the committed real-ANU buffer (tier anu_committed)
and yields a token distribution; deterministic mode (numpy_prng seed=187) is bit-for-bit
reproducible. The deterministic FORWARD (argmax=3, identical probs) is unchanged across
modes — confirming the entropy enters only at the sampling layer. This closes the M3
"추론 DECODER sampling 지점" row of the H_924 per-path coverage table.

HONEST SCOPE
------------
* SW sampling-layer wire only. The AKIDA HW forward (threshold-and-fire) remains
  byte-identical/deterministic (H_922/H_680) and is NOT modified by this change.
* Statistical quality: ANU quantum == chacha20 PRNG (#123-A QA6; NIST SP 800-22 7/7,
  JSD 23x under threshold). No "more random" claim — the value of the quantum mode is
  PROVENANCE/auditability/physical-origin, which is precisely why the deterministic
  auxiliary exists for A/B benchmarking.
* Soft dependency: decoder_qsample.py inserts mirror/qmirror/seed on sys.path and
  imports qentropy with a try/except numpy.default_rng fallback (tagged provenance),
  so it never hard-depends on the SSOT.
