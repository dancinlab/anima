THE ROUTE (the ONLY not-ruled-out trajectory mechanism after H_1207)
--------------------------------------------------------------------------------
A PROTOTYPE-TRANSITION-MEMORY / PREDICTABILITY split gate. Maintain a prototype
book + a memory of observed (nearest-proto_{t-1} -> nearest-proto_t) TRANSITIONS.
The split key fires on a TRANSITION property, NOT on sample-novelty (H_1203) and
NOT on local |Δ| roughness (H_1207).

Two transition-memory gate FORMULATIONS are measured (both pre-registered):
  GATE-A  TRANSITION-NOVELTY  : split when the current ordered prototype-transition
          (p_{t-1} -> p_t) is UNSEEN/rare in transition memory.
  GATE-B  TRANSITION-PREDICTABILITY (the principled sign-inverter): the gate learns
          a running transition model P(p_t | p_{t-1}) (count table over prototype
          ids). Split fires when the realized transition is PREDICTABLE — i.e. the
          gate had CONFIDENTLY anticipated it (the predicted-prob of the realized
          next-proto exceeds a confidence floor AND the transition recurs). Ordered
          text = coherent, learnable p->p' regularities -> model gains confidence ->
          predictable transitions recur -> division stays HIGH. A shuffled stream =
          incoherent pairings -> model never gains confidence -> few predictable
          transitions -> division SUPPRESSED. This INVERTS the H_1207 sign so that
          ORDER (predictability) yields MORE division than DISORDER -> the V14-격파
          direction (ordered >> shuffled).

WHY this can separate order from disorder where H_1203/H_1207 could not:
  - H_1203 L2 gate sees only x_t -> permutation-invariant by construction.
  - H_1207 |Δ| gate sees the PAIR but keys on magnitude -> disorder maximizes it
    (inverted sign).
  - A PREDICTABILITY gate keys on whether a transition was ANTICIPATED. Anticipation
    requires a STABLE conditional structure P(next|prev), which ONLY an ordered stream
    possesses; a shuffle has none. So predictable-transition division is HIGH for
    order, LOW for disorder -> correct V14 sign IF the mechanism works at all.
