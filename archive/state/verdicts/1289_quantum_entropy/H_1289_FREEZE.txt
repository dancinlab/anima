METHOD (locked)
---------------
- Entropy sources, IDENTICAL consumer interface (a uniform-byte stream -> draws):
    PRNG  : numpy default_rng(seed=SEED) -> uint8 stream (deterministic, reproducible).
    QRNG  : ANU QRNG paid API GET length=N type=uint8, x-api-key header (REAL vacuum bytes).
- Consumer (the ONE stochastic decision): a SUBSTRATE-MIRROR decode loop emitting
  K tokens; at each step a top-k(=8) candidate set is formed from a fixed deterministic
  logit field (so ONLY the entropy source varies), and the emitted token is selected
  by ONE uniform draw from the entropy stream. The fixed logit field + fixed seed make
  the PRNG arm fully reproducible; the QRNG arm is reproducible-in-logits but NOT in draws.
- Randomness sanity (NIST-lite, on the raw drawn bytes, bit-expanded):
    monobit frequency test (S_obs, p via erfc) and runs test (V_obs, z, p).
- Substrate gauges (B): mitosis cell-count trajectory (VAdaptField numpy mirror over the
  emitted byte windows), decode novelty proxy (distinct-token rate), and a Psi-noise proxy
  (mean abs of the draw-induced perturbation). Compared QRNG vs PRNG; null expected.
- (C): run the SAME substrate twice for each arm (PRNG seed FIXED both runs; QRNG fresh
  fetch both runs). Compare emitted byte streams: PRNG run1==run2, QRNG run1!=run2.
