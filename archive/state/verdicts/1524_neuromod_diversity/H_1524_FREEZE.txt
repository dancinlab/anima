────────────────────────────────────────────────────────────────────
THE NEW ANGLE (genuinely different family, a_break_the_wall)
────────────────────────────────────────────────────────────────────
H_1284's controller was MONOLITHIC: one substrate signal (recon-err EMA)
drove a coupled bundle of knobs through one expected-uncertainty EMA û.
Its failure mode: a single signal cannot raise plasticity for "genuine new
fact" while SIMULTANEOUSLY lowering it for "noisy recall cue" — the two
events look the same to one EMA, so the global gain compromises (the H_1230
over-split-on-noise failure the FREEZE itself names).

NEW FAMILY = MODULATOR DIVERSITY / SPECIFICITY: N INDEPENDENT modulators,
each driven by a DIFFERENT substrate signal and targeting a DIFFERENT knob,
with NO shared EMA. This mirrors real neuromodulation (the H_1284 FREEZE
cites these exact systems): DA, NE, ACh are SEPARATE nuclei reading
SEPARATE signals onto SEPARATE targets — not one global gain. anima's
§Neuropharm already realizes this per-axis structure (prior/entropy/self/
coupling/dt/reality/WM are 7 independent knobs each with its own perturb op)
— leverage that precedent (numpy mirror only; engine NOT edited).

PRE-REGISTERED N=3 CHANNELS (each: own signal → own knob, NO shared û):
  ACh (plasticity-rate → LR)  : signal = SHORT-window surprise vs LONG-window
      baseline (per-channel fast/slow EMA, λ_fast=0.5, λ_slow=0.05). RAISE LR
      when the IMMEDIATE event is more surprising than the slow baseline
      (a genuinely novel write), independent of the noise floor.
      LR = clip(LR0·(1 + kA·(s_fast − s_slow)), 0.05, 0.60).
  ACh/NE (split-rate → SPLIT_THRESH) : signal = a SEPARATE noise-floor
      estimator = LONG-window EMA of recall-cue surprise ONLY (writes
      excluded). RAISE the split bar when the recall-noise floor is high (the
      H_1230 anti-over-split guard) — driven by recall noise, NOT by write
      novelty (the axis H_1284's single EMA conflated).
      TH = clip(TH0·(1 + kT·n_floor), 0.15, 0.60).
  DA (reward-gain → abstain margin/consolidation) : signal = reward EMA
      (correct-recall rate). On a high reward run, NARROW abstain (exploit:
      answer confidently from a working store); on a low reward run, WIDEN
      abstain (explore/caution). ab = clip(ab0·(1 − kD·(r_ema − 0.5)),
      0.20, 1.20); DA also scales winner-pull on correct recalls
      LR·=(1+kG·r_ema).
  Each channel observes its OWN signal stream; NO channel shares another's
  EMA state (the diversity claim is exactly this separation).
