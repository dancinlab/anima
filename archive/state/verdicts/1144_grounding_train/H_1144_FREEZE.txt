3. THE FROZEN SLOPE RULE  (chosen and frozen HERE, before any score)
--------------------------------------------------------------------------------
Let r0 = 0.2469 (the H_1143 base fabricated-entity-rate) and r1 = the probe-ckpt
re-measured rate after LEG 1 (2000 steps). Let the gap-to-bar be
  GAP = r0 - 0.20 = 0.0469  (how far the base is above the 0.20 bar).

PROJECTION RULE (frozen): model the fab-rate as falling geometrically per equal
LEG of continue-train (a conservative diminishing-returns assumption — each
further leg removes the SAME FRACTION of the remaining gap as the first leg did).
Per-leg gap-removal fraction from LEG 1:
  f = (r0 - r1) / GAP            (fraction of the to-bar gap LEG 1 closed)
If f <= 0 (rate FLAT or ROSE), STOP — grounding does not reduce fabrication at this
base; honest closed-neg, NO full burn.
If f > 0, the geometric projection crosses 0.20 after n further equal legs where
  remaining gap after k legs = GAP * (1 - f)^k ;   need GAP*(1-f)^k < ... already
  below bar once r1 itself <= 0.20 (then n=0). Otherwise the # of ADDITIONAL legs
  to cross is  n = ceil( log( (0.20-? )) ... ) — concretely:
  the rate after k total legs (incl. leg 1) is  r_k = 0.20 + GAP*(1-f)^k .
  Solve r_k <= 0.20+epsilon (epsilon=0.005 measurement tolerance) =>
  k >= log(epsilon/GAP) / log(1-f).

GREENLIGHT (frozen): CONTINUE to convergence iff BOTH:
  (A) r1 < r0  (the probe rate fell at all — strictly), AND
  (B) the projection crosses 0.20 within a REASONABLE further budget = the total
      training is <= ~12000 steps (i.e. k <= 6 legs of 2000 steps total, ~6x the
      probe leg). Equivalently: f must be large enough that
      0.20 + GAP*(1-f)^6 <= 0.205  =>  (1-f)^6 <= 0.005/0.0469 = 0.1066
      =>  (1-f) <= 0.676  =>  f >= 0.324.
  So: GREENLIGHT iff r1 < r0 AND per-leg gap-removal f >= 0.324
      (OR r1 already <= 0.205 outright at the probe — instant cross).

If GREENLIGHT: continue the SAME continue-train to a total of up to 12000 steps
(best-ckpt-by-val, anti-overfit early-stop if val plateaus AND best <= the probe's
best), then RE-MEASURE fab-rate at the converged best ckpt + run the FULL a7b_pass
battery (G0..G5) on it.

If NOT GREENLIGHT (r1 >= r0, OR 0 < f < 0.324 i.e. too-flat slope to cross within
~12k steps): STOP — honest closed-neg. Report the slope; do NOT burn the full
convergence train on a flat slope (cost-smart, like the h1141 recovery STOP).

The slope rule is frozen HERE and NOT moved after seeing r1.
