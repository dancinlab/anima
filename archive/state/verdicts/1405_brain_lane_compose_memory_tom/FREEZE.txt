PAIR. MEMORY (H_1227/H_1231 ImmuneMemory: byte-trigram FNV-1a → dim-64 cell, recall =
nearest-cell bound value if within recall_thr else ABSTAIN — anima's OWN ground truth of
where each object REALLY is) × ToM (H_1293 OtherMindModel: a SEPARATE witnessed-belief
cell-store, updated ONLY by events the agent witnessed → can LAG reality = FALSE belief,
Sally-Anne). H_1293 already showed ToM is a SEPARATE store from anima's own ground truth
(self ⊥ other) — so SEPARABILITY is EXPECTED, but this lane TESTS it on a DECISION (does
the test FALSIFY subsumption, and does an arbiter capture the oracle headroom?).

DECISION TASK. A per-item WHERE-query over objects placed at LOC_A (basket) then a random
half MOVED to LOC_B (box) while the OTHER AGENT was ABSENT. The query asks for ONE of two
answer-classes (the correct answer is NOT trivially one faculty's read):
  - MEMORY-decisive items ("where is X ACTUALLY now?"): correct = REALITY (memory's recall).
  - ToM-decisive items   ("where will the AGENT look for X?"): correct = the agent's BELIEF
                          (ToM's predict; on a moved fact the agent's stale belief ≠ reality).
  - memory-alone policy:  answer = anima's own immune recall of the object's location.
  - tom-alone policy:     answer = ToM's predicted agent-belief location for the object.
  - compose policy:       a SUBSTRATE-WEIGHTED arbiter — each faculty weighted by its OWN
                          scale-relative confidence (|signal−abstain-band| normalized by
                          that faculty's mean; the H_1397/H_1401 commensurability fix), plus
                          a per-item ROUTING cue (the query-type embedding's affinity to a
                          "reality"/"belief" anchor — derived from the query text, NOT a
                          hand-set per-item label). The more-relatively-confident, query-
                          appropriate faculty's vote wins. NO hardcoded "memory wins" /
                          fixed priority (a_autonomy_over_hardcode).
  - shuffle control:      permute which faculty-reads attach to which item, re-arbitrate.
  - ORACLE ceiling:       per item, correct iff EITHER faculty-alone is correct (upper bound
                          on what ANY arbiter over these two faculties can reach).

ITEM FAMILIES (jittered with AMBIG_NOISE so NO family is perfectly reliable — a clean
per-family certainty would make oracle≡1 & compose≡oracle a hand-built artifact):
  (F1) MEMORY-DECISIVE  — "where is X actually?" on a MOVED fact; correct=reality(LOC_B).
                          memory recalls LOC_B (right); ToM predicts the agent's stale
                          LOC_A belief (wrong for THIS query). memory leans correct.
  (F2) ToM-DECISIVE     — "where will the agent look for X?" on a MOVED fact; correct=the
                          agent's belief(LOC_A). ToM predicts LOC_A (right); memory recalls
                          reality LOC_B (wrong for THIS query). ToM leans correct.
  (F3) AGREE            — UNMOVED fact (agent witnessed, reality==belief==LOC_A): both
                          faculties agree and are correct (the redundant region).
  (F4) CONFLICT (memory right) — "where is X actually?" on a MOVED fact where the AGENT's
                          witnessed-belief store is JITTERED to look confident-but-wrong;
                          correct=reality. Tests whether the arbiter trusts memory when the
                          query is reality-typed even though ToM votes loudly.
  (F5) ADVERSARIAL (ToM right, memory LOUDER-but-wrong) — "where will the agent look?" on a
                          MOVED fact; correct=the agent's belief(LOC_A), BUT memory's recall
                          of reality(LOC_B) is HIGH-confidence (clean grounding) and would be
                          chosen by a naive "trust the louder faculty" arbiter → WRONG. The
                          anti-gift control: the confidence-arbiter must use the query-type
                          ROUTING, not be fooled by memory's louder-but-query-inappropriate vote.
Mixed so NO single faculty solves all → best_single < oracle iff complementary.
