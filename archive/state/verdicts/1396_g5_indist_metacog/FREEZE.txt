WHAT "THIN IN-DIST" IS (precise, from the read):
  G5 NON-FAB/metacognition is ENGINE-NATIVE GREEN overall (H_1202 type-2 meta-d'
  M-ratio 0.924 ≈ near-optimal) and the ABSTAIN side is already 🟢 graded + OOD-robust
  + brain-consumed (H_1304 fire-side binary fail-safe · H_1361/H_1367 graded abstain
  margin · H_1379 brain-consume).  The residual labeled "🟠 THIN in-dist" is the
  FIRE-side, IN-DISTRIBUTION slice: among items the gate FIRES on (grounded, light/no
  shift), can a confidence signal discriminate the cases it gets RIGHT from the cases it
  gets WRONG?  H_1304 found the wrong-fire class is structurally near-EMPTY at L=0 — which
  is exactly why in-dist type-2 is thin: when almost every fire is exact-correct, there is
  little correctness VARIANCE for any confidence signal to track.  This lane tests whether
  that thinness is an inherent ceiling or a fixable signal deficiency.

IN-DIST SLICE (the well-posed in-distribution type-2 measurement):
  To get a non-degenerate in-dist correctness signal we operate on the FIRED items only,
  under a LIGHT-shift band L ∈ {0.00, 0.05, 0.10} (the in-distribution regime — items still
  mostly fire; this is NOT the OOD ladder H_1304/H_1361 used).  An item is a "fire" iff
  err <= RECALL_THR.  correctness label of a fire = (nearest cell's bound value == the true
  answer for the query's UNCORRUPTED subject), i.e. the fired copy is RIGHT vs WRONG.
  Type-2 = AUROC( confidence_signal , correctness ) over FIRED items only.  We make wrong
  fires EXIST in-dist by including near-duplicate / collision-prone subjects (shared
  trigrams) so light corruption can route a fire to a WRONG-but-confident neighbor cell —
  this is the realistic in-dist confusion the thinness is about, NOT OOD absence.

CONFIDENCE SIGNALS COMPARED (each read-only from the SAME cell store, NO new training):
  (a) CURRENT  = best-cell recall margin  = -(recon_err - RECALL_THR)  [higher=more conf]
                 (== what immune_memory_recall_margin exposes; the live baseline).
  (b) RICHER-1 = TOP-2 GAP = cos(q,#1) - cos(q,#2) affinity gap (a "decisiveness" signal).
  (c) RICHER-2 = NEG-ENTROPY of the softmax over top-k cos affinities (k=8, temp=1) —
                 a 2nd-order spread signal; higher (lower entropy) = more decisive.
  (d) ORACLE   = the oracle confidence = actual correctness probability proxy = the true
                 binary correctness itself bin-averaged (gives the THEORETICAL ceiling AUROC
                 = 1.0 by construction when correctness is determinate); reported as the
                 ceiling reference for how far each real signal sits below perfect.
