THREE ARMS

  STATIC  : fixed-repertoire control — recall-only, NEVER splits (ablation of the
            teaching op). Same initial cells as FULL; selection by same affinity.
  SHUFFLE : FULL store but the task->tool binding labels are permuted before training
            (the earned-structure control — destroys the task<->tool correspondence).
