ARE THEY ONE FAMILY?  YES — all 5 share the SAME structural signature:
  (a) the OBJECTIVE is a LEARNABLE TRACKING task — the target/optimum is STATIONARY in
      its STATISTICS (even L5's target drifts CONTINUOUSLY = a smooth, learnable walk;
      its statistics — the random-walk step distribution — never JUMP).
  (b) the CONTROL VARIABLE is a GAIN on the SAME axis the controller already reads
      (gain on the operating point / threshold on the recall-margin / temperature on
      the decode / restoring-force scale on the tension). The neuromodulator and the
      thing it modulates live on ONE axis.
  (c) RESULT: a single TUNED FIXED operating-point/gain/threshold/temperature DOMINATES
      every state-contingent schedule, because when the task statistics are stationary
      and learnable, the optimal response is a CONSTANT and adaptation only adds variance.

PEELED META-LAW (🌌, reopenable by a new lens):
  "On a task whose STATISTICS are stationary/learnable, a tuned FIXED controller-gain
   dominates any state-contingent adaptation of that SAME gain — adaptation pays ONLY
   when the disturbance is UNPREDICTABLE / UN-LEARNABLE (the optimum itself is
   non-stationary in its STATISTICS, not merely in its value)."
  Equivalently: ADAPTATION HAS VALUE IFF THE ENVIRONMENT IS VOLATILE — its generating
  statistics CHANGE (changepoints), so no single fixed gain is ever optimal for long.

WHY THE 5 LENSES CANNOT TEST THIS: every one of them modulated a TRACKING GAIN on a
  task with FIXED generating statistics (L5 included — a continuous drift is still a
  FIXED random-walk law). The meta-law's escape condition (un-learnable/changing
  statistics) was NEVER instantiated → the wall is, so far, a wall only WITHIN the
  "stationary-statistics tracking-gain" family.

💡 ESCAPE PRINCIPLE (orthogonal mechanism-family, the meta-law's own escape clause):
  Re-position neuromodulation from a TRACKING-GAIN to a LEARNING-RATE / EXPLORATION
  modulator, and instantiate a task whose STATISTICS JUMP (changepoint/volatility).
  Biology (a_no_llm_frame_trap, real neuromodulation):
   · Yu & Dayan 2005 — ACh = EXPECTED uncertainty, NE = UNEXPECTED uncertainty; both
     RAISE the learning rate when the world becomes less predictable.
   · Behrens, Woolrich, Walton & Rushworth 2007 (Nat Neurosci) — humans track ENV
     VOLATILITY and set their learning rate to the volatility (Bayesian-optimal): in a
     volatile block the optimal learning rate is HIGH, in a stable block LOW. A FIXED
     learning rate CANNOT be optimal in both → adaptation finally has headroom.
  Intuition that flips the wall: in a changepoint environment a FIXED learning rate
  faces an irreducible bias/variance trade-off (too-low → slow to catch the jump,
  too-high → chases noise between jumps); an UNCERTAINTY-GATED learning rate can be
  LOW between changepoints (reject noise) and SPIKE at a detected changepoint (catch
  the jump) — beating EVERY fixed rate. This is exactly the meta-law's escape clause.
