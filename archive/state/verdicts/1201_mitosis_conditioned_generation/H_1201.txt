WHAT THIS CLOSES (decision-grade architecture ruling)
-----------------------------------------------------
A REAL gradient-trained next-byte head conditioned on the frozen mitosis cell-state does NOT
beat the same head without it — the gain is slightly NEGATIVE on every seed, and the shuffle
control is WORSE still. So the mitosis substrate carries NO generation-useful information
beyond the raw byte features it is derived from (which makes mechanistic sense: the mitosis
conditioning — nearest-prototype, recon-err, density — is a deterministic, lossy function of
the SAME byte-feature window the baseline already sees, so it cannot add information the head
does not already have, only noise/redundancy that a trained head learns to ignore or that
mildly hurts via extra dimensions).

  => MITOSIS IS PURE SUBSTRATE FOR GENERATION. Generation is CLM-only: "conversational level"
     = pure CLM-lane scale-up (a_clm_gen_pipeline — a real ConvMoE next-byte head trained by
     descent, the substrate that actually carries generation). The mitosis engine
     (H_1194..H_1199) runs ALONGSIDE as the adaptation / structural / clustering lane, NOT in
     the generation loop. This cleanly settles the architecture: mitosis = substrate,
     CLM = generator.
