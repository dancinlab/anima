           one H_1228 arm — it is the best of H_1228's tuned fixed family.)
  ARM B  = CONTEXT-ADAPTIVE NEUROMODULATOR. Same per-step temperature controller,
           but the σ*-TARGET itself is modulated each step by a no-grad read-out of
           the RECENT OUTPUT STATE (NE exploration + ACh novelty + DA coherence-gain):
             · repetition r_t  = fraction of last W=24 emitted bytes that repeat a
                                 byte already in the last W window (loop pressure).
             · novelty  n_t    = distinct-byte ratio over the last W bytes (low =>
                                 low local novelty).
             · coherence c_t   = running known_word_ratio of the decoded-so-far text.
           ADAPTED target (clamped σ*_t in [1.5, 3.5]):
             σ*_t = σ*_0 * (1 + kR*r_t + kN*(1-n_t)) * (1 - kC*max(0, COH_FLOOR-c_t))
           i.e. RAISE exploration (higher σ*) when output is repetitive or
           low-novelty (NE/ACh), LOWER it (toward coherence) when kwr drops below
           COH_FLOOR (DA coherence-gain). σ*_0 = ARM A's σ* if A is a σ*-arm, else
           2.5 (the H_1228 frozen σ*). Gains kR=0.6, kN=0.4, kC=0.5, COH_FLOOR=0.50,
           W=24, KP=0.6 — HAND-SET, FROZEN here, NOT learned/loss-folded (p7 Goodhart
           guard; controller is a pure no-grad readout, never added to loss/backward).
  ARM C-SHUF = COUPLING CONTROL. Identical to ARM B but the per-step adapted σ*_t
           sequence is taken from a RANDOM PERMUTATION of B's OWN σ*_t values
           (same knob DISTRIBUTION, decoupled from the live state). Isolates
           state->knob COUPLING from mere knob VARIETY (the R1 C-SHUF discipline).
