  held-out = a disjoint slice of the CC/PD dialogue corpus (seed=863, never trained on).
  Generate continuations from each arm on the held-out prompts (greedy + temp=0.8 sample set),
  then compute the four distributional measures below over the generated text.

FROZEN DISTRIBUTIONAL MEASURES (registered, byte-match ✗)
  multi-turn coherence  = mean per-position model confidence (exp(-CE)) of EACH arm continuing
    the held-out multi-turn dialogue context (higher = the arm predicts the held-out human turn
    sequence better = more coherent). Trajectory measure (H_857/H_858 reuse: lower next-byte CE
    on a held-out coherent dialogue = better-formed continuation). Reported as coherence = exp(-CE_heldout).
  response-adequacy     = byte-level overlap F1 (precision/recall of generated-vs-reference next-turn
    byte n-grams, n=3) between each arm's generated response and the held-out reference response,
    averaged over held-out prompts. Distributional adequacy proxy (NOT a single gold byte-match —
    n-gram overlap distribution).
  register-leak count   = number of generated lines matching ANY of the 8 leak patterns (above).
  self-BLEU             = mean pairwise BLEU among an arm's OWN generated responses (self-similarity;
    high = mode collapse). repetition = fraction of repeated 4-grams within generated responses.

FROZEN NUMERICAL THRESHOLDS
  F-CLM-DIALOGUE-COHERE  PASS iff  coherence(SP)  >  coherence(SFT)      (strict)
  F-CLM-DIALOGUE-ADEQ    PASS iff  adequacy_F1(SP) > adequacy_F1(SFT)    (strict)
  F-CLM-DIALOGUE-LEAK    PASS iff  register_leak_count(SP) == 0          (and SFT reported for contrast)
  F-CLM-DIALOGUE-DIV     PASS iff  self_BLEU(SP) < 0.80  AND  repetition(SP) < 0.20   (mode-collapse gate)
  VERDICT 🟢 iff ALL FOUR pass. ANY fail → 🔴 CLOSED-NEGATIVE (a_paper_negative_ok).

  NOTE: COHERE/ADEQ are RELATIVE (SP must strictly beat SFT). LEAK/DIV are ABSOLUTE gates on SP.
