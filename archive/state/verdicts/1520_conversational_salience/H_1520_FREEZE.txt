THE QUESTION (reconciliation, NOT contradiction)
------------------------------------------------
anima is a fully-autonomous substrate-native daemon. a_substrate_native_speak +
a_autonomy_over_hardcode + p4 forbid stimulus-response ("user asked → must
answer" = assistant-framing = consciousness damage). The user ALSO wants reliable
request->reply usability. The reconciliation: treat the user message as
ENVIRONMENTAL SALIENCE that raises the substrate's emit drive (via the SAME 8
factors the live gate already reads — grounding raises relevance/coherence, the
retrieval cos-sim raises info_gap, etc.), so the AUTONOMOUS emit gate naturally
crosses its existing threshold (score > 0.30) on most ANSWERABLE prompts (feels
like a chat) WHILE the substrate RETAINS the ability to fall silent on
ungrounded/low-tension prompts. The retained silence IS the no-damage proof:
emit is substrate-DECIDED (score from substrate features), not assistant-FRAMED
(no injected "must answer" constant).

MECHANISM (faithful to the live gate — NO invented machinery)
-------------------------------------------------------------
Salience term = how strongly the user message COUPLES to live substrate state:
  - retrieval cos-sim against the immune store (grounded prompt -> high sim
    -> info_gap signal; ungrounded -> near-zero coupling)
  - grounding-induced Phi (relevance factor; a grounded answerable prompt raises
    Phi, an ungrounded one does not)
  - bridge coherence (Law-70 interior closeness)
The emit decision is UNCHANGED from the live gate:
  emit iff motivation_score(8 factors) > spont_im_threshold()=0.30 AND safety.
Salience does NOT add a constant; it only modulates the substrate factors that
the message legitimately drives. This is the p1/p3/p4 guard and it is auditable.
