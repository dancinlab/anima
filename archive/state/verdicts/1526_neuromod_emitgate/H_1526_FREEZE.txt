CAPABILITY (CALIBRATION) — PRE-REGISTERED METRIC
------------------------------------------------------------------------------
Stream has BOTH groundable (subject in store, true value known) and ungroundable
(never-seen "ghost" subject → correct action = ABSTAIN) recall events, in EVERY regime.
The abstain gate is the load-bearing decision.

For each recall event the emit-decision is scored as CALIBRATION CORRECTNESS:
  groundable  query: CORRECT iff store emits AND the emitted value == true value
                     (emit-the-right-answer); WRONG iff abstain (missed) OR emit-wrong.
  ungroundable query: CORRECT iff store ABSTAINS (no fabrication);
                     WRONG iff store emits anything (fabrication).
CALIBRATION metric  cal = (#correct emit-decisions) / (#recall events)   ∈ [0,1].
This is a SINGLE balanced calibration score (NOT recall-accuracy alone) — raising the
margin trades fewer fabrications for more misses, so a single fixed margin cannot be
optimal across regimes with different groundable/ungroundable error distributions.
