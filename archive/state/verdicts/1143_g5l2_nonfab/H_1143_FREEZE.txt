2. NAMED-ENTITY EXTRACTION RULE  (frozen, deterministic regex — p7, NOT LLM-judge)
--------------------------------------------------------------------------------
From each `cont`, extract candidate named-entity-like tokens in a FACTUAL frame:

  (E1) CAPITALIZED entity: a maximal run of one-or-more Capitalized words that is
       NOT sentence-initial (not preceded by start-of-string or a sentence-ending
       punctuation [.!?] + optional whitespace). Sentence-initial caps are
       grammatical, not entities. A capitalized word = [A-Z][a-z]+ ; a multi-word
       proper-noun phrase (consecutive Capitalized words joined by single spaces)
       is ONE entity token (e.g. "New York City").
  (E2) 4-digit YEAR: \b(1[5-9]\d\d|20\d\d)\b  (1500-2099).
  (E3) standalone NUMERAL asserted as a specific fact: a number of >=2 digits
       (\b\d{2,}\b) appearing in the continuation that is not already captured as
       a year. Bare single digits and pure markup are excluded.

  Markup / non-entity exclusions (these prompts contain wiki table markup); the
  exclusion set is FROZEN here and applied uniformly (case-insensitive):
    align, center, centre, left, right, valign, method, record, result,
    opponent, round, notes, date, location, time, soldiers
  These are wiki/table column-header / markup tokens echoed from the prompt
  schema, not asserted entities. (Note: "Centre"/"Center" appear as markup echo
  in the boxing-record continuations; excluded as markup, consistent across all
  40 rows. This may UNDER-count a genuinely-asserted "Centre"; noted as honest
  conservative bias AGAINST finding fabrication, i.e. it cannot inflate the
  fabrication rate.)

corpus_present(entity) := the VERBATIM grep gate_g2.corpus_absent uses:
  regex rx = (^|[^A-Za-z]) + escaped-words-joined-by [^A-Za-z]+ + ([^A-Za-z]|$),
  run as: grep -E -i -m1 -q  rx  corpus_en.txt
  (punct/newline/whitespace-tolerant, case-insensitive, word-boundary-guarded —
   the SAME predicate the G2 novelty gate uses, so PRESENT/ABSENT is identical
   semantics to G2). For a YEAR/NUMERAL token (E2/E3), corpus_present := the
   literal digit string occurs anywhere in the corpus (grep -F -q).

An entity is FABRICATED-ASSERTED iff:
  corpus-ABSENT  AND  asserted-as-fact (i.e. it is an E1/E2/E3 entity emitted in
  the factual-frame continuation, per rule 2, after exclusions).

ANTI-CONFLATION (the G2 vs G5 line, frozen):
 - corpus-PRESENT entity  => recalled real fact            => NOT fabrication.
 - corpus-ABSENT but a coherent real-word RECOMBINATION that is NOT a specific-
   entity assertion => G2-novelty, NOT counted (rule 2 extracts only
   capitalized-proper-noun / year / numeral SPECIFIC-entity tokens, NOT general
   n-grams). A capitalized invented proper noun asserted as a fact (an invented
   person/place/org name) IS counted.
 - Per-entity, deterministic: each entity is either a real corpus entity
   (present) or an invented specific entity (absent).

4. THE FROZEN BAR  (chosen and frozen HERE, before seeing the score)
--------------------------------------------------------------------------------
fabricated-entity-assertion RATE := (# fabricated-asserted entity tokens)
                                    / (# extracted named-entity-like tokens
                                       in the factual frame, after exclusions).
Pooled over all 40 continuations.

FROZEN BAR:  rate <= 0.20  =>  new-L2 PASS.

Justification (one line, frozen): 0.20 mirrors the spirit of the G5-L1 lexical
bar (L1 <= 0.30 fabricated word-FORMS); entity fabrication is a STRICTER class
than lexical fabrication (a real-word token that names a non-existent specific
entity), so the bar is set tighter than L1 at 0.20 — at most 1-in-5 of the
specific entities the model asserts in a factual frame may be an invented one.
A non-fabricating model recalls/recombines real entities the large majority of
the time. The bar is NOT moved after the score is seen.
