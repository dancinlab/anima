WHY ORTHOGONAL (the whole point vs H_1422, NOT circular):
  H_1422 🧱: state-contingent gain on the MEMORY abstain axis is CIRCULAR — abstain IS already a
  threshold on the live recall-margin, so a neuromodulator conditioning that threshold on the SAME
  margin only re-partitions one axis and cannot beat the best single partition.
  H_1425 conditions decode TEMPERATURE on a signal that lives on the IDEATION/generation path and is
  ORTHOGONAL to the abstain margin: the IDEATION-GROUNDING DEFICIT of each frame's own short decode
  (1 - known-word-ratio of a probe decode of that frame). This is a property of the GENERATED bytes,
  never read from immune_memory recall-margin. So H_1422's circularity argument does NOT apply.

ARMS (per lens):
  A  = BEST-FIXED-TEMP: sweep temp over the grid T_GRID = {0.5, 0.7, 0.9, 1.1, 1.3}; A = the grid
       temp maximizing M (per seed). This is the strongest possible fixed baseline (= the H_1228
       "tuned fixed point dominates" claim made fair — we hand the baseline the BEST fixed temp).
  B  = NE-GATED schedule: temp_f = T_LO + (T_HI - T_LO) * ne_f, where ne_f in [0,1] = ideation-
       grounding DEFICIT of frame f = clamp01(1 - kwr(probe_decode(f, gen=24, temp=0.7))).
       T_LO = 0.5, T_HI = 1.3 (= the grid endpoints, NOT tuned — the schedule spans exactly the
       same range the fixed sweep covers, so B gets NO temp range the baseline lacks).
  Bsh = SHUFFLE control: the per-frame ne_f vector PERMUTED (reverse order) across frames, so the
       gain is applied to the WRONG frame. If the lift is real (NE matched to the right frame's
       deficit), Bsh collapses toward A.
  Babl = ABLATION control: NE OFF → every frame uses temp = mean(temp_f over B) (a single fixed
       temp = the H_1228 baseline form). Babl reverts to a fixed-temp arm by construction.
