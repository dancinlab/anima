  valence ≈ f(coherence/grounding): grounded+coherent context → positive;

SUBSTRATE (numpy mirror of CORE/engine_cli.hexa VAdaptField + H_1227 immune

f() is computed PER CONTEXT from the SUBSTRATE STATE ONLY:
   valence = +(grounding margin: recall-confidence = 1 - recon_err/recall_thresh,
               positive when a context grounds cleanly to a cell)
             -(contradiction/incoherence: a context whose key collides with a cell
               bound to a DIFFERENT answer, or whose recon-err exceeds the recall
               threshold = ungrounded/threatened).
   arousal = +(novelty: recon-err to nearest cell = surprise)
             +(mitosis split-rate: did this context trigger a fresh clonal split)
             +(curiosity: distance-to-known scaled by under-exposure).
   NO emotion label, NO RLHF reward, NO sentiment string is EVER input to f().
   The valence/arousal MANIPULATION (grounded-coherent vs contradicted-incoherent;
   low vs high novelty) only SCORES the metric -- it is never read by f().
