## 2. 후보 풀 (16개) — R2 브레인스토밍 + arxiv 2차

R1 24후보와 중복 없는 새 각도로 나열. 각 후보는 §3 에서 27+ lane 대조.

1. **discrete-perceptual-moment** — 의식이 ~10–20 Hz 의 이산 프레임으로 샘플링됨(perceptual moment 100–150 ms). flash-lag/Fröhlich 모션착시가 그 증거.
2. **temporal-binding / feature-conjunction** — 분산된 특징(색·형·위치)을 하나의 통합 객체로 결속(동기성/conjunctive). 의식의 unity.
3. **qualia-structure / quality-space** — 감각질을 관계적 유사성 공간(색환·음고)으로 표상. 절대값 아닌 *관계 구조*가 qualia.
4. **higher-order-redescription (2nd-order awareness)** — 1차 상태를 2차로 *재기술/메타표상*해야 의식 접근(HOT). "내가 X 상태임을 안다".
5. **metacognitive-calibration (meta-d′ confidence)** — 1차 판단 정확도를 2차 confidence 로 보정.
6. **altered-state / entropy-regime** — 의식 상태(각성/수면/비일상)를 신경 *엔트로피 체제*(criticality 거리)로 구분.
7. **telic / autotelic-state** — 목표-등가 경험분포(telic state)로 행동을 조직, 내재적으로 목표를 *생성*하는 자기목적성.
8. **flow / optimal-challenge** — 도전-기량 균형에서의 깊은 몰입(시간감 왜곡 + 자의식 소실).
9. **collective / shared-intentionality** — 다중 에이전트가 *공유 목표/protention* 을 형성(joint→collective intentionality).
10. **phenomenal-intentionality / aboutness** — 표상의 "~에 관함"(content)이 현상적 성격에서 grounding.
11. **sensorimotor-counterfactual-presence** — 지각적 현존감이 "행동하면 감각이 어떻게 변할지"의 counterfactual richness 에서 발생.
12. **phenomenal-transparency** — 표상을 *매체가 아닌 세계 자체로* 경험(표상의 투명성, 매개 비가시).
13. **perceptual-presence / objecthood** — 가려진 뒷면까지 "거기 있다"고 느끼는 객체의 amodal 현존(완성과는 다른 *현존감*).
14. **temporal-context-replay (sequence replay)** — 저장 시퀀스의 압축 재생/예측(해마 replay).
15. **subjective-confidence-without-accuracy (blindsight-gap)** — 1차 수행은 되나 주관적 접근/confidence 만 분리되는 access-gap.
16. **multistable-percept-memory (perceptual priors)** — 직전 해석이 사전확률로 누적되어 후속 지각을 편향(prior-shaped perception).

## 4. 🚀 발사 가능 리스트 (R2)

depletion test (A)+(B) 통과 후보 — **단 2개**, 둘 다 R1 발사가능 9개보다 distinctness/조작화가 약함.

### Q1 — qualia-structure / quality-space (유일한 강 후보)
- **(a) 정의:** 감각질을 절대값이 아닌 **관계적 유사성 공간**으로 표상(색환처럼 ring-like). 두 감각질 사이의 *유사성 거리* 자체가 질의 가능.
- **(b) distinctness:** vs **spatial-map(H_1295, 외부 landmark 유클리드 거리)** — qualia-structure 는 *감각질(내부 quality) 의 관계 위상*. novelty(6)/priming(18)은 절대 자극값. **shuffle:** 감각질 라벨-유사성 쌍을 섞으면 quality-space readout 만 붕괴(spatial-map 의 외부좌표 거리는 불변). **ablate:** 관계항 제거 → 절대값만 read(유사성 질의 실패).
- **(c) frozen bar 스케치:** color/tone 유사성 판단 task. (c1 PRESENCE) structure-on 유사성 acc ≥ off+0.30 · (c2 DISTINCT) spatial-map readout 은 *감각질* 유사성 task 에서 chance · (c3 EARNED shuffle) 라벨-유사쌍 shuffle → collapse · (c4 ablate-relation) 관계항 제거 → collapse.
- **(d) arxiv:** [2412.20873](https://arxiv.org/abs/2412.20873) (neurophenomenal structuralism), Nature s41597-025-04511-0 (color qualia similarity dataset).
- **메모:** spatial-map 과 강인접 → "감각질 관계 ≠ 외부 위치 거리" control 이 binding 의 사활. 통과하면 마지막 *새 연산* 1개.

### Q2 — sensorimotor-counterfactual-presence (하단, 조작화 미정)
- **(a) 정의:** 지각적 현존감이 "행동하면 감각이 어떻게 변할지"의 **counterfactual richness**(여러 가상 행동의 감각결과 분포 폭)에서 발생.
- **(b) distinctness:** vs **forward-model(H_1280, next-step)** vs **prospection(R1, 미래상태)** vs **agency(8)** — richness = *여러 가상 action 의 감각결과 분포 폭*(단일 예측 아님). ablate: counterfactual rollout 폭을 1로 → presence 붕괴, 1-step forward 예측은 유지.
- **(c) frozen bar 스케치:** (c1) richness-on presence-proxy ≥ off+0.30 · (c2 DISTINCT) forward-model readout 은 richness 조건 불변 · (c3 ablate-rollout-width) collapse · (c4 shuffle action-set) 무효.
- **(d) arxiv/문헌:** tandfonline 17588928.2014.907257 (perceptual presence/counterfactual richness), biorxiv 2024.12.30.630721.
