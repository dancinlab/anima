### 정직한 판정

- **Cambridge Declaration (2012)**: 문어를 포함한 비-인간 동물이 "의식의 신경 기질"을 가진다고 선언. 단 **선언문이지 측정이 아님** — 동료심사 없음, DOI 없음, Φ 수치 0. 권위 인용용으로만 유효.
- **문어 신경복잡도**: ~5억 뉴런(개와 비슷), 약 2/3이 팔에 분산. 분산 신경계는 정성적 "복잡도" 서사일 뿐 **Φ-proxy 정량값으로 변환된 사례 없음**.
- **Birch 2020 (4차원 프레임)**: 의식을 단일 척도로 보는 것을 명시적으로 거부 → "graded Φ across species" 가설 자체와 긴장. 종간 단일 스칼라 Φ 순위는 학계에서 지지받지 못함.
- **종간 graded Φ-proxy 데이터?** → **없음.** PCI/LZ-complexity는 TMS-EEG(인간) 및 마취 포유류에만 적용됐고, 무척추동물(문어)에 PCI/Φ를 실측한 논문은 확인되지 않음.

### Φ-proxy 가용성: 🟡 (proxy 개념은 존재, 종간 실측 부재)

### KEY 논문 (반증 측이 동료심사 우세)

### 정직한 판정 — **이것은 hype에 가깝다**

- Taiz 외 2019는 식물 의식 주장을 정면 반박: ① 뇌·조직화된 신경망 부재, ② 식물 활동전위는 동물 신경 활동전위와 **근본적으로 다름**, ③ 의인화 경계, ④ 의식은 이동성 동물의 적응 형질.
- **"통합/Φ" 엄밀 주장 존재?** → IIT를 식물에 적용한 단 한 편(Protoplasma 2021, 10.1007/s00709-021-01633-1)이 "식물 분열조직(meristem)이 의식 활동 부위"라 주장하나, 이는 **정량 Φ 수치 계산이 아닌 IIT의 정성적·개념적 적용**이다. 곧바로 동일 저널에서 Mallatt·Taiz 외(PMC8052213)가 "IIT는 식물 의식을 더 설득력 있게 만들지 못한다"고 반박. 즉 **실측 Φ-proxy 0, 동료심사 반박 우세**.
- 식물 전기신호·균근 네트워크(mycorrhizal network)는 신호전달·자원분배로 설명되며, IIT의 **통합(integration)·환원불가 인과구조**를 만족한다는 정량 Φ 계산은 제출된 바 없다.
- "Wood Wide Web"(균근 통신) 서사도 최근(2023~) 메타분석에서 **과대평가**로 재비판됨 (forest mycorrhizal network claims overstated).
- **falsifiable/supported?** → 식물 "의식"은 검증 가능한 Φ-proxy로 조작화되지 않았고, 신경기질 부재로 IIT 적용 자체가 막힘. **반증 우세 + 사변**.

### Φ-proxy 가용성: ⚪ (측정 가능한 Φ-proxy 없음, 사변/hype)

### 정직한 판정 — 의식/Φ는 아니나 complexity proxy는 실측됨

- **Trujillo 2019**: 오가노이드 진동파가 **미숙아(25–39주) EEG 발달궤적**과 상관. 측정량 = 진동·동기화·발달 ML 분류. **Φ/의식 측정 아님**, 전기생리 발달 지표.
- **Kagan 2022 (DishBrain)**: 측정량 = **학습 행동(Pong) + 전기생리 반응**. "sentience"는 자유에너지원리 맥락의 좁은 정의(적응적 반응성)로, **현상적 의식/Φ 측정이 아님**. 용어가 과대(overstated)하다는 비판 다수 — 적응적 가소성을 sentience로 명명한 것이 쟁점.
- **Habibollahi 2023 (핵심 진입점)**: 구조화 정보 제시 중 배양 신경망이 **임계성(criticality, 자기조직화 임계)**으로 이동함을 정량 측정. **임계성·avalanche·LZ 복잡도는 IIT Φ는 아니나 실측 가능한 complexity proxy**다.

## 4. 최소 검증 각도 (데이터가 존재하는 곳)

**S23 오가노이드 MEA → LZ 복잡도 / criticality** 가 유일하게 실데이터로 굴릴 수 있는 경로.

```
공개 MEA 스파이크/LFP 시계열
  → 이진화(bin) → Lempel-Ziv 76 복잡도 (LZ76)
  → criticality: neuronal avalanche size 분포의 멱법칙 지수
  → "구조화 자극 vs 무자극" 조건 간 Δ(LZ76 / criticality)
```

- **데이터 = 즉시 가용**: Habibollahi 2023 OSF `osf.io/ncvpq/` (MEA spike 시계열 + 분석코드, view-only 공개) / Kagan 2022 OSF `10.17605/OSF.IO/5U6QV`. 둘 다 **LZ76도 Φ도 계산 안 함** → 신규 계산 여지 그대로 열림.
- 근거: Habibollahi가 이미 criticality(DCC/branching) 증가를 보고했으니, **동일 공개 MEA에 LZ76를 독립 계산**해 criticality와 정합하는지 확인 = falsifiable 최소 실험.
- 사전등록 falsifier 예: "구조화 정보(게임플레이) 조건의 LZ76(bin된 spike 행렬) > 무자극/rest 조건, 유의(p<0.05)." 반증 시 → LZ-complexity ⊥ 학습 행동 (closed-negative, 발표 가치).
- 보조: LZ76 vs DCC(저자 보고값) 상관 → 두 complexity-proxy의 수렴/발산 검정.
- IIT의 진짜 Φ는 ~수백 채널 규모에서 계산 폭발 → **LZ76/PCI proxy가 정직한 대용** (cf. E1 human-EEG 클러스터와 동일 primitive). S2 문어·S3 식물은 굴릴 공개 spike 데이터 자체 부재.
