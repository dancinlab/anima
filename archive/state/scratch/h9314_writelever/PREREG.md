# H_9314 — WRITE-LEVER: 사전학습 prior 를 뒤집으려면 얼마나 써야 하는가 · 사전등록 (데이터 전 동결)

> 🔒 `bar_audit` 2 규칙 준수. **사후 bar 변경 = 자동 INVALID.**

## 0. 왜 이 실험인가 (H_9313 이 남긴 것)

H_9313 DECON-W 는 ⛔ **INVALID-WRITE** 로 죽었다 — CPT 가 극성을 못 배웠다. 그런데 그 뒤에
**설계상의 사실**이 있었다(실측):

| 사실 | 실측 |
|---|---|
| 사전학습 템플릿 라인(960)에 **held-out 어간이 등장하는 횟수** | **0 / 29 원자 · 0회** |
| 그 자리에 온 것 | **SEEN 어간만** (20/20 · 960회 · 극성 균형 480:480) |
| 내 CPT 가 심으려 한 것 | `이 영화 <held-out>고 => <극성>.` × 120회/원자 |

⟹ 모델은 *"이 슬롯엔 SEEN 어간이 온다"* 를 **960회 학습**했고, 나는 그걸 **600 step** 으로
뒤집으려 했다. **실패가 substrate 사실이 아니라 학습 예산 사실일 수 있다.**

**이건 tune-to-green 이 아니다** — 재려는 것은 "극성이 심어지는가"(WRITE)이지 가설의 DV(flip1 합성)가
아니다. WRITE 는 **필요조건**이고, 그 조건을 만족시키는 예산을 찾는 것은 계기 교정이다.
⚠️ **flip1 은 이 실험에서 읽지 않는다** — 예산을 찾은 뒤 H_9313 사전등록(bar 불변)으로 재발사한다.

## 1. DV 와 bar (검정력 유도)

**primary DV = WRITE** = held-out flip0 (n=87 · **그 arm 이 쓴 라벨** 기준).
**bar = ≥0.95** (H_9313 사전등록에서 **바이트 이월** — 손대지 않는다).
**기준선**(무-CPT · H_9308): **0.5057**. H_9313 600-step 결과: **0.4483**(= 우연 · 실패).

**보조 DV = FORGET** = SEEN flip0 (n=60). **≥0.90** 이어야 한다(망각하면 그 예산은 무효).
H_9313 600-step: 0.9500 ✅ (망각 없음 — 즉 예산 부족이지 파괴가 아니었다).

## 3. 필수 가드 (발사 전 · 매 셀)

- **QUANT-SWALLOW**(`serialize-py-1`) — 갱신이 int4 격자를 넘는가. 로그에서 확인.
- **reference-match** — CPT 모델이 **자기 학습 라인**을 맞히는가. 이것이 곧 WRITE DV 다.
- **G0 붕괴 감시**(`train-py-3`) — val_CE 낮은데 자유생성이 깨지면 **⛔ INVALID-OVERFIT**
  (소코퍼스 과적합). 그 셀은 예산 후보에서 **제외**한다.

## 4. 판정표 (사전 고정)

| 관측 | 판정 |
|---|---|
| 어떤 셀이 WRITE ≥0.95 ∧ FORGET ≥0.90 ∧ G0 정상 | 🟢 **예산 발견** — 그 (steps, lr) 로 H_9313 재발사(bar 불변) |
| WRITE 가 예산과 **단조 증가**하나 0.95 미달 | ⚠️ **UNDER-BUDGET** — 더 큰 예산으로 1회 연장 |
| WRITE 가 예산에 **무반응**(전 셀 ≈ 우연) | 🧱 **PRIOR-LOCKED** — 사전학습 prior 를 CPT 로 못 뒤집는다 = **벌어낸 음성**. A 채널 가중치 경로가 이 코퍼스 설계에서 닫힘 ⟹ 코퍼스 재설계(자연 문맥 접지) 필요 |
| WRITE 는 오르는데 FORGET 붕괴 | ⚠️ **CATASTROPHIC-FORGET** — 그 예산 무효. replay 비율을 키워 1회 재시도 |
| G0 붕괴 | ⛔ **INVALID-OVERFIT** (그 셀 제외 · `train-py-3`) |
