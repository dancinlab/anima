# H_9347 HO-CARRIER (EN) 판정 — 통제군이 조작만큼 움직였다. 이게 무슨 뜻인가?

너는 anima 재조합 벽 연구의 판정을 검토한다. 아래는 engine-native 303M byte-LM 측정 실측이다.

## 배경 (확정)
- H_9346: held-out 어간에서 사실은 착지하고(WRITE flip0=1.0) 연산자는 SEEN 어간에서 살아있는데(SEEN flip1=1.0), held-out 어간의 `not {s}` 채점에서 모델은 심은 극성을 **되뇌고 not 을 무시**한다(ECHO, DV≈0.03). ⟹ 연산자가 **어간에 게이트**돼 있다.
- H_9347 조작: held-out 어간을 담체 안에서 가르쳐 그 게이트를 열려 한다. 3팔(모두 held-out 어간, split-seed 로 배정):
  - **hoc(12)**: 선언형 `{s} => word(pol)` + 담체 `never {s} => word(1-pol)` (연산자 자신의 키)
  - **null(12)**: 선언형 `{s} => word(pol)` + `oddly {s} => word(1-pol)` (연산자 아닌 부사 · 라벨노출 동일)
  - **decl(16)**: 선언형만 = H_9346 재현
- 채점: `not {s}` · `certainly not {s}`(코퍼스 0회). DV = 연산자 발화율 = gold=word(pol XOR 1) 뱉는 비율. margin(2AFC)=first_word(자유생성)==gold 와 원시행에서 일치 확인.
- 음성통제 `notably {s}`: P2 인구조사에서 SEEN 어간 acc=0.100(연산자 죽는 표면 · not+ably 경계 파괴). 여기서 발화하면 = 연산자 아닌 광범위 라벨 뒤집기.

## 동결 판독표(사전등록)가 말하는 것
- decl ECHO(≤0.25): ✅ 양 seed. 전제조건 통과(H_9346 재현).
- hoc DV ≥0.75: 표면상 "🟢 연산자 발화".
- **BUT 교차판독**: "hoc 양성 ∧ null 양성 = 기전은 연산자가 아니라 라벨 낙수 ⛔".

## 너에게 묻는 것

**① null 통제군이 hoc 만큼(또는 더) 올랐다.** 사전등록 교차판독대로면 "낙수, 연산자 아님". 맞나? 하지만 **음성통제 notably 가 hoc(0.08/0.42)와 null(0.92/0.83)로 극명히 갈린다** — null 은 notably 에서도 발화하고 hoc 는 안 한다. 이 비대칭이 "hoc 와 null 이 같다"는 낙수 판정을 **약화**시키는가, 아니면 무관한가? null 이 광범위 라벨 뒤집기라면 hoc 도 그 안에 포함되는가, 아니면 hoc 는 다른 기전인가?

**② 진짜 기전은 무엇인가?** 두 팔의 공통점 = held-out 어간을 "부사+뒤집힌라벨" 문맥에서 가르침. hoc 는 not{s}·certainly not{s}(연산자 표면)에서 채점되고 상승. null 도 상승. 최소모형은? 후보: (a) 담체가 무엇이든 "이 어간은 부사문맥에서 극성이 뒤집힌다"를 배워 not 에 전이 (b) never/oddly 가 각각 flip-operator 로 설치되고 not 으로 일반화 (c) 순수 라벨 노출 빈도 효과. notably 비대칭이 이 셋 중 무엇을 지지/배제하나?

**③ 프런티어 프레임과의 관계.** 병렬세션 Fable 이 이 벽의 최소모형을 **two-lane(선언 저장소 ⊥ 연산자 저장소 · 런타임 다리 없음)**이라 제안했다. 결정증거는 C3(H_9329): SEEN 어간 선언극성 뒤집어도 연산자는 옛 극성 0/12. H_9347 결과가 two-lane 과 정합하나? hoc 상승 = "연산자 lane 에 엔트리 씀"인가, 아니면 "선언 lane 의 라벨이 문맥오염으로 밀림"인가? notably 비대칭이 이걸 가르나?

**④ 판정.** 이 데이터로 H_9347 을 어떻게 착지시켜야 하나? 🟢(벽 수리)/🧱(낙수 = 연산자 아님)/⏳(더 필요)? 그리고 **다음에 무엇을 재면** hoc-vs-null 을 깨끗이 가를 수 있나(1발 · engine-native corpus 계기로 표현 가능한 것)?

## 형식
간결하게. 각 답에 **어느 숫자가 그렇게 말하는지** 명시. 확신 없으면 "모르겠다 + 무엇을 재면 안다". 사전등록 교차판독을 기계적으로 적용만 하지 말고 notably 비대칭을 진지하게 다뤄라.
