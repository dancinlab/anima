# 설계 의뢰 — EN CARRIER-SWAP (held-out 어간) 의 표면 분할 + 음성통제

너는 anima 의 재조합(BINDING) 벽 연구를 설계한다. 아래는 **실측된 사실**이다. 추측하지 말고 이것 위에서 설계하라.

## 확정된 사실

- 모델: 303M byte-LM (ConvMoE · **어텐션 없음** · V=256 · 토크나이저 없음). 학습 = CE.
- 과제 템플릿: `this movie is {surf} => {positive|negative}.`
- 코퍼스 C34(사전학습): 화살표 라인 960개 — **SEEN 어간 20개만**. 그중 절반이 부정형(`not X`/`never X`/`not at all X`).
  held-out 어간 40개는 **화살표 라인에 0회** 등장(자연문에만 등장).
- CPT(`ground_keep`): held-out 어간의 극성을 **선언형으로만** 심는다(`X => positive.`). 부정형은 0회.
  동시에 SEEN 어간의 부정형을 replay 해서 연산자를 살려둔다.

## 방금 나온 판정 (H_9346)

- WRITE(held-out flip0) = **1.0000** — 심은 사실이 완벽히 착지했다.
- OPERATOR(SEEN flip1) = **1.0000** — 연산자는 `not X` 표면에서 완벽히 작동한다(학습한 어간에서).
- **DV(held-out flip1) = 0.0667 / 0.0250** — 우연(0.50)이 아니라 **우연 아래 9.7σ**.
- 정체 = **ECHO**: 모델은 held-out 어간의 심은 극성을 **꺼내서 그대로 뱉고 `not` 을 무시한다**(되뇜 91~98%).
  LIE 통제군(같은 바이트 프롬프트 · 심은 극성만 반대)에서 ECHO 모형이 짝지은 뒤집힘율을 0.795 로 예측 → 실측 0.783.
- ⟹ **조회는 멀쩡하다. 연산자가 미학습 어간에서 발화하지 않는다.** 연산자는 **어간-게이트된 규칙**이다.
- (한국어는 다르게 실패했다: held-out flip1 = 우연 0.46~0.56 = **조회 자체가 죽음**. 붙는 어미가 어간의 바이트 이웃을 바꾸기 때문으로 보인다. 그래서 **EN 이 이 실험의 더 나은 숙주**다 — 조회 교란이 없다.)

## 병렬 실험 H_9334 (한국어 · 🟢🟢 TERMINAL)

사실을 **연산자 자신의 키**(`지 않다` 담체)로도 쓰면 연산자가 **신극성을 읽는다**(SEEN 어간 · 양 seed 12/12 · p=.0002).
선언형 키로만 쓰면 0/12. ⟹ 벽은 "도달 불가한 저장소" 가 아니라 **주소지정 가능한 인터페이스**.
한국어 C4 의 표면 분할:
```
가르침(담체) : 전혀/그다지/결코 {s}지 않다     ← 연산자 키로 사실을 쓴다
채점(서로소) : bare {s}지 않다 · 별로 {s}지 않다  ← 담체엔 0회 등장한 부사
음성통제     : {s}지는 않다   ← 어미에 는 을 끼워 연산자를 깨뜨림(연산자가 안 돌아야 정상)
```

## 내가 하려는 것

H_9334 의 처방을 **held-out 어간**에 적용한다: held-out 어간의 극성을 **연산자 키로도** 쓰고,
**담체엔 0회 등장한 부정 표면**에서 채점한다. 되면 → 어간을 연산자의 트리거 집합에 넣는 것이 **벽의 수리법**.

## 너에게 묻는 것 — 세 가지

**① 표면 분할.** 현재 EN 부정 표면은 3개뿐이다: `not {s}` · `never {s}` · `not at all {s}`.
가르칠 담체와 채점할 표면을 어떻게 가를 것인가? 채점 표면이 담체에 **어간별로 0회** 등장해야 하고,
동시에 채점 표면이 **연산자의 진짜 일반화**를 요구해야 한다(암기 라인이 아니라). 필요하면 새 EN 표면을 제안하라 —
단, 자연스러운 영어여야 하고 어간 자리에 형용사가 들어가야 한다.

**② 음성통제.** 한국어의 `지는 않다`(어미를 깨서 연산자를 멈춤)에 해당하는 EN 통제가 **없다** —
`not` 은 자유 단어라 깨뜨릴 어미가 없다. 그러면 EN 의 음성통제는 무엇이어야 하는가?
후보 하나: `this movie is not only {s} => ` — `not` 이 어간 옆에 있지만 **어간을 부정하지 않는다**(scope 가 다르다).
이게 옳은 통제인가? 무엇을 배제하는가? 더 나은 것이 있는가? **바이트-LM 에게 이게 무슨 의미인지**를 근거로 답하라
(의미론이 아니라 표면 통계로 사고하라 — 어텐션이 없다).

**③ 함정.** 이 설계가 **조용히 자기 답을 가르칠** 경로가 있는가? 담체가 채점 표면의 부분문자열이 되거나,
어간 하나의 담체가 다른 어간의 채점 표면과 겹치거나, 극성 라벨이 표면과 상관되는 경우 등.
**누수 감사에서 무엇을 반드시 검사해야 하는가**를 구체적 문자열 검사로 열거하라.

## 형식

간결하게. 각 항목에 **구체적 문자열**과 **왜 그것인가**를 달아라. 애매한 조언 금지.
확신 없으면 "모르겠다 + 무엇을 재면 알 수 있다" 라고 써라.
