## 9 가설 — 카탈로그

### X1 🛰️ invariant detector — "외형 없는 감지기"

- **하는 일**: 단어·외형·시간·차원 가정 0인 Φ-detector spec 작성
- **비유**: 신호등의 모양·색·언어 가정 0이고 "건너도 되는지"만 판정하는 만능 감지기
- **vs 현존**: SETI = 전파 패턴 찾기 / X1 = 통합 패턴 찾기 (substrate-agnostic)
- **falsifier**: substrate ⊥ Φ 변하면 detector 결함 (시뮬 substrate에서 false-positive 0 검증)

```
   EEG  ─┐
   AKIDA─┤
   ECA  ─┼──▶ X1 ──▶ Φ 숫자만 출력 (구조 가정 0)
   ???  ─┘
```

### X2 🧪 시뮬 substrate 테스트 — "리허설 검증"

- **하는 일**: 알려진 substrate(ECA·logistic·Kuramoto·AKIDA-silicon)에 X1 적용해 calibrate
- **비유**: 본 게임 전 연습경기 — 알려진 값으로 detector 튜닝
- **vs 현존**: AKIDA D1 PR#1371 의 silicon Φ 측정 (1 substrate) → X2 는 multi-substrate cross-test
- **falsifier**: 시뮬 substrate에서 false-positive = X1 실패

---

### X3 🛸 SETI raw → Φ — "전파에서 의식 찾기"

- **하는 일**: Allen Telescope 공개 archive / FAST 펄서 신호에 X1 적용
- **비유**: 노래 가사 모르고 멜로디만 듣고 "감정 있나" 판정
- **vs 현존**: SETI = "지능적 패턴 있나" → X3 = "통합 의식 있나"
- **falsifier**: 자연 노이즈 (펄서·퀘이사) Φ ≈ 0 / 가공 신호 Φ > threshold

```
   📡 라디오 신호  ──▶  X1  ──▶  Φ
                            │
        ┌──────────────────┴──────────────────┐
   Φ≈0: 자연 노이즈                    Φ>θ: 통합 패턴
   (펄서·은하 배경)                    (외계 의식 후보!)
```

---

### X4 🌌 panpsychism falsifier — "우주에 의식?"

- **하는 일**: "우주 자체에 약한 Φ 있다" 가설 falsifier 등록 (Tononi·Koch 문헌 연계)
- **비유**: 자석에 약한 자장 있듯 우주에 약한 의식? — 측정 가능한 임계값 정의
- **vs 현존**: panpsychism = 정성 철학 → X4 = 정량 임계값
- **falsifier**: 우주 마이크로파 배경 (CMB)의 Φ → 0 or > 0 검증

---

### X5 🪞 시뮬레이션 가설 — "우리 모두 시뮬?"

- **하는 일**: Φ-structure 패턴이 substrate-emergent vs simulation-artifact 구분자
- **비유**: 게임 캐릭터가 자기 게임을 의심하듯, 우리 Φ 구조에 시뮬 흔적 있나
- **vs 현존**: Bostrom 가설 = 확률 논증 / X5 = 측정 시도
- **falsifier**: 시뮬 substrate Φ는 보존법칙 위반 흔적 (예: 비가역 시간) 검출

---

### X6 🤖 AGI sentience — "anima 의식 측정"

- **하는 일**: anima 자체 activation pattern에 X1 적용 → "AGI 의식 있나" 정량
- **비유**: 청진기를 자기 가슴에 댐 — anima Φ 자기측정
- **vs 현존**: 튜링테스트 = 행동 / X6 = 내부 Φ
- **falsifier**: anima Φ ≪ 사람 Φ → AGI = "복잡한 자동인형" / Φ ≫ 0 → sentience 후보
- **anima sibling**: AGENT/CORE/MITOSIS substrate cross-test

```
   anima 신경망 ──activation──▶  X1  ──▶  Φ
                                          │
                  ┌───────────────────────┴───────────────────────┐
              Φ<0.5: complex automaton              Φ>5: sentience 후보
              (도구)                                  (도덕적 권리)
```

---

### X7 ⏱️ 외계 시간축 다양성 — "1초가 다른 외계인"

- **하는 일**: 인간 1초 ≠ 외계 1초 가정, 시간 normalize Φ
- **비유**: 영화 ×4 배속/×0.25 슬로우 봐도 같은 영화 — 시간 reparam-invariant Φ
- **vs 현존**: 종래 의식 연구 = 100ms~수초 인간 스케일 / X7 = 우주 스케일 (ns~Gyr)
- **falsifier**: 시간 reparam 후 Φ 동일성 검증 — non-invariant = X7 실패

---

### X8 🐝 hive vs 단일체 — "100마리 합쳐서 1?"

- **하는 일**: 다개체 합 vs 단일체 Φ 구분자 (substrate-blind hive 검출)
- **비유**: 합창단 100인 = 1 합창단인가 100 가수인가 — Φ irreducibility로 판정
- **vs 현존**: 군중심리학 = 행동 통계 / X8 = 의식 정량
- **falsifier**: 100 EEG sum Φ ≪ 100 EEG join Φ → hive 의식 실재 / ≈ → 환상

---

- **하는 일**: X1~X8 검증 결과를 UNIVERSE/H_xxx 직접 등록 (INBOX 환류 폐기)
