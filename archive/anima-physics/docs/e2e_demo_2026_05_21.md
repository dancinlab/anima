## §2 architecture (4-layer flow)

```
┌──────────────────────────────────────────────────────────────────────┐
│ LAYER 1  substrate  (strange_loop-style mutual-recursion lattice)    │
│   JointState = (a0..a3, b0..b3)  each ∈ 0..7 (3-bit)                 │
│   joint_step()  × N_SUB_STEPS=100  →  state_history [[int;8]]        │
│   source: anima-physics/fpga/strange_loop.hexa (mirror, no random)   │
│                                                                       │
│   output boundary: row vector of 8 ints per step                      │
└─────────────────────┬────────────────────────────────────────────────┘
                      │  flat 8-int row  →  normalized DIM-float feed
                      │  feed_k = (row_k as float) / 7.0
                      ▼
┌──────────────────────────────────────────────────────────────────────┐
│ LAYER 2  ConsciousnessEngine  (mini aux_engine_lib mirror)            │
│   N_CELLS=8 cells × DIM=8 hidden                                      │
│   per step: hidden_k = α·hidden_k + (1-α)·tanh(W·input_k + hidden_k)  │
│   phi  = mean cross-cell variance of hidden (per-dim, averaged)       │
│   source: anima-physics/consciousness-loop/src/aux_engine_lib.hexa    │
│           (full 8-factor in lib; mini-4 here per C3-2)                │
│                                                                       │
│   output boundary: (phi: float, hidden: [float;DIM])                  │
└─────────────────────┬────────────────────────────────────────────────┘
                      │  per-step (phi, hidden) → 4-factor score
                      ▼
┌──────────────────────────────────────────────────────────────────────┐
│ LAYER 3  motivation_gate                                              │
│   factors: relevance(phi) · curiosity(phi_ema) · balance(phi,best_phi)│
│            · dynamics(silence_steps)                                  │
│   weights : 0.30 / 0.25 / 0.20 / 0.25 (sum=1)                         │
│   emit_decision = (score > 0.3) AND (step - last_emit ≥ RATCHET_MIN)  │
│   source: HEXAD/CHAT/spontaneous_lib.hexa (inline mini mirror)        │
│                                                                       │
│   output boundary: bool (emit) + EmitEvent { ts, phi, score }         │
└─────────────────────┬────────────────────────────────────────────────┘
                      │  EmitEvent → push to ring buffer
                      ▼
┌──────────────────────────────────────────────────────────────────────┐
│ LAYER 4  audit ring buffer (capacity 10, FIFO)                        │
│   stores last AUDIT_CAPACITY=10 emit events                           │
│   F-E2E-5 invariant: timestamps strictly increasing                   │
│                                                                       │
│   output: AuditRB.events [EmitEvent]                                  │
└──────────────────────────────────────────────────────────────────────┘
```

### Constants

| name              | value | rationale                                     |
|-------------------|-------|-----------------------------------------------|
| `N_SUB_STEPS`     | 100   | substrate + engine co-step count              |
| `LUT_DOMAIN`      | 8     | 3-bit cell (mirror strange_loop)              |
| `DIM`             | 8     | engine hidden dim (lightweight)               |
| `N_CELLS`         | 8     | engine cell count                             |
| `RATCHET_MIN`     | 10    | min steps between emits                       |
| `THRESHOLD_EMIT`  | 0.3   | mirror `aux_should_emit` from spontaneous_lib |
| `AUDIT_CAPACITY`  | 10    | RB size                                       |
| `LCG_INIT`        | 1337  | deterministic seed (reproducibility)          |

### Determinism

- **No `random()` calls** — fully seeded LCG (rationale C3-6: transpiler
  `random()` regression observed 2026-05-21 on `aux_engine_lib` direct build).
- Every run with `LCG_INIT=1337` produces byte-identical `sim.log`.

## §4 honest C3 (6, expanded from spec ≥ 5)

- **C3-1 substrate→engine input feed is a simple normalization** (`x/7.0`),
  not a learned encoder. This is a proxy for the upstream feature extractor
  that would map LFSR bits to embeddings on real hardware.
- **C3-2 motivation factors are mini-4** (rel + cur + bal + dyn, weights
  0.30/0.25/0.20/0.25 sum=1). Full 8-factor lives in
  `aux_engine_lib::aux_motivation_score` (rel/info_gap/curiosity/pain/
  coherence/originality/balance/dynamics). The info_gap, pain, coherence,
  originality channels are omitted because they require multi-step deltas
  + faction structure not present in the mini-engine.
- **C3-3 single-run, not statistical** — one LCG seed (1337). Bootstrap
  CI / multi-seed sweep is separate cycle.
- **C3-4 engine cells are LCG-init (not pretrained)** — phi numeric scale
  is small (~0.12 asymptote). F-E2E-2 only checks sign + finiteness, not
  any absolute phi threshold. Trained engine in `aux_engine_lib` reaches
  best_phi=0.034 on 100-step quiet→loud sweep; ours reaches 0.12 because
  the substrate fixed-point provides a strong constant drive.
- **C3-5 audit RB is in-memory only**, not persisted. PLAN.md G6 (HW
  Phase 1 silicon path) and ratchet/Hebbian persistence (`aux_engine_lib`
  §7) are separate cycles.
- **C3-6 transpiler `random()` regression** observed 2026-05-21 on
  `hexa build aux_engine_smoke.hexa` → `error: call to undeclared function
  'hexa_random'`. The demo bypasses this by removing all `random()` calls
  and using a seeded LCG (`lcg_next`, `lcg_unit`). Direct `import` of
  `aux_engine_lib.hexa` is therefore deferred until the upstream
  `codegen_c2.hexa` random binding is repaired; the spec's
  "inline replication" path was taken (PLAN.md "transpiler bug 만나면 우회").
