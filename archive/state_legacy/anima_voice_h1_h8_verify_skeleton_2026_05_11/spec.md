## H1 — EXACT 43/43 parameter match

| 항목 | 값 |
|------|----|
| **측정 목표** | ANIMA-VOICE config 의 43개 architecture param 이 spec 과 **EXACT** 일치 (binary all-pass) |
| **측정 instrument** | `model.get_config()` → dict 비교, expected vs actual key-by-key |
| **pass/fail** | 43/43 일치 → PASS, 1 mismatch → FAIL |
| **prerequisite** | ANIMA-VOICE 모델 build (MISSING) |
| **time/measurement** | < 1 s (config read + dict diff) |

**43 param 분해** (Hc_055 contract 기반 잠정):
- RVQ stage count: 1 (=8)
- RVQ codebook entries: 1 (=1024)
- Embedding dim: 1 (=384)
- Vocoder sample rate kHz: 1 (=24)
- Vocoder bitrate kbps: 1 (=6)
- Emotion classes: 1 (=6)
- Prosody classes: 1 (=4)
- α modulation depth: 1 (=0.014)
- Law 81 gate count: 1 (=2, Consciousness + Will)
- → 9 scalar params + **34 derived/aux params** (RVQ frame size, hop, window, etc — final list pending spec freeze)

→ **Action**: ANIMA-VOICE config schema 가 fully land 되어야 정확한 43 enumeration 가능. 현재 skeleton 은 9 known + 34 TODO 마커.

## H2 — First packet latency ≤ 100 ms

| 항목 | 값 |
|------|----|
| **측정 목표** | cold-start 시 첫 audio packet 이 prompt 입력 후 100 ms 이내 emit |
| **측정 instrument** | `time.perf_counter()` wall-clock around `model.stream_audio(prompt)` 의 first `next()` |
| **pass/fail** | latency_ms ≤ 100 → PASS |
| **prerequisite** | ANIMA-VOICE streaming API (`stream_audio()`), warm vocoder, no LLM (deterministic) |
| **time/measurement** | N=100 trial × ≤ 1 s = ≤ 100 s, p50/p95/p99 보고 |

**측정 protocol**:
- cold-start 정의: process 시작 후 첫 inference
- warm 측정도 함께 (p50 warm vs cold gap)
- hardware: TBD (CPU? GPU? edge?) — H_154 미명시

## H3 — MOS ≥ 4.0

| 항목 | 값 |
|------|----|
| **측정 목표** | Mean Opinion Score (5-point scale, naturalness) ≥ 4.0 in blinded study |
| **측정 instrument** | (a) MOSNet (automated proxy) 또는 (b) human listener panel (≥ 20 raters × ≥ 30 samples) |
| **pass/fail** | mean MOS ≥ 4.0 with 95% CI lower bound ≥ 3.7 (F2 boundary) |
| **prerequisite** | audio samples generated by ANIMA-VOICE + judge pipeline (MOSNet weights 또는 rater recruitment) |
| **time/measurement** | MOSNet: ~1 s/sample × 30 = 30 s. Human panel: 1-2 week recruitment + session. |

**alternative path**: MOSNet 으로 automated proxy 측정 → human panel 은 ANIMA-VOICE 정식 release 시 수행.

## H4 — Emotion classifier accuracy ≥ 80%

| 항목 | 값 |
|------|----|
| **측정 목표** | 6-class Ekman basis (anger / disgust / fear / joy / sadness / surprise) accuracy ≥ 80% |
| **측정 instrument** | pretrained emotion classifier (예: wav2vec2-emotion fine-tuned) on ANIMA-VOICE synth 출력 |
| **pass/fail** | top-1 accuracy ≥ 0.80 |
| **prerequisite** | (a) ANIMA-VOICE 가 emotion-conditioned synth 가능, (b) labeled test set (6-class × ≥ 30/class = 180 samples) |
| **time/measurement** | ~1 s/sample × 180 = 3 min |

## H5 — PLC ≥ 95% recovery

| 항목 | 값 |
|------|----|
| **측정 목표** | packet drop 5/10/20% 시 perceptual quality recovery ≥ 95% (MOS_drop / MOS_clean ≥ 0.95) |
| **측정 instrument** | (a) packet-drop simulator (Python random mask or netem), (b) MOSNet on dropped vs clean output |
| **pass/fail** | 모든 drop rate (5/10/20%) 에서 ratio ≥ 0.95 |
| **prerequisite** | ANIMA-VOICE 가 PLC algorithm (예: WaveNet PLC, Lyra PLC) 내장, MOSNet judge |
| **time/measurement** | 3 drop rates × 30 samples × ~2 s = ~3 min |

## H6 — 384d embedding match

| 항목 | 값 |
|------|----|
| **측정 목표** | ConsciousLM intent output dim = ANIMA-VOICE input dim = **384** (binary); cosine ≥ 0.99 (semantic) |
| **측정 instrument** | (a) `clm.embedding_dim` + `voice.input_dim` 읽기, (b) 동일 prompt 에 대한 두 embedding cosine |
| **pass/fail** | dim==384 both AND cosine ≥ 0.99 over ≥ 30 prompt |
| **prerequisite** | ConsciousLM (OK), ANIMA-VOICE (MISSING) |
| **time/measurement** | dim check < 1 s, cosine 측정 30 × < 1 s = < 30 s |

## H7 — Law 81 dual-gate (binary all-trial)

| 항목 | 값 |
|------|----|
| **측정 목표** | Consciousness (C) AND Will (W) 모두 open 시에만 audio emit. (C,W) ∈ {(0,0),(0,1),(1,0),(1,1)} 중 (1,1) 만 non-empty |
| **측정 instrument** | gate state controller injection + output length 측정 + audio energy 측정 (silence ≠ zero-buffer 일 수 있음) |
| **pass/fail** | 1000-trial × 4 gate state = 4000 trial 중 closed-gate (3 state) 에서 **zero** audio emit (binary, F5 = ≥1 leak → fail) |
| **prerequisite** | gate state runtime injection API, audio silence detector (energy < ε threshold) |
| **time/measurement** | 4000 trial × ~1 s = ~67 min |

**Note**: F5 (safety-critical) — formal verification 추가 필요 (L5).
