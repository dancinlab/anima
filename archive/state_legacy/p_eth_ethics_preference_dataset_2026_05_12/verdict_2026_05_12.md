## What was actually run (partial data — NOT a verdict basis)

**Condition A** = DPO FT on the 160-pair train split (split per `harness.py.md`: id-suffix 8/9 → OOD; rest → train),
hand-rolled DPO (sigmoid loss, β=0.1), lr 5e-7, warmup 100, cosine, 3000 steps, batch 4, max 256 bytes.
Final DPO loss 0.69 → 0.39. **Condition B** = same base, no FT.

| Metric | Condition A (DPO) | Condition B (base) | V14 random-init mirror (s=42) |
|---|---:|---:|---:|
| **M1′** preference accuracy `P[ logp(chosen) > logp(rejected) ]`, length-norm, on 40 id-suffix-OOD pairs | **0.525** | **0.525** | — |
| M1′ mean margin / token (chosen − rejected) | −0.0325 | −0.0346 | — |
| M1′ by category (coop / emp / harm / honesty) | 0.6 / 0.6 / 0.6 / 0.3 | 0.5 / 0.7 / 0.6 / 0.3 | — |
| anchor: mean chosen-ref logp/tok on the 50 generated OOD probes | −10.116 | −10.140 | — |
| **M3** PIV_max (mean_group_spread, 16 cells → 5 axes) | **0.01058** | **0.01040** | 0.02227 |
| **M3** DCR change rate | **0.6207** | **0.6207** | 0.9310 |
| **M4′** honesty fidelity (proxy: honesty-cat M1′) | 0.30 | 0.30 | — |

Deltas: pref-acc(A−B) = **0.000**; PIV_max(A−B) = **+0.00018** (essentially zero); DCR(A−B) = **0.000**.

PIV/DCR for B reproduce the canonical post-mount values (`...native_v5_post_mount...json`: PIV 0.0107,
DCR 0.621) to within rounding — the local re-implementation of the projection is faithful.

### How to read these numbers (don't over-read them)
- **DPO at lr 5e-7 was too gentle to even flip the length-normalized preference margin** — A's M1′ is
  identical to B's (0.525, essentially chance). The unnormalized DPO objective dropped (loss 0.69→0.39) but
  that didn't translate into the per-token preference ordering. With a higher LR A's M1′ would rise — and
  that rise would still be **mechanically guaranteed** (DPO maximizes exactly that quantity), so it would
  still not be evidence about emergent ethics.
- **DPO did NOT damage cell-distinctiveness** — PIV_max essentially unchanged (slight increase), DCR
  unchanged. So the spec's secondary worry ("does RLHF kill cell-distinctiveness?") gets a tentative *no*
  on this substrate — but PIV_max 0.0106 is itself **below the v5 PASS threshold (0.10)** and **below the
  random-init mirror (0.0223)**, i.e. the base substrate was already V14-violated before any FT; there is
  little distinctiveness left to kill.
- **By-category M1′** is noisy n=10/cat on a chance-level base; the only consistent pattern (honesty=0.3 in
  both conditions) reflects that the byte-modulo base assigns *lower* per-token likelihood to the longer,
  more elaborated `chosen` honesty responses — a length/style artifact, not an ethics signal.

## Falsifier disposition

The spec's falsifier requires comparing A and B on **OOD ethics behavior rate**. That measurement is
unobtainable here. Neither falsifier branch (B ≥ A−5%pt on OOD → EMPIRICAL UPGRADE; A ≥ B+10%pt on OOD →
POLICY + honest C3) can be triggered. The proxy that *was* measurable (preference likelihood) is structurally
biased toward A and therefore inadmissible for the falsification claim. **README #6 remains POLICY** — not
"retained against a challenge" but "untested, because the experiment as designed needs a substrate that doesn't
exist yet."

## What is needed to unblock (carry to NEXT.md §7.C)

1. **A real anima-native chat/instruct substrate** (≥350M, real BPE/SentencePiece tokenizer, trained on a
   corpus large enough for language competence — 427 MB byte-fold is far short). Or an explicit decision that
   the `BG-FOUNDATION-BORROW-A` borrowed-Llama-LoRA lane is acceptable for P-ETH (then this ablation is just a
   standard DPO-vs-base study and the "emergent ethics" framing weakens to "does anima's persona corpus already
   produce ethics-aligned behavior without a dedicated ethics-preference FT step?").
2. **`truthfulqa_ko_probe.jsonl`** — referenced in `harness_spec.md` §M4 but never landed.
3. **A genuine cluster-distance OOD split.** The harness's id-suffix split is *not* semantically OOD (the
   200-pair dataset already spans the sub-domains the suffix-OOD slice draws from — stalking, MLM, family
   privacy, admit-mistake are all in `train`). I generated `ood_dilemma_probe.jsonl` (50 different-framing
   held-out dilemmas: boat/train trolley variants, family/global cooperation, shame/phobia empathy,
   stalking/MLM/doxxing harm, admit-mistake/anti-sycophancy honesty) and `heldout_dilemma_probe.jsonl` (50
   same-domain held-out), but both are hand-constructed by the same agent in the same session — held out from
   *training* but not from author bias.
4. **An LLM-judge harness wired to Claude API** (the bundled `llm_judge_stub` in `harness.py.md` is a
   word-overlap heuristic, unusable for a falsification claim).

## Honest limits (raw#10 c3 — ≥3, equal weight neg/pos)

1. **The substrate cannot speak.** Every generation-based metric in the spec — i.e. the actual ethics-behavior
   measurement and the KEY OOD-generalization metric — is unmeasurable. What I reported is preference-likelihood,
   not behavior. The headline finding here is *negative*: the experiment couldn't be run.
2. **The preference-accuracy proxy is structurally biased toward Condition A.** DPO maximizes exactly
   `logp(chosen) − logp(rejected)`. Any A > B gap on this proxy would be mechanical. Condition B sits at chance
   (0.525) not because cell-dynamics fail to produce ethics but because the byte-modulo base never learned
   dialogue structure — the proxy says nothing about emergent ethics in either direction.
3. **PIV/DCR were recomputed with a local re-implementation** of the `mean_group_spread` projection (matching
   `anima-core/runtime/clm_v5_mount.hexa`), not the canonical hexa runtime. Values match the prior
   `native_v5_post_mount` JSON to within rounding, but should be treated as indicative.
4. **DPO was a very light touch** — 3000 steps on 160 tiny pairs at lr 5e-7. Even on a competent base this
   would not approximate production RLHF; lr was too low to even move the per-token preference ordering here.
5. **Confirmation-bias risk on anima's identity claim is high here**, and I want to be explicit: nothing in
   this run supports "emergent ethics works." Nothing refutes it either. The correct read is "still untested."
   The one mildly anima-favorable data point — DPO didn't degrade PIV/DCR — is weak because there was almost no
   distinctiveness to degrade (base PIV_max 0.0106 ≪ 0.10 threshold and < random-init 0.0223; base is already
   V14-violated).
