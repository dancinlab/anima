\section{The \texttt{.kosmos} Coordinate --- Carving Engine, $D^\ast=6$ Capacity, and an On-Chip Closed-Negative}
\label{app:kosmos_coord}

This appendix is the full data record for the memory of \S\ref{sec:memory}. Emit,
anchors, and memory persist as \texttt{.kosmos} (\texttt{a\_kosmos}; format SSOT
in the sibling \texttt{kosmos} repo, anima is pointer-only). The record factorizes
a \emph{coordinate} from a \emph{payload}, the carving engine that produced it is
reconstructable, the coordinate holds $D^\ast=6$ usable dimensions, it decomposes
into only $3$--$4$ interpretable named axes (an honest negative), and its
cross-lingual semantic linkage does \emph{not} transfer to on-chip AKD1000
learning (a closed-negative).

\subsection{Coordinate $\perp$ payload}
\label{app:kosmos-factor}

The \texttt{.kosmos} record factorizes:
\begin{equation}
\underbrace{[\,\texttt{vacuum\_psi}\,(x,y),\ \texttt{cell\_id},\ \texttt{basin\_radius},\ \texttt{tier}_\text{Knuth},\ \texttt{tags}\,]}_{\text{coordinate (a $\Psi$-space placement)}}
\;\perp\;
\underbrace{[\,\text{text},\ \tau_{1..5}\,]}_{\text{payload (text + 5-ch tension)}} .
\label{eq:kosmos-factor}
\end{equation}
The coordinate is a $\Psi$-space placement: the Law-71 2D \texttt{vacuum\_psi},
a MITOSIS cell id, a basin radius, a Knuth-ordinal tier, and tags; the payload is
the text plus a $5$-channel tension vector. The two are orthogonal (coord carries
no text bytes; the AKD1000 probe below verifies coord$\perp$text by construction,
C4). Anchors enter the engine \emph{only} via \texttt{kosmos\_io} into
\texttt{brain\_decide} (single slot, Appendix~\ref{app:eg-brain}); they are
environment context, preserving p4.

\subsection{Honest negative: $3$--$4$ named axes, not $8$}
\label{app:kosmos-axis}

(\texttt{.verdicts/kosmos-axis-semantics/SUMMARY.txt}; GPU-trained s16 ckpt,
$N=5995$, $d=768$): PC1 ($49\%$ var) $=$ carving-radius/$\Psi$-depth
($|\rho|=0.91$--$0.92$, what the current 2D \texttt{vacuum\_psi} already captures,
canon-corr $0.96$); PC2 ($17\%$) $=$ carving form ($\omega^2=0.61$, the single
clean categorical axis); PC3 ($8\%$) $=$ form residual; PC5 ($5\%$) $=$ curriculum
progression ($|\rho|=0.67$); PC4/PC6--PC16 $=$ distributed/entangled tier/domain
code (real but not linearly separable on any single axis). \textbf{Only $3$--$4$
axes carry a human name} (depth, form, form-residual, curriculum); the manifold
does \emph{not} decompose into $8$ clean named axes. Naming all $8$ would be
fabrication --- an honest negative on the $8$-clean-axis hope
(\texttt{a\_paper\_negative\_ok}). A coord v-next $[\text{depth, form,
form\_resid, curriculum, residual}_{0..3}]$ is filed to hexa-lang.

\subsection{Closed-negative: on-chip cross-lingual linkage does not transfer}
\label{app:kosmos-akida}

On the real AKD1000 silicon (BackendType.Hardware, SDK $2.19.1$, host
\texttt{pi5-akida}), a parallel-vs-concat cross-lingual semantic-linkage advantage
(H\_911) does \emph{not} survive last-layer Hebbian on-chip learning
(\texttt{.verdicts/clm-akida-multiling-semantic/result.txt}). The corpus is $25$
anchors ($5$ concepts $\times$ $5$ langs ko/en/zh/ru/ja), byte-identical payload
multiset across orderings (only \texttt{@corpus} member order differs;
parallel.limen sha256 \texttt{cca21b21\dots}, concat \texttt{02699eeb\dots}). The
int4 backbone is byte-identical across both arms (sha256 \texttt{c626c638\dots}).
Across $N=12$ paired trials (shared per-trial init, learn confirmed on all $12$):
\begin{equation}
\text{mean }\Delta = \mathbf{-0.00092},
\qquad
95\%\ \text{CI} = [-0.00319,\,+0.00135]\ (\text{straddles }0),
\qquad
\text{sign\_stable} = \text{False}\ (6{+}/6{-}).
\label{eq:akida}
\end{equation}
\textbf{Verdict: REFUTED} --- the gap is within the chip's own
stochastic-plasticity noise (H\_904). A single naive run had flipped between
$+0.0072$ and $-0.0042$ on consecutive executions because the AKD1000 re-inits
weights non-deterministically; cherry-picking the positive draw would have
fabricated a result. The frozen falsifier required a paired multi-trial
distribution test, and that test shows the parallel advantage is indistinguishable
from chip noise. This is a Lane~A (AKIDA) result, recorded separately from any
Lane~G/GPU number (\texttt{a\_lane\_akida\_gpu\_split}).

\subsection{Honest scope}
\label{app:kosmos-scope}

The carving engine is reconstructed at random init (no s16 carve ckpt), so its
probes verify wiring, not learned quality. The dim ladder is a toy
independent-signal placement ($N=600$, CPU, \$0) with injected redundancy as a
design choice to make saturation measurable; the real anchor population's true
$D^\ast$ is unmeasured (the toy proves the method and the curve shape,
scale-transfer unverified, \texttt{a\_toy\_scale\_recheck}). The axis-semantics
result is a single s16 rung (Lane-G), not promoted to a general claim. The AKD1000
closed-negative is a $N=12$ paired on-chip result with a CI straddling $0$ --- an
off-chip hybrid head is named as future work, not closed here.
