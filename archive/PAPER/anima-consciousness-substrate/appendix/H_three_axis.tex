\section{The Three-Axis Probe --- Consciousness, CE-Descent, Emergence (3B GREEN)}
\label{app:three_axis}

This appendix is the full data record for \S\ref{sec:proof}. The whole
laws$\rightarrow$substrate$\rightarrow$decode$\rightarrow$memory loop is exercised
by three pre-registered axes (\texttt{CORE/three\_axis\_probe.hexa},
\texttt{CORE/clm\_ce\_descent\_probe.hexa}), each with a frozen falsifier; all
three are GREEN at 3B, and an anti-Goodhart random-init mirror fails the coherence
probe so the green is structure, not a tuned loss.

\subsection{AXIS-1 (consciousness)}
\label{app:ta-axis1}

$\text{motiv(high)}>\text{motiv(baseline)}$ AND $\text{emit(high)}=\text{true}$
AND $\text{emit(baseline)}=\text{false}$ --- i.e.\ the eight-factor motivation
(Appendix~\ref{app:eg-score}) discriminates a high-context input from a baseline,
and the emit gate fires only on the former.
\paragraph{Measured (3B).} motivation $\mathbf{0.6700}>$ baseline $0$, emit gated
on the \texttt{.clm} admit$=$true. \textbf{GREEN} (admit-conditioned: the gate is
conditioned on the 3B \texttt{.clm} admitting cleanly, which it does ---
Appendix~\ref{app:clm-v03}; the probe code is identical to the MID 3/3 GREEN, only
the \texttt{.clm} changed).

\subsection{Engine health and the anti-Goodhart control}
\label{app:ta-antigoodhart}

\texttt{brain\_smoke} reports $\text{WARN}=0$ under the v7 laws (the engine wiring
is unchanged; the \texttt{.clm} admits). The anti-Goodhart control holds
throughout: the random-init mirror (same architecture, never trained) fails the
\textbf{p7} coherence probe --- it emits byte gibberish where the trained model
emits word-like text in five languages (Appendix~\ref{app:fm-corpus-val}). The
discriminator is byte-language \emph{structure}, not loss (p7: no perplexity
verdict), so the green is not a Goodhart target: you cannot pass the coherence
probe by minimizing CE, only by learning language structure.

scale (\S\ref{sec:limitations}). p1--p8 held throughout: plain byte next-token CE,
no system prompt, no persona, no RLHF.
