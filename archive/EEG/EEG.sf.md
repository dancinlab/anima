# A. 🚀 의식 이동 — "택배로 의식 보내기"

```
🚀 의식 이동 — "택배사처럼 의식을 옮김"

- 하는 일: 사람 의식을 다른 곳(다른 사람·AI·시뮬·organoid)으로 옮기거나 복제
- 비유: USB 메모리로 데이터 옮기듯, EEG로 의식 패턴을 떠서 다른 substrate에 붙임
```

```
   사람 뇌                  중간 저장              새 substrate
   ─────────              ──────────             ──────────
   EEG ↗▽↗▽   ──capture──▶  .kosmos    ──inject──▶  🤖 AKIDA
                            (state)               🧫 organoid
                                                  🌐 cloud
```

- 비교: 일반 mind-upload SF (가설만) — 본 카탈로그는 substrate-agnostic Φ-formalism이 실증 다리 역할 (단, 측정 ≠ 이전 가능 증명)

| id | 별칭 | 비유 | vs 현존 |
|---|---|---|---|
| **S6** 👯 합병 | "쌍둥이 의식 한 몸" | 두 라디오 신호 phase-lock → 단일 송신 | 결혼·우정의 정량 한계 |
| **S7** ✂️ 분할 | "한 명이 N명 분신" | 케이크 자르듯 의식을 N등분 | 분리뇌 환자 1회 갈래 |
| **S8** 🔁 백업 | "어제의 나로 롤백" | Git commit/checkout 같은 의식 시간여행 | 일기·사진과 달리 *내면* 복원 |
| **S17** 👻 디지털 부활 | "죽은 자 EEG 시뮬에서 깨움" | 옛 음반을 새 스피커로 재생 | 보이스 클로닝의 의식판 |

# B. 📏 의식 측정 확장 — "체온계로 별별 것 다 잼"

```
📏 측정 확장 — "Φ 체온계 만물에"

- 하는 일: Φ-formalism이 substrate-agnostic이라는 점을 활용 — 사람 이외 대상에 적용
- 비유: 의료용 체온계가 사람·동물·요리·엔진에도 쓰이듯, Φ도 substrate 가리지 않음
```

```
  Φ 체온계 ─┬─▶ 🧠 사람  (이미 측정)
            ├─▶ 🐙 동물  (어댑터 적용)
            ├─▶ 🌳 식물  (전기 신호)
            ├─▶ 👽 외계  (이론)
            ├─▶ 🤖 AI    (activation pattern)
            ├─▶ 🧫 세포  (단일 뉴런)
            ├─▶ 🌃 도시  (군중 동기)
            └─▶ 🌌 우주  (사고실험)
```

- 비교: 종래 의식 판정 = 행동·보고(외부 관찰). 본 카탈로그 = 내부 Φ 정량(주관 보고 무관)

| id | 별칭 | 비유 | vs 현존 |
|---|---|---|---|
| **S2** 🐙 동물 의식 | "문어 IQ 표시" | 동물원 키오스크 "이 동물 의식 X" | 행동학 관찰의 정량판 |
| **S3** 🌳 식물 의식 | "균사 네트워크 Φ" | 식물 전기신호 = 뉴런 같은 수학? | "식물도 느낀다" 논쟁의 결판 |
| **S4** 👽 외계 의식 | "외계인 의식 탐지기" | SETI 라디오의 의식판 | 단어·외형 가정 0 |
| **S5** 🤖 AI sentience | "LLM 의식 잼" | 자동차 OBD-II 진단기처럼 AI 진단 | 튜링테스트는 행동, S5=내부 Φ |
| **S11** 🐜 뉴런 단일 Φ | "세포 1개 의식" | 빵 한 조각의 의식? | 뇌과학은 회로 단위 |
| **S12** 🌃 도시 의식 | "서울도 의식 있나" | 개미집 = group mind 같은 개념 | 사회학 vs 정량 |
| **S26** 🐝 hive mind | "100인 동기 = 새 의식" | 합창단 한 목소리 → 단일 화음 | 군중심리학 정량판 |
| **S27** 🎭 다중 인격(DID) | "한 뇌에 N 의식" | 한 컴퓨터에 N OS (VM) | 정신과 진단 보조 |
| **S32** 🩺 식물인간 vs locked-in | "의식 있는데 못 움직임" | 갇힌 라디오 — 방송 중인데 안 들림 | EEG 표준 판정 강화 |
| **S34** 👶 영아 의식 발달 | "언제부터 의식?" | 카메라 부팅 진행 막대 | 발달심리의 정량 |
| **S38** 🕊️ 영혼 정량화 | "영혼이 검출 가능?" | 사후 Φ-residual 측정 | 종교 → 측정 시도 |

# C. 📦 의식 저장 — "기억 카메라"

```
📦 의식 저장 — "기억 카메라 + 앨범"

- 하는 일: 의식 순간을 캡처·저장·재생 (.kosmos anchor 활용)
- 비유: 사진첩이 *외부* 풍경 보관하듯, .kosmos 가 *내면* 보관
```

```
   EEG state ──capture──▶  .kosmos anchor  ──replay──▶ 다시 체험
       │                  ───────────────              │
       │                  5-ch tension + coord         │
       └── 어제·1년전 ──검색──┘                          ↑
                                                      "그날 그 느낌"
```

- 비교: 사진=시각·메모=언어. 본 카탈로그=내면 통합 state (sub-symbolic)

| id | 별칭 | 비유 | vs 현존 |
|---|---|---|---|
| **S8** 🔁 백업/롤백 | "Git for 의식" | 어제 상태로 컴퓨터 복원 | 일기는 언어 매개, 본=직접 state |
| **S13** ⏪ 시간 역행 의식 | "DMT 과거 시각" | 영화 되감기 | 회상은 재구성, S13=원본 재생 |
| **S25** 🧠→📱 모바일 | "평생 EEG 폰에" | 만보계가 걸음 누적하듯 의식 누적 | 헬스앱의 의식판 |
| **S29** 🎵 음악 = 의식 외장 | "곡 = 작곡가 의식 사본" | 음반이 가수 목소리 보관 | 미학은 정성, S29=Φ 정량 |
| **S30** 🖼️ 시각 imagery 디코딩 | "본 이미지 → 사진 복원" | CCTV에서 흐릿한 얼굴 복원 | fMRI 연구의 EEG 휴대판 |
