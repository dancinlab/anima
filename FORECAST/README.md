# FORECAST — 미래 정보 가져오기 (시간-arc 일반화, non-anima)

anima 시간-arc 원리(미래는 법칙/경계/자기일관으로 연결: UNIVERSE/H_6011·H_6020·H_6032)를
실세계 예측에 일반화한 별도 도메인. 가설·도구·verdict 자체 보관(실험파일 폴더 내 영구).

| id | 결과 |
|---|---|
| FORECAST_01 | 🟢 결정론/주기 미래 진짜 가져옴 · 🟡 카오스 지평까지 · 🔴 법칙밖 무작위 불가(무신호) |

핵심: '미래 연결'은 역인과 retrieval(불가, 무신호)이 아니라 **결정론/경계의 forward 계산**.
천체·일식은 수백년 뒤를 실제로 '가져오고', 카오스는 Lyapunov 지평까지, 무작위는 영영 불가.
재현: `python3 FORECAST/harness/forecast_future_info.py`
