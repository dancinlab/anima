## §1 Origin

`hexa-brain` is the standalone v1.0.0 release of what previously lived inside
the `anima` monorepo at `anima-eeg/`. The spinoff was authorized 2026-05-04
after **7 production cycles on real OpenBCI Cyton+Daisy 16ch hardware**
demonstrated that the EEG pipeline had stabilized into a substrate-agnostic
neural-interface library with reuse value beyond anima's consciousness-research
scope.

The mechanical operation was a `git subtree split` of the `anima-eeg/` prefix
at anima HEAD `1b306eec24999ffd28505995655674b0f2beaa31`, preserving full
per-file history rooted at directory contents. License switched from anima's

**v1.0.0 commit**: `1ffd00ee feat(hexa-brain v1.0.0): spin-off from anima/anima-eeg @ 2026-05-04 — scalp EEG hexa pipeline (OpenBCI Cyton+Daisy 16ch), 30 hexa CLI tools (~600KB)`.

## §4 CLI dispatch design

v1.0.0 single-subsystem dispatcher (deprecated): bash shim that routed 8 verbs
to `<root>/<file>.hexa`.

v1.1.0 dual-subsystem dispatcher (current): bash shim that routes
`hexa-brain <subsystem> <verb>` to either `eeg/<file>.hexa` or
`tool/module/.../<file>.hexa`. See
`cli_dispatch_design_2026_05_04.ai.md` for the full v1.1.0 design.

## §5 Cross-link to anima/ consumer pattern

Anima retains its `anima-eeg/` directory as a **legacy mirror** during the
stabilization grace period. The cross-repo dependency contract is documented in
`anima_consumer_cross_link_2026_05_04.ai.md` (this package) plus the anima-side
forward-pointer at `anima/docs/ai-native/hexa_brain_consumer_cross_link_2026_05_04.ai.md`.

Pin guidance for anima cycles consuming hexa-brain: lock to v1.1.0 (current
HEAD post-d75f7c3d) until v1.2+ stabilizes the cross-subsystem interface.


1. **Same-day v1.0.0 → v1.1.0 churn** is unusual for SemVer; v1.0.0 was
   effectively a stepping-stone tag carved into git history before the
   dual-subsystem layout landed. Consumers that pinned to v1.0.0 in the brief
   window between commits `1ffd00ee` and `d75f7c3d` will see a different
   on-disk shape than v1.1.0 consumers (flat root vs eeg/ + core/ subdirs).
2. **Subtree-split history rewriting**: pre-split commit messages reference
   `anima-eeg/<path>` paths that no longer exist in this repo's working tree.
   The blobs are recoverable but the path strings in old commit subjects/bodies
   are stale. Same applies to the v1.1.0 `core/` subsystem ingestion from
   `anima-eeg-core/` (44 commits with stale paths).
3. **No CI yet at v1.0.0 or v1.1.0**: no `.github/workflows/` or pre-commit
   configuration shipped. The selftest invariants live inside individual
   `.hexa` files (`--selftest` flag); no aggregate CI gate exists. Adding
   GitHub Actions is deferred to a v1.x cycle.
   ecosystem alignment, but no per-file SPDX header sweep was performed. Files
   a known cleanup task for the next cycle.
5. **No PyPI/npm/hexa-pkg registration**: the README mentions `hx install
   hexa-brain@1.1.0` as a future install path; the registry entry is not yet
   created. Today the only working install is `git clone`.
6. **Sister-repo coupling not API-frozen**: `eeg/closed_loop.hexa` and friends
   emit WebSocket events consumed by anima's consciousness runtime. The
   interface is documented in `eeg/doc/anima_eeg_unified_cli_daemon_spec_2026_05_04.md`
   but is not a frozen versioned contract — drift between hexa-brain and anima
   is possible until the contract is pinned.
