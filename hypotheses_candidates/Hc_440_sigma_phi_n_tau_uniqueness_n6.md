## Hypothesis
Among integers n ≥ 2, the identity σ(n) · φ(n) = n · τ(n) holds if and only if n = 6 (where φ is least-prime-factor in this scheme). Equivalently, R(n) = σ(n)·φ(n) / (n·τ(n)) ∈ Fraction equals 1 ⇔ n = 6. This is the candidate uniqueness lemma anchoring the n=6 family design.
