## Hypothesis

The H_278 faithful-Phi (exact MIP over 2^(n-1) bipartitions, IIT small-side normalized) is the
reference oracle for judging the proxy (Hc_1301). An oracle is only useful where it resolves
distinct integration structures into distinct values.

CLAIM: the faithful oracle has its OWN degeneracy floor. On the frozen 6-scale H_278 ledger,
4 of 6 scales — with DISTINCT CA rules (110, 90, 110, 110) and DISTINCT couplings
(0.10, 0.20, 0.45, 0.60) — all collapse to the IDENTICAL faithful value 0.000011 (only 3 distinct
faithful values across 6 scales). Distinct integration structures therefore map to one number:
the oracle is rank-blind in the low-Phi regime. Consequence: no measure in this stack (proxy OR
faithful) is construct-valid in the low-Phi floor band, and 'tracks-faithful-rank' is undefined there.
