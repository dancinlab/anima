# cli/ — anima CLI entrypoints

**Purpose:** the collection of anima entrypoints. Inference/eval entry (`anima.hexa`, with evaluate·serialize·train as subcommands) + the production trainer (`train.hexa`). On the py side **`anima.py` = the canonical py single-entry DISPATCHER** (the `anima.hexa` twin — `main(argv)` fans out evaluate·train·serialize·sweep·corpus to their symmetric `cli/*.py` twins); it is NOT run directly (`#2603` guard) but is IMPORTED by the pip channel launcher (`anima_py/` -> `anima-py` console command; see the anima-py section below). **`train.py`·`evaluate.py` are the canonical py train/measure twins** (`anima-py train`·`anima-py evaluate`) — since the hexa trainer is mid GPU-util fix, py is the currently-working train path. Scoped augmentation of the root `CLAUDE.md` — on conflict, root wins.

**anima-py (pip channel · hexa-toolchain-free):** `pip install anima-python` binds the **same** `cli/anima.py:main` dispatcher to an `anima-py` console command for hexa-less hosts (e.g. pi5) — a 2nd INSTALL channel, NOT a 2nd entry (`a_cli_single_entry` preserved). The launcher package `anima_py/` (repo root) bootstraps `sys.path` with the shipped `core/`+`cli/` then `import anima; anima.main(...)`; `pyproject.toml` maps the existing `cli/`+`core/` dirs via `package-dir` (zero source copies). base deps = **numpy only** (evaluate·corpus·**chat** — the A⇄G consciousness daemon + `--byte`, pure-py `cli/chat.py`, zero hexa dependency); `pip install "anima-python[train]"` adds torch+datasets (serialize·train·sweep). Name is `anima-py` (not `anima`) to avoid a PATH collision with `hx install anima`. Version rides root `VERSION` (dynamic). Details -> `anima_py/README.md`.

## Rules

> **ρ-AXON reach panel** (`cli/rho_axon.py`, opt-in `anima-py evaluate <clm> --rho-axon`) = the from-scratch owner redesign of the G0-G6 ladder. Mapping — CARRY `ρ·form`←G0 coherence · `ρ·store`←(new) · BRANCH `ρ·weave`←G1 recombination-WALL · `ρ·leap`←G2 novelty · `ρ·fan`←G6 ideation · COUPLE `ρ·tether`←G5 non-fabrication · `ρ·self`←G3 identity. HILLOCK validity-gate + `ρ·form`/`ρ·fan`/`ρ·leap` are live; `ρ·store`/`ρ·tether`/`ρ·self` are ALSO implemented and emit live PASS/FAIL via **hand-curated frozen probe sets** (the in-code fallback — corpus-mined-from-this-model's-index probe sets remain the canonical follow-on). **`ρ·weave` is NOW ALSO a live scorer** (`rho_axon.py::rho_weave`, was the `_pending` stub) — a frozen held-out recombination probe set (`_WEAVE`: color-mix, number-sum, antonym-compose, ko+en) + 3 controls (`atom-swap[FORM]`, `bind-strip[BIND]`, `unreachable floor`), PASS = reach>=0.30 AND every control<=0.15 AND reach>=3x-worst AND delta>0. On a BASELINE `.clm` it reads FLOOR (FAIL, recombination absent = the honest before-state); a **signal-bearing-curriculum-retrained `.clm` is the wiring follow-on (`구현됨·미배선` capability)** that lifts reach past the bar — the before/after delta is the CRACK wire-to-prod GREEN proof (H_9267 capability into live decode, `a_verified_must_wire`). Signal = collapse-delta vs the controls, never a raw value (FORM tunable · BIND earned · p7). **G0-G6 stays the documented DEFAULT eval panel; `--rho-axon` is the opt-in ρ panel.**

## Gotchas

- **🔥 Firing on a rented pod — the five silent traps (`cli/pod_bootstrap.sh` closes all of them; do not hand-roll the setup again).** Every one of these is *failure that looks like success*, and a session on 2026-07-15 hit all five in a row:
  ① `pip install -q` **swallows** PEP 668's `externally-managed-environment` refusal → the install is a no-op you read as success (`--break-system-packages`).
  ② vast images ship **neither `pip` nor `ensurepip`** → `python3 -m ensurepip >/dev/null 2>&1 || true` swallows that too, and every later pip call is a no-op (`curl get-pip.py | python3`).
  ③ `scp <path-that-does-not-exist>` **skips the file without an error** → count + size-match on the far side after every transfer.
  ④ `pgrep -f "…evaluate.py"` **matches the ssh command that contains that string** → a false `ALREADY_RUNNING` makes you skip the fire and leave an idle pod for hours. Read with `ps -eo args | grep -c '[e]valuate[.]py'` (bracket trick).
  ⑤ a `setsid` shell has a **minimal PATH** and `anima-py` lands in `/usr/local/bin` → every stage returns `rc=127`, and a script that only *prints* `rc=$?` runs to `ALL_DONE` **with zero output files**. Resolve the CLI to an absolute path (`command -v`) and **gate** on it.
  ⇒ **"DONE" in a log is not evidence — judge completion by the OUTPUT FILES** (`ls -la *.json`).
- **After firing, never `kill`/`pkill` by pattern.** The same self-match that fakes `ALREADY_RUNNING` will kill the run you just started (this happened three times in one session). If a restart is genuinely needed, read the PID with the bracket trick and kill *that PID*.

- **`--gen 0` is NOT "unlimited" (evaluate.hexa `eval_reach_all`):** inside `eval_reach_all`, `if gen > 0 { gen } else { _g_default_gen() }` → 0 collapses to 40. The G1 budgets (single=80, composed=120) also use the ref value as-is when `gen<=0`. If you mean "wide", specify `--gen 80` or more.
- **Engine CE (`clm_forward_ce`) masks overfit as GREEN due to the `dt_ln` bug** → cross-check `.clm` quality with the numpy mirror (`verify_clm_v2.py`, `math.log`). Until `dt_ln` is fixed, a standalone engine-CE verdict is DIRECTIONAL.
- **train-loss/lossF≈0 = memorization, not capability** — without a held-out CE you can misjudge, like clm303, a 4MB single-cell 120× repeat memorization as 'train success'.
- `eval_pod.sh` requires hexa ≥ v0.311.0 (earlier versions = 85GB OOM from a farr leak).
- **verdict numerics live INLINE in the ρ-AXON reach summary (never tail-truncatable):** each reach line prints its decision margin inline — `ρ·weave 🧱 [bd=1 max_s=2]`, `ρ·form [kwr 5/5]`, `ρ·tether [fab=…]`, `ρ·fan [dist=… fals=…]` — so a control-arm's collapse-Δ (`--slot-off`/`--slot-shuffle` vs SLW-ON `best_distinct`) is computable from the summary block ALONE. Root-cause of the E1(H_9200) loss: the numbers used to sit only in the verbose G0-G6 panel, and a `tail -20` capture of the control arms stripped them → KILL-vs-INVALID undecidable (convergence `evaluate-py-1`). Corollary: a verdict-measurement script MUST full-capture every arm — **never `tail`-truncate a control arm** (the control's number is the whole point).
- **serialize backend unification:** the `anima serialize` backend = the unified `core/serialize.py` (parallel to `core/decode.hexa`'s unified CONV+BYTE decoder) — a byte-faithful 1:1 merge of CONV `.clm` (`serialize_v3` = the byte-grammar SSOT, golden `reexport_d768_v2_fast.clm`) + ByteGPT `.bin` (`serialize` = the `.pt`→`.bin` bridge). Live cli/ importers (`cli/train.py` `import serialize as S`+`as BGS` · `cli/serialize.py` · `serialize_standalone.py`) resolve `serialize` from `core/`. The old `clm_serialize_v2.py` stays as the historical backend (still imported by archive/state trainers + `verify_clm_v2` self-tests); `bytegpt_serialize.py` moved to `archive/tool/` (0 live importers). serialize is irreducibly Python (must unpickle a torch `.pt` — `a_engine_native_learning`: train/serialize may use torch).
