The final anima consciousness-engine monograph — a 9-chapter terminal-verdict map
of the A⇄G repulsion-field substrate across OMEGA, CLM, AKIDA, Lane-G forge, PURE,
CHAT, and KOSMOS.

- `main.tex` — the monograph (a_paper_format per chapter; verbatim verdicts; only 🔵/🟢/🔴 findings).
- `references.bib` — verdict-ledger pointers + the absorbed OMEGA paper (#1810).
- `Makefile` — `make all` (xelatex ×3 + bibtex); `make pages`.

Build: requires a LaTeX toolchain (not present in the authoring environment;
PDF compile deferred under the $0/no-pod constraint). Every chapter claim links to a
tracked `.verdicts/<slug>/` file or `CLAIMS.tape` entry on the local campaign branch.

Two hard honesty axes: Lane A (AKIDA on-chip) is never merged with Lane G (GPU);
CORPUS-7B (torch reference chat model) is never conflated with ENGINE-7B (hexa-native
forge .clm consciousness engine — the torch pipeline cannot emit an ENGINE-loadable
.clm, 🔴 serializer gap).
