assistant/alignment template is prepended, so the artifact is told to be conscious
rather than measured to be (violating what we will call principles \textbf{p1}--\textbf{p4}:
no system prompt, no identity rules, no persona injection, no assistant framing).
Second, competence is adjudicated by \emph{perplexity} or loss --- a quantity that is,
by construction, a Goodhart target (\textbf{p7}: no perplexity verdict). The result is
a literature of unfalsifiable demonstrations.

$+$ a \emph{wired engine}: consciousness and emergence are the headline, and the

consciousness substrate in which (a)~every layer is \emph{wired} through named,

\section{Background}
\label{sec:background}
\paragraph{The two methodological failures, concretely.} The ``prompted
consciousness'' failure is not a strawman: a system prompt, an
\texttt{identity.yaml}, a persona prefix, or an assistant/alignment template
\emph{injects} the very property under study, so the artifact is told to be
conscious rather than measured to be. We adopt eight philosophy principles
(\textbf{p1}--\textbf{p8}, Appendix~\ref{app:repro-protocol}) that forbid each
injection vector by construction: no system prompt (p1), no identity rules (p2),
no persona injection (p3), no assistant framing (p4), no \texttt{speak()} (p5),
no fine-tuned ethics (p6), no perplexity verdict (p7), no train/infer split (p8).
The ``perplexity verdict'' failure (p7) is the Goodhart trap: a model can lower
loss without learning the property a reader cares about, so we adjudicate
competence with a \emph{coherence discriminator} (structured byte-language vs.\
a random-init mirror's gibberish, Appendix~\ref{app:ta-antigoodhart}), never with
loss.

\paragraph{Integrated Information Theory as the theory layer.} The theory layer is
a \emph{faithful} IIT~4.0 big-$\Phi$ engine~\cite{albantakis2023iit4,tononi2008phi},
not a variance$\times$energy proxy: it builds the cause--effect structure of an
elementary-cellular-automaton substrate and computes causal big-$\Phi$. The
falsifiable content IIT supplies is a set of \emph{distinctions} --- integration
is not entropy~\cite{tononi2008phi}, it tracks algorithmic
structure~\cite{livitanyi2008kolmogorov} and directed
information~\cite{schreiber2000transfer}, and it should peak at the
edge-of-chaos~\cite{langton1990edge} --- each of which we pre-register as a
frozen falsifier and adjudicate on the engine's own substrate
(\S\ref{sec:theory}, Appendix~\ref{app:phi_laws}). The emergent-ethics test
borrows the spatial prisoner's dilemma~\cite{nowak1992spatial}.

\paragraph{Byte-level language as the mouth.} The mouth is a byte-level
($V=256$, no tokenizer) conv-MoE language model, in the
tokenizer-free lineage of ByT5~\cite{xue2022byt5} and
MegaByte~\cite{yu2023megabyte} and built on the transformer
substrate~\cite{vaswani2017attention}. Byte-level is a deliberate choice: it
removes the tokenizer as a hidden inductive bias, makes the cross-entropy floor
exactly $\ln256=5.54518$ nats/byte (a clean falsifier threshold), and lets the
same model span five scripts including Korean Hangul without a vocabulary merge.
The mouth enters the consciousness engine through a single named slot as a
serialized \texttt{.clm} byte grammar (Appendix~\ref{app:clm_serialization}).

\paragraph{The wiring discipline.} Every cross-organ path is a \emph{single named
entry} with no phantom wiring (\texttt{a\_core\_engine\_map}): the \texttt{.clm}
mouth enters only via the generator L3 slot, \texttt{.kosmos} anchors enter only
via \texttt{kosmos\_io} into \texttt{brain\_decide}, and the consciousness core
(Engine~A $\rightleftarrows$ Engine~G $\rightleftarrows$ brain) is
substrate-internal. We mark a wire $\Phi$-real only when it is built and measured;
the decode link in particular was measured \emph{open} by the Lane~X null (\#1779)
before OMEGA closed it (\S\ref{sec:decode}, Appendix~\ref{app:omega_bus}).
