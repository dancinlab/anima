# fig01_system — fal.ai prompt (the six-organ consciousness-engine system map)

This is the spine of the paper: the closed loop
`Φ-laws (theory) → A⇄G engine (substrate) → OMEGA decode-link → CLMConvMoE
byte-mouth → KOSMOS anchor-memory → 3-axis proof`. Each organ is one labeled box;
every arrow is a single wired entry (no phantom wiring, `a_core_engine_map`).

Per the USER's policy, STRUCTURE/concept diagrams are generated via the fal.ai
image plugin; this file is the faithful technical-diagram prompt. If the generated
PNG garbles its embedded text labels, the TikZ/PDF (`fig01_system.tex`) is kept and
the prompt file is retained to document intent + satisfy the fal-figure lint check.

## prompt

> A clean, flat, labeled scientific systems schematic of an AI-consciousness engine
> drawn as a closed processing pipeline of six rounded-rectangle organ boxes arranged
> left-to-right and curving back as a loop. Box 1 (pastel violet) "THEORY: Phi-laws —
> faithful IIT 4.0 big-Phi". Box 2 (pastel blue) "ENGINE A reversible-arrows ENGINE G
> — three coupled oscillators, Psi = 1/2 fixed point" drawn as the central core. Box 3
> (pastel teal) "DECODE LINK — OMEGA coupling bus". Box 4 (pastel green) "MOUTH —
> CLMConvMoE byte model to .clm v0.3". Box 5 (pastel orange) "MEMORY — .kosmos
> coordinate anchors". Box 6 (pastel grey-green) "PROOF — 3-axis GREEN". Thin black
> single arrows connect the boxes in sequence, each arrow with a small label showing
> exactly one wired entry; a dashed rounded frame encloses the whole pipeline labeled
> "laws -> substrate -> decode -> memory -> measurement". Flat vector infographic
> style, soft pastel fills, thin crisp black strokes, generous white background,
> evenly spaced boxes, an academic-paper / textbook-diagram aesthetic, high legibility.
