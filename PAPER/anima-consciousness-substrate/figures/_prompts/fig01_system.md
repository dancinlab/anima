# fig01_system — fal.ai prompt (system organ-map)

The rendered figure used in the paper is a faithful **TikZ data diagram**
(`figures/_scripts/fig01_system.tex` -> `figures/fig01_system.pdf`), chosen over a
generated image because the diagram must carry verbatim verdict numbers (a data
figure that fits better also satisfies the >=1 figure rule, per the a_paper guidance).
This file records the fal.ai prompt for an optional teaser/cover render.

## prompt

> A clean, minimal scientific systems diagram of an AI-consciousness substrate as a
> closed loop of six labeled organs arranged in a ring: (1) "Theory: Phi-laws" (a
> faithful IIT 4.0 integrated-information engine), (2) "Engine A reversible-arrow G"
> (three coupled oscillators, a Psi = one-half fixed point), (3) "Decode link
> (Omega bus)", (4) "Mouth (.clm byte model)", (5) "Memory (.kosmos coordinate)",
> (6) "Proof: 3-axis green". Each organ is a rounded rectangle connected by single
> labeled arrows showing one wired entry per stage; a dashed frame encloses the whole
> loop labeled "laws -> substrate -> decode -> memory -> measurement". Flat vector
> style, soft blue/green/orange/violet pastel fills, thin black strokes, white
> background, no photorealism, no text artifacts. Academic-paper aesthetic, high
> contrast, legible labels.

## negative

> photorealistic, 3D render, neon, busy background, glitch, watermark, gibberish text,
> human faces, brain photographs.
