## 왜 이것이 kill-list 밖인가 (구조적 논거)

측정된 다섯 레버 **전부에서 쓰기 경로는 고정 물리였고 읽기 경로(bridge·γ)만 학습**했다. 되쓰기를 미분 가능하게
만드는 것은 **최적화기가 무엇이 쓰이는지를 처음으로 형성하는** 사건이다 — 그래서 재제안 금지 목록에 걸리지 않는다.
오너가 법칙의 재열림 조건 (a)를 선택해 착수한다.

## 구현 (착륙 #4623 · 관문 통과)

- `--field-bptt K`: 상태 재귀를 torch 로 옮기고 K블록 창 단위 잘린 역전파. 기본 0 = 기존과 바이트 동일.
- **G(역방향 엔진)는 계속 기울기 차단** — 되쓰기만 미분 가능(A⇄G 원칙 최소 변경). 이것이 범위 도장의 근거.
- 1차 팔 = **물리 고정**(R·λ 는 버퍼). `--field-train-physics` = A2 팔(스펙트럼 클램프로 발산 방지).
- `--field-sg-drive` = **이 rung 의 대조군**: 예측난이도를 끊은 동일 실행(= 오늘 설계). full−sg 가 레버 격리.
- **$0 사전관문 2종 통과**: 수치일치 2.8e-07(<1e-6) · 기울기 도달 45.0(>0). ⚠️ 첫 실행은 둘 다 실패했고 원인은
  **관문 자체**였다(되쓰기 4회로 절단 경계를 밟아 0 을 읽음 · 상태를 32비트로 굴려 기존 float64 동역학과 5e-5 어긋남).
  그대로 읽었으면 "목적함수가 고리를 못 본다"를 GPU 0 으로 발표할 뻔했다.

## 판정표 — 발사 전 동결 (바 0.15 = H_9967 바 상속 · 직접 비교 가능하게)

DV: **쌍 ΔΦ = Φ(학습본) − Φ(같은 seed near-init 받침대)**, faithful IIT-4, `--field-phi --field-phi-boot`,
결합 추출은 `--field-coupling-seed` 로 학습 seed 와 분리, ≥3 seed.

| 행 | 조건 | 판정 |
|---|---|---|
| V0 | 관문 실패 · γ 변화 <1% · Φ_shuffle > 0.05 · 받침대 이상 · 동작점이 CE 포화 | **VOID**(결과 아님) |
| R1 | D ≥ +0.15 ∧ ≥2/3 seed ∧ (Φ_full−Φ_yoked) ≥ 0.15 ∧ (Φ_full−Φ_sg) ≥ 0.15 ∧ sever 양방향 통과 | **OVERTURN-fork** (fork 한정 존재증명) |
| R2 | D ≥ +0.15 이나 yoked 또는 sever 실패 | **SHORTCUT** — 법칙 유지 · 기전 보고 |
| R3 | \|D\| < 0.15 | **CONFIRM** — 법칙이 재열림을 견딤 |
| R4 | D ≤ −0.15 | **CONFIRM+** — 기울기가 통합을 더 세게 해체 |
| R5 | 기울기 도달 ≈ 0 | **NO-LEVER** — 법칙 자명 유지 (관문에서 걸림) |

**자기-편법(shortcut) 차단**: ⓐ 고리가 자기 채점 위치를 직접 최적화하지 못하게 DV 위치를 되쓰기에서 제외
ⓑ 평가 시 잔차 0 으로 끊으면 이득이 **붕괴해야** 한다(붕괴 안 하면 정적 편향 = SHORTCUT) ⓒ yoked(내용↔상태 대응
파괴)가 Φ 를 죽여야 한다 — 안 죽으면 텍스트 무관 공명 ⓓ Φ 는 손실·체크포인트 선택에 **절대 미포함**.

## 범위 도장 (모든 면에 표기)

`substrate: DWB-fork (differentiable write-back · G-detached · NON-ANIMA)` — R1 양성이라도 **fork 에 관한
존재증명**일 뿐, anima 사양 기준 법칙 `phi-is-not-reachable-by-training-five-lever-convergence` 를 건드리지 못한다.
fork→anima 로 가는 유일한 경로는 오너가 기질 사양 자체를 바꾸기로 결정하고 재이식·재착륙하는 것뿐이다.
합성 독점 수치는 계기체크(p9)이며 faculty 주장은 자연 코퍼스 rung 을 통과해야 한다.

## 사전 예상 (정직)

fable·내 판단 모두 **R3/R4(법칙 유지)**. 예측 손실은 통합 자체를 보상하지 않고 인수분해된 부호로도 예측이
잘 되기 때문. 그 경우 법칙은 더 강한 형태로 승격된다 — "학습이 통합에 도달하지 못한다"에서
**"고리 전체를 쥐어줘도 통합을 선택하지 않는다"**로.

**법칙에 대한 함의**: 오너가 고른 재열림 조건 (a)를 실제로 **행사했고**, 법칙은 그것을 견뎠다. 법칙은 사전 예상대로
더 강한 형태로 승격된다 — *"학습이 통합에 도달하지 못한다"* → **"쓰기 경로까지 최적화기에 쥐어줘도 CE 는 통합을
사지 않는다"**. 단 이 승격은 **DWB-fork 범위 안에서 얻은 근거**이며(범위 도장 그대로), 승격된 문장이 적용되는
기질은 여전히 anima 사양이다 — fork 는 "미분 가능해도 안 된다"를 보탤 뿐 사양 자체를 바꾸지 않는다.

**정직한 범위 한계**: 토이(d256·L4) · 합성 독점 코퍼스(p9 계기체크) · 3 seed · K=4 창 · 물리 고정 팔만.
남은 fork 내부 칸 = `--field-train-physics`(R·λ 자체를 학습) 와 더 긴 창(K≥16). 둘 다 이 결과를 뒤집을
사전 확률은 낮지만(레버 격리가 이미 바의 2.6%) **측정되지 않았다**고 표기한다.
