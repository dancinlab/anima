## 왜 쐈나 — C3 이 남긴 갈림길

[H_9329](H_9329_operator_string_rule.md) C3(⏳ DIRECTIONAL · seed 7 유효)이 확정한 것: SEEN 어간의
극성을 **선언형 `(어간⊕고)` 화살표**로 CPT 반전해 다시 써도(WRITE 12/12), `지 않다` 연산자는 여전히
**옛 사전학습 극성**을 읽는다 — 강한 표면 negL(`{s}지 않다`) · negZ(`별로 {s}지 않다`, 사전학습 0회)에서
**0/12 신극성**(= 12/12 구극성), p_old = .0002.

C3 은 그 실패를 **두 기전으로 못 가른다**:

| 가설 | 뜻 | C3 로 배제 가능? |
|---|---|---|
| **H-δ 저장소-측** | CPT 가 쓴 엔트리가 연산자의 read-path 가 **어떤 키로 써도 닿지 못하는 저장소**에 산다 | ❌ |
| **H-ε 인터페이스-측** | read-path 는 새 엔트리에 **닿을 수 있으나, 연산자 자신의 키로 썼을 때만**. C3 은 **선언형 키**(틀린 키)로 썼다 | ❌ |

## 🎯 C4 의 조작 — 단 하나의 변수만 바꾼다

C4 는 **똑같은 반전 극성을, 이번엔 연산자 자신의 표면**(`{s}지 않다`-계열 담체)**으로도** 쓴다.
사실이 이제 연산자의 키 안에 있다. 그리고 **쓴 것과 서로소인** `지 않다` 표면에서 채점한다.

```
선언형 write (C3 과 동일) :  이 영화 좋고 => 부정.        ← (어간⊕고) 키, 반전
연산자 담체 write (C4 신규):  이 영화 전혀 좋지 않다 => 긍정.  ← 연산자 키, 반전을 부정출력으로 인코딩
채점 (서로소 표면)         :  이 영화 좋지 않다 => ?         ← bare · 별로 (담체엔 없는 부사)
```

- **연산자가 신극성을 읽으면** → **H-ε**: 연산자-키로 쓴 것이 유일한 결핍이었다(인터페이스 addressable).
- **연산자-키로 써도 구극성을 읽으면** → **H-δ**: 저장소가 unreachable, **또는** write 가 `(부사,어간)`
  합동 키로 암기돼(R2 STEM-BOUND) 부사 슬롯을 못 넘는다 — **어느 쪽이든 인터페이스로 못 고침**.

**선언형 write 를 C3 과 바이트 동일하게 고정**하므로, 연산자 담체가 **유일한 추가 변수**다.

### 왜 서로소 표면이 판별을 만드는가 (담체 인구조사 · corpus-py-1 ⑨/(F) 준수)

C4 가 사는 **일반화 축 = 부사 슬롯**(C1b 가 자유·완벽 일반화로 실측: 코퍼스 0회 부사 5종 전부 연산자
작동). 담체엔 **전혀·그다지·결코**를 가르치고, **bare·별로**에서 채점한다 — 채점 표면의 부사 노출 = **0회**.
그래서 신극성 판독은 **연산자 자신의 부사-불변 일반화가 새로 쓴 엔트리에 닿은 것**이지 암기 라인이 아니다.
반대로 구극성 판독은 write 가 부사 슬롯을 못 넘은 것(STEM-BOUND 합동) = H-δ. **어간 슬롯이 아니라 부사
슬롯**을 축으로 삼는다는 점에 주의 — swap 어간은 SEEN 이며 C4 는 미학습-어간 일반화를 주장하지 **않는다**
(그건 H_9327 벽 · 이미 답 나옴). C4 의 주장 축은 **"재쓴 SEEN 어간의 극성 VALUE 를 연산자가 읽는가"**.

**신극성**(= CPT 가 심은 반전 극성)을 따르는 개수. (구/신 라벨은 어간당 정확히 반대이므로 이진.)

| 결과 | negL·negZ 신극성 카운트 | 판정 |

  임의 효과가 연산자-특이적임을 보정(C3 에서 4/12 = 우연이었다).
- **부호 예측이 서명이다**: C3 이 선언형-키로 **0/12 신극성**을 냈으므로, H-ε 는 연산자-키 추가만으로

  C3 재현 = 저장소 벽**을 뜻한다. (+) 였다면 인터페이스 가설이 반증됐을 것 — 둘 다 결정적.

## 🔧 C3 이 노출한 게이트 결함 2개 — C4 가 고친다

### ① `untouched` n=3 = 검정력 없는 망각 게이트 → 풀에서 **파생**
C3 은 untouched 를 **고정 3**으로 뒀다. 이 팔은 **CPT 코퍼스가 0회 건드리는 지층**(corpus-py-1 ⑦:
망각은 정확히 그런 지층에서 온다)이라 망각 게이트의 자리인데, n=3 이면 **1개 반전 = 33% 붕괴**라
망각과 동전 한 번을 못 가른다. **MDE(rule of three)**: 0 flip 관측 시 SEEN 망각 분율의 95% 단측 상한 =
**3/n**.

| untouched n | 0 flips → 95% UCB | 비고 |
|---|---|---|
| **3** (C3) | **3/3 = 100%** | 총망각조차 배제 못 함 = **검정력 0** |
| 12 | 3/12 = 25% | |
| **29** (C4 사전등록) | **3/29 = 10.3%** | held-out 팔(n=29)과 정합 |

**구현**: `untouched = len(seen) − 17` (swap 12 + affirm 2 + keep 3 고정, 나머지 전부). 원자 풀만 키우면
검정력이 공짜로 붙는다 — 발사는 **n-seen = 46 원자셋**(`anima corpus atoms --n-seen 46`)으로 untouched 29.
(스모크: 20-SEEN → untouched 3 = C3 패리티 · 26-SEEN → 9 · UCB 표를 build 가 인쇄.)

### ② 생명 게이트를 **DV 팔 자신**으로 이동
C3 은 연산자 생존을 옆 팔(n=6)에서 쟀다. **DV 팔이 더 강한 증명서를 품는다**: swap 팔의 flip1 판독이
**일관되게 한 극으로 쏠림**(신·구 어느 쪽이든 max(신,구) ≥ 10/12 · 순열 p ≤ .0193, C3 은 구극성 12/12
p=.0002)이면 부서진 연산자는 그 일관성을 못 만든다. 흩어진 ~6/12 = 연산자 파괴 = **INVALID**(DV 를 읽지
않는다). 방향(신 vs 구)은 그 다음 H-ε/H-δ 판독. ⚠️ **이걸로 죽은 seed 를 되살리지 않는다**(tune-to-green
금지) — C4 **설계 교훈**이지 판정 조작이 아니다.
