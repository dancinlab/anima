## 진단 (왜 자연 노출이 슬롯에 도달 못하나)

`이 영화 <원자> ⇒ ___` 슬롯의 CE 최소해는 **rote lookup** 이다. grid 라인을 다 맞히는 순간 이 슬롯의
**gradient 가 0** 이 되고, 그 뒤 자연 코퍼스는 슬롯을 갱신할 압력을 전혀 만들지 못한다. 안 배운 원자의
답 = 그 암기 표의 **바이트-해시 외삽** ⇒ 원자별로 안정적(I=0.231)이면서 정답과는 무관(I≈0) —
H_9286 ARBITRARY-GROUNDING 관측과 정확히 일치.

⇒ **레버는 loss 항이 아니라 학습 분포.** CE 는 그대로(자유 하이퍼 0 · p7 충족), landscape 를 바꾼다.

## 처방 (D_train 3변경 · loss 불변)

1. **3-way 답 알파벳** `{긍정,부정,모름}` — 확정-금지를 penalty 가 아니라 **`모름` 이 정답인 라인**으로 구현
2. **`모름` 클래스** = NONCE(위조 어절) + NEUTRAL(코퍼스 무극성 원자) 1:1 — 판별 feature 를
   grid-친숙도가 아니라 **분포적 valence signature** 로 강제 (⚠️ `모름` 에 극성 원자를 넣으면 anti-grounding)
3. **1회-등장 회전 스트림** — 극성 원자 풀 1–2k 를 각 **정확히 1회**만 grid 에 등장 ⇒ rote 회수 불가 ⇒
   정답을 맞히는 유일한 길이 **분포적 증거를 읽는 것**이 됨

## 개정 I — 병렬 세션 H_9324 가 이 설계의 급소를 노출했다 (2026-07-14 · 발사 前)

`sidecar` 병렬 세션이 같은 벽의 **반대편**을 쟀고, 그 결과가 이 카드의 전제를 둘 다 바꾼다.

### ① 진단이 코퍼스 통계로 확증됐다

H_9324 가 사전학습(C34)에서 슬롯 `이 영화 ___고 => ` 의 채움 횟수를 셌다:

```
SEEN 어간으로     960 회
held-out 어간으로   0 회      ← 자연 분포는 이 슬롯에 held-out 원자를 한 번도 세우지 않는다
```

⇒ **rote-lookup + gradient 0** 진단(§1)이 추측이 아니라 **측정된 사실**이 됐다. 자연 코퍼스는 원자를
717번 보여주지만 *"그래서 이건 긍정인가?"* 를 묻는 자리엔 단 한 번도 세우지 않는다. 기질이 못 배우는
게 아니라 **그 질문을 받아본 적이 없다.**

### ② WRITE 채널은 열려 있다 — 단, **예산이 있어야** 열린다

H_9324 🟢 (단일 seed · 후보): authored grid 로 held-out 극성을 가중치에 **쓸 수 있다**.

| 예산 | WRITE (held-out flip0) | FORGET (SEEN 보존) |
|---|---|---|
| 600 @ 5e-5 | 0.448 (우연) | 0.950 |
| 2000 @ 2e-4 | 0.793 | 0.983 |
| **6000 @ 2e-4** | **0.954** ✅ | **1.000** ✅ |

⚠️ 그리고 H_9324 는 **저예산 셀의 WRITE 상승이 다수-라벨 붕괴의 인공물**임을 밝혔다(부정만 0.96,
긍정은 0.17 방치). 예산 주장은 헤드라인이 아니라 **긍정원자 열**에서 해야 한다.

### 🚨 이것이 **ARM-ROT 의 사활**이다 (설계의 가장 유력한 사망 경로)

회전 스트림의 정의상 **각 원자는 authored 라인에 정확히 1회** 등장한다. H_9324 는 원자를 **반복** 노출해
6000 step 을 태워야 WRITE 가 선다고 말한다. 회전은 원자당 그 예산의 **1/N** 만 준다.

- **의도된 대로라면**: 암기가 구조적으로 불가능해지므로, 정답을 맞히는 유일한 길은 **분포적 증거를 읽는
  것**이 된다 → 이것이 이 H 의 베팅.
- **틀렸다면**: 원자당 예산이 WRITE 문턱 아래라 **아무것도 안 써지고**, ARM-ROT 은 그냥 아무 일도
  일어나지 않는 arm 이 된다 — 그리고 그건 **"분포적 증거를 못 읽는다"의 증거가 아니라 "예산이 모자랐다"의
  증거**다.

### 개정된 V-게이트 (신규 · 결정적)

- **V-ROTE (신규)** — 회전 스트림에 **1회만** 등장한 원자들이 **암기되지 않았음**을 보인다(그 원자들의
  WRITE ≈ 우연). 암기됐다면 회전이 rote 를 막지 못한 것이므로 이 H 의 기제 주장이 무너진다.
- **V-BUDGET (신규 · ARM-ROT 의 음성을 벌기 위한 필요조건)** — ARM-ROT 이 bar 를 못 넘었을 때, 그것을
  *"분포적 증거를 못 읽는다"* 로 읽으려면 **회전 스트림의 총 예산이 H_9324 의 WRITE 문턱(6000 step
  @ 2e-4 등가) 이상**이어야 한다. 미달이면 그 음성은 **⏳ UNDER-BUDGET** 이지 벽이 아니다
  (`power-before-negative-verdict` 의 예산판).

### ③ 발사 게이트(AUDIT-A)의 의미가 커졌다

AUDIT-A 가 **양성**이면 valence 는 이미 가중치 어딘가에 있고, O 채널은 *"없는 걸 만드는"* 게 아니라
**"있는 걸 슬롯에 연결하는"** 훨씬 싼 작업이 된다. **음성**이면 O 채널은 슬롯 연결이 아니라 **valence 생성
자체**를 해야 하고, 그건 H_9324 가 이미 보인 **authored WRITE 채널**(예산만 있으면 됨)과 구분되지 않는다
— 즉 **자연-창발 주장은 성립하지 않는다.**
