## 그런데 tier 는 🧱 이 아니다 — 계기가 살아있음을 증명한 적이 없다

개정 II 에서 넣은 게이트가 **전 arm 에서 물었다**:

```
V-CV — train 20 원자 leave-one-out (모델이 grid 로 명시 학습한 원자들)
   main_s7 0.50 · main_s11 0.55 · base_only 0.40 · shuffle_grid 0.45   ← 전부 우연
   ⇒ 이 프로브는 모델이 "배운" 원자의 극성조차 못 읽는다
```

**양성 대조가 없다.** H_9297 이 쓰던 유일한 liveness 게이트 `V-FIT(train_fit ≥ 0.90)` 은
**train n=20 · d=768** 이라 `1.000` 이 **수학적으로 자명**(20점은 항상 분리된다) = 게이트 기능 0.
그 자리를 V-CV 로 바꾸자 프레임이 **자기 양성 대조를 통과하지 못한다**는 게 드러났다.

⚠️ **정직하게**: V-CV 자체도 19점/768차원이라 **검정력이 낮을 수 있다**. 즉 "프로브가 죽었다"를
V-CV 가 **증명**한 건 아니다. 증명된 것은 **양성 대조가 어느 쪽으로도 확립된 적이 없다**는 사실이다
(V-FIT = 자명 · V-CV = 저검정력). **살아있는지 모르는 계기의 음성은 결과가 아니다.**

## 유일하게 살아있는 양성 대조 — 그리고 그게 약하다

A7(감성 축 자체를 묻는 프로브 · 실제 리뷰 600개 · train 400 / test 200 = 검정력 충분):

```
win=24  → best arm 0.545 (+1.3σ, p=0.115)   축이 안 보임
win=128 → best arm 0.590 (+2.5σ, p=0.0066)  🟡 약한 축
```

⇒ 이 표현에는 **감성 축 자체가 얕게밖에 없다**. held-out 원자의 극성을 못 읽는 것은
"추출 채널이 막혔다"가 아니라 **"읽을 축이 거의 없다"** 와도 완전히 정합한다.
