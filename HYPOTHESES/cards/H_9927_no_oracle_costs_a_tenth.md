# H_9927 — 오라클을 떼도 선다: 못 본 오프셋 **0.74~0.82**, 비용은 약 0.10~0.16

**tier:** 🟢 **사슬의 마지막 미측정 변수 종결** · $0 · **drill-only**(p9)
**runs:** `python3 lab/v6/h9927_no_oracle.py`

## 무엇이 남아 있었나

H_9915 부터 H_9926 까지 **모든** 측정이 주소를 공짜로 쥐여줬다(`a = one_hot(target_slot)`).
그러면 값 항이 극성으로 고른 상수가 되고 질문은 "판독구가 연산자를 쓸 수 있나" 하나로 줄어든다.
**실제 레인 재학습에는 그 선물이 없다** — 질의를 만들고, 내용으로 주소를 잡고, 읽기까지 해야
하며, 질의는 `h` 에서 나오는데 그게 바로 오프셋이 흔드는 것이다. H_9926 카드가 이걸
"이 사슬이 한 번도 안 건드린 변수" 로 명시했고, 여기서 닫는다.

## 계기

주소를 `core/clms.py:163` 그대로 계산한다 — 키는 동결, **`W_q` 는 학습**:

```
K = [_entity_key(key_emb, e) …]      동결 키 표
q = h @ W_q                          학습됨
a = softmax(q·Kᵀ/√d_k) − 1/n_slot    lane_type 3 중심화
v = a @ (val[pols] − mean)
```

질의된 엔티티는 덤프 자신의 프롬프트에서 복원해(`"is ruros => "` → `ruros`) 여덟 슬롯 중
하나에 실제로 넣는다. 학습되는 것은 전부 `clms.` 파라미터 — `--freeze-trunk` 가 학습 가능하게
두는 바로 그 집합이다.

## 판정

**오라클 없이도 선다.** 못 본 오프셋 0.74~0.82 로 바닥 0.50 을 크게 넘는다.
**비용은 약 0.10(촘촘)~0.16(성김)** — 실재하지만 결론을 뒤집지 않는다.

이로써 토이는 **실제 재학습의 조건에 가장 가까운 지점**에서 답했다: `W_q`·`W_g`·`W_h`·`b_h`·
`W_out` 전부 학습, 키만 동결, 주소는 스스로. 사슬의 효과 크기 추정은 **0.74~0.82** 로 확정된다.

## 🔎 관측 — 커버리지가 다시 살아난다 (표제 아님)

오라클 팔에서 촘촘/성김 격차는 0.9208 vs 0.8994 = **0.021** 로 사실상 없었고, 그래서 H_9925 는
"커버리지 축은 상류 인공물" 이라고 썼다. 오라클을 떼니 0.8198 vs 0.7438 = **0.076**, 3.6배다.

말이 된다 — 주소까지 스스로 배워야 하면 배울 게 늘고, 그러면 오프셋 커버리지가 다시 값을
가진다. **다만 분할 둘뿐이므로 법칙으로 쓰지 않는다.** H_9925 의 문장은 **오라클 조건 한정**
으로 좁혀 읽어야 한다는 것까지가 여기서 말할 수 있는 전부다.
