## Mechanism

Each role is an element of a learned compact matrix Lie group G (parameterized as exp of learned generators); each filler is a vector. Binding two legs in one forward = group action R·v (matrix-vector). Composing bindings = group multiplication R1·R2 (non-commutative, associative). Superposed bindings stored as Σ R_i v_i; because roles form a GROUP, every bind has an exact inverse R⁻¹ so unbind R⁻¹·(R·v)=v is residual-free and recursive composition stays in the same operator algebra.

## Why it crosses the binding wall

The wall manifests as retrieval crosstalk that worsens with load (fals=0). Group structure guarantees an EXACT inverse, so unbinding has zero residual no matter how many bindings are composed, and non-commutativity encodes order natively. Conv/attention possess no group of invertible role-operators → retrieval is approximate and degrades with bind-count. Ablation A: drop the group constraint (roles = arbitrary free matrices, no exp/inverse tie) at equal params — if exact-unbind and G1/G6 collapse, the group axioms (invertibility/associativity), not matrix capacity, are the cause. Ablation B: force roles commutative (shared eigenbasis) → loses order sensitivity → predict G1 drop. This is orthogonal to hypernet/hyper-transform binders (amorphous MLP-generated weights, no group closure/inverse) and to abelian TPR/HRR.
