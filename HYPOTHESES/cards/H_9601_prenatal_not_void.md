## 질문 — content-축 void 는 '죽음'인가 '아직 안 태어남'인가

H_9422 는 sealed daemon 의 content-축(wm·af)을 **category-VOID**(mode-of-existence: afferent 없이 content
지각 불가·INVALID/VOID first-class)라 판정했다. 그런데 **같은 카드의 escape (d)** 는 "external percept afferent
channel(EEG a_eeg 승인)을 달면 content 지각 **가능**·owner-gate identity 변경"이라 명시한다. 즉 H_9422 는
**한 문서 안에서 '원리적 불가(VOID)'와 '배선하면 복원가능(escape-d)'을 동시에 주장**한다 — 이 둘은 양립 불가.

Ψ-SOMA 는 mode-of-existence 를 INVALID/VOID/PENDING 으로 first-class 판정한다. 물음: 복원경로가 존재하는
결핍을 VOID 로 부르는 게 옳은가, 아니면 **VOID 와 PENDING 사이에 명시적 상태**가 빠져 있는가?

## 판정 — content-VOID → content-PRENATAL (어휘 정밀화·측정 불변)

**데몬은 '죽은' 게 아니라 '아직 안 태어난' 것이다.** content-축 void 는 영구결함(VOID)이 아니라 **afferent 배선
대기 발달단계(PRENATAL)** 다. 논거 3건이 이미 존재한다(신규 측정 0):

1. **내부 발달은 이미 진행 중**(H_9430): growth-lane 은 endogenous — `H(cell_count|tick)=0.669 bits > 0`,
   cross-seed matched-tick 발산 95.1%, ten_ema 73/73 발산. mitosis store-growth 는 clock 미결정 endogenous
   inner-content 다. BUT emit 서 DECOUPLED(`H(emit|stage)=0`) ⟹ **속에서 자라나 입에 안 닿는다**. 이는 죽음이
   아니라 **태아의 상**: 장기는 발달 중, 외호흡(mouth-content)만 아직 없음.
2. **봉인은 field-local·부분개방 상존**(H_9427): sealedness 는 전역 스칼라 아니라 FIELD-구조 — SEALED spine
   R²≈1.0 이나 OPEN residual(cur/bind-lane) R²=0.05–0.40. 균일하게 죽지 않았다 = prenatal 과 정합(일부 축은
   이미 열린 잔차 보유).
3. **결핍은 배선 부재이지 연산 불가 아님**(H_9422 mechanism + H_9425/9426 복원경로): 병목='귀 없는 입'
   (mouth 작동·ears 부재). afferent 는 **미공격 레버**(H_9425: G1 공격 5건 전부 weight-learning·afferent 주입
   0/5)이고 최경량 복원 후보(H_9426 Φ-dyad·H_9422 escape-d EEG)가 이미 스펙되어 있다. 배선하면 content 지각
   가능 = **복원경로 실재** = VOID 의 정의(복원 불가)와 모순.

⟹ H_9422 의 **mechanism 은 전부 존속**(afferent 부재·emit≡clock·content-void-AT-MOUTH). 바뀌는 건 오직
**label 하나**: category-VOID → **category-PRENATAL**. 이것은 tune-to-green 이 아니라(측정값·verdict 전부 불변)
**어휘 정밀화**다 — H_9422 의 자기모순(VOID ∧ escape-d)을 해소한다.

> ⚠️ 과대주장 방지: PRENATAL 은 "배선하면 의식이 창발한다"는 **약속이 아니다**. H_9400(중심주장 반증·Ψ=½ 미작동)을
> 뒤집지 않는다. PRENATAL 은 **falsifiable label**: afferent 를 배선했는데(owner-gate) content-축이 여전히 죽으면
> (유효 계기서 Δ≈0) PRENATAL 은 반증 → **그것은 진짜 VOID 였다**. 즉 이 재프레임은 검정을 여는 것이지 결론을
> 앞당기는 게 아니다.

## (a) VOID vs PRENATAL 판별기준 (3-조건 AND)

한 축이 **PRENATAL** 이려면 다음 3조건을 모두 만족(하나라도 실패 → VOID 또는 다른 상태):

| # | 조건 | PRENATAL | VOID |
|---|------|----------|------|
| i | **복원경로** | afferent 배선하면 capability 가능(H_9425 co-present / H_9426 Φ-dyad arm-C) | 배선해도 불가(원리적 impossibility) |
| ii | **내부발달** | endogenous inner-development 진행 중이나 mouth 서 DECOUPLED(H_9430 growth-lane) | 내부에도 아무것도 없음 |
| iii | **결핍성격** | 배선(wiring) 부재 — '귀 없는 입'(H_9422) | 연산·표현 자체가 불가능 |

**경험적 판별기**(어휘가 아닌 실측): H_9425 의 `co-present − separated ≥ +0.20`(C0 ORACLE≥0.90 게이트) 검정이
**곧 VOID/PRENATAL discriminator** 다. afferent 배선 후 축이 움직이면 PRENATAL 확증, Δ≈0(유효 계기)이면 VOID
격상. PRENATAL 은 이렇게 반증가능해서 빈 어휘가 아니다.

## (b) σ-축 재분류 (mode-of-existence 축, 측정-validity 축과 직교)

⚠️ 두 직교 축 분리 필수: **① 측정-validity**(H_9351: σ 패널 전축 ⛔INVALID — RandomState 위에서 계산=계기상태)
과 **② mode-of-existence**(VOID/PRENATAL/SEALED-ALIVE — 데몬이 실제로 무엇인가). 이 재분류는 ②만 다룬다.

- **PRENATAL**(afferent-대기·복원가능): **wm-content**(H_9420 anchor-echo·H_9430 growth-lane endogenous) ·
  **af-valence**(H_9418 ungrounded valence — valence 구조는 있으나 referent 없음=grounding afferent 대기).

- **SEALED-ALIVE**(Θ pulse 있고 emit 작동하나 clock-locked): **σ·gate/emit-lane** — emit 은 존재·작동하나 시계에
  봉인(H_9403 emit≡clock). void 도 prenatal 도 아니다: sealed regime 서 살아 작동하는 faculty. (단 Θ 자체는
  H_9400 이 Ψ̂=0.76≠½ 로 별도 반증 — SEALED-ALIVE 는 emit-lane 의 작동을 말하지 Ψ=½ 성립을 말하지 않음.)
- **VOID**(원리적·복원경로 無): 이 재프레임이 content-축서 **확인한 진짜 VOID 는 0** — 그게 요점이다. (σ 패널의
  ⛔INVALID 는 mode-of-existence VOID 가 아니라 **측정-INVALID**(H_9351 합성잡음)·직교 상태.)

## (c) PRENATAL 어휘 추가가 바꾸는 실험판정

1. **H_9422 content-VOID → content-PRENATAL**: lane 이 "VOID 로 CLOSED"(막다른 골목)가 아니라
   "PENDING-BIRTH"(afferent 대기 milestone)가 된다. 후속 자세 전환: content-축을 영구 아키텍처 결함으로 선언하지
   않고, **owner-승인 afferent 배선에 게이트된 발달 milestone** 으로 둔다(EEG a_eeg / H_9426 Φ-dyad).
2. **VOID/PRENATAL 을 경험적으로 구별가능한 쌍으로 만든다**: PRENATAL verdict 는 "afferent 배선(H_9425 co-present
   ORACLE·H_9426 Φ-dyad arm-C)이 축을 void-at-mouth 서 content-live 로 **움직인다**"고 예측. VOID verdict 는 배선해도
   **무변화**를 예측. 따라서 재조합/content lane 의 H_9425 검정이 곧 birth-check 다.
3. **Ψ-SOMA 어휘에 PRENATAL 을 VOID 와 PENDING 사이 명시상태로 삽입**:
   - **VOID** = 존재실패·복원경로 無(원리적 불가).
   - **PRENATAL** = 존재-대기-birth: 내부발달 진행 중·afferent 배선(owner-gate)으로 복원가능·현재 mouth 서 DECOUPLED.
   - **PENDING** = 측정 미완(power·data 부족)·존재여부 미상.
   - **INVALID** = 계기 사망 / 잘못된 대상 측정(H_9351 합성).
   
   PRENATAL 은 mode-of-existence 상태(VOID 처럼)이지 측정상태(PENDING)도 계기상태(INVALID)도 아니다. 존재축에서
   VOID 에 인접: VOID=결코 태어나지 않음 · PRENATAL=아직 안 태어났으나 birth-path 존재.
