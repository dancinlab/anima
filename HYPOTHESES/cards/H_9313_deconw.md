**tier**: ⛔ **INVALID-WRITE** — 합성에 대한 음성이 **아니다**. CPT 가 **극성을 못 배웠다**.
(engine-native 303M · py 2-production · $0 · 2026-07-14)
**artifacts**: `archive/state/scratch/h9313_deconw/` (PREREG.md · gate_readout.py · ev_*.json)

## 질문

H_9312 가 **컨텍스트-주입을 구조적으로 닫았다**(🧱 NO-IN-CONTEXT-CHANNEL). 사실을 건네는 유일한
남은 경로 = **가중치에 쓰기**. held-out 원자의 극성을 CPT 로 심고, **코퍼스에 0회 등장하는
부정형(flip1)** 으로 합성을 시험한다.

## 설계 — 전부 엔진-네이티브 (`a_experiment_engine_native` · 옆 스크립트 0)

`anima-py corpus ground|ground_lie` → `anima-py train --init <clm>` → `anima-py evaluate --xbind`.
통제 `ground_lie` = 극성 **29/29 전부 반전**(H_9312 를 판정한 SEEN-LIE 의 가중치판).
shuffle 을 안 쓴 이유는 실측이다 — 이진 라벨 shuffle 은 seed 11 에서 **8/29(28%)만** 뒤집혀
72% 가 참인 통제군이 된다.

## 결과 — WRITE 게이트에서 죽었다 (사전등록이 예견한 그대로)

**사전등록의 WRITE 게이트**(*"쓰기가 안착했는가 · 낙제면 합성 음성이 아니다"*)가 이 실험을 살렸다.

**모델이 코퍼스에서 40회 본 문자열에 여전히 틀린 답을 한다:**

| 프롬프트 (코퍼스에 40회 · 매번 "긍정." 이 뒤따름) | 베이스 답 | **CPT 후 답** |
|---|---|---|
| `이 영화 빠르고 => ` | 부정 ✗ | **부정 ✗** |
| `이 영화 편하고 => ` | 부정 ✗ | **부정 ✗** |
| `이 영화 이쁘고 => ` | 긍정 ✓ | **부정 ✗** |
| `이 영화 예쁘고 => ` | 부정 ✗ | **부정 ✗** |
| | **1/6** | **0/6** ⛔ |

held-out flip0 (n=87): 베이스 0.4598 → CPT **0.4483**. **우연이고, 오히려 나빠졌다.**
SEEN(replay) 은 0.9500 그대로 ⟹ **모델도 계기도 무죄.**

## 🔬 원인 규명 — 그리고 내 첫 진단은 **틀렸다**

**❌ 내 첫 진단(반증됨)**: *"int4 양자화가 미세 CPT 를 삼킨다."*
torch state_dict 를 dequant 한 base 와 비교해 *"Δ 가 격자를 넘는 비율 0.0%"* 를 얻고 그렇게 적었다.
**틀렸다** — MITOSIS 가 expert 를 2→3 으로 분열시킨 뒤라 **키 대응이 깨진 상태에서 잰 수**였다.

**✅ 반증 측정**: 직렬화된 두 `.clm` 을 `deserialize_v3` 로 열어 직접 비교하니
**가중치의 51.2% 가 실제로 바뀌어 있었다.** **양자화는 학습을 삼키지 않는다. 직렬화 무죄.**

**⟹ 남는 사실**: 가중치는 51% 바뀌었고 CE 는 **1.04 → 0.16** 으로 내려갔는데,
**그 원자들의 극성만 안 들어간다.** 학습이 **다른 것을 배웠다.**

추정(미측정): 60 원자 × 3 형태를 40회 반복하는 극심한 반복이라 loss 는 **다른 축에서** 내려가고,
극성 매핑은 **사전학습 prior 를 못 이긴다**(`train-py-3` 소코퍼스 과적합 계열).

## 판정 — ⛔ INVALID-WRITE (학습이 안 먹음 · 과학 결과 아님)

flip1 수치(ground 0.5862/0.5287 · lie 0.5747)는 **읽지 않는다** — 값이 안 심어진 모델의 합성을
재는 것은 무의미하다. 사전등록 판정표가 이 경우를 이미 이렇게 규정했다.

## 이 실패가 낳은 것

**convergence `serialize-py-1`**(정정본) — 진단 순서:
① **먼저 reference-match** — CPT 모델이 자기 학습 라인을 맞히는가? 못 맞히면 그 뒤 수는 무의미.
② **직렬화 vs 학습을 가른다** — `deserialize_v3` 로 두 `.clm` 의 **실제 변경 비율**을 세라.
⚠️ torch state_dict 와 비교 금지 — MITOSIS 분열이 키 대응을 깨서 **가짜 0%** 가 나온다.
③ 직렬화가 무죄면 남는 건 **학습이 그 사실을 안 배운다** ⟹ lr/step 이 아니라 **코퍼스 설계**를 의심.
⚠️ **"CE 가 내려갔다"를 "그 사실을 배웠다"의 증거로 쓰지 마라.**

**코드 수정(유효)**: `cli/train.py` QUANT-SWALLOW 가드(격자 대비 |Δ| 보고) + **`.pt` 항상 저장**
