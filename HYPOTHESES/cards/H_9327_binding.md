## 왜 쐈나 — 오너의 한마디가 프레임을 깼다

오너: *"byteLM, conv 가 아니라 자체구현 해야 되는 거 아닌가?? claude 규칙위반인데 LLM 관련"*

나는 그 전까지 **"이 4층 conv byte-LM 은 어텐션이 없어서 in-context 복사 경로가 없다"** 고 진단하고
있었다. 그건 트랜스포머 해부학 언어이고 **`a_no_llm_frame_trap` 이 금지하는 바로 그 사고**다.
프레임을 버리고 **원장을 세자** 두 가지가 연달아 드러났다.

## ① 사전학습은 연산자를 이미 480회 시연했다

C34 코퍼스 직접 카운트: **arrow 라인 960개 중 480개(정확히 절반)가 부정형** · **전부 SEEN 어간** ·
held-out 어간은 **0개**. 실제 라인: `이 영화 전혀 훌륭하지 않다 => 부정.`

⟹ Fable 이 설계한 A1(*"서로소 디코이 어간에 연산을 시연하라"*)은 **사전학습이 이미 돌린 실험**이다.
발사 전 원장 조회(`check-ledger-before-lever-fire`)가 죽였다.

## ② 그래서 공짜 양성대조를 쐈고 — 우리가 연산자를 죽이고 있었다

| SEEN 어간 (부정 480회 시연) | flip0 | flip1 |
|---|---|---|
| 사전학습 base | 0.9500 | **0.8833** ← 연산자가 작동한다 |
| `ground` CPT 6000@2e-4 | 1.0000 | **0.4333** ← 파괴 |
| `ground` CPT 6000@5e-4 | 1.0000 | **0.3333** ← 예산 늘수록 더 파괴 |

`ground` 코퍼스엔 부정형이 **0회**(합성 테스트의 전제였다). 그런데 평서형만으로 6000 step 을 돌리면
부정 연산자를 붙잡아주는 게 없어 무너진다. **그리고 FORGET 게이트가 이걸 못 봤다** — SEEN **flip0**
을 쟀는데 그건 CPT 코퍼스가 매 step 강화하는 지층이라 1.000 을 찍고 "망각 0"을 인증했다.

⟹ **H_9324 '망각 0' = 거짓 · H_9322 flip1 판독 = ⛔ INVALID** (연산자를 부숴놓고 "합성해봐"라고 물었다).

## 🧱 판정 — BINDING-FAIL (벌어낸 음성)

**표면 편향이 뒤집혔을 뿐이다**:

| | flip1 에서 무조건 답하는 것 | 긍정원자 | 부정원자 |
|---|---|---|---|
| `ground` (연산자 죽음) | '부정' **88.5%** | 0.022 | 0.786 |
| `ground_keep` (연산자 생존) | '긍정' **66.7%** | 0.622 | 0.286 |

긍정 층이 살아난 만큼 부정 층이 죽었다 — **합이 그대로**다. 모델은 심은 사실을 **읽는 게 아니라**
어느 쪽으로 쏠릴지만 바꿨다. replay 가 바꾼 것은 *어떤 표면 규칙이 발화하느냐*이지
*사실을 조회하느냐*가 아니다.

**도망갈 구멍이 전부 막혔다**:
- ~~"연산자가 없다"~~ → 있다. **0.9833** 으로 작동한다.
- ~~"기질이 못 한다"~~ → 같은 기질이 SEEN 어간에선 **한다**.
- ~~"사실이 안 심겼다"~~ → 심겼다. **WRITE 0.9770**.
- ~~"우리가 연산자를 부쉈다"~~ → 살렸다. **base 보다 높다**.
- ~~"예산이 부족하다"~~ → 10배 늘려도 **Δ=0.0000**(H_9324).

**남는 것 하나**: **사전학습으로 배운 극성에는 연산자가 붙고, CPT 로 쓴 극성에는 붙지 않는다.**
두 종류의 사실이 **같은 연산자에 접근하지 못한다.** 이것이 벽이고, 이름은 **BINDING** 이다.

## ✅ 확정 — 통제군 4/4

**④ s11 재현**(#3462): 연산자 1.0000 · WRITE 0.9885 · DV 0.5632 [긍 **.378** 부 .762] ⟹ 형상 일치.
게다가 **표면 편향의 방향이 seed 마다 뒤집힌다**(s7 긍정 쪽 · s11 부정 쪽). 모델이 사실을 **읽는다면
방향은 사실이 정하므로 seed 에 무관**해야 한다 — 방향이 seed 잡음을 따라간다는 것 자체가 추가 증거다.

**⑤ LIE 통제군**(`ground_keep_lie` · 사실만 29/29 반전 · 연산자 replay 는 참 유지 · SEEN flip1 = **1.0000**
으로 유효성 확인):

| | held-out flip1 | 긍정원자 | 부정원자 |
|---|---|---|---|
| 참 사실 (`ground_keep`) | 0.4598 | 0.622 | 0.286 |
| 거짓 사실 (`ground_keep_lie`) | 0.5402 | **0.911** | **0.143** |
| | **Δ = −0.0805** | | |

동결 규칙(Δ<0.10)은 BINDING 이라 말한다. **그런데 헤드라인을 믿지 않았다** — 층은 크게 움직였는데
(긍정 +0.29 · 부정 −0.14) 헤드라인에서 **상쇄**됐다. 이게 오늘 세 번 반복된 함정이다. 그래서 두 검사를 더 했다:

- **원자별 일치율** 60/87 = **69%**(사실을 뒤집어도 같은 답) — BINDING 방향이나 **전역 편향 이동에 오염**
  (긍정 베팅 66.7% → 88.5%)되어 결정적이지 않다.
- **편향-무관 검사(결정적)** — 각 팔 **안에서** 답이 심은 극성에 의존하는가(전역 편향 자동 상쇄):

| | P(긍정 \| 심은=긍정) | P(긍정 \| 심은=부정) | 의존도 |
|---|---|---|---|
| 참 사실 | 0.714 | 0.622 | **+0.092** |
| 거짓 사실 | 0.911 | 0.857 | **+0.054** |
| | | **평균** | **+0.073 ≈ 0** |

**합성이면 크게 음수**(답 = 심은 것의 반대), **되뇜이면 크게 양수**여야 한다. **0이다.**
⟹ **심은 사실이 flip1 에서 조회되지 않는다는 직접 증명.** 69% 는 편향 이동의 부산물이었고
이 검사가 그걸 걷어냈다.
- **기질은 세 번째로 무죄**다. 내가 "어텐션이 없어서 못 한다"고 한 말은 **틀렸다** — 이 모델은
  부정 합성을 **한다**(SEEN 0.9833).
- 이건 `xbind-g1-crack-measure-not-substrate`(H_9267: 합성 corpus 로 held-out 1.000)와도 정합한다.
  **연산자를 코퍼스가 시연하면 배우고, 사실을 CPT 로 쓰면 그 연산자가 그 사실에 닿지 못한다.**
