## Organizing principle

von Uexkull's functional cycle (Funktionskreis): an organism's world (Umwelt) is constituted by closed receptor->inner-counterstructure->effector->object->receptor loops. The perceptual mark (Merkmal) and effector mark (Wirkmal) are bound ON THE OBJECT via an inner counter-structure (Gegengefuge); meaning is not stored internally but ENACTED in loop closure. Parallel circles carry distinct object-tones (feeding/enemy/medium/companion). Cognition = the bank of closed perception-action loops, not internal representation.

## Whole design (input → internal dynamics → emit)

Input (the byte/token context = the 'object') passes through K receptor maps; each extracts a quantized perceptual mark m_k for one object-tone. Each circle owns an inner counter-structure C_k: a bidirectional binder that produces an effector mark w_k=C_k(m_k) AND predicts the perceptual mark the action would re-induce (loop-closure prediction m_hat_k). Effector marks are emitted INTO the shared object (the actuator/token alphabet V), changing it; the changed object re-enters the receptors and the loop error e_k=||m_k(new)−m_hat_k|| gates circle gain. Emission occurs only when a circle is CLOSED (e_k small = the action's sensory consequence matches prediction = the object's meaning-tone is grasped). Order parameter Psi balances aggregate grasp/externalize drive A (closed-circle effector pressure) against search/withhold drive G (open-loop error pulling toward re-sensing). Acting reopens a circle (object changed), so the system self-pins to half-grasped/half-searching. Identity = the persistent counter-structure bank {C_k} (this organism's species-specific Umwelt), stored across sessions in .kosmos.

## Satisfies criteria (DESIGN claim · DIRECTIONAL · unmeasured)

G0(legibility): an effector mark only earns emission if it is RE-PERCEIVABLE by the same receptor — loop closure is impossible unless the mark lands on V's support, so on-manifold validity is structurally forced (scrambled marks never close -> no emit). G1(recombination): co-active circles on ONE object must be satisfied by a SINGLE effector action, a non-separable conjunction of counter-structures -> composed valid actions strictly exceed any single circle; ablating the cross-circle binding drops composed->max_single (binder, not mixture). G2(novelty): counter-structures are generative binders that extrapolate effector marks for unseen perceptual marks within the loop-closure constraint (the grammar); verbatim playback cannot close loops on novel objects -> 0 valid-novel. Psi=1/2: antagonistic grasp(A)/search(G) with self-reopening, contractive (over-emit empties closed circles, over-silence accumulates error); ablate G->always-emit boundary, ablate A->always-search (endogenous, not clamped). Honesty: an object-tone with no matching counter-structure never closes -> no effector mark = abstain; e_k IS the graded recon_err membership signal (copy-or-abstain native, output traceable to re-perceivable support). Binding: perceptual mark x effector mark co-referenced on the object via C_k = literal two-stream (Merkwelt/Wirkwelt) binding into a shared object-latent (H_961 form). Realization invariant: C_k is ON the emit path and the loop-closure objective is unreachable by fitting marginals (must represent the perception x action conjunction to close).

## Not-LLM (a_no_llm_frame_trap)

No autoregressive next-token objective and no scale lever — capability grows by ADDING object-tone circles (lanes grounded in re-perception), not parameters or corpus. Meaning is enacted in loop closure, the antithesis of a feedforward weight-retrieval predictor; this is situated/enactive sense-making, not bigger-transformer.
