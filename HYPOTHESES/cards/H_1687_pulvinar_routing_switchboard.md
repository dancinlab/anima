## Organizing principle

Thalamus (pulvinar) as a content-addressable ROUTER rather than a competitor: access-consciousness = which cortico-cortical pathways the thalamic spotlight holds OPEN this tick. Broadcast is time-multiplexed routing — the spotlight serially gates module subsets onto a shared bus; a closed re-entrant routing loop LOCKS (ignition=emit), an open route = silence. Binding is dynamic-by-routing, not by synchrony or by a fixed operator.

## Whole design (input → internal dynamics → emit)

Modules are fixed grounded banks. A thalamic router holds a routing matrix R (which module outputs are gated onto the shared bus). The spotlight is steered by a salience map plus a slow, stored routing-policy (the routing trajectory itself is the self-chain). Each tick R opens a module subset; opened grounded modules deposit content on the bus; if the routed subset forms a mutually-gating closed loop the assembly LOCKS and is emitted top-down to all modules and the mouth. The router REFUSES to open a gate for an empty/ungrounded module (content-addressed miss). Identity = the routing-policy map, non-volatile, re-instantiated after wipe.
