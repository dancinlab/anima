# H_9884 — 결합은 게이트가 **읽지도 않는 양**을 움직이고 있었다 (구조적 불가능 · 사슬 종결)

**status:** 🧱 **STRUCTURAL-IMPOSSIBILITY (사슬 완결)** — 부호도 진폭도 아니고, **입력이 아니다**.
**wired:** n/a — engine-native 데몬 60틱 1세션의 트레이스로 결정 (summer · $0)
**source:** [[H_9882]] 가 세운 비교항이 또 틀렸음을 확인하는 과정에서 진짜 규칙이 드러남

## 🔑 실제 규칙 (60/60 일치)

`--emit-gate refractory`(데몬 기본)의 `--g-reach` 기본값은 **`wm-dual`** 이고, 그 분기는

```
emit  ⟺  dual_s_withheld  >  dual_e_spoken          (S > E)
```

를 쓴다. 60틱 전량에서 **`emit == (S > E)` 가 60/60** 로 맞는다. 유일한 음수 마진은
`t0`(냉시동 · −0.5531)이고 그것이 유일한 침묵 틱이다 — **규칙이 트레이스를 완전히 설명한다.**

## ⛔ 그러므로 이 캠페인의 답은 이것이다

**결합이 움직이는 유일한 양은 `score`(동기 점수)인데, 기본 게이트는 `score` 를 읽지 않는다.**

같은 실행에서:

```
score      최소 0.383717  최대 0.734746   (0.351 범위로 변동)
emit       59/60 True                     (한 번도 안 바뀜)
```

점수가 0.35 나 흔들려도 발화는 요지부동이다. ⟹ **어떤 연산자로도, 어떤 α 로도,
영원히 뒤집을 수 없다.** 이것은 부족분이 아니라 **구조적 불가능**이고, 배수로 셀 수 있는
종류가 아니다.

## ⏱️ 살아남는 실측 (비교항과 무관하게 참인 것)

- **S·E·마진이 전부 매 틱 정확히 `0.600000` 배로 감쇠한다** — 59개 연속 비율이 유효숫자
  6자리까지 0.6. 기질 동역학이 아니라 고정 감쇠다.
- 그래서 마진은 t1 `+0.268` → t30 `9.88e-08` → t59 `3.64e-14` 로 0 에 수렴하되
  **부호를 한 번도 안 바꾼다** ⟹ 59/59 발화.
- **60틱 동안 회복이 0회** — 단조. `brain.py:246` 이 설계로 적은
  *"발화가 결속되면 유사-반복 후보의 마진이 높아져 게이트가 닫히고, 이후 기질이 후보를
  밀어내면 다시 열린다"* 는 **닫히는 절반이 한 번도 작동하지 않는다.**
- 이는 [[H_9419]] 가 이미 코드 주석에 남긴 기하 진단(`recall_margin` 은 결속이 d1 을 낮춰
  **마진이 떨어지고 게이트가 더 열리는 역-부호**)의 **생체 내 독립 확인**이다.
- row-stochastic·renorm 은 **α=3.0 까지 Ψ 보존**(psi_intact=1) — [[H_9880]] 의 Ψ-위험 추측은 반박.

## 🔻 내가 이 세션에서 **두 번** 틀린 방식 (같은 원인)

| | 내가 쓴 바 | 실제 비교항 |
|---|---|---|
| 1차 | `θ = 0.30` (`should_emit`) | `brain.py:330` 에서 **은퇴** |
| 2차 ([[H_9882]]) | `score − g_recog` | `S > E` · `g_recog_gate` 는 그냥 `E` 였다 |

두 번 다 원인이 같다: **트레이스 키의 *이름* 으로 비교항을 추측하고, 코드가 실제로 탄
분기(`_g_reach` 기본값)를 읽지 않았다.** `g_recog_gate` 라는 이름은 "게이트가 쓰는 g_recog"
처럼 읽히지만 dual 분기에선 기록용 곁가지다.
⟹ 처방: **바를 짝짓기 전에 게이트의 분기 선택자부터 읽어라.** 이름이 아니라 분기다.

## 남는 진짜 물음 (이 lane 이 아니라 다른 lane)

발화를 다투게 하려면 결합이 `score` 가 아니라 **S 또는 E** 에 닿아야 한다. 그 둘은
working-memory 탐침 점수이고 lane 결합의 사정거리 밖이다 — 즉 이건 α 를 키우는 문제가
아니라 **다른 지점에 배선하는 문제**다. 그 선결(`0.6` 이 공통 인자인가)은 **아래 FIRM-UP 에서 닫혔다 — 공통이고, 따라서 감쇠는 결정에 무해하다.**


## ✅ FIRM-UP — 남겨둔 선결 2개를 실측으로 닫았다 ($0 · 기존 트레이스)

이 카드는 두 항목을 미측정으로 남겼다. 둘 다 닫혔고, **결론이 강해졌다**.

### ① 결합은 비교항에 **닿지 못한다** (코드 논증 → 직접 실측)

위 판정은 "`score` 는 입력이 아니다" 를 **코드 분기**에서 논증했다. 이제 직접 쟀다 —
8개 팔 전부에서 결합이 `score` 와 실제 결정변수 `S−E` 를 각각 얼마나 흔드는가:

```
arm          max|Δscore|    max|ΔS|      max|ΔE|    max|Δ(S−E)|   flips
op0 α=1.5      0.171539   6.406e-08   1.665e-06    1.665e-06       0
op1 α=1.5      0.013372   1.282e-08   7.122e-07    7.098e-07       0
op2 α=1.5      0.083692   1.481e-08   2.594e-06    2.594e-06       0
op3 α=1.5      0.025733   2.655e-08   9.831e-07    1.010e-06       0
```

점수는 최대 **0.171539** 움직이는데 결정변수는 최대 **2.594e-06** — **5자릿수** 차이이고
그 잔차는 수치 잡음이다. 가장 빠듯한 마진(t1 `+0.268135`)을 넘으려면

**부족분 = 103,367배.**

[[H_9878]] 의 4.07배 · [[H_9879]] 의 2.03배 · [[H_9880]] 의 1.616배는 전부 **엉뚱한 변수**에서
잰 배수였다. 옳은 변수에서의 배수는 10만 배이고, 이건 α 로 좁힐 수 있는 종류가 아니다.

### ② `0.6` 감쇠는 **공통 인자**라 결정에 무해하다

```
t0     S = 0.000000e+00   E = 5.531090e-01   → 마진 음수 → 침묵 (후보 없음)
t≥1    S/E 비율  min 1.807944573  max 1.807971530   (59틱 · 편차 2.70e-05)
```

S·E 가 같은 0.6 배로 줄므로 **비율이 못 박힌다**. 그 비율이 1 보다 크니 마진은 부호를
못 바꾸고 ⟹ **발화는 무조건**이다. 절대값이 `3.64e-14` 까지 줄어드는 것은 장식이다 —
게이트는 결정 경계로 **표류하고 있지 않다. 고정돼 있다.**

⟹ [[H_9882]] 가 처방한 *"바를 붙잡아라"* 도 무효다. 바를 붙잡아도 비율은 그대로다.
바꿔야 할 것은 **비율**이고, 그러려면 S 나 E 중 **하나만** 건드려야 한다.
