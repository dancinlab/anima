## 결정적 함의 — XOR-class 가 소진됐다

γ census: *"진짜 비가법 = XOR-class 뿐(부정 / 역접)"*.
⇒ **이제 그 클래스의 두 멤버가 모두 추정기-무관하게 측정됐고, 둘 다 ≈ 0 이다.**

이는 Fable 의 **구조적 논증**을 두 번째 독립 사영에서 확증한다:

> NSMC 가 +0.002 를 낸 이유는 XOR 이 없어서가 아니다(δ̂ 방향은 맞았다). **주효과가 라벨 분산을 다 먹어서**다. 그리고 그 원인: **언어는 이해되기 위해 쓰인다** — 화자는 청자가 XOR 를 풀지 않아도 되게 **가법 단서를 선불로 깐다**. 즉 **marginal 무력화 구조는 소통 언어가 구조적으로 기피한다.** +0.002 는 코퍼스 버그가 아니라 **이 압력의 서명**이다.

## 남은 것 (같은 Bonferroni 가족 · 미발사)

- **P1 SARCASM (반어)** — Fable 이 지목한 **극단 leverage**: 소통 언어 중 marginal 이 **능동적으로 오도**하는 유일한 자연 구조(긍정 단어 → 부정 의미). 반어에서조차 +ε 이면 **"소통적 자연 언어 = DATA-ADDITIVE" 를 부류 수준에서 종결**할 수 있다.
  ⛔ **데이터 블로커(실측 확인)**: **감성 라벨 ∧ 반어 라벨을 함께** 가진 코퍼스 필요(하나만 있으면 B 와 T 가 같아져 퇴화). 확인한 공개 코퍼스(ETS twitter shared task)는 `label`(SARCASM/NOT) **하나뿐** ⇒ 사용 불가. 필요 사양 = 텍스트 + **감성 점수** + **반어 플래그**(SemEval-2015 Task 11 계열).
- **P3 PARITY (이중부정)** — 이론상 가장 순수한 XOR 이나 자연 텍스트에 2+ 부정문이 극희소 ⇒ held-out n≈0 위험. 발사 시 G-POWER 가 먼저 죽으면 INVALID 로 정직 종결.
