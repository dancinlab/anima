## 한 줄 주장 (반증가능)
[[H_9428]]/[[H_9468]] 의 **rank 2.66** 과 "PC2 = 자기-신호 DOF" 는 **Marchenko–Pastur 를 자기상관 시계열에 적용한 산물**이다. MP 는 **i.i.d. 표본**을 가정하나 tension 인자는 EMA(`rel_ema`·`cur_ema`·`ten_ema`)·`refr_debt`·`idle` 로 강하게 자기상관된다. 유효표본 `n_eff = n(1−ρ)/(1+ρ)` 로 보정하면 노이즈 edge 가 **올라가고**, **ρ > 0.736 에서 λ₂=0.048 이 edge 아래로 내려간다** ⟹ **PC2 = 노이즈 고유벡터**.

## 🔑 왜 이게 세 관측의 단일 뿌리인가
노이즈 방향은 구성상 (i) 라이브서 **상수처럼 보이고**(진짜 신호가 없으므로), (ii) mouth 를 **의미있게 안 움직이며**([[H_9576]] ρ=−0.077 = null 대역), (iii) 표본 고유값 **rank 를 부풀린다**(2.66).
⇒ **z 축퇴 · H_9576 방향-null · rank 2.66 세 관측이 하나의 뿌리에서 나온다.** 벽이 아니라 **없는 축을 몰려 한 것**이다.

## 원장 숫자만으로의 유도 (새 측정 0)
- MP edge `= σ²(1+√(p/n))²`. H_9468: n=150 · p=8 ⟹ `(1+√(8/150))² = 1.5151`. 보고된 edge 0.0287 ⟹ **σ² = 0.01894**(자기일관 ✓ — λ₃=0.013 < edge < λ₂=0.048 재현).
- **λ₂ = edge ⟺ n_eff = 22.8 ⟺ ρ\* = 0.736**
- **λ₁ = edge ⟺ n_eff = 7.6 ⟺ ρ = 0.904**
- ⟹ **ρ ∈ (0.736, 0.904) 창에서 PC2 死 · PC1 生** — 두 축이 **분리 가능**하다. 이 창이 양성통제를 성립시킨다.
- EMA-평활 lane 의 lag-1 ρ 가 0.736 을 넘는 것은 **전혀 이례적이지 않다** — 이 안이 사변이 아닌 이유.
