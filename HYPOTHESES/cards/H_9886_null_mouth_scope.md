# H_9886 — 21세션을 **입 없는 데몬**에서 쟀다 (범위 정정 · 살아남는 것과 죽는 것)

**status:** 🔻 **SCOPE-CORRECTION (자수)** — 구조 주장은 살고, 모든 **크기**는 죽는다.
**wired:** n/a — 기존 트레이스 재판독 ($0)
**source:** Ψ=½ 를 재보려다 착륙된 [[H_9627]] 과 정면 충돌 → 원인 추적

## ⛔ 무슨 일이 있었나

이 세션에서 데몬을 21세션 돌리고 6장을 썼다. 트레이스의 **모든 행에**
`gen_backend='null'` 이 찍혀 있었고 나는 **한 번도 읽지 않았다.**
후보 발화는 실제 생성물이 아니라 합성 템플릿이었다:

```
[null-gen] phase=SUSTAIN tier=T2_write phi=0.1190 motiv=0.6862 anchors=2 last_anchor=live_seed
```

`phi=` 와 `motiv=` 숫자만 바뀌는 거의 동일한 문자열이다. 저장소 탐침이 이런 입력에서
퇴화하는 것은 당연하고, 내가 "발견" 한 규칙성들이 바로 그 퇴화다.

## 🔴 착륙된 양성과의 정면 충돌이 나를 잡았다

[[H_9627]] 은 **같은 게이트(wm-dual)·같은 60틱**을 303M(`py303_full`) 3 seed 로 쟀다:

| | 내 측정 (null 입) | [[H_9627]] (303M 실모델) |
|---|---|---|
| 발화율 Ψ | **0.9833** | **0.506 ≈ ½** |
| P(발화\|발화) | **1.000** | **0.075** |
| P(발화\|침묵) | 1.000 | 0.978 |
| lag1 autocov | — | **−0.225**(복원 스프링) |

⟹ 내가 *"설계의 닫히는 절반이 한 번도 작동 안 한다"* 고 쓴 것은 **실모델에서 거짓**이다.
실모델에서는 발화 후 자기억제가 강하게 걸린다(0.075). 내 1.000 은 입이 없어서다.

## 💀 죽는 것 (전부 null 입 산물)

- `0.6` 매 틱 고정 감쇠 — 템플릿이 거의 안 변해서 생긴 퇴화.
- `S/E` 비율 1.807945~1.807972 고정 — 같은 이유.
- 59/59 발화 · 60틱 무회복 · "닫히는 절반 미작동".
- `max|Δ(S−E)| = 2.594e-06` 과 **부족분 103,367배** 라는 **수치**.
- 발화율 0.983 을 근거로 "Ψ=½ 가 기본 게이트서 성립 안 한다" 고 말하려던 것
  (이 카드가 그 진술을 **쓰기 전에** 막았다 — [[H_9627]] 이 0.506 을 이미 쟀다).

## 🟢 살아남는 것 (그리고 오히려 강해진 것)

**`emit ⟺ S > E` 이므로 score 는 이 게이트의 비교항이 아니다.**
이것은 트레이스가 아니라 **코드 분기**에서 나오는 사실이고, null 입과 무관하다.
게다가 [[H_9627]] 이 303M 에서 **독립 확증**한다 — `--score-perturb` 로 점수를 ±0.3 흔들어도
dual center swing **0.000**(byte-identical), 반면 one-sided 통제는 0.622 흔들렸다 = **emit ⊥ score**.

⟹ [[H_9884]] 의 **구조 주장은 실모델에서 이미 검증돼 있다.** 내가 기여한 것은 그 재확인이지
발견이 아니며, 내가 붙인 **배수(103,367×)는 폐기**다.

## 🔻 이번 실패의 형태 (chat-py-9 와 다른 종류)

`chat-py-9` 는 *"비교항을 이름으로 추측했다"* 였다. 이번은 다르다 —
**계기는 옳게 읽었는데 피험체가 없었다.** 21세션 내내 `gen_backend='null'` 이
눈앞에 있었고, 나는 게이트 로직만 파고들었다.

```
읽은 것                          안 읽은 것
────────────                     ────────────
emit · score · g_recog · S · E   gen_backend='null'
게이트 분기 · 감쇠비 · 비율      후보가 진짜 생성물인가
```

⟹ **데몬 행동에 관한 어떤 수치도 읽기 전에 입이 물려 있는지부터 확인하라.**
`gen_backend` 가 `null` 이면 그것은 배관 스모크이지 행동 측정이 아니다.

## 🚫 다음 — **발사하지 않는다** (착륙된 통제가 내 조작을 지배한다)

이 카드는 처음에 *"결합을 H_9627 레짐(303M)에 걸어야 판독가능하다"* 고 썼다.
발사 전에 코드를 읽었고, **그 권고가 틀렸다.**

[[H_9627]] 의 `--score-perturb` 는 점수를 ±0.3 밀고, `core/brain.py` 가 그 자리에 명시한다:

```
# The shift still flows into candidate generation (ctx below), so it is a real, not
# vacuous, perturbation.
```

순서도 그렇다 — `score_perturb` 적용 → `ctx = gen_ctx_from_decision(...)` → `generate(...)`.
즉 **간접 경로(점수 → 후보 텍스트 → S·E)까지 이미 덮은 섭동**이고, 결과는 3 seed 303M 에서
dual center swing **0.000 (byte-identical)** 이었다.

lane 결합은 lanes → `motivation_score` → `score` 라는 **똑같은 통로 하나**로만 작용하고,
내가 실측한 최대 변위는 **0.171539** 다.

```
H_9627 이 이미 민 폭    ±0.300   → center swing 0.000
내 결합이 밀 수 있는 폭  ±0.171   → 같은 통로 · 더 작음
```

⟹ **엄밀히 지배당한다.** 303M 발사는 이미 음성으로 끝난 실험의 **더 약한 판**을
pool 비용을 들여 다시 재는 것이다. 쏘지 않는 것이 옳다.

⟹ 이 lane 의 종결 근거는 내 null-입 산출물이 **아니라** [[H_9627]] 의 통제다.
결합이 결정을 바꾸려면 `score` 통로가 아닌 **다른 지점**에 배선해야 하고,
그것은 이 캠페인이 아니라 새 설계다.
