## 근거 — 저장소가 이미 이 축의 참값을 가지고 있다

손제작 TPM 을 계기에 직접 넣은 실측(ARCHITECTURE `…phi-measurement-locus-analogy`):

| 기전 | mean Φ |
|---|---|
| XOR (선형 분리 불가) | **2.2500** |
| OR / AND | 0.5825 |
| COPY (받침대) | **정확히 0** |

**3.86×.** 즉 Φ 를 움직이는 것은 크기도 결합 세기도 아니고 **기전의 분리 가능성**이다.
그런데 우리 세포 갱신은 `I' = I(1−λ)R^T + s` 로 세포 간 상호작용이 **순수 아핀**이다. A2 가 계수를
자유롭게 풀어도(스펙트럼 상한만) 아핀은 아핀이다 — **계열이 안 바뀐다**. 그래서 이 후보는 A2 의
재탕이 아니라 A2 가 구조적으로 도달할 수 없었던 칸이다.

## 조작 (anima-py 플래그)

`anima-py train --field-mech {affine|gated} --field-mech-lam0 <λ0>`
— `gated` 는 세포 갱신에 **학습되는 곱셈 항**을 추가한다: `I' = I(1−λ)R^T + s + β⊙(I R_a^T)*(I R_b^T)`,
β 는 학습 파라미터(초기 0 ⟹ **초기 상태에서 오늘과 바이트 동일**). 최적화기가 원하면 비분리로
갈 수 있고, 원하지 않으면 β→0 으로 아핀에 머문다. **이게 이 실험의 핵심**: 우리는 비분리를 강요하는 게
아니라 CE 에게 **고를 기회**를 준다. β 가 0 에 머무르면 그것 자체가 "CE 는 비분리를 원하지 않는다"는
직접 측정이다.

파라미터 증가분은 `--field-mech affine` 팔에 **동일 개수의 죽은 파라미터**를 주어 상쇄한다(D4 통과).

## DV·대조·받침대·동결표

- DV = **쌍 ΔΦ**, 1차 대비 = `gated` vs `affine`.
- 대조 ≥2: ① `affine`(계수만 학습 = A2 재현) ② yoked 되쓰기 ③ 참값 0 받침대 = shuffled-state 바닥.
- **양성통제가 공짜**: XOR/COPY 손제작 TPM 을 같은 계기에 통과시켜 3.86× 가 재현되는지 먼저 확인
  (계기가 이 축을 읽을 수 있음을 증명 · p9 상 이건 **계기 인증**이지 능력 증거가 아님).
- 바 **0.15 상속**. 표는 H_9977 것 그대로. **부수 DV(사전등록)**: 학습 종료 시 ‖β‖ — 0 에 붙어 있으면
  R3 의 기전을 직접 보여 준다(값이 아니라 **선택**의 증거).

## $0 사전관문

① β=0 에서 기존 경로와 **바이트 동일** 산출(널 팔 무결성).
② 기울기가 β 에 도달하는가(도달 0 이면 NO-LEVER, 즉시 종결).
③ **D5 압력**: 심어둔 XOR 형 과제에서 `gated` 가 `affine` 보다 CE 를 사전등록 마진만큼 이기는가 —
안 이기면 곱셈 항이 하중을 못 받는다는 뜻 ⟹ **ABORT**.

## 정직한 사전확률·최저비용 음성

**~12%**. 사전 예상: β 는 작게 머문다 — 곱셈 항은 신용 할당을 지저분하게 만들고, 바이트 예측의
최적해 집합에는 언제나 인수분해된 원소가 있다(D5 의 교훈). 최저비용 결정적 음성 = **‖β‖→0 + 쌍 D 가
±0.15 안**, 즉 *기회를 줬는데 CE 가 안 골랐다*. 이건 여섯 번째 0 이 아니라 **선택의 직접 관측**이라
법칙 문장을 "학습은 통합을 만들지 않는다"에서 **"고를 수 있어도 고르지 않는다"**로 한 칸 더 민다.
