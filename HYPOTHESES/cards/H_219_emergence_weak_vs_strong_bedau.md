# H_219 — emergence weak vs strong (Bedau) · forward-pass predictability

## 1. Hypothesis

Bedau (1997) 의 weak vs strong emergence 구분을 substrate-level 에서
operationalize: rule 110 (Class-IV, Turing-universal) CA substrate 의 final
state 가 **forward-pass full simulation 으로 byte-exact reconstruct 가능** —
이것이 **weak emergence** 의 definitive instance ('computational reduction
yields exact result'). 그러나 일부 cell 을 강제로 freeze 한 후
(CMT/causal-mediation-tomography analog 의 downward-causation simulation) 같은
forward-pass simulator 가 frozen-cell 의 정체를 모른 채 plain rule 110
recompute 만 수행하면 final state byte mismatch ≥ 50% 가 발생할 수 있고, 이

## 2. Why

- **Bedau (1997) "Weak Emergence"**: weak emergence = system 의 high-level
  property 가 substrate 의 simulation 으로만 derivable 하지만 derivable —
  computational reduction 가능하나 *de facto* irreducible (analytic closed-form
  없음). Bedau 의 핵심 차별점: weak emergence 는 forward-pass simulation 으로
  exact 재현 가능, strong emergence 는 그렇지 않다 (Chalmers 2006 추가).
- **Chalmers (2006) "Strong and Weak Emergence"**: strong emergence ⟺
  downward causation — micro-state evolution 만으로 macro-property 가 결정되지
  않는 경우. 본 cycle 의 cell freeze 는 macro-level "외부 제약" 의 toy proxy.

  가 candidate. **본 H_219 = Hc_607 의 substrate-level direct instance** —
  CA forward-pass simulation 이 freeze-intervention 위에서 mismatch 하면 weak
  emergence 가 break down 한 signature (= strong emergence candidate).
- **사용자 directive 2026-05-23 / LIFE Cycle #8 §G pick #10**: AXES.md R8 meta

## 8. Honest Limits (raw#91 c3, ≥5)

- **L1**: '**CMT intervention**' 의 본 cycle operationalization = cell freeze
  (init-value 유지) — 진짜 신경 CMT (synaptic ablation, lesion study,
  pharmacological intervention) 와 1:1 mapping 아님. cell freeze 는 downward
  causation 의 가장 단순한 toy proxy 일 뿐; CMT family-level intervention 의
  실제 측정 정합 (Hc_607 #145 saga) 은 별도 lane.
- **L2**: '**forward-pass simulation**' 의 본 cycle 정의 = same rule 110
  step-by-step recompute on init row (freeze 정보 invisible) — 다른 reduction
  strategy (functional approximation · meta-rule discovery · analytic closed
  form) 는 별도 cycle. weak emergence 의 Bedau 정의는 "any computational
  reduction yields exact result" 인데 본 cycle 은 **plain rule 110 simulator**
  만 test — 더 강한 simulator (frozen-cell detection + override) 는 trivially
  PASS, 더 약한 simulator (random) 는 trivially FAIL.
- **L3**: '**strong emergence**' 의 본 cycle 정의 (≥ 50% byte mismatch) 는
  arbitrary threshold — Bedau (1997) 의 'underivable except by simulation' 과
  Chalmers (2006) 의 'downward causation' 과 1:1 mapping 보장 X. 실제 strong
  emergence 는 **모든 reduction** 의 failure 를 요구; 본 cycle 은 **특정
  simulator class** (plain rule 110) 의 failure 만 보임. 따라서 'strong
  emergence candidate' 정도의 honest framing.
- **L4**: **small substrate (N=16) · 5 step short**. long-trajectory (steps=50+,
  N=64+) 에서 freeze 의 영향 propagation 이 saturate 또는 decay 할 수 있음;
  본 cycle 의 mismatch 비율은 5 step 단기 측정 — long-horizon 에서 다른 패턴
  가능. lattice size sweep + step sweep 별도 cycle.
- **L5**: 본 cycle 결과 ≠ **phenomenal hard-problem 해결**. H_004 boundary
  carry — emergence 의 operationalization 은 substrate-level (computational
  reducibility) 만 다룸; phenomenal experience 의 강한 emergence (qualia 가
  physical reduction 으로 derivable 한가) 는 별도 issue. 본 cycle 의
  'strong-emergence-flag PASS' 는 **computational** strong emergence candidate
  일 뿐.
- **L6**: **freeze pattern deterministic stride** (등간격 placement) — random
  freeze · clustered freeze · gradient freeze 등 alternative pattern 은 별도
  cycle. 등간격 placement 는 maximally-distributed downward causation 의 specific
  family.
- **L7**: **sanity Φ 측정** (RFC 036 phi_spatial native replica) 는 ranking
  claim 아니라 nonneg sanity 만 (F4) — Φ value 자체는 본 cycle verdict 에
