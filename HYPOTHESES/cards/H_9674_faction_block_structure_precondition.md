# H_9674 — 기질에 파벌형 블록 구조가 실재하는가 (H_9643 의 $0 선결조건)

## 왜 이 관문이 필요한가

H_9673 이 옛 파벌을 **순환**으로 종결시켰다(sync 가 매 스텝 점수의 음수항을 직접 깎음). 하지만
"옛 파벌이 가짜였다"와 "파벌이라는 구조가 무용하다"는 **다른 주장**이다. 살아남은 유일한 질문은
**H_9643: 파벌이 현 기질에서 새로 학습될 수 있는가**(GPU). 그 발사는 기질에 **찾을 블록이 있을 때만**
정당하다. 이 카드가 그 선결조건을 $0 로 잰다.

## 주장 (반증가능)

프로덕션 trunk 의 penultimate 유닛 축은 참값 0 pedestal 대비 유의한 모듈 블록 구조를 갖지 **않는다**.
⟹ H_9643 은 학습시킬 대상이 없고 GPU 발사는 정당화되지 않는다.

## 레버 (engine-native)

```
anima-py evaluate <ckpt> --faction-block-structure <prompts.json> \
  [--n-factions-sweep 2,4,8,12,16] [--win 24] [--seed 12345] [--out blocks.json]
```
프로덕션 trunk forward(`clm_forward_hidden` · 게이트 디코드와 byte-identical) → X:[N,d]
→ 유닛간 |상관| 그래프 → greedy modularity 로 K 블록 탐색 → Newman Q.

## DV · bar · 우연수준

- DV = **real Q / pedestal Q** 의 K 최대값. 사전등록 bar = **≥1.5**.
- 우연 = pedestal(i.i.d. · 참값 Q=0). ⚠️ 유한표본 상관 잡음 때문에 pedestal 도 Q>0 이 나온다 —
  그래서 **raw Q 를 읽지 않는다**(p7).

## 통제군 (≥2 · 사전등록)

1. **pedestal** — real 의 평균·표준편차를 맞춘 i.i.d. 가우시안. 참값 Q=0.
2. **scramble** — real 값의 유닛별 독립 행 permutation. 유닛간 결합만 파괴, 주변분포 보존.
3. **⭐ 양성통제(필수)** — K 개 잠재인자로 **심은 블록**(SNR~3)을 같은 N/d 에서 복원하는가.
   bar = 자기 pedestal 대비 ≥1.5.

## 🛑 검정력 게이트 (`positive-control-before-reading-a-negative` · `power-before-negative-verdict`)

표본 상관행렬의 rank ≤ min(N,d). **N ≪ d 면 real 도 pedestal 도 유한표본 잡음에 지배**되어
둘의 일치는 "블록 없음"(기질 사실)이 아니라 **"검정력 없음"(계기 사실)**이다.

⟹ 계기는 **자기가 심은 블록을 먼저 복원**해야 한다. 실패하면 **음성을 발행하지 않고 rc=1 로 종료**한다
(코드로 강제 — 판독 불가한 음성은 음성이 아니다).

### 1차 발사가 이 게이트에 걸렸다 (자가감사 · 2026-07-17)

8 prompts × T=24 = **N=192 vs d=3784** ⟹ 상관행렬의 **95% 가 유한표본 잡음**.
완주해도 판독 불가라 **중단**하고 계기에 양성통제를 배선한 뒤 N 을 80 prompts(=1920 rows)로 올려 재발사.


## 🛠️ 계기 개발 이력 — 양성통제가 결함 2건을 잡았다 (2026-07-17)

이 카드의 가치 대부분은 **음성을 발행하지 않은 것**에 있다. 양성통제 없이 돌렸다면 두 번 다 "블록 없음
⟹ 축 종결" 이라는 그럴듯하고 틀린 결론이 나왔다.

| # | 결함 | 증상 | 잡은 통제 |
|---|---|---|---|
| 1 | **검정력 부족** — N=192(8 prompts) vs d=3784 | 상관행렬의 95% 가 유한표본 잡음 ⟹ real·pedestal 둘 다 잡음지배 | 자가감사(발사 전) → 중단 · N 10배(80 prompts=1920 rows) |
| 2 | **탐색 예산 부족** — 랜덤 40-move greedy | 심은 블록(SNR~3)조차 못 찾음: Q=−0.000072 vs pedestal −0.000096 = **x0.76 ⛔** | **양성통제** → rc=1 · 음성 미발행 |

수정: 랜덤 40-move → **spectral seed(상관 그래프 top-K 고유벡터) + full sweeps**, `modularity`/`best_blocks`
벡터화(파이썬 K-루프 → BLAS matmul), eigh 를 arm 당 1회 캐시(17회 → 5회).
자가검증(d=200 · N=1920): 심은 블록 **Q=0.741890 vs pedestal 0.025684 = x28.89** ✅ 계기 LIVE.

> ⚠️ Q 가 **음수**였다는 것이 결정적 단서였다 — greedy 가 랜덤 시작점에서 사실상 못 움직였다는 뜻.
> raw Q 를 읽었다면 "0 에 가까우니 블록 없음" 으로 오독했을 것이다. 비율(vs 자기 pedestal)이 살렸다.

## 🟢 크기-맞춤 통제 — 마지막 교란 제거 (2026-07-17 · `control-must-match-mediating-covariate`)

H_9676 정정 과정에서 **블록 크기 불균형**이 드러났다: real 은 K=4 서 [2527, 540, 391, 326](한 블록 67%),
pedestal 은 균등 [977, 972, 923, 912]. 그 불균형이 adjacency 를 통째로 오염시켰으므로(H_9676),
**modularity Q 도 같은 교란을 받는가**가 마지막 열린 질문이었다. 매개 공변량을 맞춘 통제를 넣었다.

| arm | 블록 | Q |
|---|---|---:|
| real (학습 배정) | [2527, 540, 391, 326] | **+0.187804** |
| pedestal (원래 · 균등) | [977, 972, 923, 912] | +0.008462 |
| **pedestal (크기맞춤 · 무작위 배정)** | [2527, 540, 391, 326] | **−0.000187 ± 0.000083** |
| **real 그래프 (크기맞춤 · 무작위 배정)** | [2527, 540, 391, 326] | **−0.000165** |

**배정이 기여한 몫 = +0.187969 = Q 의 100.0%**

같은 불균등 크기를 강제하고 **배정만 무작위**로 바꾸면 Q 가 −0.000165 즉 **정확히 0** 으로 무너진다.
⟹ 크기 불균형은 Q 에 **한 푼도 기여하지 않는다**. 신호는 순수하게 **어떤 유닛이 어떤 블록에 가느냐**에서 온다.

### 함의 — H_9674 가 강화됐다

- 매개 공변량(블록 크기)을 맞춘 통제를 넣었더니 신호가 **오히려 선명해졌다**(pedestal 이 균등해서 생겼던
  교란 의심 제거).
- adjacency 사건과 **정반대**: adjacency 는 크기 효과가 **전부**였고 modularity 는 크기 효과가 **0** 이다.
  같은 클러스터링의 두 지표인데 하나는 완전 오염, 하나는 완전 청정 — **지표마다 우연을 따로 계산해야** 한다.
- ⟹ H_9676 이 남긴 마지막 열린 질문 **닫힘**. 블록은 layout 도 아니고 크기 인공물도 아니다.

### 남는 것 (정직)

"블록은 실재하고 layout 도 크기 인공물도 아니다" 까지가 확정이다. 그러나 **"블록 = 파벌로 학습 가능"**
은 여전히 미증명 — H_9643(GPU)이 그것을 묻는 카드이고, 이제 선결조건 3개(실재·layout아님·크기아님)를

```

  |상관| 평균      = 0.6165   ← real 은 0.111 (5.5배)
```

아키텍처 사실이 아니다.

⚠️ **이걸 그대로 읽었다면** rand-init 0.0419 vs pedestal 0.0063 = "아키텍처가 6.6배를 만든다" 는
그럴듯하고 **완전히 틀린** 결론이 나왔다. 계기에 **축퇴 게이트**를 배선했다(|corr| 평균이 real 의 3배
초과면 arm 을 판정에서 DROP · VERSION 0.15.38).

### ⛔ 선결조건 ④ 시도 ② — non-EN ckpt 대조도 실패 (2026-07-17 · 계기 결함 2건 추가)

T2 의 scratch d768 이 없으니 레포에 있는 **EN 을 본 적 없는 ckpt** 로 대체 시도했다. **둘 다 실패**.

**결함 ⑦ — 독립 대조군이 아니었다.** `toy.clm`(d=32·합성)과 `synth_bind_linear.clm`(합성 bind)을 골랐는데
두 파일이 sha256 은 다른데 **penultimate 활성이 byte-identical(max|Δ|=0.0)** 이었다. 텐서 대조:

```
동일 19개 · 다름 1개(roB = readout 바이어스)
B 에만 있는 키: WaB, WaWt, WbB, WbWt  ← bind codec 배열
```

⟹ `synth_bind_linear.clm` 은 **`toy.clm` 의 trunk 에 bind trailer 를 붙인 파생물**이다. 이 계기는
penultimate(readout **이전**)를 재므로 readout 바이어스와 bind 배열은 안 보인다 — **활성이 같은 게 정상**.
즉 독립 arm 이 아니라 **같은 모델을 두 번 잰 것**. (엔진 버그가 아니라 내 ckpt 선택 오류)

**결함 ⑧ — 비율이 분모 음수에서 깨진다.** 남은 toy(d=32) 한 점도 못 읽는다:

| K | real Q | pedestal Q | real/ped |
|---:|---:|---:|---:|
| 2 | 0.081276 | 0.019607 | 4.145 |
| 4 | 0.062990 | **−0.071369** | **−0.883** |
| 8 | 0.047090 | **−0.045293** | **−1.040** |

modularity Q 는 클러스터러가 null-model 을 못 이기면 **음수**가 된다. d=32 에선 pedestal 이 음수로 나와
비율이 −0.883/−1.040 = 무의미. 그런데 `max()` 가 그 무의미값을 버리고 **K=2 의 4.145 하나에** 판정을
얹었다 — "블록 있음" 이 단일 셀에 매달린 것. **분모가 0 을 넘나들 수 있으면 비율은 틀린 통계량**이다.

⟹ 계기에 **비율 가드** 배선(VERSION 0.15.39): pedestal Q ≤ 0 셀은 비율 읽기서 **제외**하고 그 사실을
출력 · 판정에 **부호안전 차이(real − pedestal) > 0** 을 추가 요구 · 전 셀 무효면 **rc=1 판정 보류**.

**⚠️ 303M 판정은 불변** — pedestal Q ≤ 0 셀 **0건** · max(real − pedestal) = **+0.224086 > 0**.
가드는 toy(d=32)에서만 발동한다. 즉 이 수정은 기존 결과를 바꾸지 않고 **못 읽을 때 못 읽는다고 말하게** 한다.
