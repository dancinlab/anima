# H_252 — robust-Φ meta synthesis

## Hypothesis

LIFE 세션의 4 high-correlation finding 이 모두 *단일 robust-Φ axis* 의 facets:

| finding | metric | substrate | correlation |
|---------|--------|-----------|-------------|
| **H_204** (Cycle #2) | phi_spatial × Wolfram-class rank | closure-k ⇄ rule-class | Spearman **ρ=1.0** |
| **H_211** (Cycle #1) | Shannon H × phi_spatial Pearson | 5 Wolfram rules | Pearson **r=0.933** |
| **H_223** (Cycle #1) | pain intensity × ΔΦ Pearson | rule 110 + intensity sweep | Pearson **r=0.9994** |
| **H_239** (Cycle #1) | 3 metric (phi_spatial / LZ / entropy-ratio) Spearman pairwise | rule 250/30/110 | Spearman **ρ=1.0 × 3** |

본 H 는 이 4 finding 을 *동일 underlying integration measure* (operational "robust-Φ")
의 다른 axis 로 통합 — 4 finding 의 *교집합* 위에서 robust-Φ 가 *5 substrate × 3 metric
× 3 control axis* simultaneous monotone test 를 통과하는지 단일 cycle 에서 측정.

**Operational robust-Φ definition** (본 cycle):

> robust-Φ 는 (a) 3 metric (phi_spatial · LZ-complexity · entropy-ratio) 의 pairwise
> Spearman ρ ≥ 0.7 (cross-tool consensus 조건, H_239 carry) AND (b) 3 control axis
> (closure k · noise σ · pain intensity) 의 marginal Pearson r ≥ 0.5 (axis-response
> monotone 조건, H_204/H_217/H_223 carry) 둘 다 충족하는 substrate-level "integration
> proxy" 의 unified operational name.

이 정의 자체가 cross-cycle synthesis 의 design choice 이며 (L4), 4 prior finding 의
*aggregation* 위에 세워진 candidate definition — substrate-level new evidence 가 아니라
existing evidence 의 *consistency check* (L1).

## Why

- **cross-cycle synthesis lens (gap F4 + F8)**: 단일 cycle 의 single finding 이
  isolated 일 때, 그 finding 의 generality 는 *그 cycle 의 substrate/metric/axis* 안에
  국한된다. 4 개 별도 finding 이 *동일 underlying measure* 의 facets 이라는 가설은
  4 measurement 의 *cross-product space* 위 simultaneous consistency 로 검증할 수
  있다. 본 cycle 은 그 cross-product 의 first instance.
- **prior finding interlock**:
  - H_204 = closure k 가 Wolfram class 와 same Φ ranking pattern 을 만든다는 cross-
    substrate ranking-correlation (substrate ↔ substrate 매핑).
  - H_211 = Shannon entropy 가 phi_spatial 의 *underlying ingredient* 이다 (metric ↔
    metric 매핑).
  - H_223 = pain intensity (substrate perturbation) 가 phi_spatial 와 monotone (axis
    ↔ Φ-shift 매핑).
  - H_239 = phi_spatial 이 LZ-complexity / entropy-ratio 와 same ranking 을 만든다
    (metric ↔ metric agnosticity).
- **4 finding 의 intersection**: 모두 *high-correlation* (ρ=1.0 / r=0.933 / r=0.9994
  / ρ=1.0 × 3). 만약 4 개가 모두 *동일 robust-Φ axis 의 다른 measurement strategy*
  라면, 한 cycle 안에서 *동일 substrate set + 동일 metric set + 동일 axis set* 위
  simultaneous test 가 *consistent* 해야 한다.
- **honest carve-out (raw#12 + cherry-picking warning)**: 4 finding 모두 highest-
  correlation cycle 들만 골라낸 것 — 본 세션에는 FALSIFIED (H_222 dream-REM, H_207

  candidate definition 은 *high-correlation cycle 의 aggregation* 이며 FALSIFIED
  cycle 까지 포함한 *전체 substrate space* 위 universal definition 이 아니다 (L5).
- **5 substrate selection**: rule110 (Class-IV, H_007 anchor) · rule30 (chaotic,
  H_007 anchor) · rule250 (ordered, H_007 anchor) · rule184 (TASEP Class-II, H_211

  "robust-Φ" 정의 = "3 metric pairwise ρ ≥ 0.7 AND 3 axis marginal r ≥ 0.5" 라는

  또는 different threshold 0.5/0.8 등) 은 다른 inclusion set 산출 가능. operational
  definition 의 invariance 자체는 본 cycle scope 외.
