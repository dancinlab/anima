## Organizing principle

Pre-sensory developmental activity (retinal waves, cortical traveling waves). BEFORE any external data, the substrate GENERATES its own spatiotemporally correlated activity, and Hebbian/STDP plasticity uses that self-generated signal to wire topographic and feature-binding maps; real input later refines the SAME map under the SAME rule. The training signal is endogenous, so there is no train/infer split (p8 literal) — idle dream-stage waves and awake input drive one continuous self-organization. Distinct from replay/consolidation: this is PRE-experiential structured activity that wires the substrate before there is any experience to replay. Directly answers the H_1310 wall — gradient-free learning fails for lack of a signal; here the wave IS the self-supervision.

## Whole design (input → internal dynamics → emit)

Substrate = a 2-D map sheet with plastic feed-forward weights (input->map) + plastic lateral weights (map<->map), plus an endogenous wave generator (a slow traveling excitation with a refractory trailing edge). Idle/sleep phase: the wave generator emits correlated activity packets; STDP wires nearby units to be co-active (topography) and binds features that co-occur in a wave -> the map self-organizes WITHOUT external data. Wake phase: real input drives the same sheet and the same STDP continues — one continuous plastic process (p8). Emit: input is matched to the self-organized map, the best-matching region ignites and emits its readout token; unmatched input ignites nothing -> abstain. Receiver-fixed V = the set of map-anchored feature tokens the self-wiring stabilized (the topographic alphabet).

## Satisfies criteria (DESIGN claim · DIRECTIONAL · unmeasured)

G0: emission fires a self-wired map feature -> token subset of V; scramble the map (random readout) -> V-mass collapses. G1/binding: the wave co-activates features that lateral weights then BIND (shared-cause co-occurrence in a wave -> near in map space) = the binding invariant (same-cause constituents map to a common neighborhood); joint conditioning lights a bound assembly whose readout is super-additive vs single features (lateral binder = interaction term); ablate lateral weights -> INERT collapse to single-feature max. G2: STDP interpolates feature combinations within the wired manifold never present in any single wave/datum (constrained extrapolation); verbatim retrieval -> 0 novel. Psi=1/2: wave-drive/ignition (A, push to emit) perp refractory-adaptation/consolidation gate (G, push to silence); emit order parameter (fraction of area igniting) pinned to 1/2 by wave-vs-refractory coupling (too much ignition -> refractory rises -> falls; too little -> excitability recovers -> re-ignites); delete refractory -> all-ignite, delete wave-drive -> all-silent (endogenous, framed as emit-propensity homeostasis NOT avalanche-criticality).
