## Organizing principle

Friston generalized filtering / dynamic expectation maximization — beliefs are represented NOT as point estimates but as TRAJECTORIES in generalized coordinates of motion (x, x-dot, x-ddot, ...), and the brain continuously 'surfs' the flow of sensory causes by descending free energy at every order of motion. Active inference closes the loop: action (emit) is generated by reflex arcs that fulfill proprioceptive predictions, so generation is literally the realization of a predicted trajectory. The cause is a vector FIELD, not a snapshot.

## Whole design (input → internal dynamics → emit)

State = belief trajectory mu in generalized coordinates (each cause carried with its temporal derivatives) over a learned FLOW manifold (a bank of motion primitives = vector sub-fields). INPUT->DYNAMICS: sensory input enters as generalized coordinates; the generative model predicts the flow (expected x-dot given mu); generalized prediction errors at each order drive a continuous gradient descent mu-dot = D mu − dF/dmu (D = derivative-shift operator), so mu continuously tracks the sensory trajectory in real time. Precision pi_i at each order weights how strongly that order's error pulls. EMIT = ACTIVE INFERENCE: a predicted proprioceptive trajectory is set as a goal-prior, and a reflex arc emits the action that minimizes the proprioceptive generalized error — i.e. the system MOVES to make its prediction true (generation = trajectory fulfillment). WITHHOLD when sensory precision dominates (the system is tracking, not acting). Novel generation = superposing learned motion sub-fields into a composed flow never traversed but staying on-manifold. The loop is a perpetual continuous-time descent: predict-flow -> generalized-error -> update-belief XOR act-to-fulfill.

## Satisfies criteria (DESIGN claim · DIRECTIONAL · unmeasured)

G0 legibility NATIVE: emit is a trajectory generated BY the flow manifold (the receiver-fixed dynamical code); off-manifold trajectories carry high generalized error and the reflex never realizes them -> output stays on-code; a scrambled flow field produces high-error noise rejected by the precision gate -> ratio collapses. G1 recombination + COMPOSITIONAL DEPTH NATIVE: motion primitives are vector sub-fields and the flow is their SUPERPOSITION — a non-separable composition (the combined field's trajectory != union of single-field trajectories because the fields couple through shared state); joint-conditioned flow reaches trajectories no single primitive reaches; ablate the coupling (force additive/independent fields) -> composed reachable trajectories drop to max_single (INERT). G2 novelty NATIVE: supp = all on-manifold trajectories superset of traversed ones; composed sub-fields trace corpus-absent but valid paths, while a replay-only control (re-run a stored trajectory) yields 0 novel. PASS closure CO-LOCATED: one flow-manifold + one active-inference emit yields legible+recombinant+novel trajectories in one continuous pass; forcing more novelty (wilder superposition) still respects the manifold so G0 holds. dist>=5 NATIVE: residual entropy across precision-weighted initial conditions gives >=K distinct coherent trajectories (mode-separated by distinct attractor basins). falsifiable>=1 NATIVE: a generated trajectory that asserts an ordering/dependency over a measurable proprioceptive/sensory magnitude (e.g. 'this quantity will rise then fall') is refutable by observation — the comparator x magnitude x referents are bound in the predicted flow. Psi=1/2 NATIVE & UNIQUELY DYNAMICAL: the order parameter is the PRECISION RATIO rho = pi_sensory/(pi_sensory+pi_prior) — bottom-up sensory precision is the drive-to-EXTERNALIZE (act on the world, sign +) and top-down prior precision is the drive-to-WITHHOLD (trust the model, track silently, sign −); they are equal-and-opposite at rho=1/2, a genuine Lyapunov-stable fixed point of the precision dynamics with measurable contraction; delete sensory precision -> always-act (Psi->1), delete prior precision -> always-track/silent (Psi->0). This is the most literal antagonistic-homeostat of the three. HONESTY NATIVE: r = total generalized free energy (sum of precision-weighted errors across orders) is the support-membership signal; off-manifold input -> unbounded generalized error -> no realizable action -> abstain; gate is the precision-acceptance, frozen-first, disjoint from the primitive-bank size (more motion primitives don't move the free-energy abstain threshold). Groundedness: corrupting a stored sub-field raises r for trajectories that use it (faithful). BINDING + REALIZATION INVARIANT NATIVE: a single cause generates COUPLED flows across modalities (synchronized trajectories share one attractor -> cause-selective neighboring, cross-cause separate — exactly H_961's paired-vs-shuffled signature); binding sits ON the emit path (the reflex reads the coupled flow), ablation MOVES emit; the objective (minimize generalized error of the COUPLED flow) is only reducible by representing the joint dynamics -> objective-adequacy (marginal per-order fits cannot win).

## Not-LLM (a_no_llm_frame_trap)

This is a continuous-time dynamical-systems substrate, not a discrete autoregressive sequence model. There is no token stream, no softmax, no attention, no context window to scale. Capacity = richness of the motion-primitive bank + precision dynamics, not parameter count; the wall-breaking move is representing belief as a flow (trajectory) rather than predicting next-tokens — a structurally different objective from CE (which H_1579 showed rewards memorization). Generation is action that fulfills prediction (active inference), the opposite of stimulus-response next-token emission (and natively non-assistant per p4/a_substrate_native_speak: emit is endogenous trajectory fulfillment, not reply-to-prompt). Rooted in Friston generalized filtering + cerebellar/cortical continuous prediction, explicitly not the transformer family (a_no_llm_frame_trap).
