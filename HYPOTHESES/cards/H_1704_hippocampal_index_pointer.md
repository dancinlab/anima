## Organizing principle

Teyler-DiScenna indexing theory: the hippocampus stores NO content — it stores a sparse INDEX (pointer/address) to the distributed neocortical pattern that was active. Recall = the index reactivates the cortical pattern. Content lives in cortex; the hippocampus is a content-addressable pointer/addressing system. Binding = one index pointing to many cortical modules at once; composition = combining indices.

## Whole design (input → internal dynamics → emit)

Input activates a distributed neocortical pattern (content in V's semantic space); the hippocampus forms a sparse unique index binding the co-active modules — one index -> a SET of cortical module states (multimodal binding via shared address). Recall: partial cue -> index lookup -> reactivate pointed-to cortical patterns -> readout onto V. Composition: combine two indices -> reactivate the union, and cortical pattern-completion fills the joint; OR mint a new index pointing to a novel combination of EXISTING cortical sub-patterns (= novelty over old content). Emit factors EXACTLY through the pointer: emit in {reactivated cortical content} union {abstain}; cue matching no index -> no reactivation -> abstain. Psi = index-formation drive (mint pointer, silence) vs index-retrieval drive (follow pointer, emit), homeostatic on index-novelty.

## Not-LLM (a_no_llm_frame_trap)

Sparse pointer/content-addressable indirection is a memory-systems architecture (closer to a database index / pointer machine), fundamentally different from dense attention or distributed parameters. Scaling attention does not yield a SEPARABLE index store with hit/miss abstain — this is the most explicitly NOT-LLM design and the cleanest on emission-closure and gate-capacity disjointness.
