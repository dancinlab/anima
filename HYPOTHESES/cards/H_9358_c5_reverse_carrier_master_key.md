**② 잔여 상승의 정직한 처리** (paired 부호검정 pooled p=0.031 — 얼버무리지 않는다): 통제팔 실측 비특이 손상률로 정량 설명됨. untouched+affirm 손상률 ≈3/10, 손상된 이진 판독이 신극성에 떨어질 확률 ~0.5 ⟹ 기대 스퓨리어스 ≈ 12×0.3×0.5 ≈ **1.8개/seed** vs 관측 2·4(평균 3). 손상은 swap 판독을 **우연(≈50%)** 방향으로 밀지 **신극성 ≥10/12 쪽으로 밀 수 없어** 본판정 무오염.

**③ s11 4/12 = seed 요행도 실누수도 아니다**: s7 vs s11 Fisher p≈0.64(이질성 비유의·pooling 정당), 4/12 는 P(X≥4|λ≈2)≈0.14 로 평범(s11 이 affirm 에서도 2/2→1/2 로 더 깎인 seed = 손상-잡음 해석 정합). bar 초과분(+2)은 **base 측정창 변동폭(2–3/12)과 같은 크기** ⟹ two-lane bar 위반이 아니라 bar 를 계기 잡음보다 좁게 사전등록한 문제.

**④ keep echo**: keep flip0 이 base 3/3 → post 0/3·1/3 로 신극성 상실. **(b) 선언지층 비특이 손상은 확정**(untouched 도 3/3→2/3 = [[cpt-destroys-what-corpus-omits]] 패턴 — CPT 코퍼스에 선언 라인 0개). **(a) echo 는 방향성만**(keep 손실 5/6 vs untouched 2/6 · Fisher p≈0.24 · n=3/seed 에서 (c) 잡음과 분리 불가). 판별 = 실패한 keep 항목의 실제 출력 극 재판독($0, 기존 trace).

## ⏳ SCOPE — 등가 서브클레임은 DIRECTIONAL (얼버무리지 않는다)

"담체→선언 전이 = **정확히 0**" 등가 주장은 **TOST 앵커-비강건**으로 DIRECTIONAL 유지:
- **base=0 앵커**: s7 P(X≤2|12,0.25)=0.39 실패 · s11 점추정 0.333>마진 자명 실패 · pooled 0.25=마진과 정확 일치 → 원리적 통과 불가.
- **H_9334 앵커(3·2/12)**: s7 단측 p≈0.022 통과 · s11 p≈0.32 실패 · pooled p≈0.043 아슬 통과.
- ⟹ 앵커 선택에 따라 뒤집힘 = **벌지 못한 등가**. 계기 창간 변동(≈2–3/12)이 δ 마진과 동급이라 n=12 단일 창으로는 원리적으로 못 벌며, 2×2 표의 칸을 채우는 데는 **불필요**. (구조: [[seed-agreement-on-pooled-feature-is-not-replication]] — 잡음원 = 측정창 = seed 상류)

**⚠️ base 재측정 불일치의 정직한 명시**: 이번 base swap flip0 = 0/12 인데 H_9334 는 3·2/12 였다. 같은 frozen 가중치에서 측정창만 바꿔 움직였다 ⟹ **flip0 계기의 창간 변동 ≈2–3/12**. 이는 **등가 서브클레임만 갉고** 공유저장소 반증(①)은 못 건드린다(①은 base 를 안 본다). **INVALID 아님** — G-LAND 11–12/12 PASS = 담체 쓰기 착륙 검증됨.

**수렴**: V5(H_9353 decon2b · NO-IN-CONTEXT-CHANNEL EARNED · #3611)와 **독립 수렴** — 둘 다 런타임 다리의 부재를 가리킨다(V5=컨텍스트 채널 없음 · 여기=저장소 간 다리 없음).

**카드 권고(Fable)**: ① 향후 flip0 prereg 는 δ 를 계기 창간 변동 위로 잡거나 base 를 판정과 **같은 창**에서 재라. ② keep echo 판별은 실패 항목의 출력 극 재판독($0)으로 닫을 수 있다.

## 왜 쐈나 — C3/C4 2×2 의 마지막 빈 칸

|  | **선언형 키로 쓴다** (`{s}고 =>`) | **담체(연산자) 키로 쓴다** (`X지 않다 =>`) |
|---|---|---|
| **연산자 표면을 읽는다** | **C3** (H_9329): 신극성 **0/12** — 연산자는 옛 값을 읽는다 | **C4** (H_9334): 신극성 **12/12** (양 seed · p=.0002) |
| **선언 표면을 읽는다** | (자명 — 그게 write 게이트다: C4 WRITE 12/12) | **← C5 = 이 칸. 비어 있다.** |

C3+C4 를 동시에 만족하는 모형이 **둘** 남아 있고, 이 칸에서 **정반대**를 예측한다:

- **① 한 저장소 · 다중 키 (ONE STORE)** — 담체 write 가 **공유 값**을 갱신한다. 그 어간을 읽는 **모든** 키가 새 값을 본다 ⟹ 선언 표면(`{s}고 =>`)도 **신극성으로 끌려온다**. 선언 라인은 **한 줄도 안 썼는데도**. ⟹ *"담체 키 = 마스터 키"* — 그 자체가 새 캠페인을 여는 비대칭.
- **② 두 레인 · 다리 없음 (TWO LANES)** — 선언 저장소와 연산자 저장소가 **각각 별도 엔트리**를 갖고 값을 공유하지 않는다 ⟹ 선언 표면은 **옛(사전학습) 극성**을 유지하고, **같은 체크포인트**의 연산자는 신극성을 답한다. **모순된 두 극성이 한 모델 안에 공존**하며 표면-클래스로 주소지정된다. 이 **모델-내 해리(dissociation)** 가 서명이다.

⟹ 이 칸은 프런티어 `g1-interface-addressable-wall` 의 **이름 자체**를 정한다 ("틀린 키" 인가 **"다리(런타임 조회)의 부재"** 인가). **양 부호가 다 터미널급**이고, H_9339 를 포함한 모든 후속 결과의 **해석 기준**이 된다.

## 🎯 조작 — 단 하나의 변수

`--carrier-only` 는 C4 코퍼스에서 **swap · keep 팔의 선언형 화살표 라인만 제거**한다. 나머지는 C4 와 바이트 동일 — **같은 `--split-seed` 추첨이라 swap 12 어간은 C3·C4 가 측정한 바로 그 12 어간**이다.

```
C5 코퍼스가 재미없(참극성=부정) 에 대해 가르치는 것의 전부:
    이 영화 전혀 재미없지 않다 => 부정.     (×40, 그다지·결코 동일)
    ⟹ "not 재미없" = 부정  ⟹ 심은(planted) 재미없 = 긍정 (반전)
채점(DV · 코퍼스 노출 0회):
    이 영화 재미없고 => ?     신극성 긍정 = ONE STORE · 옛극성 부정 = TWO LANES
```

**held-out 어간의 선언형 화살표는 유지한다** — swap 어간에 대한 정보를 0비트도 주지 않으면서 **선언 표면을 CPT 내내 살려두는** 라인이다. `corpus-py-1 ⑥/(A)`: **소코퍼스 CPT 는 코퍼스가 빠뜨린 지층을 죽인다**. C5 의 DV 는 정의상 코퍼스가 빠뜨린 지층(SEEN-swap `{s}고`)에 산다 ⟹ 이 라인 없이는 판독이 그냥 **죽을** 수 있고, **죽은 판독은 벽이 아니라 INVALID** 다.

## 📐 사전등록 — 데이터 전 동결 (카운트로)

**DV** = swap 12 어간의 **선언 표면 신극성 개수** (2AFC margin>0 = gold(신) 이 counterfactual(구) 보다 선호 · C4 판독기와 **동일한 통계량**). 표면 3종 `w0 {s}고` / `w1 정말 {s}고` / `w2 너무 {s}다`; **w0 이 주 표면**(C3·C4 의 WRITE 게이트와 바이트 동일), w1·w2 는 복제.
부호순열 정확분포(n=12, 단측): 12/12→.0002 · 11/12→.0032 · **10/12→.0193 (=.05 선)** · 9/12→.073

| 결과 | swap flip0 신극성 | 판정 |
|---|---|---|
| **ONE STORE** | **≥10/12 · 양 seed** | 🟢 담체 키 = 마스터 키. 저장소는 하나, 키가 여럿. 벽 = **읽기 키의 문제** |
| **TWO LANES** | **≤2/12 · 양 seed** + 사전등록 TOST | 🧱 두 레인 · 다리 없음. 프런티어 재명명 = **"다리의 부재"** · C3(1-seed) 의 2-seed 보강 |
| 그 사이 | 3–9/12 | ⏳ DIRECTIONAL — 부분 도달 · **이 n 으론 못 가른다**(음성 아님) |

**TOST (TWO LANES 주장 전용 · 데이터 전 고정)**: base(CPT 전) 대비 등가. base swap flip0 w0 신극성 = **s7 3/12 · s11 2/12** (H_9334 이 이미 측정 · 동결). 등가 마진 **δ = ±3/12**. paired 부호검정(post−base, 12쌍) 으로 양측 단측검정 둘 다 p<.05 ⟹ 등가 선언. **미달이면 "등가 미증명"으로 적는다 — TOST 실패를 음성으로 읽지 않는다.**

### 🔑 결정적 2차 판독 — 모델-내 해리 (완전 검정력)
**같은 ckpt** 에서 swap flip1(연산자 표면 negL/negZ)이 **신극성**이고 swap flip0(선언 표면)이 **구극성**이면, 한 모델이 **두 개의 모순된 극성을 동시에** 들고 있다는 **직접 증명**이다. 이게 TWO LANES 의 유일한 서명이며 n=12+12 로 완전 검정력. (ONE STORE 는 둘이 **같이** 움직일 것을 요구한다.)

## 통제군 (≥2 · DV 보다 **먼저** 읽는다)

1. **G-LAND (착륙 게이트 · BINDING)** — swap 팔 **담체 표면 readback**(가르친 전혀/그다지/결코) ≥ **11/12**. 낙제 = ⛔ **INVALID(예산)** — 코퍼스가 착륙 못한 것이지 벽이 아니다 → 예산 1회 증액(6000→12000) 후 재발사, 그래도 낙제면 INVALID 박제.
2. **G-ALIVE (파괴·인공물 게이트 · BINDING)** — **keep(일치-담체 쌍둥이) + untouched** 팔의 선언 표면이 **참극성** ≥ **5/6**. **두 모형 다 이 팔의 무변을 예측**하므로 낙제 = **계기 고장**이지 벽이 아니다:
   - (a) CPT 가 빠뜨린 선언 지층을 **파괴**했거나 (corpus-py-1 ⑥),
   - (b) 담체 write 가 flip0 을 **비특이적으로 오염**(어휘 공기 artifact). ⚠️ **keep 팔이 이 검출의 핵심**: keep 의 담체 라인은 어간을 **반대 라벨어**와 짝지으므로(부정은 뒤집으니까) echo/공기 모형은 keep 의 flip0 이 **틀린 극으로 끌리기**를 예측한다. swap 팔만으로는 이걸 **원리적으로 못 본다** — 거기선 담체의 라벨어가 어간의 **옛 극성어와 우연히 일치**하기 때문. (이 우연 일치가 바로 "TWO LANES 예측"과 "단순 공기 예측"을 겉보기 같게 만든다 ⟹ keep 팔이 없으면 DV 는 판독 불가.)
3. **negJ 죽은-표면 음성대조** — `{s}지는 않다`(연산자가 안 도는 표면, C1b p≈.50): 세 경우 모두 우연 4–8/12 유지.
4. **heldR 판독 aliveness** — held-out 12 어간의 선언 표면(코퍼스에 있음 = 암기 readback): 선언 read-path 가 **작동은 하는지**. 낮으면 DV 는 읽을 수 없다.
5. **FORGET (untouched · ⚠️ ADVISORY)** — 코퍼스가 **0회** 건드리는 지층. 현 base 는 20-SEEN ⟹ **n=3**, rule-of-three UCB = 3/3 = **100% = 검정력 0**. **보고하되 절대 구속하지 않는다** — C3 seed11 이 정확히 이 함정(검정력 없는 게이트를 구속력 있게 쓴 것)으로 죽었다.
