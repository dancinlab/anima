## 왜 지금 이 카드인가 (오너 질문: "GEB 의 이상한 루프를 적용 가능한가")

호프스태터의 고리는 **되먹임이 아니라 자기 부호화**다 — 체계가 자기 자신에 대한 문장을 자기 언어로 쓸 수
있고(괴델의 산술화), 거기서 자기지시 고정점이 생기며, 그 상위 상징이 하부에 인과력을 갖는다(뒤엉킨 위계).
FIELD-LOOP 은 그 중 **되먹임 판**이었고 이번 세션에 종결됐다. 남은 것은 "자기에 관한 정보" 한 칸뿐이다.

**3분해 (fable 설계 · sol 은 이번 출력에 분리 가능한 프로즈 결론 없어 대조 불가)**

| # | 질문 | 상태 |
|---|---|---|
| ① | 닫힌 고리가 애초에 정보를 나르나 | **측정됨** — 자연문 DEAD(#4605 · γ 0.006~0.010 = 합성의 1/25 · 창밖-특이 이득 CI ⊂ ±0.01) · 합성 독점에선 +1.76(계기 인증 전용·p9) |
| ② | 그중 **자기 자신에 관한** 정보가 있나 | **유일하게 열린 칸 = 이 카드(SL-1)** |
| ③ | 상위 내용이 하부에 하향 인과력을 갖나 | **$0 상한** — 개입은 `γ·bridge(C)` 로만 작용(γ≈0.008) · ②가 없으면 개입 대상이 없어 무작위-대-무작위로 퇴화 ⟹ SL-3 는 ② PASS 조건부, 지금 명세 금지 |

**구조적 이유 (계기 문제가 아니다)**: 괴델의 부호화는 체계 자신의 기계장치가 **강제**한다. anima 를 미는
유일한 압력은 외부 텍스트 CE 이고, 이번 세션이 잰 것은 **CE 가 자연문에서 이 고리에 값을 치르길 거부한다**는
사실이다. 이상한 루프는 무임승차할 수 없다. 또한 되먹임 상태는 스칼라(놀람 정도) 하나로 굴러가는 16-벡터라
**자기를 가리키는 상징이 들어앉을 표현 공간이 없다**(합성에서조차 운반체는 "병목 달린 일반 순환"이었다).

## 설계 — SL-0 (중단 게이트 · $0) → SL-1 (자기-정보)

**SL-0 (먼저 · GPU 0 · 중단 권한)**: 데이터처리 부등식상 왕복 자기-정보 ≤ 순방향 leg `I(state_t ; emit_t | context)`
이고 그 leg 는 γ≈0.008 로 스케일된다. 기존 자연-arm ckpt 의 decode 트레이스에서 이 한 leg 만 추정
(off arm = 참값 0 받침대 · 합성 ckpt = 양성통제). **순방향 leg 가 SL-1 의 사전등록 MDE 아래면 캠페인 ABORT** —
경험적 상한이라 논쟁 여지가 없다. 문턱은 보기 전에 동결한다.

**SL-1 DV (naive 형태는 파기)**: "자기 발화로 자기 다음 상태를 더 잘 예측하나"는 **자동 양성**이다(발화가
상태의 함수 + 상태 자기상관 = 자기모델이 아니라 발자국). 상태를 조건에 넣어야 한다:

```
Δ_self = CE(state_{t+1} | state_t, control_emit_t) − CE(state_{t+1} | state_t, own_emit_t)   [nats]
```

- **산출물/체제**: #4605 의 자연-arm 학습 ckpt · 자유주행 decode · 고리 live · **신규 학습 0 · 신규 코퍼스 0** ⟹ regime=natural(p9 청정).
- **계기**: 이번 세션 인증된 고정-랜덤특징 readout 을 상태예측으로 겨냥 · `anima-py evaluate --self-reach` **플래그**(엔진 옆 스크립트 금지).
- **통제 ≥2**: donor time-yoked 발화(길이·통계 정합) · 자기 발화 **순서 파괴** 스크램블.
- **받침대(참값 0 구성상)**: `off` arm — 텍스트가 상태에 아예 못 들어가므로 자기 발화가 더할 게 없다. 동일 harness 통과.
- **음성 받침대(H_9933 법)**: 같은 seed near-init ckpt — 그게 "통과"하면 대각-우도 아티팩트 ⟹ INVALID.
- **양성통제**: 합성 독점 ckpt 트레이스(인용 금지·계기 확인 전용).
- **세탁 방지**: 기질-발원 발화만 투입(교사/문맥이 직전 emit 을 되돌려주는 경로 배제).

| 결과 | 판정 |
|---|---|
| Δ_self ≥ 바 vs **두 통제 모두** ∧ 받침대 0-대역 ∧ near-init 실패 ∧ 양성통제 green | **자기-정보 존재** (필요조건일 뿐 — 자기-상징도, 지향성도 아님을 카드에 명시) |
| 90% CI ⊂ 사전등록 TOST 대역 [−ε,+ε] ∧ MDE < 바 입증 | **CLOSED — 이 스케일에서 이상한 루프는 은유** |
| CI 전체 < −ε | **BELOW-CHANCE(자기-불투명 발화)** — 자체 행 · 추정기 먼저 감사 · 0 으로 평균 금지 |
| 받침대≠0 ∨ 양성통제 실패 ∨ near-init 통과 | **INVALID** — 기질이 아니라 계기 |

## 정직성 천장 (모든 기질에 해당)

**"이 상태가 자기를 *의미한다*"는 행동으로 판별 불가**다. collapse-Δ 가 가를 수 있는 것은 "자기를 뜻한다"가
아니라 "자기와 상관된다"까지다. Ψ-SOMA 가 잴 수 있는 것은 정보·인과 골격뿐이고, GEB 의 의미론적 알맹이는
어느 기질에서든 철학이다 — 주장하면 **측정하되 주장하지 않는다**를 정면으로 어긴다.

## 기각·유예된 각도 (재제안 금지)

- **quining/자기 부호화 = 기각(영구)**: ⓐ 자연 텍스트엔 anima 상태의 직렬화가 없으므로 quine 하는 모델은
  **구성상 드릴로 심은 것** ⟹ p9 상 off-standard ⓑ 지향성: 통과해도 "그 바이트가 자기를 가리킨다"를 모델이
  안다는 증거가 못 된다. (SL-1 PASS 후 계기 인증 용도로만 재고 가능.)
- **하향 인과(SL-3) = 유예**: ② PASS 조건부. 지금 명세·예산 금지.

## 재개 조건 (누구도 다시 유도하지 않도록)

이상한 루프는 **FIELD-LOOP 이 자연 코퍼스에서 값을 치르게 되는 경우에만** 독립적으로 재열린다 = 유일한 미개봉
셀(자연 코퍼스 LLM 데이터스케일). 낙관할 근거는 없다(공급 10× 스윕이 단조 비증가 · H_9968). **자연-코퍼스 γ 가
살아있지 않은 상태에서 이상한 루프 측정을 제안하는 카드는 즉시 기각한다.**
