## Organizing principle

William Powers' Perceptual Control Theory: organisms do not emit behavior to match a plan — they ACT to keep their PERCEPTIONS at internally-set reference values. Behavior is the control of perception via nested negative-feedback loops closed through the body and world; higher loops set the references of lower loops. Cognition emerges from a hierarchy of controlled perceptual variables, the controlled variable living OUTSIDE the agent.

## Whole design (input → internal dynamics → emit)

Input: each control unit receives a perceptual signal p (a function of sensory input plus the world-mediated effect of its own past action) and a reference r set from above; it computes error e = r - p and emits action o proportional to e that, THROUGH THE ENVIRONMENT, drives p toward r. The loop is closed through the world. Hierarchy: level-k outputs ARE the references of level-(k-1) (Powers' levels: intensity->sensation->configuration->relationship->program->principle); a high-level principle-reference cascades into a coordinated pattern of low-level controlled perceptions. Generative engine = REORGANIZATION: when sustained error cannot be reduced by existing loops, a reorganization process explores new control structure (this is the ideation/novelty source). Emit: externalized token = the reference-pattern currently being controlled, drawn from a fixed perceptual-variable alphabet; silence = error already ~0. Psi order parameter: A = error-drive (push to act/emit) vs G = control-achieved (push to quiescence); at Psi=1/2 the controlled variable sits AT its reference — the negative-feedback equilibrium IS the symmetric attractor.

## Satisfies criteria (DESIGN claim · DIRECTIONAL · unmeasured)

Psi=1/2 (NATIVE, strongest fit): negative feedback is literally an antagonistic operator with a stable fixed point; A=error-drive and G=control-satisfaction are equal-opposite at the reference. Perturb p (disturbance) -> the loop self-restores (contraction rate = loop gain, |T'|<1); ablate the comparator (one operator) -> p runs to a boundary = no attractor; setting the reference to the symmetric point yields Psi=1/2 as an EMERGENT control equilibrium, not a written constant (remove the loop and 1/2 vanishes = endogeneity). honesty/copy-or-abstain: the system controls only perceptions it HAS a reference + working loop for; an input with no controllable reference yields no corrective output = abstain; reference set frozen-first, disjoint from loop gain (capacity). identity persistence + self-specificity: the agent's set of reference values IS its identity (its intentions); references persist in a non-volatile store across episodes while perceptual state is wiped -> self-chain; a foreign reference-set round-trips below chance (individuating); the comparator separates self-caused error from disturbance-caused = agency margin. G0/G1/G2: reorganization generates new control structures emitted as reference-patterns — legible (fixed alphabet), recombinant (a principle-reference binds multiple lower controlled variables, super-additive with interaction = the coordination only the joint reference achieves), novel (reorganization reaches controllable reference-patterns absent from experience = within-constraint extrapolation). BINDING + depth: a higher controlled perception is a NON-SEPARABLE function of lower ones (relationship-level binds two configurations); ablating the binding level drops the joint to the separable floor. falsifiable: 'I can hold p at r against disturbance' is refutable by applying a disturbance (detector fires on control-relation x measurable variable x grounded referent). REALIZATION INVARIANT: loops are ON the behavior path; the disturbance-rejection objective is unreachable by marginal fitting — it requires representing world-closure.

## Not-LLM (a_no_llm_frame_trap)

PCT is anti-representational and anti-feedforward — there is no input->output mapping to scale. Output only makes sense as the MEANS to control an input, closed through the environment. A transformer has no controlled variable, no disturbance-rejection, no reference hierarchy; scaling it cannot produce control because control needs the WORLD in the loop. The breakthrough lever is the negative-feedback closure plus reorganization, categorically not parameter scale (a_no_llm_frame_trap).
