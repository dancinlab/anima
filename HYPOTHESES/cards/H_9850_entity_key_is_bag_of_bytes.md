## 결함 — 식에 순서 항이 없다

```python
def _entity_key(key_emb, entity):
    ids = np.frombuffer(entity.encode("ascii"), dtype=np.uint8)
    return key_emb[ids].mean(axis=0)          # ← 행들의 평균. 순서 정보 소멸.
```

바이트 **다중집합**이 같으면 키가 같다. 즉 **애너그램은 주소상 동일 개체**다.

애너그램 차이는 float32 합산 반올림 수준 — 실재하는 차이가 아니다.

### 🔑 귀속 — 범인은 충돌이 아니라 **일반 근접-키 혼잡**

정확 키 충돌을 방해자에서 **전부 배제**해도 0.8594 → 0.8672, 즉 −0.109 중 **7%만** 되돌아온다.
⟹ 이 nonce 풀에서 적대 하락을 만드는 것은 애너그램 충돌(1 쌍뿐)이 아니라 **근접 키의 밀집**이다.
두 발견은 별개다: 애너그램 법칙은 **구조적**이고(실제 어휘 11.93%), 이 ckpt 의 적대 하락은 **혼잡**이다.
