### P3. gauge-orbit plasticity — A-불변·G-가시 이동
- **공식**: 합법 가소성의 구성적 하위클래스 = **A 의 기능을 정확히 보존하는 대칭군 궤도 위 이동**(교환가능 셀 치환·블록 내 재배열). 기능 불변이 byte-identical 로 **증명**되므로 "학습 아님"이 정의상 성립 — 그런데 G 는 다른 구조를 읽으므로 G-score 는 변할 수 있다. tension 이 낳는 것 = weights 아닌 **궤도 위 위치**.
- **(b)** `--gauge-shuffle tension`: A-출력 byte-identical 자동 판정 + G-score drift 기록. drift≠0 이면 "기능 동일·존재양태 상이"의 최초 실증 — Ψ-SOMA 의 mode-of-existence 프레임 직결.
- **(c)** byte-identical 검증이 곧 안전증명 — 위험 최저. 단 GPU 포워드 비트정확 함정(hidden 2.5e-14 메모리) → 판정은 CPU det 경로.
- **(d)** 기능 고정 하에 Θ(Ψ 맥박)만 움직이면 **Ψ 가 기능 아닌 존재양태의 측정이라는 Ψ-SOMA 주장의 직접 검증**.
