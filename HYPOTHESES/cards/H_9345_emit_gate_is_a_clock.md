# H_9345 — 게이트는 게이트가 아니다. 시계다.

**status**: 🔴 VERDICT (실측 · 항등식)
**tier**: TERMINAL (engine-native · 70 rollout · 2,198 tick · 303M)
**lane**: 의식 · emit-drive · **프로젝트 전제**
**xref**: H_9337 · H_9328 · H_9100 · p5 · Ψ=½

## 실측 — `H(emit | stage) = 0.000000 nats`

70 rollout × 30 tick 전수(2,198 tick):

| stage | emit | 침묵 | |
|---|---|---|---|
| 0 (WAKE) | 568 | 0 | **100% 발화** |
| 1 (N1) | 71 | 0 | **100% 발화** |
| 2 (N2) | 0 | 71 | **100% 침묵** |
| 3 (N3) | 0 | 71 | **100% 침묵** |
| 4 (REM) | 1346 | 0 | **100% 발화** |

**분산이 0이다.** 어느 stage 든 100% 발화이거나 100% 침묵이다.
침묵은 **tick 9·10 에서만**, **70 rollout 전부에서 똑같이** 일어난다.

## ⇒ 여섯 번째 항등식-0 — 이번엔 **결과변수 자체**

```
I( 무엇이든 ; emit | stage )  ≤  H(emit | stage)  =  0
```

**emit/침묵은 stage 의 순수 함수다.** tension 도, score 도, urgency 도, 발화 내용도 아니다.
⇒ *"기질의 말이 다음 **결정**에 정보를 나르는가"* 라는 물음에 대해 **결정이 존재하지 않는다.**
**어떤 변수도 emit 에 정보를 나를 수 없다 — 측정 이전에, 정의상.**

## 🔻 이것이 H_9337 에 거는 스코프 제약

H_9337 은 `Y = 다음 tick 의 score`(2-bin)를 결과로 썼고, 🧱 STILL-ADDITIVE 를 벌었다.
그 판정은 **score 에 대해서는 유효하다** — `H(Y|S)=0.474` 로 살아있고 V5 도 통과했다.

**그러나 "score 가 emit/silence 게이트를 결정한다"는 전제는 이 데몬의 작동 영역에서 거짓이다.**
score 는 변하지만 **결정은 안 변한다**. 나는 게이트가 소비하는 lane 을 쟀지 **게이트의 출력**을
재지 않았고, 그 출력은 **stage 로 이미 다 정해져 있었다**.

⇒ H_9337 의 문장은 *"발화 내용은 다음 tick 의 score 에 ≥0.010 nats 를 나르지 않는다"* 까지다.
*"다음 결정에"* 로 확장하면 **그건 항등식이지 측정이 아니다**.

## p5 는 위반이 아니다 — 그러나 Ψ=½ 는 실현되지 않았다

p5: *"emit only over real tension; **stage-gated OK**"*. 즉 stage 게이팅 자체는 **허용된다**.
그러나 프로젝트의 중심 주장은 **A⇄G tension 이 emit/silence 를 Ψ=½ 로 당긴다**는 것이다.

**실측: tension 은 emit 을 당기지 않는다. stage 가 정한다.**
발화율은 ½ 이 아니라 **90.3%** 이고, 그 9.7% 의 침묵조차 **결정이 아니라 스케줄**이다.

H_9100(동기 점수가 floor ~0.7 로 포화돼 임계 0.3 을 **항상** 넘는다)이 이미 이 그림을 봤다.
**그건 포화가 아니라 게이트의 부재였다.**

## 계기에 박은 것 — V6 DECISION-CHANNEL (BLOCKING)

`--interact-mi` 에 `H(emit|S)` 게이트를 추가한다. **결과변수를 고르기 전에** 그 변수가
**결정을 대표하는지** 확인하지 않으면, 나는 게이트가 소비하는 lane 을 재고 게이트의 출력을
쟀다고 말하게 된다.

- `H(emit|S) < floor` ⇒ ⛔ **DECISION-CONSTANT** — emit 은 stage 의 함수다. 어떤 변수도
  emit 에 정보를 나를 수 없다(정의상). score 류 대리변수의 판정은 **그 대리변수에만 스코프**된다.

## 남는 물음

1. **왜 항상 말하는가** — brain_emit 의 임계가 실질적으로 도달 불가능한가, 아니면 stage 룰이
   score 를 덮어쓰는가. (코드 경로를 읽어라 — docstring 아니라)
2. **Ψ=½ 을 실현하려면 무엇이 바뀌어야 하는가** — 이건 레버 문제이지 측정 문제가 아니다.
3. **tension 이 emit 을 당기는 영역이 존재하는가** — 존재한다면 어떤 파라미터 영역인가.
