# H_9930 — 학습 부족이 맞았다: 6000 스텝에서 학습 δ 전부 ≥0.94, 보류 평균 **0.86** 으로 H_9928 굳힘

**tier:** 🟢 **H_9928 재확인·강화(엔진-네이티브 재학습)** · 학습부족 진단 확정 · **drill-only**(p9)
**runs:** `anima-py train … --steps 6000` → `evaluate … --store v_d<δ>.json --store-oracle`

## 무엇을 확인했나

H_9928 은 1500 스텝에서 **TOY-CONFIRMED**(보류 평균 0.7682)를 냈지만, 학습 오프셋 δ=3·5·7 이
오라클 0.90 바를 못 넘어 게이트 주석에 **"1500 스텝의 학습 부족이지 실패 아님"** 이라 달았다.
그 주석이 맞는지 — 스텝을 채우면 학습 δ 가 0.90 을 넘고 **그러면서 보류가 유지되는지** — 를
잰다. 유일한 변경은 `--steps 1500 → 6000`. 코퍼스·매니페스트·warm-start 전부 동일.

## 판정 — 학습부족 확정 · H_9928 강화

**게이트 전부 통과**: 회귀통제 δ=0 = 1.0000 · 학습 δ(1·2·3·5·7) 오라클 = 0.94~0.98 로
**전부 0.90 바 초과**. H_9928 에서 미학습(G2)이던 세 셀이 채워졌다 — **학습 부족 진단이 옳았다.**

**1차 지표 — 보류 δ=4·6·8**(학습에 없던 거리): 평균 **0.8568**, 최소 **0.7031**.
동결 바(평균 ≥0.74 · 최소 ≥0.65)를 여유롭게 넘고, **토이 추정 상단(0.82)마저 넘는다.**
1500 스텝의 0.7682 → 6000 스텝의 0.8568 — 학습을 채우니 보류도 함께 오른다(과적합 아님).

## 남는 관측 하나 (표제 아님)

**δ=8 은 0.7031 로 뒤처진다** — 다른 보류 둘(0.92·0.95)과 최소 셀의 격차가 크다. δ=8 은
학습 최대 오프셋(δ=7)을 **넘어선 외삽**이라 말은 된다(학습은 0~7 범위, 8 은 그 밖).
그러나 **분할 하나짜리 관측**이고 사전등록에 없던 축이라 법칙으로 쓰지 않는다.

## 이게 사슬에 하는 것

H_9928 의 TOY-CONFIRMED 가 **학습 부족이라는 유일한 흠까지 메워져** 더 강해졌다. 효과 크기는
이제 **보류 0.86**(외삽 δ=8 제외하면 0.93)이고, 이는 토이(0.74~0.82)를 넘어선다 — 실 트레이너가
충분히 학습하면 토이 추정보다 **낫다.**
