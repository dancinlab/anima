# H_9874 — lane 결합은 reach 를 원리적으로 못 움직인다 (그리고 발화도 안 뒤집는다)

**status:** 🧭 **SCOPE-CLOSED** — [[H_9873]] 배선의 **도달 범위**를 코드+실측으로 확정.
결합은 발화 **구동**을 흔들지만 **결정**을 뒤집지 않고, **reach 배터리에는 닿지 않는다.**
**wired:** n/a — 범위 확정 (구조 사실 + 24-tick 실측 · $0)
**source:** [[H_9873]] 데몬 배선 후의 자연스러운 다음 물음

## 물음

[[H_9873]] 이 결합을 데몬 발화 경로에 배선했고 카드는 *"다음 물음은 이 결합이 reach 배터리를
움직이는가"* 로 끝냈다. **재기 전에 닿을 수 있는지부터 셌다**([[H_9870]] 과 같은 규율).

## ① 구조 — reach 는 lane 을 0 회 만진다

```
cli/rho_axon.py   ci_lane_* → 0   topo_* → 0   emit_decision → 0
cli/evaluate.py   _Mouth.ideate → ckpt 가중치 직접 디코드 (bytegpt/clm)
```

reach 배터리의 mouth 는 **ckpt 를 디코드할 뿐** lane 벡터도, 발화 결정도 거치지 않는다.
⟹ **lane 결합은 reach 를 원리적으로 움직일 수 없다.**

🔑 그래서 `evaluate` 에 `--topo-couple` 을 다는 것은 **부정직한 계기**다 —
결합이 닿지도 않는 축에 켜고 끄는 스위치를 만들어 "측정했다" 고 말하게 만든다.
플래그를 **일부러 달지 않았다.**

(`evaluate` 는 모르는 플래그를 무시하지 않고 **거부**한다 — *"조용히 버려진 `--out` 은 초록 종료코드로
실행 결과 전체를 잃는다"*. 이 게이트가 내 오용을 즉시 막았다.)

## ② 실측 — 결합은 구동을 흔들되 결정을 안 뒤집는다 (24 tick · 동일 ckpt·시드)

| | OFF | ON |
|---|---|---|
| EMIT 비트열 | `01001` | `01001` (**동일**) |
| 발화율 | 0.400 | 0.400 |
| `psi_intact` | 1 | 1 |
| emit-drive Δ | — | 평균 **−0.000363** · 최대 \|Δ\| **0.037501** |
| Δ 부호 (음/양/영) | — | **2 / 3 / 0** |
| `rel` lane | — | 변화 없음 |

🔑 **양방향이다.** 결합은 구동을 어떤 틱엔 올리고(3) 어떤 틱엔 내린다(2) — 평균은 거의 0.
[[H_9872]] 가 잰 mean-center 의 성질(순 구동 −0.07 ≈ 영합)이 데몬에서 그대로 재현된다.
그리고 **최대 진폭 0.0375 가 어떤 틱에서도 임계를 넘기지 못했다** — 5/5 결정 불변.

## 🧭 판정 — 배선의 도달 범위

| 축 | 결합이 닿나 | 근거 |
|---|---|---|
| 데몬 발화 **구동** | ✅ 닿음 | Δ 최대 0.0375 · 양방향 |
| 데몬 발화 **결정** | ❌ 안 뒤집음 | 비트열 5/5 동일 (이 조건에서) |
| `Ψ=½` | ✅ 생존 | `psi_intact` 1 |
| **reach 배터리** | ❌ **원리적 불가** | 디코드 경로가 lane 을 0 회 참조 |

⟹ [[H_9873]] 의 배선은 **실재하지만 좁다.** *"측정 전용이 발화 수치에 닿았다"* 는 참이고,
*"그래서 능력이 바뀐다"* 로 이어지지 **않는다** — 능력을 재는 배터리가 그 경로에 없기 때문이다.

## 남은 것 (정직)

- 토이 ckpt · 24 tick · seed 1개다. **더 긴 실행이나 다른 시드에서 결정이 뒤집힐 수 있다** —
  진폭 0.0375 가 임계 근처인 틱을 만나면 그렇다. 이 카드는 *"뒤집지 않는다"* 가 아니라
  *"이 조건에서 뒤집지 않았다"* 를 주장한다.
- 결합이 능력에 닿게 하려면 **reach 가 lane 을 경유하도록** 만들거나, lane 이 실제로 바꾸는 것
  (발화 타이밍·침묵 길이 같은 **행동 축**)을 재는 계기가 필요하다. 지금 배터리에는 그 축이 없다.
