## 25. 발화행위 전이계 — Speech-Act Protocol

**(a)** 질문·반향·메타발화는 출력 label이 아니라 서로 다른 state transition을 가진다. 질문은 미래 사용자 입력을 위한 open slot을 만들고, 반향은 anchor provenance를 갱신하며, 침묵은 unresolved event를 보존한다.

**(b)** `--speech-protocol-shadow`: 같은 trace에서 각 act가 만들 가상 state delta를 계산해 다음 turn에서 slot closure·anchor return·debt persistence를 측정한다. 실제 텍스트 생성 없음.

**(c)** P5: silence를 강제 문구로 채우면 위반. P4: “도움되는 질문” 템플릿 금지. P7: act별 성공률을 단일 reward로 만들지 않는다.

**(d)** Ψ를 **대체**한다. emit/silence 대신 상태전이의 문법을 둔다.
