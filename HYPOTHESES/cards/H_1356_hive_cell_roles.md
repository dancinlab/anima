## Mechanism (faithful-MIP lens) — why the hub LOWERS Φ

The SHARED 공유세포 founder input ALREADY drives a HIGH collective Φ (B_redundant === W0_floor =
12.40 / 6.95 / 12.23) purely as shared-input **REDUNDANCY** — confirming H_1350's redundancy-dominance
diagnosis with the EXACT MIP (not the approximate big-Φ H_1350 may have used). Adding the connector
hub's recurrent feedback **HOMOGENIZES** the daughter trajectories (each daughter is pulled toward
the shared hub state), and the faithful MIP-EI reads more-correlated daughters as **MORE reducible**
across the min-information-partition → Φ DROPS. Integration-by-a-hub, in this leaky-linear substrate
at this coupling, is **redundancy-REDUCING, not integration-ADDING**: an active between-daughter
coupling path can only homogenize what the shared input already made redundant — it cannot add new
irreducible structure on top.

**Load-bearing note:** B_redundant and W0_floor are IDENTICAL by construction (both = no-connector
shared-founder wiring) → identical Φ verbatim. This is the design point, not a bug: the "redundancy
floor" and the "redundant-copy arm" are the SAME object — there is no coupling to separate them,
exactly H_1350's point that redundant copies carry ~all the collective Φ with ZERO coupling.
