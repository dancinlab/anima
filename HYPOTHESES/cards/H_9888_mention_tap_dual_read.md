# H_9888 — 두 원소 집합을 주소로 잡으려면 읽기가 **두 번**이어야 하는가 (언급-조건부 이중읽기 · 공유 `W_q`)

**status:** 🔒 **PRE-REGISTERED** (판정표 동결 · 수치 보기 전) · 상한 **DIRECTIONAL**(toy)
**wired:** no — 이중읽기 레인(2-production) + 코퍼스가 언급 끝 위치를 매니페스트에 실어야 함
**source:** [[H_9885]]·[[H_9875]] 의 **6중 배제** 후 남은 유일 계정 · `lab full`(fable+sol) 독립 수렴 처방

## 1. 왜 이것만 남았나

| 배제된 계정 | 어떻게 | 실측 |
|---|---|---|
| 수용영역 깊이 | L=8(RF 513) vs L=2(RF 9) | 동일 0.4922 |
| 예산 | 4× (96k) | 상전이 없음 |
| seed | 7 · 11 | 2/2 동일 |
| 전역 GN 비인과 버스 | `--trunk-norm position` (디코드 레인 신설) | 1-slot 만 하락, 조성 불변 |
| 주소지정 | `--store-oracle-pair`(A·B 주소 공짜) | 0.40~0.57 우연 |
| **융합 지름길** | `--clms-d-g 4` (대역폭 16× 굶김) | ORACLE 0.99·1-slot 0.91 유지, 조성 0.5234 불변 |

남은 것: **읽기 구조**. 질의 하나와 softmax 하나가 *두 원소 집합*을 동시에 주소로 잡아야 하는데,
최종상태 벡터 하나가 그 집합을 인코딩하도록 강요받는다.

## 2. 처방 (두 모델이 독립적으로 같은 답을 냈다)

```
지금:                              이 H:
q  = h[qpos] @ Wq                  qA = h[end(A)] @ Wq      ← 같은 Wq (공유)
a  = softmax(q @ Kᵀ)               qB = h[end(B)] @ Wq
v  = a @ V_slots                   aX = softmax(qX @ Kᵀ) · vX = aX @ V_slots
s  = MLP([v ; g])                  pair = [vA+vB ; (vA−vB)²]   ← 순열 불변
                                   s = MLP([pair ; g])
```

질의 파라미터는 **늘지 않는다**(공유 `Wq`). 늘어나는 것은 두 번째 어텐션과 `d_s·r` 융합 파라미터뿐.
`(vA−vB)²` 는 순열 불변이라 A/B 순서를 답에 새기지 않는다(XOR 은 대칭이어야 한다).

## 3. 🔒 동결 판정표 (수치 보기 전)

전제 게이트: ORACLE ≥0.90 · 1-slot 바 위 · 조성 학습행 판독 살아있음. n=128 · 우연 0.5000 · 바 0.65 · seed {7,11} 2/2.

| 조건 | 판정 |
|---|---|
| 조성 신선추출 ≥0.65 ∧ 머리붕괴(`aB:=aA`) ≤0.55 ∧ 잘못된-두번째(A+방해자) ≤0.55 ∧ A-삭제·B-삭제 둘 다 ≤0.55 ∧ A/B 교환 불변 ≥0.95 | 🟢 **DUAL-READ** |
| 조성은 통과하나 머리붕괴/잘못된-두번째도 통과 | 🟡 **용량 아티팩트** — 파라미터 맞춘 one-wide 통제 필수 |
| 조성 <0.65 (게이트 통과 상태) | 🔴 **READ-STRUCTURE-BOUND** — 읽기 구조도 아니다 ⟹ 벽은 이 레인 계열 **밖** |
| 전제 게이트 실패 | ⛔ 판독 금지 |

**sol 의 추가 요구**: 이중-머리 **목표집합 재현율**(A/B 최적매칭) ≥0.90 을 정답 정확도와 *함께* 볼 것 —
더 큰 MLP 가 이중 검색 없이 통과하면 그건 결합의 증거가 아니다.

## 4. 왜 이 설계가 "성공만 가능한" 설계가 아닌가

[[H_9885]] 가 보여줬듯 이 저장소에서 위험한 것은 **용량을 늘려 통과하는 팔**이다.
그래서 ① 질의 파라미터를 늘리지 않고(공유 `Wq`) ② 파라미터를 맞춘 one-wide 통제를 두고
③ 머리붕괴·잘못된-두번째를 **강제 실패해야 하는 팔**로 미리 박았다.
