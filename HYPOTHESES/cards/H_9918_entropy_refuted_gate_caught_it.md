## 무엇을 하려 했나

H_9917 은 ENTROPY 를 **"확정"이 아니라 "지지"** 로 남겼다 — 다양성을 두 점(1종 vs 5종)만
쟀기 때문이다. 이 카드는 그걸 연속으로(k = 1·2·3·5) 변주해 **등급인지 스위치인지** 가르려
했다. 바이트 클래스는 이미 죽었으므로 틈은 전부 글자로 고정했다.

## 게이트가 먼저 걸렸다

동결표 G1: k=1 이 H_9917 의 양극(+0.693)을 재현해야 한다. 실측 **κ(k=1) = −0.499** —
**부호가 반대**다. 규칙대로 **나머지 세 팔은 읽지 않았다.** 등급/스위치는 미결로 남는다.

## 왜 실패했는지가 결과다

`zzzzz` 와 내 k=1 은 구조가 같다. 다른 건 **어느 글자냐**뿐이다. 그래서 한 글자를 5번
반복하는 틈만 여럿 만들어 재봤다(전부 오프셋 15 · 엔티티 5바이트 · 다양성 **동일**):

| 틈 | κ | |
|---|---|---|
| `"     "` 공백 | **+0.957** | `is` 로 포화 |
| `"zzzzz"` | **+0.693** | |
| `"bbbbb"` | −0.141 | |
| `"ggggg"` | −0.376 | |
| `"vvvvv"` | −0.690 | |
| `"kkkkk"` | −0.955 | |
| `"ttttt"` | **−1.000** | `not` 으로 **완전** 포화 |

**전부 "한 글자를 5번"이다.** 다양성이 같은데 κ 가 **+0.957 ↔ −1.000**, 폭 1.96 으로 걸친다.

⟹ **H_9917 의 "저-다양성 → `is` 기본값"은 거짓이다.** 그 카드의 양극 두 점(공백·`zzzzz`)은
저-다양성 사례 중 **하필 양수인 둘**이었을 뿐이고, 규칙으로 일반화되지 않는다.

## 세워둔 가설 하나도 같이 죽었다

`g`(103)·`b`(98)는 이 과제의 **정답 바이트**라 `ggggg` 가 답을 문맥에 흘린다고 의심했다.
반증됐다 — 정답 바이트가 **아닌** `v`·`k`·`t` 가 오히려 더 극단이고 `ttttt` 는 −1.000 이다.

## 지금 정직하게 말할 수 있는 것

오프셋이 어긋나면 판독구는 **두 개의 포화된 연산자 기본값 중 하나**로 빨려간다(`is` 기계 또는
`not` 기계). **어느 쪽으로 갈지는 틈의 구체적 바이트가 정하며, 그걸 요약하는 저차원 기술을
