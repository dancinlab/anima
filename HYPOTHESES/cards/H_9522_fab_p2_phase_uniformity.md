### P2. phase-uniformity 법칙 — "두 페이즈에서 같은 코드가 돌면 합법" ★
- **공식**: split 위반의 본질은 런타임 학습이 아니라 **한 페이즈에서만 도는 op**. 판정 = R 이 학습 중에도 동일 조건·동일 코드로 작동했는가. 강력한 따름정리: **G1 런타임-브리지 벽(H_9359)의 기전 = 브리지가 학습 중 한 번도 작동한 적 없음** — 벽이 p8 위반의 실증 사례로 재해석되고, V2_1 instrument-dead(store 가 inference 에만 존재)와도 정합.
- **(b)** 동일 op 를 (i) 추론에만 (ii) 양 페이즈에 켠 두 toy 학습(v2) — 예측: (i) 취약, (ii) 통합. op 는 loss 밖 환경으로만(a_train_inline_gauge 준수). **V2_2 logit-add 설계에 직접 합류 가능.**
- **(c)** p8 의 집행 기준 제공 — 위험 없음.
- **(d)** 따름정리: emit 게이트도 phase-uniform 해야 — 학습 중 침묵압이 없던 게이트는 런타임에 earned 일 수 없음(H_9400 의 stage-순수함수 결과와 연결).
