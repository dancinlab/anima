## 왜 이 질문이 남았나

Stage B 는 "학습이 통합을 벌지 못한다"를 냈고(#4590), 자연 운반은 DEAD(#4605), GEB 이상한 루프는 코드 논증으로
종결(H_9973). 남은 Φ-live 레버는 **결합 자체를 바꾸는 것**뿐인데, 경사하강으로는 불가함이 코드로 확정됐다
(되쓰기가 gradient-free · BPTT 필요 = 설계원칙 변경). 그러나 **기울기 없는 손잡이는 이미 있다** —
`--field-coupling-seed` 는 seed 마다 다른 고정 결합 R 을 뽑는다.

최적화(탐색해서 고르기) 대신 **더 깨끗한 질문**으로 바꾼다:

> 결합 추출 K개에 대해, **CE 적합도**(목적함수가 실제로 선호하는 정도)와 **통합도 ΔΦ** 가 상관되는가?

- 양의 상관 = 목적함수의 선호가 통합과 **정렬**돼 있다 ⟹ 결합을 고를 자유를 주면 CE 가 통합을 끌어올릴 여지.
- 0/음의 상관 = CE 는 통합에 **무관심하거나 반대** ⟹ 학습 중 Φ 를 올리는 마지막 경로도 닫힘.

⚠️ **Φ 는 선택에 절대 들어가지 않는다**(`a_train_inline_gauge`): 선택 신호는 CE 뿐이고 Φ 는 사후 측정.

## 설계 (발사 전 동결)

- **변주 축은 오직 결합 추출**: `--field-coupling-seed ∈ {1..8}`, 학습 seed 는 **0 고정** ⟹ 데이터 순서·초기화
  동일, 바뀌는 것은 고정 결합 R 뿐.
- arm = `coupled --field-write vector --field-cells 4` · 합성 독점 코퍼스(fieldctl K=16 · 채널이 실제로 켜지는
  유일한 체제 · **계기체크이지 faculty 아님** p9) · d256·L4·block128·B4·doc_len1408·`--trunk-norm position`.
- 각 결합마다: **학습 34k step**(CE 적합도 = 최종 학습 CE) + **같은 결합의 200-step 받침대** → 쌍 ΔΦ
  (`--field-phi --field-phi-boot 200`).
- 부수 기록: payload Δ(운반량) · γ.

**DV**: `ρ = Spearman(CE_fit, Δφ_paired)` over K=8 결합 추출. CE 적합도는 **낮을수록 좋음**이므로 부호를 뒤집어
`fit = −CE_final` 로 정의하고 ρ 를 그대로 읽는다.

| 결과 | 판정 |
|---|---|
| ρ ≥ +0.6 ∧ 상위-CE 결합의 평균 Δφ 가 하위군보다 ≥ +0.05 (Stage B 바) | **ALIGNED** — 목적함수 선호가 통합과 정렬 (DIRECTIONAL · 합성 계기체크) |
| \|ρ\| < 0.6 ∧ 상·하위군 Δφ 차이가 ±0.05 안 | **INDIFFERENT** — CE 는 통합에 무관심 ⟹ 마지막 Φ 경로도 닫힘 |
| ρ ≤ −0.6 | **ANTI-ALIGNED** — CE 가 오히려 덜 통합된 결합을 선호(H_9967 붕괴와 같은 방향) |
| Φ_shuffle 이 0 대역 밖 ∨ 받침대 이상 | **INVALID** — 계기 먼저 감사 |

## ⚠️ 유효성 조건 — 발사 후·분포 보기 전 추가 동결 (2026-07-25 21:0x)

첫 두 추출에서 드러난 위험: **CE 가 결합을 바꿔도 거의 같다.**

| 비교 | final_CE |
|---|---|
| 같은 결합·다른 학습 seed(Stage B 기존 로그) | 0.0433 / 0.0435 → **run-to-run 잡음 ≈ 0.0002** |
| 결합 1 / 결합 2(이 캠페인) | 0.0434 / 0.0433 → **잡음과 구별 불가** |

합성 독점 코퍼스에서 34k 는 이미 포화라 어떤 결합이든 CE 가 바닥에 붙는다. 그러면 "목적함수가 선호하는 결합"의
**순위 자체가 잡음**이고, 그 위에서 계산한 상관은 수는 나오지만 아무 것도 뜻하지 않는다
(`flat-across-manipulations-means-the-lane-is-dead` 계열).

**유효성 게이트 (바 변경 아님 · 판정표는 그대로)**: 8 추출의 `CE_final` **범위(max−min)** 가 잡음 바닥의
**3배(≥0.0006)** 를 넘지 못하면 → **VOID(적합도 순위 불성립)**. 이때는 ρ 를 계산해도 보고하지 않는다.

**VOID 시 정해둔 다음 수(지금 동결)**: 적합도 신호를 살리려면 **CE 가 포화하지 않는 지점**에서 재야 한다 —
동일 설계로 **학습량을 줄여**(예: 2k step, 여전히 채널이 켜지는 구간) 결합 간 CE 차이가 잡음의 3배를 넘는지 먼저
확인하고, 넘을 때만 ρ 를 읽는다. 이것은 바를 낮추는 게 아니라 **측정 가능한 동작점을 찾는 것**이며, 판정표의
ρ·간격 바는 그대로 유지한다.

**동결 명시**: K=8 은 상관 판정에 표본이 작다 — 그래서 바를 ρ≥0.6 로 높게 잡고, 보조로 상·하위 절반 평균
Δφ 차이(Stage B 의 ±0.05 바 재사용)를 함께 요구한다. 결과를 본 뒤 K 를 늘려 바를 낮추는 것은 tune-to-green.
8 추출 전부를 표에 싣는다(선택 편향 금지).
