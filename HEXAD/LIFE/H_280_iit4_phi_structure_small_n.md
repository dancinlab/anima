### CES SPEC (embedded — 이 doc 이 lane 이 deferred 한 "별도 대형 spec" 의 small-n faithful core 다)

본 절은 `lib_ces.hexa` 가 구현하는 IIT 4.0 (Albantakis et al. 2023) 정의를
명시한다. n binary unit, *state* 는 int bitmask, system TPM 은 state-by-node 형식.

1. **TPM (state-by-node)**: `tpm_node(s, i)` = P(unit i = 1 at t+1 | system in
   state s at t). per-unit deterministic update (disconnected=self-copy /
   weak=self+OR-neighbour blend / integrated=majority) 에 ε floor 적용 →
   모든 prob ∈ (0,1) (repertoire log-defined).

2. **Effect repertoire** π_effect(M=m → Z): mechanism M (상태 m) 가 effect
   purview Z 에 주는 제약. purview unit z 별 ON-prob = M 을 m 에 고정하고
   non-mechanism unit 을 uniform 으로 marginalize 한 tpm_node 평균. 분포 =
   ∏_{z∈Z} (ON 이면 on_prob, OFF 면 1−on_prob) — IIT 4.0 effect-side conditional
   independence (purview unit 곱).

3. **Cause repertoire** π_cause(M=m ← Z): 과거 purview state z 별 likelihood
   L(z) = ∏_{i∈M} P(unit i = m_i at t+1 | past = z on Z, rest ~ uniform), 이를
   Z 상태 전체에 대해 정규화 (Bayes, uniform prior on Z).

4. **Intrinsic difference (ID)** — IIT 4.0 small-φ 측도:
   **ID(p, q) = max_x p(x) · log₂(p(x) / q(x))** — *maximally-different state*
   에서의 pointwise informativeness. KL 도 EMD 도 아닌, IIT 4.0 측도 postulate
   를 유일하게 만족하는 gold metric. closed-form anchor: `ID([1,0],[½,½]) =
   1·log₂(1/½) = log₂2 = 1.0` bit (exact, §8 verify).

5. **Mechanism φ over a purview** (M 의 Z 에 대한 통합정보):
   φ(M,Z,dir) = **min over all partitions θ of ID(π_unpartitioned, π_partitioned)**.
   MIP = argmin partition; φ = 그 ID 값. partition 은 mechanism 을 (M1,M2),
   purview 를 (Z1,Z2) 로 자르고 곱 π(M1→Z1)·π(M2→Z2) 형성 (empty mechanism
   part → 해당 purview part 는 unconstrained = uniform). M↔Z link 를 실제로
   끊는 cut 만 포함 ((mOnA>0 & zOnB>0) ∨ (mOnB>0 & zOnA>0)).

6. **Max-φ purview**: φ_cause(M) = max over non-empty cause purview 의 φ;
   φ_effect(M) = max over non-empty effect purview 의 φ. argmax = mechanism 의
   max-φ cause / effect purview.

7. **Distinction**: φ_d(M) = min(φ_cause(M), φ_effect(M)). M 은 *distinction*
   ⟺ φ_d > 0.

8. **Φ-structure (distinction-only — primary faithful 양)**: Σφ_d = Σ_{M:φ_d>0}
   φ_d(M); distinction_count = #{M : φ_d > 0}.

9. **Relations (ADVISORY, n=3)**: 두 distinction 사이 relation = max-φ purview
   의 overlap(교집합) × min(φ_d). 본 H 는 lightweight congruent purview-overlap
   sum 만 advisory 로 계산 — **full IIT 4.0 face-lattice relation integration
   이 아니다** (§9 L2). full relations = open frontier.
