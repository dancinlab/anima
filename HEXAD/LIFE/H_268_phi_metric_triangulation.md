# H_268 — Φ-metric triangulation: verdict metric-robustness

## 1. Hypothesis

Φ proxy `phi_spatial` (RFC 036)** 위에서 판정되었다. gap report 의 gap#1 (verdict

independent integration metric (LZ-complexity · entropy-ratio, H_239 carry) 으로
재측정해도 유지되는가?

H_268 = 2 개 핵심 SUPP 가설의 *핵심 관계*를 **3 개 Φ metric** 으로 재계산해 verdict
의 metric-dependence 를 검정한다:

- **T1 = H_223 pain↔ΔΦ** — 본 세션 최강 coupling (phi_spatial Pearson r=0.999). 핵심
  관계: `corr(intensity, Δmetric) ≥ 0.7` (monotone coupling).
- **T2 = H_204 closure↔Φ** — inverse-U threshold (PARTIAL_DIRECTIONAL). 핵심 관계:
  inverse-U shape (interior peak AND Φ(k=1) > Φ(k=0)).

verdict 가 **≥2/3 metric** 에서 유지되면 metric-robust (신뢰), **1 metric (phi_spatial)

(rule 250/30/110) 위 cross-metric ranking 을 측정했다면, H_268 은 H_239 L4 가 명시한
strict path — *각 SUPP H 의 실제 substrate* (pain perturbation · closure lattice) 위

## 2. Why

- **cross-tool consistency (gap F8)**: 단일 측정 도구의 결과는 그 도구의 systematic
  bias 와 분리 불가능하다. 동일 substrate 위 *독립적으로 motivated 된* 여러 metric 의
  verdict 합치/불합치 는 결과가 substrate-property 인지 tool-property 인지를 가른다 —
  측정 metrology 의 inter-instrument calibration 과 동형.
- **counterfactual (gap F4)**: "만약 phi_spatial 대신 LZ / entropy-ratio metric 을
  썼다면 H_223/H_204 의 verdict 가 그대로였을까?" 라는 counterfactual 을 deterministic
  하게 답한다.
- **H_239 L4 strict path**: H_239 는 generic-CA 위 metric-agnosticity (CONSISTENT)
  를 확립했으나, L4 에서 "각 FALSIFIED/SUPP H 의 specialized substrate 위
  metric-agnosticity 는 *간접 evidence*; 각 H 별 cross-metric 재측정이 strict path"
  로 명시했다. H_268 = 이 strict path 의 SUPP-direction instance.
- **T1 (H_223) 최강 coupling 선택 근거**: r=0.999 는 본 세션 가장 강한 monotone
  관계 — 만약 *이* 관계가 metric-dependent 라면 더 약한 SUPP 들은 더욱 fragile 할
  것. 최강 coupling 의 robustness 가 lower-bound proxy.
- **T2 (H_204) inverse-U 선택 근거**: H_223 의 monotone coupling 과 *질적으로 다른*
  shape (interior peak + decay). monotone 은 ranking-trivial 하지만 inverse-U 는
  metric 이 interior 구조까지 재현해야 하므로 더 까다로운 robustness 시험.
- **3 metric distinct axes (H_239 carry)**: phi_spatial = MI / cause-effect repertoire,
  LZ-complexity = algorithmic (Kolmogorov) incompressibility, entropy-ratio =
  redundancy / shared-information. 서로 다른 information-theoretic 공리에서 출발 —
  3 의 합치는 강한 robustness 증거.
- **raw#12 strict**: deterministic + hexa-only + ≥5 falsifier + ≥6 honest limit.
  LLM judge 없음 (raw = 3 metric). $0 mac local. SUPPORTED 든 PARTIAL 든 FALSIFIED 든
  *모두 valuable* — gap F4 의 양방향 정보가.

- **L3 (T2 absolute scale 차이)**: phi_spatial(k) ∈ [3.7, 5.4], LZ(k) ∈ [0.13, 0.21],

  inverse-U 를 재현하지 *못함* — LZ 는 k 증가에 따라 *monotone 감소* (0.210 →
  0.127). 이유: closure strength ↑ 가 lattice 를 fixed-point 으로 빠르게 수렴시켜

  fragility surface — H_204 closure↔Φ verdict 의 *interior 구조* (inverse-U) 는
