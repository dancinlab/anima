**TRUE upstream root cause discovered** (memory entry
`feedback_hexa_resource_local_dispatch`): `hexa run <file>` auto-routes
single-file (no `use`/`import`/`from`) scripts to **ubu-1 remote machine**
via `~/core/resource/bin/hexa-r ubu-1 run`. The hexa_interp shim at
`$HEXA_LANG/build/hexa_interp` checks 4 conditions (`RESOURCE_LOCAL_HEXA=1`
/ multi-file directive grep / `~/.resource-off` / `$RESOURCE_R` absent),
and falls through to the remote dispatch when all 4 fail. anima_chat_aot.hexa
matches the no-use single-file case → was being run on ubu-1, ckpt not
present → silent failure that looked like "env-var strip" / "logits
divergence" but was actually "wrong host". `RESOURCE_LOCAL_HEXA=1` env
var (or `~/.resource-off` global off) forces local Mac execution. AOT
binary unaffected (direct native execution, no shim).

## §2 What did NOT land (honest C3)

1. **Cross-module `use`**: AOT-buildable `anima_chat.hexa` with full
   mitosis_hook + gen_modes integration is BLOCKED on three hexa_v2
   transpiler limitations:
   - `use "<module>"` emits all module symbols into one C file →
     `selftest()` and `main()` collide across modules.
   - Plain `fn` (non-`pub`) symbols are emitted as global symbols rather
     than file-static.
   - No `__main__` guard idiom → top-level statements (e.g.
     `selftest()` at mitosis_hook.hexa:1119) execute on import.
   The stripped variant `anima_chat_aot.hexa` sidesteps these by inlining
   3 no-op stubs.

2. **D4 live mitosis events on AOT binary**: Disabled (stub returns
   pass-through). The full anima_chat.hexa interpreter SSOT preserves
   D4 capability with chat_init_cell_pool + chat_mitosis_tail wired to
   mitosis_hook. AOT variant is library/helper layer only.

3. **M3 repetition-penalty mode on AOT binary**: Stubbed to passthrough
   (logits unchanged). M3 mode degenerates to greedy if invoked.
   gen_m1/m2/m4 are local to anima_chat.hexa already and remain
   functional in AOT build.

4. **AOT binary arg parser**: ✅ **LANDED 2026-05-13 commit `16acce465`**
   — `main()` now parses `--prompt / --ckpt / --max-new / --mode /
   --temp / --seed / --help / --smoke` and dispatches to `chat_new` →
   `chat_load_weights` → `chat_generate` → `println(response)`. Binary
   440 KB after rebuild. `--help` exit 0, `--smoke` regression-free 17/17
   PASS. Real-inference path on native binary still 🟡 PARTIAL due to
   dims dict-key bug — see updated TL;DR. (Distinct from D4c "anima CLI"
   session orchestrator, separate lane.)

5. **Linux x86_64 binary**: Mac arm64 only. Per
   `docs/clm_aot_build_plan_20260419.md` precedent, Linux build path
   is `ssh ubu 'hexa build ...'` (separate cycle, depends on ubu being
   alive + hexa_v2 Linux ELF rebuild).

6. **First-attempt clang error**: Initial `hexa build` with full
   anima_chat.hexa (pre-strip) emitted clang `implicit-function-
   declaration` for `hexa_val_heapify` at runtime.c:1860 even though
   the forward decl is present at runtime.c:1783 (FIX 2026-05-13).
   Could not reproduce on the stripped variant — likely a hexa_v2
   incremental-cache artifact. Documented as advisory; root cause
   unconfirmed.

7. **Toolchain version**: `hexa 0.1.0-dispatch` (binary at
   `/Users/ghost/.hx/bin/hexa`). Upgrades may change `use` semantics
   or AOT emit; this doc snapshots the 2026-05-13 toolchain behavior.

## §7 Honest C3

1. AOT binary tests library helpers, NOT the full inference path. Real
   model load + token generation NOT exercised on AOT binary.
2. mitosis hook + M3 mode disabled in AOT variant. Distribution binary
   is feature-subset of interpreted SSOT.
3. Cross-module hexa AOT remains a real toolchain gap. We did not fix
   it; we sidestepped it. Documenting this so future work can target
   the upstream limitation.
4. First-attempt `hexa_val_heapify` clang error not root-caused. Stripped
   variant succeeded without addressing it directly. Could resurface on
   other AOT targets.
5. Linux build untested.
6. Helper smoke tests are deterministic ASCII / Hangul / emoji byte
   round-trips + regex predicates. They do not validate the LLM math
   path (matmul / RoPE / attention) — those use farr_* RFC builtins
   which are linked but unexercised by `--help`.
7. `hexa 0.1.0-dispatch` toolchain may evolve. Re-validate AOT build
   after toolchain upgrades.
