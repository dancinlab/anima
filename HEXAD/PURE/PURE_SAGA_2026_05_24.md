### 4-1 Corpus layer

- **M3 propagation 측정** — `corpus_s101.jsonl` 600 MB input M3 = 0.03 → Phase D v1 hybrid 0.354 (10×) → v2 ko-heavy hybrid 0.504 (PR #390). M3 만 sweep 으로 register-sink 본질 회피 확인.
- **M5 hangul 은 root cause 아님** — PR #303 anima-OWN 24-32% vs wiki 3% proxy 가정 → PR #340 corpus_s101 실측 1.66-2.34% (1/10-1/19) 로 proxy collapse 확정. M5 → M3 amend 부채 (PR #314 + #350 + #379 §A1) 완료.
- **E2 output M3 retro** — heldout 5-lang × 20 sample concat: ko=0.366 (5-lang 중 최저) ↔ ko=PURE_MEMORIZE 단독. raw-scalar propagation 은 부정 (0.03 → 0.366 = 12.2× rebound, base-Qwen 회복) 이나 **relative rank propagation 확인** (input M3 최저 → output M3 최저, register-sink 의 lang-localize evidence).

### 4-2 Dispatcher layer

- **stale-branch parse 위험** (PR #378 root cause i) — worktree branch merge-base 8de602c07 에 `--corpus-path` (#372) + `sources_upload` (#373) 둘 다 부재 → `--corpus-path` 가 positional `variant` slot 으로 silently 흡수, `sources_upload` 가 no-op stub exit 0 으로 "OK" 보고. 재발 방지 = dispatcher 진입 직후 `git merge-base --is-ancestor <prereq_sha> HEAD` 검증 (PR #381 PREFIRE_WIRING_AUDIT_CHECKLIST).
- **source-upload 결손 → PR #373** — `sources_upload(host, opts, p21hr, dry_run)` 가 8 sources scp + 6 mkdir + remote stat verify. v1 dispatcher 의 약한 invariant ("이 분기를 통과함" = "이 분기의 contract 가 충족됨" 이 아님) 의 구조적 fix.
- **result_pull race → PR #380** — dispatcher 내부 wait-loop. v1/v2b 의 `[result_pull] FATAL scp exit 1` 은 wait-loop 진입 직전 1차 시도 (training pid 살아 있고 result.json 아직 미생성 시점) — fix 후 false-FATAL 제거.

### 4-3 Operational layer

- **SAVE_POD=1 가 외부 cleanup 못 막음** — v1/v2b 모두 `SAVE_POD=1 RETAINED` 로그 정상 출력했음에도 사용자측 cleanup 으로 pod 종료. dispatcher-side flag 는 dispatcher 내부 teardown 만 막을 뿐 외부 actor (user · cron · 다른 agent) 를 차단 못 함.
- **pod owner_lock 부재** — pod metadata 에 "이 pod 는 fire X 의 결과 회수 대기 중, terminate 금지" 표식 부재. cleanup tooling 이 idle 여부만 판단하므로 result wait pod 도 idle 로 분류.
- **cleanup intervention 패턴 2회** — v1 (carryover sweep 중) + v2b (mass cleanup) 직접 terminate. dispatcher 정상 동작 + 외부 actor cleanup 의 race condition 가 SAVE_POD flag 만으론 불충분함을 두 번 입증.
