## Core findings (3)

1. **eternal cap monotone 가설 FALSIFIED — U-shape 발견.** continuous_total
   v9(74) → v10(52) → v11(34) → **v12(91)**. v11 의 30% retain 이 sweet
   spot, 0% (STRIP-ALL) 은 **v9 보다도 더 나쁨**. 해석: eternal 템플릿은
   register density 의 "스폰지" 역할 — 30% 보존 시 모델이 템플릿 슬롯을
   학습하면 continuous emission 이 슬롯 안에 갇히지만, 0% 일 때는 모델이
   register 신호를 자유 위치에 분산 emit (잠재량은 다른 패턴에 보존됨).
   WAVE15 finding #1 ("eternal cap = continuous 주 lever") 의 단방향
   인과는 **틀림** — 정량적 관계는 비단조.

2. **register emission이 bimodal — 12/20 0-hit + 4/20 ≥16-hit clustered burst.**
   v11 평균 1.7 이 균등 분포였다면 v12 평균 4.55 는 4 outputs (#3,7,9,17 →
   18,16,13,17) 만 register 폭발, 나머지는 완전 cleansed. eternal 템플릿이
   사라지면 모델은 "register 모드 ON/OFF" 두 모드를 spike emit 으로 다룸
   (gradient 가 template slot 으로 흘려보낼 곳 없음). continuous_total
   metric 만으로는 register-leak 양상이 보이지 않음 — distribution 가
   1차 quality marker.

3. **train CE 5배 증가 (0.129 → 0.568) 가 multilingual 품질 회복과 동행.**
   v11 의 매우 낮은 final_CE 0.129 = corpus 정보량 손상의 신호 였다는 가설
   재확인: v12 가 더 많이 strip (14.49% > 13.0%) 했지만 train CE 가
   오히려 높음 (corpus 가 충분히 diverse 한 영역에 redistributed)
   + n_strong 회복 (2→3). final_CE 의 절대값이 multilingual 품질의 inverse
   proxy 라는 **WAVE15 finding #4 강화**.

## What this saga proves / does not

- **proves**: eternal-tag retention 의 continuous_total 영향은 단조함수가
  아니다. 30% sweet spot 존재. corpus-side 단일 lever 로 register-leak
  과 multilingual 품질을 동시 최적화하는 path 는 v11 ≈ 한계점.
- **does not prove**: tag-leak (binary template memorization) 의 STRIP-ALL
  효과 — eval1 별도 verify 필요. ko/ja 회귀가 eternal STRIP 직접 인과인지,
  random seed 동요 + 1500-step 짧은 training 의 noise band 인지 unresolved
  (3-seed bootstrap 필요).
