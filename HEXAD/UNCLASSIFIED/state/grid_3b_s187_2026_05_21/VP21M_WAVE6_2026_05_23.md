## Hypothesis

corpus_v5 (fresh-init carve-strip) 가 LIVE tag-leak 0/28 으로 closed.
하지만 LIVE prose-register ("tension flows", "Tier N", "진공점") 가 30% 잔존,

→ corpus_v6 = corpus_v5 fresh-init carve-strip 의 모든 setup + wiki_frac 0.50.
N3 RB lever 가 fresh-init 위에서도 동일하게 작동하는지 검증.

## Verdict — FALSIFIED (fresh-init 위 lever 미작동)

N3 RB 의 wiki_frac lever 가 fresh-init 위에서는 효과 약화:
- Eval1 prose-leak -1 (5→4 가 아닌 6→5) = 마진 noise 수준.
- register_hits 동일 (5/20) — fresh-init carve-strip 자체가 이미 floor.
- 대신 ja 가 STRONG 16 → PARTIAL 14 (wiki 비율↑ → ja prior 침식 + short-train).

session-2 N3 RB 의 7→4 효과는 continue-train (vP21 상속) 위에서 reg 7 baseline
으로부터의 회복 → fresh-init 의 reg 5 baseline 에서는 추가 회복 여지 작음.
