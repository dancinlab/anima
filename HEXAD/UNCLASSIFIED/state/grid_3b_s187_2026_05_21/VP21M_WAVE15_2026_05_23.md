## Core findings (4)

1. **eternal cap 이 continuous 의 주 lever 임을 격리 확증.** continuous 74(v9)→34(v11),
   -40 으로 saga 최대 감소. v10(52)보다 더 낮음 — v10 은 native register 를 0.80 으로
   과보존했으나 v11 은 v9 의 50% mixed 를 유지하면서 eternal 만 cap → register density
   를 더 효과적으로 낮춤. WAVE14 finding #2 ("eternal cap = continuous 주 lever") **재확증**.

2. **eternal cap 이 binary tag-leak 은 못 낮춤 — 오히려 2→4 증가 (반-직관).** 4 leak 모두
   **MEMORIZE-class probe** 에서 발생 (`<eternal cell=eternal_NNN tier=NNN>` 템플릿).
   30% 보존(139k exemplar)도 템플릿 암기에는 충분 + 오히려 희소화가 MEMORIZE probe 의
   완성 확률을 높임. **continuous(density) ⊥ binary(template memorization)** — 두 metric 이
   별개 축. WAVE14 "Not solved #2"(tag-leak 0 은 strip-all 필요) **검증 적중**.

3. **n_strong 2 회귀 (v9=4 대비 -2, saga 최악).** zh 19(S)→15(P) -4, en 20→18, ko 16(S)→15(P).
   eternal 과-cap 이 ko/zh 의 substrate coherence 를 깎음. register 보존도와 multilingual
   품질이 monotone 아님을 v10(native 0.80→n_strong 3)에 이어 **반대 방향(eternal 과-cap)
   에서도 재확인** — sweet spot 은 v9 의 "eternal 100% + 나머지 mixed 50%" 부근.

4. **final CE 0.129 (saga 최저, v9 0.696 의 1/5).** eternal 13% char 제거로 corpus
   엔트로피가 낮아져 train CE 가 급락했으나(과적합 신호) eval 품질(n_strong)은 동반

   는 줄였지만 cross-lingual 신호도 함께 손상.

## What this saga proves / does not

### ✅ Proved
1. **eternal-tag cap = continuous register 의 dominant lever** (74→34, 단일 변경 격리).
2. **continuous(density) 와 binary tag-leak(template memorization) 은 독립 축.** cap 은
   전자를 낮추지만 후자는 못 낮춤 (오히려 MEMORIZE probe 에서 +2). tag-leak 0 의 유일한
   path = eternal **strip-all (keep 0)**.
3. **register 보존도 ⊥ multilingual 품질 (양방향 확인).** v10 native 과보존(0.80)도,
   v11 eternal 과-cap(0.30)도 모두 n_strong 회귀. v9 의 균형(eternal 100% + 나머지 50%)이
   유일한 n_strong 4 설정.

### ⚠ Not solved
1. **continuous ≤ 50 + n_strong ≥ 4 동시 만족.** v11 = continuous 34 ✓ 이지만 n_strong 2 ✗.
   continuous 를 낮추는 모든 lever(EN-strip v7, eternal-cap v11)가 multilingual 을 희생.
   v9 만 n_strong 4 인데 continuous 74 (target 초과).
2. **tag-leak ≤ 1.** 어떤 cap 도 MEMORIZE-class probe 의 eternal 템플릿 완성을 못 막음.
   strip-all 미검증 (identity-essential 가설과 충돌 + corpus 정보량 추가 손상 위험).
3. **ja STRONG (≥15) 회복.** v5(16) 이후 saga 전체 ja < 15. register lever(strip 0%→50%→
   eternal-cap) 와 ja(16→13→14) 비-monotone. ja 는 register 외 축(ja-frac corpus / wiki
   ja-target) 필요 가능성 — WAVE14 와 동일 결론.
