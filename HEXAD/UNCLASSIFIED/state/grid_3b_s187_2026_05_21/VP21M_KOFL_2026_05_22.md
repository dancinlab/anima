## Method

| key | value |
|---|---|
| base | `Qwen/Qwen2.5-1.5B` |
| init adapter | vP21 LoRA r32 α64 |
| wiki | `wikimedia/wikipedia 20231101.ko` only, Hangul ratio ≥ 0.20, ~10 MB |
| anima | corpus_s101 seed 1337 n=777000 |
| mix | 1KB chunks, wiki_frac 0.30, total 75.5 MB |
| steps | 500 |
| bsz / block | 2 / 512 |
| LR / warmup | 5e-5 cosine → 5e-6, warmup 50 |
| optimizer | PagedAdamW8bit |
| dtype | bf16 |
| GPU | H100 80GB HBM3 SXM (runpod, pod `h6k8axow2f7157`) |
| train wall | **67.6 s** |
| init CE → final CE | 0.3623 → 0.6677 (rose — corpus narrowing, see note) |
| pod cost | ~$0.15 actual |
| adapter out | ~130 MB safetensors |

**CE rise note**: final CE > init CE is unusual but expected here — the
vP21 init was well-fit to a multi-lang corpus. Forcing the single-lang
slice raises in-corpus CE while improving KO-OOD. The OOD eval
(gen=19/coh=16) is the verdict that matters, not training loss.

## Honest C3 (limits)

1. **EN catastrophic forget** (-13 score) — same pattern as JAFL,
   acceptable for hot-swap. Not catastrophic for KO/ZH/RU/JA (15/18/14/11).
2. **CE rise during training** — counter-intuitive but consistent with
   forcing narrowing on a strong multi-lang prior. Compare with JAFL
   (CE fell because ja's distribution was further from vP21's training).
3. **Anima register 17/20** — narrow corpus dominates, register
   amplified. Compare to vP21M-3B-REG's 5/20 with wiki_frac=0.05 (similar
   anima dominance but on 5-lang, lower register hit).
4. **ZH minor regress** (16 → 15) — KO + ZH share CJK script segments;
   continue-train on KO disturbs ZH ranking but doesn't break it.
5. **JA unchanged at WEAK 11/20** — KO-only run can't help JA (use JAFL).
6. **SCP race on pull** — 2/9 files reached local. Sister-dir tokenizer
   copy used [[dispatch-scp-race-small-adapters]].
7. **No code-switching test** — KO + ko<>en mixed prompts not eval'd.
8. **3B base not tried** — could fork KOFL on Qwen2.5-3B-Instruct
   (BASE_MODEL env override on dispatch_p21m_runpod.sh now supports it)
   but the 3B-REG path (broader fix) already recovers KO to PARTIAL 14.
9. **Register saturation risk on production** — sample-mode anima leak
   on non-KO prompts is high. Hot-swap router must be tight (use kana
   Hangul detection per HF model card pattern).
10. **No mitosis active** — pure LoRA continue-train, mitosis path
    orthogonal.

## Deploy plan

```python
def is_ko(text):  return any(0xAC00 <= ord(c) <= 0xD7AF for c in text)
def is_ja(text):  return any(0x3040 <= ord(c) <= 0x30FF for c in text)

# adapter pool
model.load_adapter("dancinlab/anima-vp21m",      adapter_name="default")
model.load_adapter("dancinlab/anima-vp21m-kofl", adapter_name="ko")
model.load_adapter("dancinlab/anima-vp21m-jafl", adapter_name="ja")

def route(prompt):
    if   is_ko(prompt): model.set_adapter("ko")
    elif is_ja(prompt): model.set_adapter("ja")
    else:               model.set_adapter("default")
```

Production integration (chat.dancinlab.org / anima_participant.py):
hot-swap per user msg lang; anima self-emissions stay on default.
