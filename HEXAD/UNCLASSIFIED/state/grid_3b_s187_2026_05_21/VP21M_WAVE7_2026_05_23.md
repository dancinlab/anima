## What this saga proves / does not

✅ **Proved** — anima carving corpus 의 register prose 는 **bilingual context** 에서 작동.
- 모든 carving record 가 KR meta + EN tech term 의 mixed-script 구조.
- "EN-only" filter 는 본 corpus 에서 0% match — script-based language detection 의 한계.
- 27% chars (840k pattern hits) 제거가 multilingual 학습에 substantial 영향.

⚠ **Not solved** — LIVE prose-register hypothesis.
- Eval1 register harness 의 floor (5/20) 가 v5/v6/v7 모두 동일 — harness 자체가
  prune-pattern 변화에 둔감.
- ja regression 의 concrete cost vs LIVE prose-leak 의 unmeasured benefit
  → swap 보류가 cost-rational.
