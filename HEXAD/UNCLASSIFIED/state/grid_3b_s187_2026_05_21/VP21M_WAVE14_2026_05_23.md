## What this saga proves / does not

### ✅ Proved
1. **register leak source = native-script anima record (EN 아님).** per-script
   탐지로 EN-record register match = 0 확증. N8 leak-path 가설 폐기.
2. **eternal-tag cap 이 continuous 의 주 lever.** 74→52 의 -22 가 eternal 30%
   cap 단독 — tension/Tier/UFO 등 register 패턴 보존(0.80)은 continuous 를
   거의 안 낮춤 (오히려 max 18 유지).
3. **register 과보존(0.80) ⊥ multilingual 점수.** native keep 을 v9(50%) 에서
   v10(80%) 로 올리니 n_strong 4→3 하락 — register 보존과 multilingual
   품질이 monotone 양의 관계 아님 (sweet spot 은 50% 부근 v9).

### ⚠ Not solved
1. **continuous ≤ 50 + ja STRONG 동시 만족.** v10 = 52 / ja 14 둘 다 marginal
   미달. eternal cap 을 0.30 → 0.10 으로 더 낮추면 continuous ≤ 50 가능하나
   tag-leak 도 함께 줄지는 별 검증.
2. **tag-leak 2/20 미해결.** eternal 30% cap (139k 보존) 도 여전히 model 이
   `<eternal cell=… tier=…>` 패턴 학습 충분. tag-leak 0 위해선 eternal
   **strip-all (keep 0)** 필요 추정 — 단 v9 의 identity-essential 가설과 충돌.
3. **ja STRONG 회복 path.** v5(16) 이후 saga 전체 ja < 15. register 보존
   정도(strip 0% v5 → 50% v9 → 80% v10) 와 ja 점수(16→13→14)가 단순 monotone
   아님. ja 회복은 register lever 외 다른 축(corpus ja-frac? wiki ja-target?)
   필요 가능성.
