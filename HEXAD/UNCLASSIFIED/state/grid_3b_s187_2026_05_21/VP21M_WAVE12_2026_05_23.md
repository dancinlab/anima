## Honest C3

1. **Buffer rotation rate** — Sample A → B 사이 16/50 새 emit (32% 회전). 5min 안 buffer 의 33% 만 교체 → 두 snapshot 의 union 은 23.1min window 의 모든 emission 을 포함하지 않을 수 있음 (broker 의 50-msg cap). longer-window 측정은 더 큰 broker history dump 가 필요.
2. **Sample bias** — n=66 union 은 WAVE10 n=37 의 1.78× 지만, sample 시점이 deploy+22~27min 에 집중. +1h+ 측정이 mission 요청이었으나 실제 elapsed 는 ~21~27min 에서 측정 종료 (broker history rolling 50 의 saturation 으로 +1h 측정은 별도 cycle 필요).
3. **TS-window precision** — deploy ts 정확도는 PR #123 squash-merge commit ts 기준 (`072aa773c` 2026-05-23T06:37:00Z). cutoff = deploy+60s 로 dampener 의 first-fire 안정화 시간 확보.
4. **langdetect noise** — broker `lang` field langdetect 기반. 짧은 mixed-lang snippet (예: ko prose 안에 EN keyword) 의 분류 오차 가능. EN-share 의 ±1~2pp uncertainty.
5. **Dampener fire direct trace 불가** — daemon log private. WAVE10 +13min 의 18.9% → WAVE12 +22min 의 21.2% 의 +2.3pp drift 가 (a) transient minimum 해소인지 (b) dampener 가 점진적으로 lenient 해지는지 직접 검증 불가. 후자라면 1h+ 측정에서 추가 drift 가능.
6. **Sample B 의 ja tag-leak 1/14 = 7.1%** — Sample A 의 ja 0/12 = 0% 와 Δ +7pp. 단일 ja msg 가 tag-leak detect (`<carve` substring). 14 small-n noise σ ≈ 7pp 범위 안 → noise plateau 안. WAVE10 ja 0/7 = 0% baseline 과 union 5.3% 도 ja domain 안 unstable.
7. **dual-snapshot 의 5min gap 이 짧다** — buffer 평균 emission interval ~21s 라 5min = 14 emit. broker 50-cap 에 도달 (rolling). longer-gap (15~30min) 측정 시 buffer 완전 회전 → 더 strong steady-state estimate 가능. WAVE12 는 +5min gap 의 가장 보수적 estimate.
8. **WAVE10 의 18.9% 가 lower bound** — WAVE12 의 21.2% 가 더 정확한 steady-state. WAVE10 의 단일 측정이 transient minimum 을 catch 했을 가능성 (broker rotation phase) 인정. 두 측정 모두 ⭐ STRONG 이상 충족 (한 단계 더 보수적 estimate 가 ⭐⭐ ULTRA-STRONG 도 충족).
