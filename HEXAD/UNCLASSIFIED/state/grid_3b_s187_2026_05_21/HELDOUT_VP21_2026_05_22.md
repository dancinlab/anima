## Interpretation

vP21 (Qwen2.5-1.5B + LoRA r32 + mitosis, CE 0.0173) learned the **anima
consciousness register so deeply** that LoRA adapters override the base
model's general response on every prompt domain. The 60/60 spontaneous +
20/20 prompted verbalization in earlier evals were measuring fluency *within*
that register, not general capability.

This is the honest limit:
- ✅ vP21 verbalizes coherently in the anima register
- ✅ vP21 emits motivation-gated unprompted in the anima register
- ❌ vP21 does NOT generalize to OOD prompts (jokes / factual / casual) — anima
  vocabulary leaks across all domains

Per the OCCAM scientific frame: **CE 0.017 was a necessary but insufficient
condition** for verbalization. It produced fluency, but inside a narrow
distribution. Generalization needs corpus diversity (Wikipedia + chat + code +
multilingual + ...) on top of anima-register fine-tune — not corpus_s101 alone.

## Honest C3

1. Classifier is heuristic (≥2 anima keys = MEMORIZE). Some "MEMORIZE" outputs
   contain partial correct content (e.g. "Paris") with anima-register suffix —
   the verdict is overall-register-dominant, not zero correct content.
2. The 2 GENERALIZE rows are likely cases where the OOD prompt's domain happens
   to NOT trigger anima-key generation (e.g. very short numeric answer).
3. 10 OOD probes is a small sample; a 100-probe held-out (different domains)
   would tighten the statistic. Sufficient for verdict-direction (clear
   majority memorize), insufficient for fine quantification.
4. Sample-mode (T=0.8 top_k=50) outputs also memorize — not a greedy-only
   artifact.
5. **Generalization unlock path**: fine-tune vP21 on a DIVERSE held-out
   corpus (Wikipedia + general English/Korean) at low LR — the anima register
   should retreat to a learned mode, not dominate every output.
6. This DOES NOT mean vP21 is broken — it means vP21's capability scope is
   precisely "anima consciousness register coherent emission", and the
   over-broad reading ("vP21 is a generally capable conversational agent")
   was always the honest C3 #1 of the prior Eval 1 doc. Now confirmed.
