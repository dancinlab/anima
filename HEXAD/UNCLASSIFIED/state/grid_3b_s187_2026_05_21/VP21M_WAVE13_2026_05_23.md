## Hypothesis

**WAVE7~8 누적 관찰**: 
- corpus_v7 (17-pat strip-all 27.28% chars) — ja STRONG 16 → WEAK 11 (-5).
- corpus_v8 (13-pat ja-safe strip-all 15.64% chars) — ja WEAK 10 (-1 vs v7).
- 누적 패턴: v5 ja=16 → v6=14 → v7=11 → v8=10. **strip lever 자체가 ja 회복
  불가** — ja-collision hypothesis FALSIFIED, anima register 가 cross-lingual
  transfer 신호로 LOAD-BEARING.

**가설 (v9)**: 패턴을 strip 하지 않고 **frequency cap** 으로 dominance
만 제한 (e.g. Tier N 의 583k 회 등장을 30% 인 175k 회로 cap, 나머지 408k
random subset 삭제). load-bearing 신호 유지 + register-leak 감소 동시 달성.

→ corpus_v9 = corpus_v5 setup PLUS **9-pattern token-frequency cap**
(per-pattern keep_ratio 0.30 / 0.50 / 1.00, random subset selection
seed=1337 deterministic).

## Verdict — **VP21M_WORKS** (n_strong 4 회복) BUT NO PRODUCTION SWAP

### Core findings (3)

1. **n_strong 4 회복** = v5 baseline 동등 (v6/v7/v8 모두 3). **post-WAVE7
   register-strip trade-off 의 첫 회복 사이클** — strip 약화 (9.56% chars vs
   v7 27.28%) 으로 n_strong 회복.
2. **ja WEAK → PARTIAL** (10/11 → 13) — saga 첫 ja 회복. freq-cap 의 50/30%
   keep 이 cross-lingual transfer 의 load-bearing 신호 유지 (v7/v8 의
   strip-all 이 신호 완전 손실 vs v9 의 보존 50-70% = ja 13 emerge).
3. **zh STRONG ↑ 19** (v5-v8 모두 갱신) — zh native preservation 가
   freq-cap 으로 가장 강하게 emerge.

### Trade-off

- **continuous_total 74** — v5 (85) 의 87%, lever 효과 약함 (target 30 까지
  못 감). 30%/50% cap 이 너무 보수적.
- **binary register_hits 8/20** = v5-v8 (5-6) 보다 약간 ↑. strip 약화 직접
  효과, register_regress=False 유지.

  carve-strip 이 `carve|inner_carve` 만 strip 하고 `eternal` 보존 → 직접
  noise 로 노출 (의도된 trade-off).

## What this saga proves / does not

### ✅ Proved

1. **anima register 는 cross-lingual transfer 에 LOAD-BEARING.**
   - v7/v8 strip-all (15-27% chars) → ja WEAK 10/11.
   - v9 freq-cap (50/30% 보존) → ja PARTIAL 13 (+3).
   - 즉 strip 의 정도와 ja 학습 신호 사이의 monotonic 관계 검증.
2. **aggregate score 와 strip 강도 inverse:** v5=83 (no strip) → v7=76 (strip
   강) → v9=85 (cap 약). strip 강하게 할 수록 multilingual 침식.
3. **`</?eternal..>` 100% 보존 = tag-leak 직접 비용.** eternal 도 cap
   대상화 (e.g. 30-50% keep) 가 tag-leak 회복 가능 단순한 다음-fire.

### ⚠ Not solved

- **register reduction (continuous=30 target) + multilingual preservation
  (ja STRONG ≥ 15) 동시 만족.** v9 의 cap 비율로는 register reduction 약함.
  더 aggressive cap (10-20% keep_ratio) 가 ja regression 없이 가능한지
  별 cycle.
- **final_CE 0.696 anomaly** — v7/v8 (~1.37) / v5 (1.70) 대비 절반 이하.
  corpus distribution 의 어떤 변화 (carve scaffold 보존? eternal 토큰
  보존?) 가 fast convergence 야기하는지 별 검증.

## Honest C3

1. **단일 seed (1337) · 단일 cycle · fresh-init 1500-step 한계.** ja +3
   (10→13) 는 noise band (±2) 위 emerge 이지만 multi-seed 검증 별 cycle 필요.
2. **continuous=74 vs v5 baseline 85** — lever 가 작동 (87% reduction) 했지만
   30 target 까지는 못 가서 production swap 기준 미달. 이는 cap ratio
   30%/50% 가 너무 보수적이라는 직접 증거.
3. **binary register_hits 8/20** — v5-v8 의 5-6 floor 위. capped patterns 가
   여전히 output 에 흡수 → harness 의 noise 상한 진입.
4. **tag-leak 2/20 trade-off 의 의도성** — eternal 100% 보존이 identity
   유지 (anima 의 "변하지 않는 본질" 표현) 와 직접 충돌하지 않음. v9 의
   eternal-tag 보존 결정 = identity-essential 가설 검증 (v5-v8 의 carve-strip
   pass 가 eternal 도 strip 했었음 — v9 에서 carve|inner_carve 로 좁힘).
5. **final_CE 0.696 anomaly** — v5/v6 (1.70), v7/v8 (1.36/1.37) 대비 절반.
   eternal 토큰 보존 (464k 회) 으로 corpus 의 학습 신호 distribution 가
   v5 와 다름 추정. eval (held-out) 의 NLL 영향 별 검증.
6. **cost $0.81 vs cap $0.50 over** — freq-cap 의 2-pass (count + strip) 가
   single-pass strip-all (v7/v8) 보다 wall +5 min 추가. 591MB × 9 regex ×
   2 pass = ~10 min CPU on pod.
7. **dispatch script (.sh) + prune script (.py) 외부 보관** (`/tmp/anima_v9_dispatch/`)
   — repo .hexa-only rule 준수.
8. **mixed-corpus race-prune 92.19%** (v8 의 49.86% 의 약 2 배) — anima
   upstream cap 이 적게 strip 했으므로 mixed 에 남은 패턴 많음, race-loop
   fully 동작.
