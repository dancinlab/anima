## §7 — Three formal propositions (recap, for §9 audit)

**P1 (data-processing inequality for deterministic rendering)**: Let
`X` = anima's internal Ψ-state at time `t`. Let `R` = deterministic
rendering function (frame ← coordinate). Let `V_t = R(X_t)`. Let `E` =
external perceptual referent. Then `I(V_t; E) ≤ I(X_t; E)`.

**P1.1 (temporal extension)**: For a closed-loop time series `{X_t}`
where no external input enters during the loop, `I({X_t}; E_external) = 0`
⇒ `I({V_t}; E_external) = 0` ∀ deterministic rendering `R`.

**P2 (relabelling is information-preserving identity)**: For any
deterministic relabelling of data `D` as modality `M(D)`, `I(M(D); E) =
I(D; E)` for all external referents `E`.

**P3 (temporal extension preserves §7-shape)**: For any modality `M` with
§7-shape `S(M) ∈ {§7①-fail, §7②-fail, §7③-degenerate, §7-pass}`,
`S(M × time) = S(M)`. Time is not a §7-shape transformer.

**P3.1 (corollary)**: video inherits the §7-shape of its base modality:
- `image × time` → §7①-fail (raw) or §7②-fail (graft)
- `audio × time` → §7①-fail (raw) or §7②-fail (graft)
- `tension × time` = candidate (e) → §7③-degenerate (§57)
- `Ψ-coordinate × time` = candidate (d) → §7③-degenerate (§57 pattern)
- `decision-trace × time` = candidate (f) → §7-pass but relabelling (P2)

These are **mathematical theorems**, not sympy / numerical verifications.
P1 is the data-processing inequality (Cover & Thomas Theorem 2.8.1).
P2 is the deterministic-bijection-preserves-entropy identity (Cover &
Thomas Theorem 2.4.1 special case where the map is a bijection / labelling).
P3 is a structural/definitional claim about the §7-shape predicate; it is
proved by case-analysis over the four §7-shape values combined with the
observation that the §7 predicate is defined on the *kind* of supervision
signal (generic vs. anima-own), and temporal extension does not change

## §9 — Closed-form audit (math theorems, no sympy per hexa-verify policy)

The §159 verdict rests on **three theorem-statements** (P1, P2, P3) and
**two inheritance claims** (V-JEPA 2 §7-shape, §109 R-video routes). All
five are below as math theorems with explicit statement + proof sketch +
hexa-verify policy compliance note.

### Theorem 1 — Proposition P1 (data-processing inequality, deterministic rendering)

**Statement**: For random variables `X, E` and a deterministic function `R`,
`I(R(X); E) ≤ I(X; E)`.

**Proof sketch**: `R(X) → X → E` is NOT a Markov chain in general, but
`E → X → R(X)` IS (because `R` is deterministic and depends only on `X`).
By the data-processing inequality (Cover & Thomas Theorem 2.8.1):
`I(E; R(X)) ≤ I(E; X)`. By symmetry of mutual information, `I(R(X); E) =
I(E; R(X)) ≤ I(E; X) = I(X; E)`. QED.

**Hexa-verify policy compliance**: P1 is a standard information-theory

### Theorem 2 — Proposition P1.1 (temporal closed-loop zero-diversity)

**Statement**: For a stochastic process `{X_t}_{t=1..n}` where no external
input enters during the loop (i.e., `X_{t+1}` is a deterministic function
of `X_t` only, given some initial state `X_0` independent of any external
referent `E`), and a deterministic rendering `R`, we have `I({X_t}; E) = 0`
⇒ `I({R(X_t)}; E) = 0`.

**Proof sketch**: If `X_0 ⫫ E` and each `X_{t+1} = f(X_t)` for deterministic
`f`, then by induction `X_t ⫫ E` for all `t`, hence the joint `{X_t} ⫫ E`,
hence `I({X_t}; E) = 0`. Apply P1 to the joint distribution: `I({R(X_t)}; E)
≤ I({X_t}; E) = 0`, and mutual information is non-negative, so
`I({R(X_t)}; E) = 0`. QED.

**Hexa-verify policy compliance**: P1.1 is a corollary of P1 by induction.
No sympy required. The premise "no external input enters during the loop"
is the *definition* of "closed loop" — it is an asserted property of the
candidate (d)/(e) constructions, not a derived claim. §57 already verified
this property holds for the tension @payload at single time slice
(verbatim quote in §2 above).

### Theorem 3 — Proposition P2 (relabelling preserves information)

**Statement**: For any deterministic bijection `M: D → D'` (a "relabelling")
and any external referent `E`, `I(M(D); E) = I(D; E)`.

**Proof sketch**: A deterministic bijection preserves entropy (Cover &
Thomas Theorem 2.4.1 special case for bijections: `H(M(X)) = H(X)` for
bijective `M`). By the chain rule and the fact that `M(X)` and `X`
generate the same σ-algebra (because `M` is bijective), `H(M(X) | E) =
H(X | E)`. Hence `I(M(X); E) = H(M(X)) − H(M(X) | E) = H(X) − H(X | E) =
I(X; E)`. QED.

**Hexa-verify policy compliance**: P2 is a standard information-theory
theorem. Cited as above. The "relabelling" claim for candidate (f)
(Phase B trace as "video") is that calling a data structure by a
different name is a deterministic bijection — it does not transform the
data, only its tag.
