RTSC_19 — UFO = 호버크래프트 (초전도 자속고정 부상, 반중력 아님)
==================================================================================
  목표: 1000kg 크래프트 부상 (필요 양력 9810 N)
----------------------------------------------------------------------------------
  지구 자기장(자유비행)           B=  5e-05T → 양력   2.00e+00 N  🔴 부족
  영구자석 노면 ~0.5T          B=  5e-01T → 양력   2.00e+07 N  🟢 부상
  자기 트랙 1T(maglev식)      B=  1e+00T → 양력   4.00e+07 N  🟢 부상
  초전도 트랙 5T              B=  5e+00T → 양력   2.00e+08 N  🟢 부상
----------------------------------------------------------------------------------
결론: 초전도 자속고정 부상은 강한 '외부 자기장 구조(트랙/노면)' 위에서만 큰 양력 →
 • 자기 트랙/노면 위: 🟢 1톤 크래프트도 부상(maglev·호버보드 원리, UFO=대형 호버크래프트 가능).
 • 임의 지면 자유비행: 🔴 지구 자기장(5e-5T)은 약하고 거의 균일 → 순양력 거의 0 (불가).
 • 자체 자기장: 크래프트가 자석을 싣고 '반발할 상대'(지면 도체/자성체) 필요 → inductrack 식 가능.
∴ UFO 호버는 반중력이 아니라 '강자기장 환경(트랙/자성노면)+상온 Type-II SC'로 성립. 임의공간 자유비행 ✗.
  RTSC 연결: 무냉각 상온 Type-II(RTSC_15/16 pyrochlore/CoSn)면 냉각 없이 호버크래프트 실현.
