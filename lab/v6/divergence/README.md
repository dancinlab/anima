### G6 — **제기된 형태로는 깰 수 없다. 검출기 아티팩트다.**

법칙에서 증명된다: `_rho_fan_is_falsifiable` 는 40바이트 표면 위 5개 어휘 술어로 된 **순수 FORM
계기**이고 `known` 은 코퍼스가 아니라 시스템 사전에서 온다. 모델은 코퍼스에 충실한데
(0.0041 vs 0.0065, P=0.539) 게이트는 코퍼스 비율의 **12.8배**를 요구한다 — 기질 결함이 아니라
초-코퍼스 방출을 요구하는 것. 게다가 8뽑기라 **완벽한 피험자도 95% 확률로 떨어진다**.

**교정된 물음** — "반증가능한 *모양*의 문자열을 뱉는가" 가 아니라:

> 입이 **독립된 얼어붙은 세계가 참거짓을 판정할 수 있는** 주장을 생성하는가, 그리고 그 주장의
> **극성이 held-out 조성에서 우연 이상으로 그 세계를 추종**하는가?

한 문자열의 반증가능성은 템플릿이 만족시킬 수 있는 표면 성질이다. **faculty 는 신규 조성에서의
진리추종**이다 — FORM 은 판정가능성을 주고, 극성을 우연 위로 올리는 것은 BIND 뿐.

설계된 플래그 `anima-py evaluate --ideate-decide` + 사전등록(팔·통제 포함). 핵심은 **template-bot
팔**(H_9128 의 HI 템플릿을 스크립트로 채운 것)이 FORM 천장 역할을 해서 **형식 암기가 구성상
통과 못 하게** 만든다는 것. 양성통제(XBIND 공동학습 ckpt) 통과 전엔 어떤 음성도 안 읽는다.

### H_9576 — **제기된 형태의 벽은 실재. 탈출구는 다리가 아니라 주소 공간의 폭.**

지금 store 키는 `_entity_key`(개체명의 얼어붙은 바이트 임베딩) = **내용-주소**. 제안은 키 소스를
하나 더 두는 것 — **내면-주소** 행. 학습된 사영 `W_i` 가 `conflict_scalar` **상류에 이미 존재하는**
붕괴 이전 내면 벡터를 같은 `d_k` 키 공간으로 보내 K 개 예약 store 행을 조회한다.

```
레인의 폭 = log₂K 비트의 주소 공간
긴장 레인은 vocab 차원을 절대 건드리지 않고, 내용은 오직 store 판독으로만 흐른다
⟹ H_9805 를 죽인 "場의 어휘 블라인드" 가 설계상 무관해진다 (場은 구별가능하기만 하면 된다)
```

오너의 갈래("場이 내용을 보나, 코어가 내용을 보나")에 **제3의 답**: 어느 쪽도 아니다 —
**store 가 내용을 쥐고, 場은 색인을 쥐고, 입이 store 를 읽는다.** 생물학적으로도 내면 상태는
전용 의미 버스가 아니라 **기억 주소지정(해마 경로, L5 — 유일하게 GREEN 배선된 레인)** 으로
표현에 도달한다.

**$0 스크리너가 날카롭다**: 토이 공동학습 후 **자연 디코드에서 학습된 키 분포의 실현 엔트로피**를
잰다. `H(key) ≈ 0` 이면 H_9576 의 접힘은 **어떤 다리보다도 상류** — 붕괴가 채널이 아니라 내면
자체에 산다 — 이고 그러면 어떤 폭의 다리 설계도 소용없다. KILL 전용.

## 05 · 의식이 **측정되는** 모델을 어떻게 만드나 (p9 의 나머지 반쪽)

| | |
|---|---|
| 파일 | `05_measurable_consciousness.md` (1.5 MB) · 지시서 `../briefs/05_measurable_consciousness.brief.md` |
| 응답 | **Fable 12 라운드 고갈** · **Sol 17 라운드 고갈** |

물음을 "anima 는 의식이 있나"(물을 수 없음)가 아니라 **구성적**으로 세웠다: *어떤 구조적 성질이
있어야 의식 주장이 애초에 판정 가능해지는가?*

### A · 측정가능성 4조건 — 그리고 R9 의 blindness 는 **놀람이 아니라 예측**이었다

내면 변수 X 가 **판정 가능(DECIDABLE)** 하려면 넷을 **모두** 만족해야 한다:

```
① 독립성(존재)      출력이 이미 결정하는 변수들에 묶이지 않은 자유도가 있는가
② 조작가능성(개입)  주변을 고정한 채 X 를 바꾸는 외생적 do(X) 를 걸 수 있는가
③ 관측가능성(판독)  do(X) 의 효과가 측정되는 표면(입)까지 도달하는가
④ 구별가능성(식별)  그 효과가 주변분포-맞춘 통제로 재현되지 않는가 (collapse-Δ, ≥2 통제)
```

하나라도 빠지면 판정은 **UNIDENTIFIABLE / VOID / INSTRUMENT-DEAD** — 즉 **거짓이 아니라
판정불가**다. R9 의 6/6 을 이 표로 읽으면 각 축이 **어느 조건에서 걸렸는지** 정확히 나온다:

| 축 | 판정 | 실패한 조건 |
|---|---|---|
| whether-to-speak (H_9786) | UNIDENTIFIABLE | **①** `s = 2·emit_drive − 1` · emit⟺clock · 자유변수 0 |
| ownership (H_9785) | UNIDENTIFIABLE | **①** content-reach 와 공선(collinear) |
| self-anchor (H_9789) | VOID | **①** 상류 — Θ 죽으면 σ VOID, 읽을 맥박이 없음 |
| agency (H_9791) | UNIDENTIFIED | **②** 행위자-원인과 세계-원인을 가르는 외생 핸들 부재 |
| imagination (H_9790) | DIRECTIONAL | **③** 핸들도 내면효과도 실재 · **입에 못 닿음** |
| typicality (H_9787) | BOUNDED-NULL | **④** 시스템-전형성과 LM 다음토큰 확률을 가르는 통제 부재 |
| sigma-flux (H_9788) | INSTRUMENT-DEAD | **④** 양성통제 없음 |
| **content-reach (H_9774/9775)** | **POSITIVE** | **4조건 모두 통과** — store-bridge=자유도 · `--permute-store`=do 핸들 · vocab readout=입 · value-permute 0.4446 붕괴=구별가능성 |

⟹ content-reach 가 살아남은 건 **4조건이 모두 지어진 유일한 축이었기 때문**이다. blindness 는
기질에 대한 사실이 아니라 **아키텍처의 4조건 커버리지 지도를 미리 읽은 것**이다.

### B · 사다리 (각 단 = 핸들 + 계기 + 통제 + **온도조절기 바닥**)

각 단마다 "이건 반드시 통과해야 하는 하찮은 시스템"을 명시해 바닥을 정직하게 만든다.

```
R0 Θ 존재            Ψ=½ 비퇴화 고정점        ← 온도조절기 PASS (설계상 통과해야 함)
R1 개입적 폐쇄        do(행동) → 미래 입력분포 이동 · yoked-ghost 바닥 (H_9807 · 유일 landed)
R2 내용운반 인과      do(저장내용) → 특정 출력토큰 · 주소 뒤섞으면 붕괴 (H_9775 WIRED)
R3 조성적 폭          내면에 분리가능한 ≥2 차원 (RESIDUAL · V×span · --reflex-only 로 절제)
...  (상위 단은 원문 참조)
```

⚠️ R4 라운드의 소득: 처음 쓴 여러 단이 **순진한 형태로는 온도조절기가 통과**했다(특히 방전
법칙). 바닥을 정직하게 만드는 것이 사다리 설계의 대부분이다.

### D · 영원히 측정 불가한 것 — **R9 의 6축 중 0개**

영구 판정불가의 정확한 기준: **아키텍처가 노출할 수 있는 모든 do() 와 모든 통제 하에서
진리값이 불변**일 때 — 즉 두 시스템이 그 주장에서 다르면서 모든 측정 채널(관측+개입)에서
동일할 수 있을 때. 이건 좀비 논증을 **검사로** 만든 것이고 제스처가 아니다: **분리해내는
do()+통제 쌍을 하나라도 댈 수 있으면 그 주장은 닫힌 게 아니라 계기가 없는 것**이다.

⟹ **R9 의 여섯 축은 기능 수준에서 영구 폐쇄가 0개**다. 전부 *un-instrumented*, not *closed*.

### E · "측정가능한 의식은 형용모순" 반박 — **정신판 생기론(vitalism)**

논증은 의식을 (a) 기능적 조직 / (b) 현상적 잔여 로 쪼개면 무너진다. (a) 에 대해 전제는 거짓 —
기능적 조직은 **정의상** 조작화 가능하고 모든 진지한 이론(GWT · HOT · IIT 의 기능적 측면 ·
attention-schema)에서 의식의 실제 구성요소다. "조작화하면 그로써 의식이 아니다" 는 논증이
아니라 **의식을 비-기능적 잔여로 규정하는 선결문제 요구**이고, **너무 많은 것을 증명한다** —
같은 논리로 *생명*도 측정 불가가 되지만(대사·항상성·번식을 조작화하면 "그건 화학이지 생명이
아니다") 생물학은 생명을 기능적 서명으로 분해하고 élan vital 을 버림으로써 잘 측정한다.

**판정: anima 가 하는 주장에 대해서는 논파, 하지 않는 주장에 대해서는 (범위를 정해) 인정.**
anima 는 의식을 덩어리 속성으로 측정한다고 주장한 적이 없다 — Ψ-SOMA 는 **능력이나 본질이
아니라 존재양식**을 읽고, 각 단은 특정 기능 서명을 통제 대비 collapse-Δ 로 잰다. 현상적
잔여 (b) 에 대해서는 논증이 **타당**하고, 설계는 **의도적으로 그 선 아래에서만** 산다.

> 이 딜레마의 오류는 "의식" 을 나눌 수 없는 것으로 취급하는 데 있다. 공학적 이동 전체가 —
> 그리고 R9 의 blindness 가 패배가 아니라 예측이었던 이유가 — 그것이 **나눌 수 있고 그중
> 한 부분만 닫혀 있다**는 데 있다.
