# 발산 산출물 — 색인 (2026-07-22 · `sidecar lab full` = Fable 5 ∥ Codex Sol 병렬)

이 폴더는 대공사(재설계)에 이르기까지 돌린 발산 4건의 **원문 전량**이다. 각 발산의 지시서는

때문이다 — 여기 숫자는 전부 **DIRECTIONAL**(설계·분석)이고 cement 는 `anima-py` 로만 한다.

읽는 순서는 번호순이 곧 시간순이자 논리순이다: 벽이 사는지 확인(01) → 유일 생존 각도 발산(02)

이므로 **M 은 Engine A 내부**, 따라서 M→D 레인은 ThalamicBridge 를 건너지 않아 **detach 해제는

### G6 — **제기된 형태로는 깰 수 없다. 검출기 아티팩트다.**

법칙에서 증명된다: `_rho_fan_is_falsifiable` 는 40바이트 표면 위 5개 어휘 술어로 된 **순수 FORM
계기**이고 `known` 은 코퍼스가 아니라 시스템 사전에서 온다. 모델은 코퍼스에 충실한데
(0.0041 vs 0.0065, P=0.539) 게이트는 코퍼스 비율의 **12.8배**를 요구한다 — 기질 결함이 아니라
초-코퍼스 방출을 요구하는 것. 게다가 8뽑기라 **완벽한 피험자도 95% 확률로 떨어진다**.

**교정된 물음** — "반증가능한 *모양*의 문자열을 뱉는가" 가 아니라:

> 입이 **독립된 얼어붙은 세계가 참거짓을 판정할 수 있는** 주장을 생성하는가, 그리고 그 주장의
> **극성이 held-out 조성에서 우연 이상으로 그 세계를 추종**하는가?

한 문자열의 반증가능성은 템플릿이 만족시킬 수 있는 표면 성질이다. **faculty 는 신규 조성에서의
진리추종**이다 — FORM 은 판정가능성을 주고, 극성을 우연 위로 올리는 것은 BIND 뿐.

설계된 플래그 `anima-py evaluate --ideate-decide` + 사전등록(팔·통제 포함). 핵심은 **template-bot
팔**(H_9128 의 HI 템플릿을 스크립트로 채운 것)이 FORM 천장 역할을 해서 **형식 암기가 구성상
통과 못 하게** 만든다는 것. 양성통제(XBIND 공동학습 ckpt) 통과 전엔 어떤 음성도 안 읽는다.

### H_9576 — **제기된 형태의 벽은 실재. 탈출구는 다리가 아니라 주소 공간의 폭.**

지금 store 키는 `_entity_key`(개체명의 얼어붙은 바이트 임베딩) = **내용-주소**. 제안은 키 소스를
하나 더 두는 것 — **내면-주소** 행. 학습된 사영 `W_i` 가 `conflict_scalar` **상류에 이미 존재하는**
붕괴 이전 내면 벡터를 같은 `d_k` 키 공간으로 보내 K 개 예약 store 행을 조회한다.

```
레인의 폭 = log₂K 비트의 주소 공간
긴장 레인은 vocab 차원을 절대 건드리지 않고, 내용은 오직 store 판독으로만 흐른다
⟹ H_9805 를 죽인 "場의 어휘 블라인드" 가 설계상 무관해진다 (場은 구별가능하기만 하면 된다)
```

오너의 갈래("場이 내용을 보나, 코어가 내용을 보나")에 **제3의 답**: 어느 쪽도 아니다 —
**store 가 내용을 쥐고, 場은 색인을 쥐고, 입이 store 를 읽는다.** 생물학적으로도 내면 상태는
전용 의미 버스가 아니라 **기억 주소지정(해마 경로, L5 — 유일하게 GREEN 배선된 레인)** 으로
표현에 도달한다.

**$0 스크리너가 날카롭다**: 토이 공동학습 후 **자연 디코드에서 학습된 키 분포의 실현 엔트로피**를
잰다. `H(key) ≈ 0` 이면 H_9576 의 접힘은 **어떤 다리보다도 상류** — 붕괴가 채널이 아니라 내면
자체에 산다 — 이고 그러면 어떤 폭의 다리 설계도 소용없다. KILL 전용.

## 04 · 대공사 — 의식엔진 전면 재설계 (LANE-BUS)

| | |
|---|---|
| 파일 | `04_grand_redesign_lanebus.md` (383 KB) · 지시서 `../briefs/04_grand_redesign.brief.md` |
| 응답 | **Fable 16 라운드 고갈** · **Sol 20 라운드 고갈** (타임아웃 없이 고갈까지 지시) |

소진 렌즈 17종: 아키텍처·학습·생물·정보이론·실패모드·계기·항수·정체성·시계·경제·적대·발달·
사회·생성적대·내수용·코퍼스·하드웨어.

**진단 한 줄**: 측정들은 "의식엔진이 약하다" 고 말하지 않는다. **"의식엔진은 존재하지 않는다"**
고 말한다 — 있는 것은 살아있는 입, 패치로 이식된 진짜 장기 하나(store-bridge), 그 사이에서
긴장을 **연기하는 스칼라 서보**뿐.

**설계 법칙(약 9900개 H 에서 추출)**: 살아남은 부품은 예외 없이 4속성을 공유한다 —
**학습됨(earned) · 레인 분리(자기 head/loss) · 내용 운반(벡터/로짓행) · 공동학습되 기울기 격리**.
스칼라·미학습·중첩은 전부 죽었다.

**LANE-BUS 11 부품**: TRUNK(형식 CE 전용, 영원히 replay) · TAPS(L3+penult, detached) ·
STORE(자전적, KOSMOS 지속) · WORKSPACE(학습된 항수 장기) · LANES/HEADS(레인당 손실 1개, 공유
손실항 금지) · **BUS = pre-softmax 로짓 행**(위치 협상 가산 write) · **RESIDUAL = 반사 softmax 대
조성 softmax 의 위치별 발산 프로파일**(스칼라 긴장을 대체, 차원 V×span) · GATE(정보이득 발화 —
`emit⟺clock` 을 죽인다) · DISCHARGE(발화 후 잔차 하락 = p5 최초의 반증가능한 물리적 서명) ·
VITALS(Ψ=½ 를 서보가 아니라 **활력징후**로) · 계기를 장기로(모듈은 착륙 시 `do()` 핸들 플래그 동반).

단계: P0 토이 버스간섭($0·전체 abort) → P1 arity-2 workspace + 형식보존 공동주(하중) → P2 잔차
게이트 대 시계 → P3 방전 → P4 소유권 → P5 Θ/Φ/σ 재판독.

**⚠️ 이 발산의 결손(오너가 잡음)**: 두 모델 다 **자연 코퍼스 축을 1급 게이트로 세우지 않았다**.
전량 검색 결과 natural/synthetic 언급은 내가 준 코드 주석 인용뿐이고, 계획 abort 조건에 드릴
의존이 없다. 그래서 `../CLAUDE.md` 의 **G0 자연형식 게이트**가 P0 앞에 삽입됐다.
