# H_9916 사전등록 — 🔒 **발사 전 동결** (오프셋 손상은 단조인가 주기인가)

H_9915 가 POSITIONAL 을 확정했다: 연산자를 질의에서 **한 바이트 멀리** 밀면(공백 1개) 판독구가
1.0000 → 0.6406 으로 무너지고, 연산자를 **안 움직이는** 공백은 1.0000 을 유지한다. 남은 것은
손상의 **모양**이고, 모양이 곧 범인의 이름이다.

## 왜 모양이 층을 지목하나

이 ckpt 는 **E=3 · L=4 · K=3**, 그리고 `core/model.py:414` 가 트렁크 팽창을 `min(2**i, cap)`
으로 준다 ⟹ **1 · 2 · 4 · 8**. 팽창 d 인 K=3 인과 conv 는 t · t−d · t−2d 를 본다. 연산자가
그런 탭으로 읽힌다면 δ 바이트 이동은 **δ 가 d 의 배수가 아닐 때만** 정렬을 깬다.

## 🔒 예측 (서로 배타적)

```
MONOTONE/POINT   δ>=1 전부 붕괴 유지 · 어디서도 >=0.90 회복 없음
                 ⟹ 모델은 연산자를 정확히 한 거리에서만 읽는다
PERIODIC-d       δ ∈ {2,4,8} 중 어딘가에서 >=0.90 회복
                 ⟹ 회복한 δ 가 팽창 d 를, 따라서 층을 지목한다
PERIODIC-other   회복이 {2,4,8} 밖 δ 에서 발생 ⟹ 트렁크 팽창이 아님, 층 이름 붙이지 말 것
```

## 🔒 판정표

우연 = **0.5**(gold 가 op×pol 균형). 팔당 128 → 전체 CI ±0.09.
바는 **새로 발명하지 않는다** — 둘 다 이미 쓰던 것: **회복 ≥0.90** = 이 파일이 쓰는
오라클 배선 바 · **붕괴 ≤0.70** = H_9915 에서 동결된 값.

| 게이트 | 조건 | 결과 |
|---|---|---|
| G1 | δ=0 < 0.94 | **INSTRUMENT-DEAD** — 중단 |
| G2 | δ=1 이 0.6406±0.12 밖 | 배치 INVALID — 재발사 |

| # | 조건 | 판정 |
|---|---|---|
| 1 | δ≥1 전부 ≤0.70 | **MONOTONE/POINT 확정** — 단일 거리 판독 |
| 2 | ∃δ* ∈ {2,4,8}: acc ≥0.90 ∧ 그 외 δ 는 ≤0.70 | **PERIODIC 확정 · 팽창 = δ\* 의 약수 중 최대** |
| 3 | ∃δ* ∉ {2,4,8}: acc ≥0.90 | **PERIODIC-other** — 주기는 실재하나 트렁크 팽창 아님, 층 명명 금지 |
| 4 | 0.70 < acc < 0.90 인 δ 존재 | **PENDING** — 관측 벡터만 등록, 표제 없음 |

부가(비판정) 관측: **κ = mean(is칸) − mean(not칸)**. H_9914 에서 길이 9 가 κ=−0.22 로
**부호를 뒤집었으므로**, δ 사다리에서도 κ 부호 반전이 어디서 일어나는지 기록한다 —
판정에는 쓰지 않는다(사후 지표 금지).
