# H_9917 사전등록 — 🔒 **발사 전 동결** (틈을 채운 것의 어떤 성질이 방향을 정하나)

H_9916 의 탐색적 매칭쌍: 연산자 오프셋을 **15로 고정**했는데 틈을 **공백**으로 채우면
κ=+0.962(완전 `is` 편향), **글자**로 채우면 κ=−0.210(`not` 편향). 전체 정확도는 둘 다 0.5156.
방향을 정하는 변수가 무엇인지가 지금 열린 질문이고, 그게 다음 층 탐색의 범위를 정한다.

**κ = mean(is 칸) − mean(not 칸)** — 양수면 `is` 로 기본값, 음수면 `not` 쪽.

## 후보 (서로 배타적 예측)

```
LEXICALITY    "발음 가능한 단어처럼 보이는가" 가 변수
              ⟹ CV-글자만 음수 · 숫자·구두점·반복문자는 공백처럼 양수
BYTE-CLASS    "공백(0x20)이냐 아니냐" 가 변수
              ⟹ 공백만 양수 · 숫자·구두점·글자·반복문자 전부 음수
ENTROPY       "틈이 정보를 담느냐" 가 변수
              ⟹ 반복문자(zzzzz, 저엔트로피)는 공백처럼 양수 · 무작위 글자/숫자는 음수
NULL          넷 다 비슷 ⟹ H_9916 의 매칭쌍이 우연이었음, 관측 철회
```

## 🔒 판정표

우연 = 0.5. 팔당 128. **바를 새로 발명하지 않는다** — H_9916 에서 실측된 두 극을 쓴다:
**양(공백형) = κ ≥ +0.60** · **음(글자형) = κ ≤ −0.05** · 그 사이는 **중간**.
(+0.60 은 관측된 공백극 +0.962 와 사다리 최저 양수극 +0.686 사이 아래쪽 · −0.05 는 관측된
글자극 −0.210 과 0 사이.)

| 게이트 | 조건 | 결과 |
|---|---|---|
| G1 | G-space κ < +0.60 **또는** G-letters κ > −0.05 | **재현 실패 → 배치 INVALID**, 아무것도 읽지 않음 |

| # | 조건 | 판정 |
|---|---|---|
| 1 | digits·punct·repeat 전부 κ ≥ +0.60 (공백형) | **LEXICALITY 확정** |
| 2 | digits·punct·repeat 전부 κ ≤ −0.05 (글자형) | **BYTE-CLASS 확정**(공백만 특별) |
| 3 | repeat ≥ +0.60 ∧ digits·(punct) ≤ −0.05 | **ENTROPY 지지** |
| 4 | 위 어디에도 안 맞음 | **PENDING** — 관측 벡터만 등록, 표제 없음 |

부가(비판정): 전체 정확도. H_9916 에서 공백/글자가 **둘 다 0.5156** 이었으므로 전체는
방향을 구분하지 못한다 — 그래서 κ 가 1차 지표다. 전체가 0.70 을 넘는 팔이 나오면 그건
**별개의 사건**(회복)이므로 즉시 기록하고 판정표 밖으로 뺀다.
