## 무엇을 막는 통제인가

```
"이 시스템은 통합한다"       ← 내부 구조에 대한 주장
"이 시스템은 무언가를 한다"   ← 세계에 대한 주장
```

Φ 는 **첫번째만** 말한다. 그래서 **Φ 는 같은데 기능은 죽은** 쌍둥이를 만든다.
어떤 주장이 "Φ>0 이므로 …" 에 기대면, 죽은 쌍둥이가 같은 Φ 로 아무것도 안 하면서 그 주장을
**구성적으로 반박**한다.

## ⚠️ 이 파일이 저지른 실수 — 그리고 그게 이 카드의 핵심

구성 세 판이 연달아 **깊은 구조 법칙처럼 보이는 것**을 냈다:

| 구성 | Φ | function |
|---|---|---|
| 구동을 **한** 유닛에 | 1.0000 → **0.0000** | 1.0000 |
| 구동을 **두** 유닛에 대칭으로 | 1.0000 유지 | **0.0000** |
| 요크 구동 | **0.0000** | 0.0000 |

순진하게 읽으면: **"통합과 세계에 대한 열림은 비트 대 비트로 맞바뀐다."**
그리고 이게 **xor(선형) + maj·and·or-and(비선형 3종)** 에서 **전부** 성립해서 일반 법칙처럼
보였다.

### 실제로는 **측도 아티팩트**였다

입력을 **평균내면** 그건 입력을 **시스템 내부 잡음**으로 취급하는 것이고, 그러면 구동된 유닛이
독립 난수가 된다. Φ 는 **절단에 대한 최소값**이므로, 그 유닛 하나를 떼는 절단이 I=0 을 읽고
전체 점수를 0 으로 끌어내린다. **세포형은 무관했다** — 잡음 구동 유닛 하나면 어떤 min-over-cuts
측도든 0 이 된다.

IIT 는 그렇게 하지 않는다. **외부 입력은 배경조건(background condition)이고 고정된다.**
평균 대신 조건화하면:

```
driver 를 0 으로 고정      Φ = 1.0000
driver 를 1 로 고정        Φ = 1.0000     ← 두 배경 모두에서 통합 온전
두 배경의 출력분포가 다름                   ← 그런데도 세계가 도달한다
```

⟹ 코어는 **Φ 와 function 을 동시에** 갖는다. "맞바꿈 법칙" 은 내 평균 방식의 버그였다.

> **교훈**: 네 가지 세포형을 통과한 결과도 시스템이 아니라 **추정기의 성질**일 수 있다.
> 가리는 법은 **그 측도가 입력을 실제로 어떻게 다루는지 읽는 것**이다.

## 수리 후 구성과 결과

고리 XOR + 유닛 0 이 **배경조건**인 구동 비트를 XOR. 코어는 배경=실제 입력, 죽은 쌍둥이는
배경=상수. 둘 다 "고정 배경의 같은 고리" 라 **Φ 가 구성상 일치**하고, 출력분포가 입력에 따라
움직이는 건 코어뿐이라 **기능은 코어에만** 있다.

```
system                              Phi     function
core (background = input)        1.0000       1.0000
matched-dead (background fixed)  1.0000       0.0000

🟢 CONTROL HOLDS — Φ 가 정확히 일치(1.0000)하는데 기능은 1.0000 → 0.0000
```

두 시스템은 **Φ 로는 구별 불가**이고 **세계가 닿는지에서는 최대로 다르다.**
⟹ "Φ>0 이므로 이 시스템은 X 한다" 형태의 논증은 **구성적으로 반박**된다.
Φ 는 내부 구조에 대한 주장일 **뿐**이고, 기능은 **직교 축에서 따로 벌어야** 한다.
