# V6_14 — 필요 규모는 **LLM 스케일이 아니다** (자연문 규모 사다리 · ON-STANDARD)

**status:** 🔑 코퍼스 성질 실측 + 외삽 · **ON-STANDARD** · 모델 없음 · 판정 아님
**cost:** $0 · 정규식 + 세기 · 분 단위
**runs:** `python3 lab/v6/natural_scale_ladder.py`
**답하는 물음:** 설계 발산의 **D** — *"MB 규모로 되는가, 아니면 데이터 규모 칸을 열어야 하는가"*

## 왜 이걸 잴 수 있나

[[V6_13]] 이 4.8MB 자연문에서 **개체 쌍의 82% 가 딱 한 번** 나온다는 걸 쟀다. 거기서
"반복이 없으니 암기가 막힌다" 까지는 나왔지만, **그게 코퍼스가 작아서인지 자연문의 성질인지**
는 몰랐다. 그건 **논쟁거리가 아니라 측정거리**다 — 같은 코퍼스를 크기별로 잘라 곡선을 보면 된다.

## 측정 (같은 코퍼스의 중첩 접두부 · 추출 방식은 V6_13 과 동일)

```
    MB    문장     개체      쌍        1회      ≥2회     ≥3회   쌍/개체
  0.30   2,170   4,281   13,785     98.4%    1.6%    0.2%    3.22
  0.60   4,327   7,497   26,742     96.5%    3.5%    0.4%    3.57
  1.20   8,702  13,089   53,401     94.2%    5.8%    0.8%    4.08
  2.40  17,381  21,651  100,516     90.3%    9.7%    1.4%    4.64
  4.81  35,055  33,183  181,337     82.0%   18.0%    2.4%    5.46
```

**반복은 규모와 함께 온다.** 16배 텍스트에서 싱글턴이 98.4% → 82.0% (**−16.4 포인트**),
≥3회는 0.2% → 2.4% (**12배**). 곡선이 매우 깨끗하다.

## 외삽 — 멱법칙 적합 (log-log · R² 0.99+)

```
≥2회 관측   alpha = 0.845   R² = 0.9935
    25% 도달 →    7.0 MB  (현재의 ~1.5배)
    50% 도달 →   15.9 MB  (~3배)
    80% 도달 →   27.7 MB  (~6배)

≥3회 관측   alpha = 0.897   R² = 0.9961
    25% 도달 →   61.1 MB  (~13배)
    50% 도달 →  132.4 MB  (~28배)
    80% 도달 →  223.6 MB  (~46배)
```

## 🔑 이게 데이터-규모 물음을 다시 씁니다

지금까지 이 저장소의 서술은 이랬다:

> anima 코퍼스는 MB, LLM 은 ~10¹² 토큰 — **5~6 자릿수 차이**. 그게 유일하게 안 열어본 칸.

그 자릿수는 **토큰 총량**의 차이다. 그런데 **조성이 필요로 하는 성질은 총량이 아니라
쌍 반복**이고, 그 성질은:

```
쌍이 절반이라도 2회 이상 보이려면          ~16 MB     (3배)
쌍이 절반이라도 3회 이상 보이려면         ~132 MB    (28배)
쌍의 80% 가 3회 이상 보이려면             ~224 MB    (46배)
```

**5~6 자릿수가 아니라 1~2 자릿수다.** TB 가 아니라 **수십~수백 MB**.

⟹ "LLM 데이터 규모를 열어야 한다" 는 프레임이 과장이었을 수 있다. 필요한 것은
**같은 종류 텍스트를 30~50배** 더 모으는 것이고, 그건 렌트 규모가 아니라 다운로드 규모다.

## ⚠️ 이 외삽을 어디까지 믿을 것인가

- **측정 구간은 16배**(0.3→4.8MB)인데 **46배까지 외삽**한다. 마지막 줄은 측정 밖이다.
- **중첩 접두부**라 독립 표본이 아니다. 다른 코퍼스는 어휘 증가율(Heaps 지수)이 달라
  기울기가 바뀔 수 있다.
- 개체 추출이 **대문자 연속**이라 과다 계수하고, "쌍" 은 **문장 공기**이지 진술된 관계가
  아니다([[V6_13]] 와 같은 한계) — 진짜 관계 기준이면 곡선이 오른쪽으로 밀린다.
- **"≥3회면 일반화 가능"** 은 내가 고른 대리 기준이지 확립된 임계가 아니다. 그 숫자가
  바뀌면 필요 MB 도 바뀐다.

그래서 이 카드가 확정하는 것은 **"수십~수백 MB 자릿수"** 이지 특정 수치가 아니다.

## 다음에 이걸 확정하는 법 (가정 아닌 측정)

- **다른 코퍼스**(같은 크기, 다른 출처)로 곡선을 재서 기울기가 재현되는지 — 접두부
  비독립성을 깬다.
- **진짜 관계**(공기 아닌 진술 관계) 기준으로 다시 재서 곡선이 얼마나 밀리는지.
- 실제로 **~30MB 를 모아** 외삽점을 하나 찍어보기 — 외삽 대신 측정.

**아슬아슬한 재현**으로 읽어야 하고, 그래서 아래처럼 **점추정을 버리고 범위로 간다**.

### 필요 코퍼스 — 점추정 → **범위** (두 표본추출 방식)

```
                        중첩접두부    서로소표본     범위
쌍의 50% 가 ≥2회          15.9 MB      16.9 MB     16–17 MB
쌍의 80% 가 ≥2회          27.7 MB      33.3 MB     28–33 MB
쌍의 50% 가 ≥3회         132.4 MB      49.0 MB     49–132 MB
쌍의 80% 가 ≥3회         223.6 MB      76.7 MB     77–224 MB
```

`≥2회` 계열은 두 방식이 거의 일치하고, `≥3회` 계열은 **2.7배까지 벌어진다** — 외삽 구간이
멀수록 방식 차이가 증폭된다는 뜻이다. 그러니 이 카드가 확정하는 것은 다시 한번 **자릿수**다.

### 🔀 세 번째 독립 방법과도 같은 자릿수

발산 07 의 **암기 경제학** 논증(3.6 비트/파라미터 ⟹ 303M 용량 ~170MB · 압력 시작 ~1~3GB)이
전혀 다른 경로로 같은 대역에 떨어진다.

```
쌍 반복 (중첩)      49–224 MB
쌍 반복 (서로소)    49–133 MB
암기 경제학         170 MB (용량) · 1–3 GB (압력)
────────────────────────────────────────────
전부 10²~10³ MB — 수치는 3배 안에서 흔들리고 자릿수는 안 흔들린다
```

⟹ **"TB · 10¹² 토큰" 프레임 반박은 견고하다.** 남은 한계는 이 재현이 건드리지 않은 것들이다
— 조잡한 개체 추출 · 공기≠진술관계 · "≥3회면 일반화" 가정.

## ⚠️ 진짜 관계 기준 재측정 — **내 예측이 방향부터 틀렸다**

이 카드는 한계 절에서 이렇게 적었다:

> "쌍" 은 문장 공기이지 진술된 관계가 아니다 — **진짜 관계 기준이면 곡선이 오른쪽으로 밀린다**.

실행했다(`natural_relation_ladder.py` · 두 개체 **사이**의 간격이 짧고(≤40자) 관계어를 담을
때만 쌍으로 셈 — 계사·소유격·동격 쉼표·관계 전치사). **반대로 밀렸다.**

```
기준          4.81MB 쌍 수        1회 비율
공기         181,337              82.0%
진술관계      35,774 (19.7% 생존)  71.9%   ← 싱글턴이 오히려 낮다

필요 코퍼스            공기        진술관계
50% 가 ≥2회          15.9 MB       7.7 MB
80% 가 ≥2회          27.7 MB      12.1 MB
50% 가 ≥3회         142.0 MB      43.0 MB   ← 0.30배, 왼쪽으로
80% 가 ≥3회         241.9 MB      63.2 MB
```

### 왜 반대인가 — 기전이 쌍 개수에 보인다

엄격하게 재면 쌍의 **80% 가 탈락**하는데(181,337 → 35,774), **살아남은 것들이 더 반복된다**
(싱글턴 82.0% → 71.9%).

> **싱글턴이 많았던 건 우연한 공기 쪽이었다.** 실제로 **진술된** 관계는 다시 진술되는 경향이 있다.

그러니 엄격한 기준은 단지 **더 어려운 시험이 아니라 더 깨끗한 시험**이다 — 다시 나타나지 않는
잡음 쌍을 걷어낸다.

### 결론에 미치는 영향

"TB 가 아니다" 주장이 **여유를 두고 살아남는다**. 더 엄격하고 더 방어 가능한 기준이 텍스트를
**덜** 요구하기 때문이다. 세 방법 대역이 이렇게 갱신된다:

```
쌍 반복 · 공기 기준        49 – 242 MB
쌍 반복 · 진술관계 기준    43 –  63 MB   ← 가장 방어 가능한 기준이 가장 낮다
암기 경제학                170 MB (용량) · 1–3 GB (압력)
```

### 남은 한계

관계 검출이 **파서 없는 정규식**이라 여전히 조잡하다 — 관계어 목록이 임의적이고 40자 창도
임의적이다. 그래서 이 재측정이 확정하는 것은 **부호(더 엄격 ⟹ 덜 필요)**이지 43MB 라는 수치가
아니다. 그리고 `"≥3회면 일반화"` 대리 기준은 여전히 미확립이다.
