# H_9928 사전등록 — 🔒 **발사 전 동결** (오프셋 변화 재학습 · 실 엔진)

토이 사슬(H_9915~H_9927)이 낸 효과 크기: 오라클 없이 **못 본 오프셋 0.74~0.82**.
이제 **실제 트레이너**로 같은 처방을 태운다. 토이가 못 건드린 것 — `val`·`λ`·실 코퍼스·실
손실·실 스케줄 — 이 전부 들어온다.

## 무엇이 바뀌었나 (계기)

`anima-py corpus storebind --sb-gap-jitter 0,1,2,3,5,7` 신설. 학습 라인의 연산자-질의 거리가
그 집합에서 뽑힌다. **평가 매니페스트는 지터하지 않는다** — 판정 사다리는 `evaluate` 가 만들고,
코퍼스에 구우면 시험 분포로 학습하는 것이 된다(H_9922 가 내 증거 안에서 잡은 함정).
플래그 부재 = 이전 코퍼스와 **바이트 동일**(검증함) · `0` 미포함은 **거부**(학습된 조건은 모든
판정이 첫 번째로 읽는 회귀 통제).

## 🔒 판정표

우연 0.5 · 팔당 128 · 바는 **신설하지 않는다**:
**오라클 ≥0.90**(이 파일이 원래 쓰던 배선 게이트) · **붕괴 ≤0.70**(H_9915 동결값).

| 게이트 | 조건 | 결과 |
|---|---|---|
| G1 | δ=0 오라클 < 0.90 | **회귀** — 학습된 조건을 잃음, 판정 없음 |
| G2 | 학습에 쓴 δ 중 하나라도 오라클 < 0.90 | **미학습** — 지터가 안 먹음, 판정 없음 |

| # | 조건(보류 δ = 4·6·8, 학습에 없음) | 판정 |
|---|---|---|
| 1 | 보류 평균 ≥0.74 ∧ 최소 ≥0.65 | **TOY-CONFIRMED** — 토이 추정(0.74~0.82)이 실 엔진에서 재현 |
| 2 | 0.70 < 보류 평균 < 0.74 | **TOY-LOW** — 방향 맞고 크기는 토이가 낙관적이었음 |
| 3 | 보류 평균 ≤ 0.70 | **TOY-REFUTED** — 토이가 실 트레이너를 예측 못 함 |
| 4 | 위 어디에도 안 맞음(최소만 미달 등) | **PENDING** — 벡터 등록, 표제 없음 |

바 0.74/0.65 의 출처: H_9927 의 무오라클 보류 평균 **0.7438~0.8198** 과 최소 **0.6687~0.6875**
의 각 하단. 즉 **토이가 낸 하한을 그대로 재현 기준으로 삼는다** — 사후에 고른 값이 아니다.
