# V6_P1e — 빠진 편향은 **기하가 아니라 조합**이었다 (판독구가 신호를 버리고 있었다)

## 물음

latin 은 답이 유일한데 모델이 0.0417 을 냈다. **무엇이 그 답에 닿는가?**
같은 학습 모델·같은 seed·같은 표에 **판독구만 바꿔서** 셋을 비교했다.

```
argmax      P1 이 쓰던 것 — 칸마다 독립적으로 최고 로짓을 고른다
hungarian   순열 편향 — 한 행/열의 held-out 칸들은 그 행을 순열로 완성해야 하므로
            독립이 아니라 **함께** 배정한다 (모델 점수로 탐욕 배정)
propagate   순수 제약 전파 — **모델을 아예 안 쓴다**
```

## 결과 (3 seed · 우연 0.1250)

| 표 | 판독구 | held-out |
|---|---|---|
| cyclic | argmax | 0.6875 |
| cyclic | **hungarian** | **0.9167** |
| cyclic | **propagate** | **1.0000** |
| latin | argmax | 0.0417 |
| latin | **hungarian** | **0.4375** ← 10배 도약 |
| latin | **propagate** | **1.0000** |

## 세 가지가 한꺼번에 나온다

**① 제약 전파가 두 표를 모델 없이 정확히 푼다(1.0000).** 정보는 전부 거기 있었고,
필요한 건 **올바른 알고리즘**이지 더 나은 임베딩이 아니었다.

**② 모델은 생각만큼 눈멀지 않았다.** latin 에서 판독구만 순열-인지로 바꾸니
**0.0417 → 0.4375**(10배, 우연의 3.5배)다. 학습된 로짓은 **쓸 수 있는 신호를 갖고 있었고,
칸별 독립 argmax 가 그걸 버리고 있었다.** cyclic 도 0.6875 → 0.9167 로 같은 방향이다.

**③ 그래서 빠진 편향은 조합적이다.** [[V6_P1c]] 는 "구조에 맞아떨어진 편향" 이라 했고 그건
맞지만, 그 편향이 **임베딩 기하**(군-덧셈 결합)일 필요는 없었다. latin 에서 통하는 건
**판독 시점의 결합 제약**이다.

## LANE-BUS 로 되돌아오는 함의 — 이게 실질이다

버스는 **위치마다 독립적으로** 가산 쓰기를 한다. 그게 정확히 **칸별 독립 argmax** 의 실패
양태다. [[V6_P0]] 이 경합을 "보이는 불일치" 로 만든 것은 좋았지만, 거기서 **함께 배정**하는
데까지는 가지 않았다.

⟹ **버스에 필요한 것은 위치-협상이 아니라 위치-공동배정(joint assignment)** 이다.
이 표에서 그 차이가 0.0417 과 0.4375 를 갈랐다.

## 주장하지 않는 것

제약 전파가 1.0000 인 것은 **이 과제군이 조합 제약으로 완전히 결정되기 때문**이지 어떤 일반
능력의 증거가 아니다. 실제 관계 표가 라틴방진일 이유는 없고, 그러면 전파가 풀 것도 없다.
여기서 얻는 것은 좁고 실용적이다:

> **정보가 있는데 못 읽고 있다면, 임베딩을 고치기 전에 판독구를 의심하라.**
