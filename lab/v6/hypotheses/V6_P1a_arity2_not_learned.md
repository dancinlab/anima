## P1 이 묻는 것

[[V6_5]] 의 P0 은 **표면**이 쓸 만하다는 것만 보였다 — 두 유능한 레인이 한 로짓 행을 조용한
오염 없이 공유한다. 거기서 두 레인은 **일부러 오라클**이었다. P1 은 오라클을 뗀다.

설계가 존재하는 이유는 용량 사다리다: replay 를 조금이라도 섞으면 조성 0.000, 안 섞으면 언어
사망. 한 CE 가 둘을 못 섬긴다. 그 해법이 레인 분리이므로 P1 은 두 반쪽을 **동시에**(공동주) 묻는다.

```
(a) WORKSPACE 가 store 에서 held-out 2-slot 조성을 배우는가   ← 진짜 위험한 쪽
(b) 트렁크의 FORM 이 살아남는가                                ← 구성상 참
```

**(b) 는 정직하게 먼저 말한다**: comp 헤드가 **detach 된** 표현을 읽으므로 comp 손실이 트렁크에
도달할 수 없고, 따라서 형식 보존은 **구성상 참**이다. 그건 설계의 요점이지 발견이 아니며,
나중에 누가 증거로 보고하지 않도록 파일에도 박아뒀다.
