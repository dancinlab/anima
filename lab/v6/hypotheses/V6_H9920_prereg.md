# H_9920 사전등록 — 🔒 **발사 전 동결** (회전은 매끄러운가, 제멋대로인가)

H_9919 가 낸 것: 연산자 비트는 트렁크에 **남아 있고 방향만 회전**했다(전이=우연 0.48~0.58 vs
조건내부 0.75~0.81 > 실측 섞기천장 0.6875). 다음 수리 후보는 **판독구를 오프셋-불변으로**
만드는 것인데, **그게 가능한지 자체가 회전의 모양에 달려 있다.**

## 왜 이 측정이 ①의 선행조건인가

```
매끄러운 회전  δ 가 커질수록 방향이 조금씩 연속으로 돈다
              ⟹ 정렬(재중심화·회전 보정)로 하나의 고정 사상이 전 오프셋을 읽을 수 있다
제멋대로       δ 마다 방향이 무관하게 튄다
              ⟹ 정렬로는 못 푼다. 오프셋별 판독을 두거나 표현 자체를 바꿔야 한다
```

## 계기

각 δ ∈ {0..8} 에서 **조건 내부** 선형 연산자 판독기 `w_δ` 를 맞추고(각 96 프롬프트: is 48 /
not 48), 방향끼리 **코사인 유사도**를 잰다. 1차 지표 두 개:

- **인접 코사인** `cos(w_δ, w_{δ+1})` — 연속성
- **기준 코사인** `cos(w_0, w_δ)` — 학습 오프셋에서 얼마나 멀어졌나

## 🔒 바닥은 실측한다

방향 벡터는 d=3784 에 n=96 로 적합되므로 **무작위 두 방향의 코사인도 0 이 아니다.** 그래서
**라벨을 섞어 맞춘 방향 쌍**의 코사인 분포를 20회 뽑아 그 **최대**를 바닥으로 쓴다
(`chance-level-must-be-derived-per-metric`). 아래 바는 그 실측 바닥 `F` 로 표현한다.

## 🔒 판정표

| 게이트 | 조건 | 결과 |
|---|---|---|
| G1 | δ=0 조건내부 정확도 < 0.90 | **INSTRUMENT-DEAD** — 중단 |
| G2 | 어떤 δ 의 조건내부 정확도가 실측 섞기천장 이하 | 그 δ 는 **방향 미식별**로 표시하고 코사인 계산서 제외 |

| # | 조건 | 판정 |
|---|---|---|
| 1 | 인접 코사인 **전부** > F ∧ 기준 코사인이 δ 에 대해 **단조 감소** | **SMOOTH 확정** — 정렬 수리 가능 |
| 2 | 인접 코사인 **전부** ≤ F | **ARBITRARY 확정** — 정렬 수리 불가, 오프셋별 판독 또는 표현 교체 |
| 3 | 인접은 > F 인데 기준이 비단조 | **SMOOTH-LOCAL** — 국소 연속이나 전역 정렬은 미보장(①은 국소 창에서만 시도) |
| 4 | 위 어디에도 안 맞음 | **PENDING** — 관측 행렬만 등록, 표제 없음 |
