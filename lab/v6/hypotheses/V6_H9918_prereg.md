# H_9918 사전등록 — 🔒 **발사 전 동결** (다양성은 **등급**인가 **스위치**인가)

H_9917 이 ENTROPY 를 **지지**로만 남긴 이유: 두 점(서로 다른 문자 **1종** vs **5종**)만 재서
"다양성이 변수"까지는 갈랐지만 **연속 변주를 안 했다.** 여기서 채운다.

## 설계 — 한 가지만 변한다

틈 5바이트를 **전부 글자**로 고정하고(바이트 클래스는 H_9917 이 이미 KILL) **서로 다른 문자
수 k ∈ {1,2,3,5}** 만 바꾼다. 연산자 오프셋 15·엔티티 학습된 5바이트도 고정.

```
k=1  "zzzzz"  (H_9917 의 +0.693 재현 기준)
k=2  2글자를 5칸에 채움
k=3  3글자를 5칸에 채움
k=5  5칸 모두 다름 (H_9917 의 -0.534 재현 기준)
```

## 🔒 예측 (배타적)

```
GRADED    κ 가 k 에 따라 단조 감소하고 인접 간격이 실질적 ⟹ 다양성은 연속 등급
SWITCH    k=1 만 양수이고 k=2·3·5 가 서로 붙어 있음 ⟹ "변화가 조금이라도 있나" 이진 스위치
NULL      k 에 따라 안 변함 ⟹ H_9917 의 축이 다양성이 아니었음, 재해석 필요
```

## 🔒 판정표

우연 0.5 · 팔당 128 · 1차 지표 **κ = mean(is칸) − mean(not칸)**.
바는 **새로 발명하지 않는다** — H_9917 의 두 극: 양 = κ ≥ +0.60 · 음 = κ ≤ −0.05.
인접 간격의 "실질" 기준도 H_9917 실측에서 가져온다: 그 카드의 양극 두 점 간격
(+0.957 − 0.693 = 0.264)의 **절반 = 0.13**.

| 게이트 | 조건 | 결과 |
|---|---|---|
| G1 | k=1 κ < +0.60 **또는** k=5 κ > −0.05 | **재현 실패 → 배치 INVALID** |

| # | 조건 | 판정 |
|---|---|---|
| 1 | κ(1) > κ(2) > κ(3) > κ(5) ∧ 인접 간격 3개 모두 ≥ 0.13 | **GRADED 확정** |
| 2 | κ(1) ≥ +0.60 ∧ κ(2)·κ(3)·κ(5) 모두 ≤ −0.05 ∧ max−min(그 셋) ≤ 0.13 | **SWITCH 확정** |
| 3 | 순서는 단조인데 간격 하나 이상이 < 0.13 | **GRADED-WEAK** — 방향만, 등급 주장 금지 |
| 4 | 위 어디에도 안 맞음(비단조 포함) | **PENDING** — 관측 벡터만 등록, 표제 없음 |

## 못 정하는 것

- k 는 **서로 다른 문자 수**지 섀넌 엔트로피가 아니다. 배치(예: `ababa` vs `aabba`)는 안 잰다.
- ckpt 1개 · seed 1개 · 팔당 128 · 합성 드릴 ⟹ **drill-only**(p9).
