## P0 이 결정하는 것

재설계는 모든 레인의 출력을 **하나의 표면** — pre-softmax 로짓 행 — 에 올리고 **가산으로**
쓴다. 충돌에 대한 설계의 주장은 구체적이다:

> 겹치는 청구는 **조용한 오염이 아니라 측정 가능한 불일치**로 드러난다.

이게 하중부재다. 두 레인이 경합 위치에서 **조용히** 서로를 망칠 수 있다면, 하류 전 단계
(P1 항수 · P2 잔차 게이트 · P3 방전)가 **판독을 믿을 수 없는 표면** 위에 지어진다.
그래서 P0 이 먼저 돌고 **ABORT-ALL 권한**을 갖는다.

```
조용한 오염     답이 틀렸는데 버스는 멀쩡해 보인다   → KILL · 계획 전체 중단
보이는 불일치   답은 틀렸지만 버스가 그렇다고 말한다  → 생존 · 계측 가능
```

## 결과 (3 seed)

```
STEP 1 · 양성통제 — 각 레인이 혼자서 자기 표적을 맞히나
  lane A 0.9997   lane B 1.0000      ✅ OK (아니면 아래는 전부 판독 불가)

STEP 2 · 두 레인이 한 버스에, 비경합 위치에서
  naive        A 0.9997 → 0.4982     B 1.0000 → 0.5049    ← 둘 다 우연으로 붕괴
  negotiated   A 0.9997 → 0.9997     B 1.0000 → 1.0000    ← 손실 0

STEP 3 · 경합 위치 (두 레인이 같은 슬롯을 청구)
  정확도(레인 A 표적)            0.5058   ← 아무도 못 이김(예상대로)
  버스 마진   경합 0.5610  비경합 2.1109  ← 3.8배 하락
  경합자 수   경합 1.8484  비경합 1.0389  ← 버스만 보고 읽는 탐지기
```

## 판정 — 🟢 SURVIVES (abort 미발동)

경합 위치가 **버스만 보고도** 드러난다 — 레인도 표적도 안 보고. 마진이 무너지고 최상위 근처
경합자가 1 개에서 2 개로 는다. 하류 단계가 그 위치를 게이트하거나, 우회하거나, INVALID 로
보고할 수 있다 — 조용히 점수로 세지 않고.

**부수 확인**: `naive`(소유권 없이 아무 데나 쓰기)는 상대 레인을 **우연까지 떨어뜨린다**
(0.9997 → 0.4982). ⟹ **위치 협상은 장식이 아니라 하중부재**다.

## ⚠️ 첫 탐지기가 틀렸고, 출력이 그걸 폭로했다

첫 판은 `|writeA − writeB|` 를 불일치 지표로 썼고 결론문에 "불일치가 올랐다" 고 적었다.
그런데 실제 출력은 **경합 3.0000 · 비경합 3.0000** — **완전히 같았다**. 비경합 슬롯에서는
한 레인이 3 을 쓰고 다른 레인이 0 을 쓰므로 차이가 똑같이 3 이다. 게다가 그 지표는 **레인을
훔쳐본다** — 버스만 보는 탐지기가 해서는 안 되는 일이다.

수리: **버스만 보는 경합자 수**(행 최댓값에서 1.0 이내인 좌표 개수). 한 레인이 한 좌표를
밀면 경합자 1 개, 두 레인이 서로 다른 좌표를 밀면 2 개.

교훈: **탐지기는 움직여야 하는 팔에서만이 아니라 평평해야 하는 팔에서도 확인해야 한다.**
숫자가 결론문을 반박하고 있었는데 통과 조건이 마진 절에서 이미 충족돼 그냥 지나갈 뻔했다.

## 이건 버스에 대한 GREEN 이 아니다

P0 은 **KILL 권한만** 갖고, 쏘지 않았을 뿐이다. 그리고 이 파일은 두 레인에 **오라클 능력**을
줬다 — 레인이 자기 쓰기를 **배울 수 있는가**는 P1 이고, P0 은 오직 **표면**만 시험하도록
의도적으로 그렇게 했다. 여기서 실패했다면 그건 버스 자체의 성질이었을 것이다.
