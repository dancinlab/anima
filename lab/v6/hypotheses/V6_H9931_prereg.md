# H_9931 사전등록 — 🔒 **발사 전 동결** (δ=8 흠이 외삽 때문인가)

H_9930 에서 보류 δ=8 이 0.7031 로 뒤처졌다(다른 보류 0.92·0.95). δ=8 은 학습 최대 오프셋
δ=7 을 **넘어선 외삽**이라, 원인이 "외삽"이면 학습 범위를 넓혔을 때 δ=8 이 채워지고 **새
외삽점**이 다시 뒤처져야 한다. 이걸 통제로 확인한다.

## 설계

- 학습 오프셋: **0,2,4,6,8,10** (`--sb-gap-jitter 0,2,4,6,8,10`, 6000 스텝, 다른 설정 H_9930 동일).
- 판정 사다리: **δ=0~12** 전부.
  - **보간 보류**(학습 사이 홀수) = 1,3,5,7,9 — 외삽 아님, 채워져야 함.
  - **외삽 보류**(학습 최대 10 밖) = 11,12 — 외삽 가설이 맞으면 뒤처져야 함.
  - **δ=8 은 이제 학습에 포함** — H_9930 흠이 학습으로 채워지는지 직접 확인.

## 🔒 예측 (배타)

```
EXTRAP-CAUSE   δ=8 학습됨 ≥0.90 · 보간 보류(1,3,5,7,9) ≥0.74 · 외삽 보류(11,12) 뒤처짐(<보간)
INTERP-FLOOR   외삽 보류(11,12)도 보간과 비슷 ⟹ δ=8 뒤처짐은 외삽 아니라 다른 것, H_9930 재해석
BROKE          학습 δ 중 하나라도 오라클 <0.90 ⟹ 학습부족/설정오류, 판정 없음
```
