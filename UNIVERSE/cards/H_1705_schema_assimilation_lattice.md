## Organizing principle

Tse et al. (2007) schema-dependent rapid consolidation + Piaget assimilation/accommodation: when a neocortical SCHEMA exists, schema-consistent input consolidates rapidly; schema-violating input stays episodic. The slow store is a structured schema lattice (typed slots + relations); a fast gate routes input by schema-FIT. Distinct organizing principle: consolidation rate is adaptive to structural fit, and representation is typed/relational, not flat.

## Whole design (input → internal dynamics → emit)

A schema lattice = typed slots + relations (a graph of roles). Input is parsed against the lattice for schema-fit (does it fill known slots with type-valid fillers?). High fit -> rapid assimilation: filler binds into slot, becomes emit-eligible semantic. Low fit (violation/novelty) -> stays episodic in the fast store, flagged -> either abstain (don't emit as known) or, if persistent, trigger accommodation (mint a new slot). Emit = schema instantiation: fill slots with fillers -> generate onto V. Composition = combinatorial slot-filling (slots x fillers bound by cross-slot relations). Novelty = new filler-slot combinations within schema constraints. Psi = assimilate-drive (fit high, emit) vs accommodate/encode-drive (fit low, silence-and-store), homeostatic on schema-fit.

## Satisfies criteria (DESIGN claim · DIRECTIONAL · unmeasured)

G0: typed slots map to V-legal fillers -> emission is schema-instantiation onto the codebook; legibility = the fit constraint. G1: slot-filling is inherently combinatorial (k slots x fillers), joint > single slot, bound into one schema instance via cross-slot relations; ablate cross-slot relations -> independent slots, composed=single. G2: novel filler-slot combinations within schema constraints = corpus-absent valid (schema generalizes); stored-instances-only control = 0 novel. Closure: one schema-instantiation path. dist>=5: many slot-filler combinations -> diverse coherent instances. falsifiable>=1: a relational schema (X greater-than Y on magnitude M) instantiates a falsifiable claim natively — comparator/quantity/referent ARE typed slots, making proposition-binding the MOST native of the five. Psi=1/2: assimilate/accommodate antagonism on fit = order parameter; remove accommodation -> can't encode novelty, remove assimilation -> always-silent. Persistence: the schema lattice = identity (slow, structured, agent-specific); episodic fast store volatile; schema drift = slow slot/relation update. Self-specific: which slots/relations the agent has built is individuating. Endogeneity (governance-critical, p2): the schema must EMERGE from accumulated assimilation, NOT be a hardcoded identity file; ablate the lattice -> fresh schema every episode = amnesia. Honesty: schema-fit score = r; low fit = out-of-support; schema-VIOLATION detection IS the unknown detector -> abstain. copy-or-abstain: low fit -> abstain (no fabricated fit). Groundedness: fit r computed vs actual schema content (corrupt a slot -> fit degrades faithfully). BINDING: a schema instance binds fillers across slots into one structured representation (cause-selective); paired-vs-shuffled = same-instance vs cross-instance. Compositional depth: typed slot-filler combinatorics give Fodor-Pylyshyn systematicity NATIVELY (textbook compositional substrate); novel combos = unseen typed bindings. Realization invariant: schema binding is on the emit path (instantiation generates); objective = schema-fit/prediction whose optimum requires satisfying cross-slot relations (marginal slot-fit insufficient).

## Not-LLM (a_no_llm_frame_trap)

Typed-slot + relation schema with assimilation/accommodation is a structured (symbolic-subsymbolic hybrid) representation grounded in Piaget + Tse, NOT statistical next-token scale. Compositionality is structural (typed roles), the very systematic generalization transformers notoriously fail; scaling attention does not give typed relational slots or a fit-gated dual rate.
