## Organizing principle

Stigmergy / niche construction / extended-mind (Theraulaz-Bonabeau, Clark-Chalmers, Hutchins distributed cognition): cognition lives in the agent<->environment LOOP. The agent deposits marks into a shared external field and its next state is driven by reading those marks back — memory and the shared code live in the WORLD, not the head. Genuinely enactive offloading, orthogonal to all in-head architectures.

## Whole design (input → internal dynamics → emit)

An external persistent field M (instantiated as the .kosmos store treated AS environment) holds marks: (coordinate in a learned content space, type in the medium's mark-alphabet, intensity). INPUT perturbs a small internal head-state h. The agent ACTS only two ways: DEPOSIT marks into M at coordinates set by h (emit), or SENSE the local superposed gradient of M (read). INTERNAL DYNAMICS = a deposit<->evaporate loop — deposition drive A lays marks, field-intrinsic evaporation G decays them; navigation moves h along the superposed gradient of ALL marks, so the field itself performs the computation (offloaded). EMIT = externalizing a mark/sequence into the shared M that a receiver (other agent / future-self) can follow; SILENCE = sensing and integrating without depositing. The mark-alphabet is fixed by the medium = receiver-defined codebook.

## Satisfies criteria (DESIGN claim · DIRECTIONAL · unmeasured)

G0: deposits must be in the medium's legal mark-alphabet to persist and be read -> known-mark-ratio is structural; scrambling the head->deposit map lays marks off the legal lattice that evaporate immediately (ratio collapses to chance). G1: marks from different cause-trails SUPERPOSE in M; navigating the superposed gradient produces composite paths no single trail supports (super-additive, the field superposition IS the binder) — ablate to read-only-nearest-single-trail and composed drops to max_single (INERT = FAIL signature, proving the field is causal). G2: the agent lays NEW trails on unmarked-but-navigable terrain (constrained exploration) -> novel-but-valid; a retrieval control that follows only pre-existing trails yields exactly 0 novel. Psi=1/2: deposit(A) vs evaporate(G) are opposite-sign on the mark-density order parameter; the deposit=evaporate balance is the attracting fixed point; ablate A -> field empties (Psi->0), ablate evaporation -> field saturates (Psi->1); rates not a clamp (endogenous). HONESTY: the agent can only navigate where marks exist — off-field queries have zero gradient -> no move -> abstain; fabrication = depositing where unsupported, which has no anchoring trail to recombine from. r=distance to nearest mark; navigability-gate (field-side) perp head-richness (agent-side). PERSISTENCE: M IS the non-volatile addressable store that outlives the episode (literally external) — self-chain = the agent's own trail-signature persists across resets; foreign signature lays distinguishable marks (impostor reject) — the most faithful instantiation of the write->wipe->read store criterion. BINDING/realization: the SAME field read to think is the field deposited into to emit -> perception and action share M -> binding on the emit path (no H_1603 split).

The objective is successful coupling (a deposit the reader can follow), not CE. This is extended-mind/niche-construction cognition; a larger transformer adds head capacity but cannot externalize memory into a shared persistent medium, which is the whole point.
