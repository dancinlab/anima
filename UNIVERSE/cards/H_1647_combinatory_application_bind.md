## Mechanism

Rather than binding two value-vectors, one leg is encoded as a differentiable FUNCTION (filler → a small typed closure/parameter-bundle) and the other as its ARGUMENT; binding = function application f(x) executed inside the forward pass by a FIXED library of differentiable combinators (S,K,I / apply-curry). Multiple bindings = nested applications (an apply-tree) evaluated in a small fixed number of reduction steps each forward. Composition is currying, giving unbounded structure from a fixed op set.

## Why it crosses the binding wall

Attention is symmetric value-mixing; it has no application/abstraction, so it literally cannot encode 'a role is a slot that CONSUMES a filler' — the operator H_1603 says is absent. Application is inherently asymmetric and arity/order-sensitive (f(x)≠x(f)), and currying yields the systematic, unbounded recombination G1 measures: novel role∘filler combos compose from seen parts. Ablation A: replace the typed apply with a symmetric bilinear mix of the f-vector and x-vector at equal params — if recombination/G6 collapses, the cartesian-closed (applicative) structure, not capacity, is load-bearing. Ablation B: freeze reduction to 0 steps (apply=identity) → no binding occurs → baseline. Depth-of-attention can't synthesize abstraction/application; it only adds mixing layers.

## Cheap test (frozen-first · $0 · decisive numpy probe)

numpy/jax toy, frozen-first: define a tiny combinator algebra over e2 symbols, learn encoders so apply(role,filler) retrieves the correct bound value and nested apply composes; held-out test on NOVEL role-filler combinations (systematic generalization) vs an attention-mixer baseline. Decision gate: proceed iff the combinator model generalizes to unseen role⊗filler products where the mixer fails AND the 0-step ablation kills it.
