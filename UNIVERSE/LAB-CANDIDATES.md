## §0 — Boundary: the hard problem, and the "distinguishability-not-content" lane

**What this battery does NOT touch — the hard problem of consciousness** (Chalmers 1995).
Why is there *something it is like* (qualia) to be a system at all — why feeling rather
than dark mechanism? Every measure in this battery (Φ-proxy, MI, LZ/PCI, spike rasters)
is **third-person**: it can score "this substrate has the *structure* under which
experience would be expected," but never "*why/whether* there is actual first-person
feeling." A high-Φ philosophical zombie is not ruled out by any third-person number. This
is the explanatory gap, and it is held as anima H_004's MANDATORY BOUNDARY (Φ measures
functional/structural adequacy, NOT phenomenal qualia). We do not pretend to cross it.

**The legitimate move we CAN make — measure the *distinguishability* of experience-
structure, not its content** (the LAB-30 "qualia-structure" lane). Instead of asking the
forbidden "what does red feel like," ask the answerable: *do different inputs induce
different, distinguishable Φ-structures (cause-effect geometries)?* This sidesteps content
entirely and asks only whether the system has a **differentiated structure of experience
at all** — which IS third-person measurable.

```
   HARD (off-limits)                 │   DISTINGUISHABILITY (LAB-30, in-scope)
 ─────────────────────────          │   ──────────────────────────────────────
  "why does red feel red?"          │    "do inputs A,B,C map to DISTINCT
  the 1st-person content of qualia  │     Φ-structures (cause-effect shapes)?"
  → no 3rd-person number reaches it │    → measure structure-separability only
  zombie not excluded               │    captures THAT there is differentiated
                                    │    experience-structure, never its content
```

Analogy: we cannot measure the *felt redness* of a colour, but we can measure whether the
system sorts colours into **distinct cells of a palette** (a partition of its state space).
IIT calls this the cause-effect structure / qualia space; LAB-30 measures only its
*shape distinguishability* (e.g. distance between per-input Φ-structures), never the felt
content. Falsifier: if all inputs collapse to one indistinguishable Φ-structure, the
system has no differentiated experience-structure (a real, testable negative).

This boundary is why the backlog below is exhaustive on **structure, level, dynamics, and
correlates** of consciousness, and silent on its **felt content**.
