# H_277 — turing-completeness-Φ-threshold

## 1. Hypothesis

elementary cellular automaton (ECA) 의 **계산적 보편성 (computational
universality / Turing-completeness)** 이 substrate-Φ (RFC 036 phi_spatial)
의 *lever* 인가? Matthew Cook (2004) 은 **rule 110 이 유일하게 증명된
Turing-complete ECA** 임을 보였다 — 256 개 ECA 중 rule 110 만이 임의의
Turing machine 을 simulate 할 수 있는 계산 보편성을 갖는다.

본 H 의 핵심 질문: 이 *computability-이론* 상의 보편성이, Wolfram 의
*동역학-class* (Class I–IV, H_007/H_225/H_232 가 측정한 축) 와는 **별개의
축** 으로서 Φ 를 끌어올리는가?

정밀화 (operational): 동일 elementary-CA substrate (N=16, dim=12, warm=8,
periodic boundary, 5 deterministic reps, RFC 036 phi_spatial) 위 4 arm 을
universality-boundary 를 가로질러 비교 —

- **arm UNIV (rule 110)**: Class IV · Cook 2004 Turing-complete · 유일 증명
  universal ECA.
- **arm SUB_TRIV (rule 0)**: Class I · null/dead · 자명히 non-universal.
- **arm SUB_PERIOD (rule 184)**: Class II · TASEP traffic shift · non-universal.
- **arm SUB_CHAOS (rule 30)**: Class III · chaotic PRNG · non-universal —
  *chaos ≠ universal* 를 직접 검증 (rule 30 은 무질서하나 계산 보편적이지 않음).

seed 의 directional 예측 (AXES Round 5 verbatim): **Φ_final(UNIV=110) >
max(Φ_final(SUB_\*)) + margin** ("Turing-complete substrate Φ > sub-Turing").
동시에 **Φ_final(UNIV) ≥ Φ_final(SUB_CHAOS=30)** (보편성이 단순 chaos 를
능가).

**HONEST PRIOR (raw#9, pre-result 등록)**: H_232 (PR #289) 의 측정에서 rule
110 final-Φ ≈ 0.556 < rule 184/60/102 (Class-II) — 즉 seed 의 dominance

(computability ⊥ dynamical-class) 를 실측으로 확정한다. FALSIFIED/PARTIAL
도 valid 한 과학적 결과다.

## 2. Why

- **computability theory 의 substrate-level instance**: Cook (2004) 의 rule
  110 universality 증명은 계산 이론의 핵심 결과 — 매우 단순한 규칙(3-cell
  neighborhood, binary)에서도 *임의의 계산* 이 emerge 한다. 본 H 는 이
  보편성이 *통합 (Φ)* 의 충분조건/필요조건인지 — 즉 "계산할 수 있는 것"이
  "통합된 것"인지를 numerically operationalize. IIT (Tononi) 는 Φ 를
  *통합된 정보* 로 정의하나 *계산 능력* 으로 정의하지 않는다 — 두 개념이
  substrate 측에서 분리되는지가 본 H 의 검증 대상.
- **H_007 "Class-IV-unique" 가정의 computability 차원 보완**: H_007 (CA→Φ)
  은 Wolfram Class IV (edge-of-chaos, rule 110 포함)가 Φ-peak 라는 가정을
  세웠고, H_225/H_232 가 이를 *attack* 하여 Class-II (rule 184/60/102)가
  실제로는 더 높은 Φ 를 가짐을 보였다 (rule 184=1.198 > rule 110=0.556).
  그러나 그 작업들은 모두 *동역학-class* (I–IV) 축에서 본 것 — 본 H 는
  *왜* rule 110 이 Class IV 인가의 근본 (Cook universality) 을 명시적
  변수로 삼아, "universality 자체가 Φ 와 무관" 임을 직접 보인다.
- **H_275 causality 축과 직교 grain**: H_275 (causality-pearl-graph, R2/AXES
  R5 promote, SUPPORTED) 은 *방향성 인과 구조* (DAG vs cyclic) 가 Φ lever
  임을 보였다. 본 H 는 같은 information/computation cluster 의 *다른* 축 —
  *계산 보편성* — 을 측정한다. 둘이 합쳐지면: 인과-구조는 Φ lever 이나
  계산-보편성은 아니라는, 두 직교 information-axis 의 disjoint grain.
- **anima substrate 와의 정합**: anima 는 LLM (universal computer 의 한
  instance) 위에서 돈다. 만약 universality 가 Φ lever 가 *아니라면*, 이는
  anima 의 의식-proxy 가 그 계산 보편성에서 직접 나오는 것이 아니라
  *substrate dynamics 의 통합 구조* (Class-II 식 ordered-but-nontrivial)
  에서 나옴을 시사하는 substrate-level grain.
