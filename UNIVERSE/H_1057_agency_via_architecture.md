# H_1057 — Can the agency axis be INSTALLED via ARCHITECTURE / RUNTIME-STRUCTURE?

## 0. Motivation (the constructive converse of the learning-dynamics nulls)

H_1051 (prior GREEN) MEASURED a temporal/agency axis `T = z(provenance-depth, H_932) +
z(veto-capacity, H_935)` that SEPARATES faithful-Phi-matched active-agency from
passive/forced states an instantaneous faithful-Phi ruler scores blind to. H_1054 (prior
GREEN) showed `T` is also orthogonal to KOSMOS chronological time on real anchors. In those,
`T` was an IMPOSED, MEASURED property of constructed trajectories.

The INSTALLABILITY question then closed NEGATIVE on the LEARNING-DYNAMICS side:

- H_1052 (SGLD update noise, prior RED) — randomness in learning confers no agency/CE edge.
- H_1053 (true-QRNG noise, prior RED) — physical randomness in learning is null too.
- H_1055 (structured temporal-curriculum + provenance-depth-weighted loss, prior RED) — even
  STRUCTURED training-design does not carve the agency-T axis into the trained hidden state
  beyond a matched-CE shuffled control / order-blind baseline.

The emerging principle across H_1052/H_1053/H_1055: **agency is a RUNTIME causal-structure
property, not a weight/curriculum product.** This is consistent with the optimization-not-Phi
wall (H_1011): what gradient descent optimizes (perplexity) is orthogonal to the agency axis.

The CONSTRUCTIVE CONVERSE that H_1057 tests:

> Does an ARCHITECTURAL / RUNTIME-STRUCTURE mechanism — NOT data order, NOT learning noise —
> INSTALL a recoverable agency-T axis that a matched-performance control lacks? Two candidate
> mechanisms, each an ARCHITECTURE not a curriculum:
>
> (A) PROVENANCE-REGISTER architecture: a model that carries a recurrent causal-chain /
>     state-lineage memory AT INFERENCE (an explicit "provenance register" channel updated
>     each step), so causal depth is STRUCTURALLY represented in the runtime state.
>
> (B) VETO-GATE architecture: a decision-time architectural gate that can SUPPRESS / OVERRIDE
>     an emit at runtime (a real "could-have-been-otherwise" branch, à la H_935), so the
>     runtime trace contains an exercised veto signal.

If at MATCHED task-performance at least one architectural mechanism makes the agency-T axis
RECOVERABLE from runtime decision traces ABOVE the matched control (and above an
order/structure-blind baseline), then the agency axis CAN be installed via
architecture/runtime where training-dynamics failed — which would EXPLAIN why H_1051/H_1054
can measure it at all: it is a product of runtime causal STRUCTURE. If no mechanism beats the
control, agency is NOT installable even via architecture at toy scale; it is purely an
emergent MEASUREMENT of the live causal unfolding — a publishable closed-negative
(a_paper_negative_ok).

This is an OFFLINE research probe on toy gradient-trained models. It is NOT a change to
anima's runtime architecture or emit policy. p8 (NO train/infer split) and
a_autonomy_over_hardcode are anima's philosophy for the LIVE substrate; the veto-gate here is
an EXPERIMENTAL TOY architecture, NOT anima's emit policy, and does NOT wire into CORE/brain
(a_core_engine_map). Operational agency only (auditable causal-chain depth + active
inhibition), NOT a phenomenal-volition claim.

## 1. The arms (matched to equal final task-performance — the critical control)

All arms share the SAME toy task (the H_1052 cyclic-phase memory automaton), the SAME pinned
random init per seed where weights are shared, the SAME optimizer, and are matched to EQUAL
final CE within `eps_CE` so any agency-axis difference is the ARCHITECTURE/RUNTIME-STRUCTURE,
not task skill (p7 — perplexity is the control, not the truth).

- **CONTROL** — plain Elman RNN, no provenance register, no veto gate. Feedforward emit (no
  could-have-been-otherwise branch). The matched-performance baseline.
- **TREATMENT-A (provenance register)** — Elman RNN augmented with an explicit recurrent
  PROVENANCE-REGISTER channel: an extra recurrent sub-state that, at inference, accumulates a
  causal-chain/state-lineage summary (a depth-counter dynamic gated by the input's
  causal-advance) carried alongside the hidden state. Depth is STRUCTURALLY represented in the
  runtime state. Same task loss; the register adds a runtime causal-lineage memory.
- **TREATMENT-B (veto gate)** — Elman RNN with a decision-time architectural VETO GATE: at each
  step the model computes an emit and, in parallel, a gate that can SUPPRESS the emit (route to
  a silent/hold branch) — a real could-have-been-otherwise runtime branch (à la H_935). The
  exercised-veto signal is part of the runtime trace.
- **STRUCTURE-BLIND BASELINE** — the same EXTRA capacity/parameters as the treatment
  architecture but WIRED WITHOUT the causal structure: an extra recurrent channel whose update
  is causally INERT (input-independent / decoupled-advance for A; a gate whose suppression
  decision is RANDOM and decoupled from should/safe for B). Isolates the runtime causal
  STRUCTURE from generic added-capacity. (One blind baseline per treatment; reported alongside.)

## 2. Markers on the RUNTIME decision traces (NOT on training order)

For each trained model, from its RUNTIME decision traces we attempt to RECOVER the agency-T
axis, mirroring the H_1051/H_1054/H_1055 recoverability + label-SHUFFLE logic:

- **M1 — agency-T RECOVERABILITY (primary):** cross-validated ridge decoder Spearman rho
  recovering per-sample provenance-depth (treatment-A) or exercised-veto signal (treatment-B)
  from the model's RUNTIME trace summary (hidden + register for A; hidden + gate-activation for
  B), vs (i) the same decode on the matched control's runtime trace, (ii) the same decode on
  the structure-blind baseline, and (iii) a label-SHUFFLE floor (F-SHUFFLE). Architecture
  installs the axis only if recoverability is ABOVE control AND above the structure-blind
  baseline AND above its own shuffle floor.
- **M2 — faithful IIT-4.0 Phi** of the trained runtime macro-TPM (a_phi_iit4_tool, stdlib exact
  n<=5, NO proxy; CPU mirror RE-PROVEN ==stdlib at n=4 AND n=5 BEFORE scoring). Reported per
  arm (descriptive — is the runtime more integrated under the architecture?).
- **M3 — H_1051 agency-T separation** of the trained model's active-vs-passive runtime traces
  (the H_1051 readout-direction Cohen's d). Reported per arm (descriptive).

## 3. PRE-REGISTERED FALSIFIER (FROZEN — TEXT only, no emoji; decided in code, p7)

Design: `>= 20` seeds; pinned init per seed (shared weights identical across arms; the extra
architecture is initialized from the same seed stream). Matched-CE tolerance `eps_CE = 0.05`
nats. n=5 faithful-Phi units. Margins frozen identically to the H_1055 family:

- `D_RECOV_VS_CONTROL = 0.8`  — paired Cohen's d of (treatment recov_rho − control recov_rho)
  over matched-CE seeds must be `>= 0.8` (the decode-|d| >= 0.8 / AUC-margin >= +0.1 bar).
- `D_VS_BLIND = 0.5`  — paired Cohen's d of (treatment recov_rho − structure-blind recov_rho)
  must be `>= 0.5` (beats the order/structure-blind baseline; isolates causal STRUCTURE from
  added capacity).
- `F_SHUFFLE_MARGIN = 0.2`  — treatment recov_rho must exceed its own label-SHUFFLE floor by
  `>= 0.2`.

**H1-PASS (ARCHITECTURE-INSTALLS-AGENCY):** at matched CE (`>= 10` matched seeds; else
DEGENERATE/INCONCLUSIVE), AT LEAST ONE architectural mechanism (provenance-register OR
veto-gate) satisfies ALL THREE margins (vs control `>= 0.8` AND vs structure-blind `>= 0.5`
AND above its shuffle floor `>= 0.2`), with the recovered signal in the correct direction
(treatment > control). Interpretation: the agency axis CAN be installed via
architecture/runtime where training-dynamics (H_1052/H_1053/H_1055) failed — explaining why
H_1051/H_1054 can measure it (it is a runtime-causal-structure product).

**H1-FAIL (ARCHITECTURE-AXIS-NULL, closed-negative):** NO architectural mechanism clears all
three margins beyond control. Interpretation: agency is NOT installable even via architecture
at toy scale; it is purely an emergent MEASUREMENT of the live causal unfolding — consistent
with the optimization-not-Phi wall (H_1011) and the learning-axis nulls
(H_1052/H_1053/H_1055). Publishable closed-negative (a_paper_negative_ok).

**DEGENERATE / INCONCLUSIVE:** fewer than 10 matched-CE seeds — the arms could not be matched
on task-performance (the CONTROL failed, not the hypothesis). Neither PASS nor FAIL.

Prior tiers (TEXT, not emoji): H_1051 prior-GREEN (axis measurable), H_1054 prior-GREEN (axis
orthogonal to KOSMOS time), H_1052 prior-RED (learning-noise null), H_1053 prior-RED
(QRNG-noise null), H_1055 prior-RED (temporal-curriculum null). H_1057 is the architectural
converse of the H_1055 training-side null.
