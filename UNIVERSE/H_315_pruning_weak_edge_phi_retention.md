# H_315 — PRUNING × IIT4-Φ (최약 에지 가지치기와 통합정보 보존)

## 1. Hypothesis

생물학적 **synaptic pruning(시냅스 가지치기)** 은 약한 연결을 솎아내면서도 회로의
기능적 통합은 유지한다고 알려져 있다 (Huttenlocher 1979; 발달기 과잉-시냅스 후
사용-의존적 제거). 의식 관점에서 자연스러운 가설은 — pruning 이 **가장 약한
연결(에지)을 선택적으로 제거** 해 통합도(Φ)를 비용-효율적으로 보존한다는 것이다.
즉 "약한 연결을 쳐내도 통합은 거의 안 깎인다 (selective pruning is Φ-efficient)"는
주장.

이는 H_312 와 **다른 축** 이다. H_312 = **APOPTOSIS = 노드(세포) 제거** 였고
🔴 FALSIFIED 였다. 본 H_315 = **PRUNING = 에지(연결) 제거, 모든 노드 유지** 다.
substrate 는 계속 n-세포계로 남고, 변하는 것은 *각 세포가 읽는 이웃 입력의 wiring*
이다. 시냅스 가지치기 ≠ 세포 죽음.

**가설 H1 (검정 대상 — 기각될 수 있음)**: IIT 4.0 substrate(ECA ring)에서
**가장 약한 에지(연결)를 선택적으로 가지치기** 하면, 무작위 에지 가지치기나 최강
에지 가지치기보다 **big-Φ 를 더 잘 보존** 한다 (Φ-retention 곡선이 더 높다).

**Falsifier (사전 등록)**: 패널 전반에서 약한-에지-우선 가지치기가 무작위-에지
가지치기보다 Φ 를 더 잘 보존하지 **못하면** — 즉 (a) weak 의 Φ-retention AUC 가
패널 평균에서 random 을 **넘지 못하거나**, (b) substrate 별 정면 대결(head-to-head)
에서 weak 이 **과반을 이기지 못하면** — **H1 은 FALSIFIED**.

H1 이 SUPPORTED 면 pruning = 통합-보존 메커니즘. H1 이 FALSIFIED 면 "약한 연결을
쳐내도 통합은 보존된다"는 직관은 IIT big-Φ 위에서 성립하지 않는 **closed-negative**
다 (a_paper_negative_ok: 닫힌 부정도 유효한 발견).

## 2. Why (동기)

- **H_312 후속 (axis pivot: node → edge)**: H_312 은 *노드 제거(apoptosis)* 의
  통합-선택 기능을 묻고 🔴 였다 — 어떤 세포든 빼면 부분계가 작아져 LOO 통합 기여가
  기계적으로 감소. 그러나 그것은 "노드를 줄이면 통합이 깎인다"는 자명한 구조에
  가까웠다. 본 H 는 다른 질문 — *노드를 다 유지한 채 연결만 솎으면* 통합이
  보존되는가, 그리고 *어떤 연결을 솎느냐(약↔강)* 가 통합 보존에 기능적 차이를
  내는가 — 를 직격한다. 이것은 node-cardinality 효과와 분리된 진짜 edge-level 검정.
- **생물학 (pruning = 효율적 정련)**: 발달기 뇌는 과잉 시냅스를 만든 뒤 약한 것을
  솎아 "비용은 줄이되 통합은 유지" 한다고 읽힌다. 이 읽기를 통합정보 차원으로 옮긴
  것이 H1. 약한 연결 = 낮은 영향력 = 솎아도 안전, 이라는 가정이 검정 대상.
- **IIT 4.0 정합 (sister IIT4 M6/M10)**: big-Φ 는 distinction(인과 구별)과
  relation(2차 관계)의 비-가산적 통합. 약한 에지가 단지 "약한 marginal" 이라고
  해서 그것이 만드는 distinction/relation 구조도 약하리라는 보장은 없다 — 이
  비-자명성이 검정의 핵심.
- **reductive-null 가치**: "약한 것을 솎아도 전체는 멀쩡" 은 공학·신경과학의 흔한
  직관(graceful degradation)이다. faithful big-Φ 로 검정해 *기각* 하면, 통합이
  연결-수준에서 어떻게 비선형적으로 무너지는지(cliff vs graceful)를 자기 substrate
  에서 드러낸다.

## 3. Method (방법 — 결정적 · hexa-only · llm:none · $0)

엔진은 **재발명하지 않는다** (memory: H_280 IIT4 재발명 오류). 기존 stdlib 재사용:

- `stdlib/consciousness/iit4_tpm.hexa` — `iit4_pow2`, `iit4_bit` 원시자.
- `stdlib/core/math/rng.hexa` — `lcg_next` (고정-seed Fisher-Yates 셔플; g61 준수,
  자체 LCG 재구현 금지).
- ECA rule 의미는 본 run.hexa 에서 **prunable TPM builder** 로 재유도 (M6 의
  `eca_tpm` 는 가지치기-불가 형태라, force-0 입력을 지원하는 변형이 필요).

**substrate & 에지 정의**:
ECA ring 의 세포 i 의 다음 상태는 3-세포 이웃 (L=i-1, C=i, R=i+1)에 대한 rule
lookup 으로 결정된다. **유향 에지 (j → i)** = 이웃 j 가 세포 i 의 출력에 실제로
영향을 주는 의존성. 세포당 최대 3개 입력 에지(L/C/R). **present(유효) 에지** =
그 이웃을 뒤집으면 세포 i 의 다음 값이 적어도 한 상태에서 바뀌는 에지 (영향력 ≠ 0).

**에지 가중치 (측정 가능한 영향력 — 하드코딩 금지)**:

> weight(pos → i) = (1/2ⁿ) · Σ_s [ nextbit(i|s) ≠ nextbit(i|s 의 pos 비트 뒤집음) ]

즉 전체 2ⁿ 상태에 걸친 입력 pos 의 평균 출력-민감도(activity / 영향력). weight 0 ⇒
에지 부재(canalised). 높을수록 강한 연결. 표준 Boolean-network edge-activity 척도.

**에지 가지치기 (TPM 재구성, 모든 노드 유지)**:
에지 (pos → i) 가지치기 = 세포 i 가 이웃 pos 를 더 이상 읽지 않음 — rule-lookup
인덱스에서 그 이웃 비트를 **고정 0** 으로 치환. 모든 n 세포 유지, i 의 입력 wiring
만 축소. K 에지 가지치기 = K 개 (pos,i) 입력을 0 으로 고정해 n-세포 TPM 재구성 후,
**전체 n-세포계** 의 faithful big-Φ 재계산.

**세 가지 가지치기 순서 (present 에지 위, 누적 분율 증가)**:
- `weak`   : 가중치 **오름차순** (가장 약한 에지 먼저)
- `strong` : 가중치 **내림차순** (가장 강한 에지 먼저)
- `random` : **고정-seed** 순열 (결정적 Fisher-Yates, seed = 777+rule+n)

각 가지치기 step 후 big-Φ(전체계) 재계산 → **retention = Φ_pruned / Φ_0**. AUC =
모든 가지치기 분율에 걸친 평균 retention (측정 Φ 의 결정적 함수). H1 ⇔ weak 곡선이
random 곡선을 지배.

**Panel**: ECA rule {90, 110, 30, 54, 150, 22, 60, 105} × n=4 (sys=11) +
{90, 110} × n=3 (sys=5). 총 10 substrate, n≤4 → 2ⁿ≤16 상태 → 정확 big-Φ 가능
(H_312 와 동일 패널). 고정 seed/state → cross-process byte-identical.

## 5. Finding (발견)

- **주장(H1 primary) 기각**: 가장 약한 에지를 선택적으로 가지치기해도 big-Φ 가
  무작위 에지 가지치기보다 더 잘 보존되지 **않는다**. weak 은 (a) 패널 평균
  Φ-retention AUC 에서 random 에게 **진다** (0.162 < 0.227), 그리고 (b) substrate
  별 정면 대결에서 **4/10 (과반 미달)** 만 이긴다. 사전 등록 falsifier 가 **두 절
  모두 충족** → **🔴 FALSIFIED**. eca90 퇴화 cell 을 빼도 결론 불변 (0.180 < 0.253).
- **기계적 이유**: big-Φ 는 distinction(인과 구별)과 relation(2차 관계)의 *비-가산*
  통합량이다. 에지의 평균 민감도(weight)가 낮다고 해서 그 에지가 만드는
  distinction/relation 구조까지 약한 것은 아니다 — 약한 에지도 통합 구조에 결정적
  partition-경계 기여를 할 수 있어, 그것을 솎는 것은 "Φ-저렴" 하지 않다. 오히려
  무작위 순서가 (평균적으로) 강한 에지 제거를 뒤로 미뤄 초반 retention 을 더 높게
  유지하는 경우가 빈번했다.
- **2차(약한) 주장은 별개**: weak 는 *strong (최강 에지 먼저 제거)* 보다는 낫다
  (패널 평균 0.162 > 0.129; 5/10). 즉 "가장 강한 연결부터 죽이는 것이 가장 나쁘다"는
  직관은 유지된다. 그러나 이는 H1 의 검정 대상(weak vs random)이 아니며 verdict 를
  구원하지 못한다 (weak 이 strong 보다 덜-나쁨 ≠ weak 이 random 보다 Φ-효율적).
- **2차 발견 (degradation 형태)**: Φ-vs-분율 곡선은 **graceful 가 아니라 cliff** 형.
  대부분 substrate 가 present 에지의 첫 ~5–7개(8–12개 중) 가지치기 안에 retention 0
  으로 붕괴하고, retention > 1.0 의 비-단조 bump 가 자주 나타난다 (partition 에
  유리한 에지를 솎으면 big-Φ 가 일시적으로 *상승*). 어떤 순서도 선형적 점진 퇴화를
  보이지 않음 — "약한 연결은 솎아도 안전" 직관과 정반대.
- **closed-negative 가치**: synaptic pruning 을 "통합-보존 효율화" 로 보는 읽기는
  faithful IIT 4.0 위에서 거짓. pruning 의 기능적 의미는(있다면) per-edge big-Φ
  효율이 아닌 다른 축(예: 에너지/metabolic 비용, 노이즈 제거 후 *재배선*, 또는
  동적 상태-평균)에 있어야 한다.

## 6. Verdict

**🔴 FALSIFIED** — 측정값에서 직접 유도. weak-에지 가지치기가 random-에지 가지치기보다
big-Φ 를 더 잘 보존하는 substrate 는 10개 중 4개뿐(과반 미달)이고, 패널 평균

## 7. Honest limitations (정직한 한계 · g5)

- **에지-가지치기 의미 선택**: "force-0 입력" 은 한 가지 정당한 에지-제거 모델(이웃을
  안 읽음 = 그 자리를 0 으로 본다). 다른 모델(이웃 자리를 자기-루프로 치환, 또는
  marginal 평균으로 대체)은 retention 곡선을 흔들 수 있으나, 핵심 결과(weak 4/10,
  패널 평균 weak < random)를 SUPPORTED 로 되돌릴 구조적 이유는 없다 — big-Φ 의
  비-가산성이 원인이지 force-0 관례가 아니다.
- **에지 가중치 정의**: 평균 출력-민감도(activity)는 측정 가능한 영향력 척도지만
  여러 정당한 edge-weight 정의 중 하나. distinction-기반 에지 중요도 같은 대안 척도는
  weak/strong 라벨을 재정렬할 수 있으나 random 이라는 baseline 자체를 바꾸지 않는다.
- **단일 sys_state**: 각 rule 당 고정 sys_state 1개 (H_312 와 동일 관례). 상태-평균
  sweep 은 후속 H 후보지만, 본 closed-negative 의 방향(약한 에지 솎기가 Φ-저렴하지
  않다)은 big-Φ 비-가산성의 구조적 사실에 가깝다.
- **random 단일 seed**: random 순서는 substrate 당 고정-seed 1개 순열. 다수-seed
  ensemble 평균은 별도 확장 후보지만, weak 이 단일-seed random 의 *과반* 에게도 지는
  현 결과는 ensemble 로 뒤집힐 가능성이 낮다 (오히려 다수 seed 평균이 weak 의
  열세를 안정화).
- **n≤4 정확-Φ 범위**: 더 큰 n 은 IIT4 M9 tractability 한계(bounded approx)로
  넘어가며 본 정확-계산 결론과 분리.
- **eca90 퇴화 cell**: rule 90 은 sys=11 에서 big-Φ=0 (pure-XOR 가역, H_312 와 동일)
  이라 신호가 없다. 집계에 포함/제외 모두 결론 불변임을 명시.
